# Podcast Creator Database — files (podcast-creator-signature)

- `demo-podcast-creator-signature.py` — runnable demo program (run with `python3 demo-podcast-creator-signature.py`).
- `podcast-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/podcast-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-podcast-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
