# Academic Paper Search Database — files (academic-paper-search)

- `demo-academic-paper-search.py` — runnable demo program (run with `python3 demo-academic-paper-search.py`).
- `academic-paper-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/academic-paper-search/index.jsonl.gz` (24 records).
- The generator is `gen-academic-paper-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
