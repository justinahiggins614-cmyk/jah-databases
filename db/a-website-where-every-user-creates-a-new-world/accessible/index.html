The A Website Where Every User Creates a New World Database

Accessible version: plain text, no scripts, no sign-in, free forever. A website where every user creates a new world gives each visitor a blank map and plain tools: name your world, draw its seas, place its towns, and write its story, then share it for others to visit. Every world is a clearly labeled design study of an invented place, and the site never claims an invented world is a real place.

Twenty-four full records, ordered simple to compounded to complex.

  1. A World of Seas and Small Islands

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    A website where every user creates a new world gives each visitor a blank map and plain tools: name your world, draw its seas, place its towns, and write its story, then share it for others to visit. Every world is a clearly labeled design study of an invented place, and the site never claims an invented world is a real place. A World of Seas and Small Islands is one new world in this database, and it needs a plain design a visitor can read in one sitting, with every step written out and every rule stated, so the idea can be judged on its own words before anything is built. This record asks for a design that a visitor can try in one sitting, with the steps written out, the cost named plainly, and the rules stated so everyone gets the same fair start. Without those plain words, the idea can only be guessed at, and a guessed-at idea helps nobody, because a visitor who cannot see the steps cannot follow them. The record therefore writes the whole idea out, so a stranger to the idea can read it once and know what it does. Worked example: in a website built this way, a world of seas and small islands runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

    History: Drawing a map of a made-up land is an old habit: a map on a table, a tale of a distant shore, a world that exists only in words. The website form grows out of that habit, adding a blank map, plain tools, and a shared shelf of worlds. A World of Seas and Small Islands grows out of an older habit: drawing a map of a made-up land, a map on a table, a tale of a distant shore, and the website form adds a plain list, a search, and a written record for it.

    Proposed solution: Name the new world and what a visitor does in it; Write the rules in plain sentences a new visitor can follow; Give every new world the same fair start: the same clues, the same time, the same scoring; Let a visitor try one new world without signing in; Check the new world works the same way on a phone and on a computer.

    Dependencies: What must exist first: a blank map for each visitor, plain tools to draw seas and place towns, a way to write each world's story, and a review step before publishing. Nothing else is needed to open the first new world.

    Verification path: A visitor opens one new world, follows the rules in plain sentences, and finishes it without help. The demo program prints the same total as the math proof, and a second visitor repeating the steps gets the same result.
