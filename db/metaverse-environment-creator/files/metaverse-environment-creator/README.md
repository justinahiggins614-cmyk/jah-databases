# Metaverse Environment Creator Database — files (metaverse-environment-creator)

- `demo-metaverse-environment-creator.py` — runnable demo program (run with `python3 demo-metaverse-environment-creator.py`).
- `metaverse-environment-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/metaverse-environment-creator/index.jsonl.gz` (24 records).
- The generator is `gen-metaverse-environment-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
