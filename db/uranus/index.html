About this data base

Archive
Record kinds: Overview, Physical Data, Geology & Landforms, Atmosphere, Exploration, Future & Speculative. Factual records carry verified data (NASA/JPL); speculative records are clearly labeled Signature-authored projections. Every record is the full file, never a stub.
Record schema
id (JAH-URA-) · title · description · kind · body · body_type · parent_body · demo (runnable program) · src (fact / signature) · _seed
Known vs speculative
Records with ✓ fact carry verified planetary data. Records with ✳ Signature-authored are clearly labeled projections — never presented as established fact.
Demos
Every record carries a runnable program — orbital math, light-travel time, escape velocity, transfer estimators. Paste into any console.
Generator
jahdb-uranus-1.0 — deterministic: same seed always makes the same record. Every record validated by an independent checker before acceptance.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent checker.
Target
1,000,000 records. The archive marches toward the million mark with overload protection: 100-record chunks, lazy loading, and a collapsible per-kind archive so no device ever renders everything at once.
AI
JAH Uranus Archivist — archive-aware, a uranus specialist, and aware of the whole JAH Databases network through cross-database reasoning. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
Signature system
✳ Property of Justin Addam Higgins (JAH). Factual records are Signature-governed public data; speculative records are Signature-authored originals.
