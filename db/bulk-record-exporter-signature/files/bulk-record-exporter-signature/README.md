# Bulk Record Exporter Database — files (bulk-record-exporter-signature)

- `demo-bulk-record-exporter-signature.py` — runnable demo program (run with `python3 demo-bulk-record-exporter-signature.py`).
- `bulk-record-exporter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/bulk-record-exporter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-bulk-record-exporter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
