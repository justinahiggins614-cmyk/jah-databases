1. Description

A code interpreter reads code and runs it at once, line by line: type an expression, and it prints the answer. It runs only safe code in this browser: numbers, variables, loops and functions, with no files and no network. No sign-in, no data leaving the page.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Interpreting is arithmetic in order: 2 + 3 * 4 is 14, not 20, because multiplication comes before addition, while (2 + 3) * 4 is 20. With x = 5 and y = 3, x + y is 8. A loop that adds 1 three times turns 0 into 3. The total of [1, 2, 3, 4] is 10, and the first item of [10, 20, 30] is 10.

3. Science proof

An interpreter works because code is text with rules: it reads a line, works out its value, and prints it, then moves to the next line. Variables hold values under names, so x = 5 makes x hold 5 wherever it appears. A loop repeats lines, and a function is named lines that can run again. That is why the interpreter shows each line as it runs: the steps are the program.

6. Use
