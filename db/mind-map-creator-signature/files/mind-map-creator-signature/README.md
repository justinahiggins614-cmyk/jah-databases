# Mind Map Creator Database — files (mind-map-creator-signature)

- `demo-mind-map-creator-signature.py` — runnable demo program (run with `python3 demo-mind-map-creator-signature.py`).
- `mind-map-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/mind-map-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-mind-map-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
