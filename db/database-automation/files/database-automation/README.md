# Database Automation Database — files (database-automation)

- `demo-database-automation.py` — runnable demo program (run with `python3 demo-database-automation.py`).
- `database-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-automation/index.jsonl.gz` (24 records).
- The generator is `gen-database-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
