Universal Generator Builder: Failure Modes and Recovery

JAH-UGB-000021 — universal generator builder record

The Universal Generator Builder fails safely: this record names the ways it can fail — a missing file, a refused input, an unreachable source, a test that does not pass — and what the program does in each case. A failure never loses data, never writes a half-result, and never pretends to have succeeded. Each failure mode carries its recovery: what the user does, what the program does on its own, and how to tell the failure is fixed. In this public edition the program offers 8 capabilities (creating a seeded generator from a kind and a seed (1); repeatable output: the same seed gives the same output (2); a hard stop at 1,000,000,000 outputs per file (3); a test suite for every generator it builds (4); registering each new generator in the Generator Registry (5); generators for records, files, and websites (6); an API other programs use to build generators (7); a plain-text build report (8)), 6 interfaces (Generator form — kind and seed, in plain words; Kind picker — what the generator will make; Sample output — the first outputs, shown before saving; Build report — generator built, tests run, registry entry written; Builder API — machine-readable generator building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (kind — what the generator makes; seed — its starting number; code — the generator's working code; hard_stop — its output ceiling, 1,000,000,000; samples — the first outputs it produced; tests — the test result for the new generator; registry — its entry in the Generator Registry; throttle — its per-call output limit). This record is number 21 of 24 in the public edition of the Universal Generator Builder database pair, and it specifies the failure modes and recovery topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
