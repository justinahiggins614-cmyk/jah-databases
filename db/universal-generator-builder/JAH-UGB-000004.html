Universal Generator Builder: Main Screen: the Human Interface

JAH-UGB-000004 — universal generator builder record

The main screen is the human face of the Universal Generator Builder: one page that shows the program's name, its purpose in plain words, and its main action, with every button doing what it says. A first-time user must be able to complete the program's main job from this screen without reading documentation first. This record specifies the screen's parts, the order they appear in, and what each control does when used — including what happens when the user makes a mistake. In this public edition the program offers 8 capabilities (creating a seeded generator from a kind and a seed (1); repeatable output: the same seed gives the same output (2); a hard stop at 1,000,000,000 outputs per file (3); a test suite for every generator it builds (4); registering each new generator in the Generator Registry (5); generators for records, files, and websites (6); an API other programs use to build generators (7); a plain-text build report (8)), 6 interfaces (Generator form — kind and seed, in plain words; Kind picker — what the generator will make; Sample output — the first outputs, shown before saving; Build report — generator built, tests run, registry entry written; Builder API — machine-readable generator building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (kind — what the generator makes; seed — its starting number; code — the generator's working code; hard_stop — its output ceiling, 1,000,000,000; samples — the first outputs it produced; tests — the test result for the new generator; registry — its entry in the Generator Registry; throttle — its per-call output limit).
