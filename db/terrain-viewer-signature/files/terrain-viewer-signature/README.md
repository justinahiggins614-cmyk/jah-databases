# Terrain Viewer Database — files (terrain-viewer-signature)

- `demo-terrain-viewer-signature.py` — runnable demo program (run with `python3 demo-terrain-viewer-signature.py`).
- `terrain-viewer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/terrain-viewer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-terrain-viewer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
