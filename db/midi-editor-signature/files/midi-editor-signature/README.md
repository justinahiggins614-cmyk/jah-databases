# Midi Editor Database — files (midi-editor-signature)

- `demo-midi-editor-signature.py` — runnable demo program (run with `python3 demo-midi-editor-signature.py`).
- `midi-editor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/midi-editor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-midi-editor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
