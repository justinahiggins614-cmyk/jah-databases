# Structured Data Generator Database — files (structured-data-generator)

- `demo-structured-data-generator.py` — runnable demo program (run with `python3 demo-structured-data-generator.py`).
- `structured-data-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/structured-data-generator/index.jsonl.gz` (24 records).
- The generator is `gen-structured-data-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
