The Kief Sifter Box — Signature edition — is a Signature-made design study of the same supply, drawn up as a new product rather than a report on an existing one. This design keeps the same job, kief sifter box with mesh screen, but reworks the parts as a single matched set: a wooden box with a removable mesh screen frame, a collection tray below the screen, a glass collection plate, a soft brush, and a pollen press. The Signature design specifies beechwood box, stainless steel mesh, food-grade nylon mesh option, borosilicate glass plate throughout, with each part sized to the others so that no tool in the case is a loose fit for its task. The design dimensions are box 200 mm by 150 mm by 90 mm; screen area 180 mm by 130 mm; standard screen 120 microns; collection tray 20 mm deep. In the Signature design, dried plant material is agitated above a woven mesh screen, and particles smaller than the mesh opening fall through into the tray below while larger plant matter stays on top. Place a small amount of dry material on the screen, close the lid, shake gently for two to three minutes, rest, tap the frame, then brush the collected kief from the tray onto the glass plate. Maintenance of the design follows the same rules as the public version. Brush the mesh clean after every use, wash the tray with warm soapy water, let the screen dry fully before storage, and replace a torn or stretched screen, since a sagging mesh passes plant matter it should hold back. Planned variants of the Signature design are the single-screen shaker box at 120 microns; three-screen stack at 160, 120 and 75 microns; tumbler drum with interchangeable 100, 150 and 200 micron screens. This is a design study, not a real product and not an established fact: no Signature edition unit has been manufactured, tested, or sold, and the dimensions and figures in this record are design targets, not measured results. import hashlib, json, math, random

SCREEN_LENGTH_MM = 180
SCREEN_WIDTH_MM = 130
MESH_MICRONS = 120
OPEN_FRACTION = 0.30
INPUT_GRAMS = 28
YIELD_PERCENT = 12

def compute(seed):
    rng = random.Random(seed)
    screen_area = SCREEN_LENGTH_MM * SCREEN_WIDTH_MM
    open_area = round(screen_area * OPEN_FRACTION, 1)
    aperture_m2 = (MESH_MICRONS / 1000000.0) ** 2
    holes = int(open_area / 100.0 / (aperture_m2 * 1000000.0 / 100.0 * 100.0)) if False else int(open_area / ((MESH_MICRONS / 1000.0) ** 2))
    kief_g = round(INPUT_GRAMS * YIELD_PERCENT / 100.0, 2)
    trials = 1000
    passed = 0
    for _ in range(trials):
        size = rng.uniform(40.0, 200.0)
        if size < MESH_MICRONS:
            passed += 1
    pass_rate = round(100.0 * passed / trials, 1)
    out = {
        "screen_area_mm2": screen_area,
        "open_area_mm2": open_area,
        "mesh_aperture_microns": MESH_MICRONS,
        "mesh_holes_approx": holes,
        "input_grams": INPUT_GRAMS,
        "expected_kief_grams": kief_g,
        "simulated_particles": trials,
        "simulated_pass_rate_percent": pass_rate,
    }
    return out

def main():
    first = compute(7)
    second = compute(7)
    for key, value in first.items():
        print(f"{key}: {value}")
    d1 = hashlib.sha256(json.dumps(first, sort_keys=True).encode()).hexdigest()

main()
