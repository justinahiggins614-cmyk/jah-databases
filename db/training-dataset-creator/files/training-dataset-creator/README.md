# Training Dataset Creator Database — files (training-dataset-creator)

- `demo-training-dataset-creator.py` — runnable demo program (run with `python3 demo-training-dataset-creator.py`).
- `training-dataset-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/training-dataset-creator/index.jsonl.gz` (24 records).
- The generator is `gen-training-dataset-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
