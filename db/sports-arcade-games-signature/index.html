Harbor Hoops Showdown Rank 1 · simple · sports arcade · beginner

Harbor Hoops Showdown is an original sports arcade game. a dockside streetball game where two-on-two crews play on a floating court, and every third straight basket sets the shooter on fire for bonus points.

The rules are built around one timing skill: a shooting challenge: aimed shots at a hoop that shifts along the baseline. Each turn the mark moves in a fixed pattern, the player aims a number from zero to nine and shoots, and only an exact meeting of aim and mark scores. Every scored shot is worth two points.

Learn the pattern before you trust your aim. Two quiet turns of watching will tell you the step, and from there the game becomes a rhythm: aim, shoot, step, repeat, without rushing the release.

Original game note: This is an original arcade-style game created for this Signature edition, with its own title, rules, and play.

How to play

Type aim N (0-9) then shoot each turn, quit to stop.

Working demo program

Save the code below as game.py and run python3 game.py --play to play it. Running it without arguments replays the scripted session whose output is stored with the record.

import sys
PARAMS = {'shots': 13}
AUTO = [2, 5, 0, 6, 4, 7, 0, 3, 6, 9, 2, 5, 8]

def hoop_pos(shot):
    return (shot * 3 + 2) % 10

def auto_play():
    baskets = 0
    print("Sports tribute: auto session")
    for i, aim in enumerate(AUTO):
        pos = hoop_pos(i)
        hit = (aim == pos)
        if hit:
            baskets += 1
        print("Shot %d: aim %d hoop was %d %s baskets %d" % (i + 1, aim, pos, "BASKET" if hit else "MISS", baskets))
    print("FINAL SCORE: %d" % (baskets * 2))
    print("RESULT: BASKETS %d/%d" % (baskets, len(AUTO)))

def play():
    baskets, shot = 0, 0
    aim = 5
    print("Sports tribute: type 'aim N' (0-9) then 'shoot' each turn, or quit. The hoop moves in a pattern; learn it.")
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        parts = cmd.split()
        if len(parts) == 2 and parts[0] == "aim":
            try:
                aim = int(parts[1]) % 10
            except ValueError:
                print("Use: aim N")
            continue
        if cmd == "shoot":
            pos = hoop_pos(shot)
            hit = (aim == pos)
            if hit:
                baskets += 1
            print("Shot %d: aim %d hoop was %d %s baskets %d" % (shot + 1, aim, pos, "BASKET" if hit else "MISS", baskets))
            shot += 1
            if shot >= PARAMS["shots"]:
                break
            continue
        print("Use: aim N, then shoot")
    print("FINAL SCORE: %d" % (baskets * 2))
    print("RESULT: BASKETS %d/%d" % (baskets, PARAMS["shots"]))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()
