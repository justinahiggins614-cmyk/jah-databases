# Vehicle Specification Database Database — files (vehicle-specification-database-signature)

- `demo-vehicle-specification-database-signature.py` — runnable demo program (run with `python3 demo-vehicle-specification-database-signature.py`).
- `vehicle-specification-database-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/vehicle-specification-database-signature/index.jsonl.gz` (24 records).
- The generator is `gen-vehicle-specification-database-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
