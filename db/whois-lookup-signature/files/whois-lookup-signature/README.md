# Whois Lookup Database — files (whois-lookup-signature)

- `demo-whois-lookup-signature.py` — runnable demo program (run with `python3 demo-whois-lookup-signature.py`).
- `whois-lookup-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/whois-lookup-signature/index.jsonl.gz` (24 records).
- The generator is `gen-whois-lookup-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
