# Universal Time Calculator Database — files (universal-time-calculator)

- `demo-universal-time-calculator.py` — runnable demo program (run with `python3 demo-universal-time-calculator.py`).
- `universal-time-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/universal-time-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-universal-time-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
