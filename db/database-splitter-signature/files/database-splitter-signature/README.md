# Database Splitter Database — files (database-splitter-signature)

- `demo-database-splitter-signature.py` — runnable demo program (run with `python3 demo-database-splitter-signature.py`).
- `database-splitter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-splitter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-database-splitter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
