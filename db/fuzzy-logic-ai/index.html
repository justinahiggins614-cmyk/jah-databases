Fuzzy logic is logic that admits degrees of truth: instead of a statement being simply true or false, it can be true to a degree, like 0.7 true. It was built for the vague words people actually use, like hot, tall, fast, and soon, which have no sharp boundary. A temperature of 25 degrees can be warm to degree 0.8 and hot to degree 0.2 at the same time, and fuzzy logic reasons with those grades instead of forcing a choice between them.

Fuzzy Sets and Membership JAH-FLAI-000003 · simple

Evidence: established The claims in this record are documented in the cited sources; numbers in the ledger are a model, labeled as such.

A fuzzy set is a set with a soft edge: every element carries a membership grade, a number between 0 and 1, saying how much it belongs. A grade of 1 means fully in, 0 means fully out, and anything between means partly in. The set of tall people has no sharp cutoff: a person 190 centimeters tall might belong to degree 1, a person 175 centimeters to degree 0.6, and a person 160 centimeters to degree 0.1, and the grades are the set.

The early work was theoretical: operations, relations, and numbers, all rebuilt with grades. The applied work followed in the 1980s, when engineers found that membership grades were a natural way to write control rules in words. The set with a soft edge is now a standard tool.

Type-2 Fuzzy Sets JAH-FLAI-000013 · complex

A type-2 fuzzy set is a fuzzy set whose grades are themselves fuzzy: instead of one grade for each element, there is a range of grades, because the membership function itself is uncertain. The set is described by a footprint of uncertainty, the region between an upper and a lower membership function, and the grade at each point is a fuzzy set of its own. Type-2 sets model the case where even the expert is unsure where the boundary sits.

Skeptical analysis

Forecasts of a steady field are easy to make and easy to be wrong about: a single new method, a hardware shift, or a funding wave can change the pace. The honest forecast is a range, not a date, and this record keeps its scenarios as scenarios, scored and labeled, not as promises.
