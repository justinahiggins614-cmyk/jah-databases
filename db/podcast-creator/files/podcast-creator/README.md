# Podcast Creator Database — files (podcast-creator)

- `demo-podcast-creator.py` — runnable demo program (run with `python3 demo-podcast-creator.py`).
- `podcast-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/podcast-creator/index.jsonl.gz` (24 records).
- The generator is `gen-podcast-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
