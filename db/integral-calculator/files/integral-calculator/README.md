# Integral Calculator Database — files (integral-calculator)

- `demo-integral-calculator.py` — runnable demo program (run with `python3 demo-integral-calculator.py`).
- `integral-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/integral-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-integral-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
