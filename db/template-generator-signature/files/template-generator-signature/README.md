# Template Generator Database — files (template-generator-signature)

- `demo-template-generator-signature.py` — runnable demo program (run with `python3 demo-template-generator-signature.py`).
- `template-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/template-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-template-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
