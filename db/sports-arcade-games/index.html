Track & Field Rank 1 · simple · sports arcade · beginner

Track & Field, released in 1983, is an Olympic-style button-mashing game in which players race sprints, long jump, and throw the javelin by hammering buttons to build speed and timing the action button at the right moment.

The tribute demo frames the game as its shooting and timing challenge, and says so plainly: a sprint-timing challenge: the demo frames the race as a series of timed shots where the moving target must be met exactly. Each turn the target mark moves in a fixed pattern, and the player aims a number from zero to nine and shoots; a basket scores only when the aim meets the mark exactly. The demo is an original program inspired by the mechanics, not the arcade game itself.

The pattern is the puzzle. Watch two or three turns before committing, learn the step the mark takes each turn, and then aim ahead of it rather than chasing it. A steady run of met marks beats a lucky streak every time.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Track & Field (1983). It is not Track & Field (1983), and it uses no art, music, or code from that game.

How to play

Type aim N (0-9) then shoot each turn, quit to stop.

Working demo program

Save the code below as game.py and run python3 game.py --play to play it. Running it without arguments replays the scripted session whose output is stored with the record.

import sys
PARAMS = {'shots': 10}
AUTO = [2, 5, 8, 1, 4, 7, 0, 8, 8, 9]

def hoop_pos(shot):
    return (shot * 3 + 2) % 10

def auto_play():
    baskets = 0
    print("Sports tribute: auto session")
    for i, aim in enumerate(AUTO):
        pos = hoop_pos(i)
        hit = (aim == pos)
        if hit:
            baskets += 1
        print("Shot %d: aim %d hoop was %d %s baskets %d" % (i + 1, aim, pos, "BASKET" if hit else "MISS", baskets))
    print("FINAL SCORE: %d" % (baskets * 2))
    print("RESULT: BASKETS %d/%d" % (baskets, len(AUTO)))

def play():
    baskets, shot = 0, 0
    aim = 5
    print("Sports tribute: type 'aim N' (0-9) then 'shoot' each turn, or quit. The hoop moves in a pattern; learn it.")
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        parts = cmd.split()
        if len(parts) == 2 and parts[0] == "aim":
            try:
                aim = int(parts[1]) % 10
            except ValueError:
                print("Use: aim N")
            continue
        if cmd == "shoot":
            pos = hoop_pos(shot)
            hit = (aim == pos)
            if hit:
                baskets += 1
            print("Shot %d: aim %d hoop was %d %s baskets %d" % (shot + 1, aim, pos, "BASKET" if hit else "MISS", baskets))
            shot += 1
            if shot >= PARAMS["shots"]:
                break
            continue
        print("Use: aim N, then shoot")
    print("FINAL SCORE: %d" % (baskets * 2))
    print("RESULT: BASKETS %d/%d" % (baskets, PARAMS["shots"]))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()
