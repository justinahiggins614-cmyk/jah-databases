# PCB Designer Database — files (pcb-designer)

- `demo-pcb-designer.py` — runnable demo program (run with `python3 demo-pcb-designer.py`).
- `pcb-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/pcb-designer/index.jsonl.gz` (24 records).
- The generator is `gen-pcb-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
