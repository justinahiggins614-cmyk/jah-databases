Mastercard — Overview and history
Public edition. Public records, fact-checked reference. Mastercard Incorporated is an American multinational financial services company headquartered in Purchase, New York, operating a global payments network second in scale to Visa. Like Visa, Mastercard does not issue cards; it provides the network linking merchants, issuers, and cardholders, and has expanded into data analytics, cybersecurity, and real-time payments.
