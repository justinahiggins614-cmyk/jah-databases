Section 2: Math proof

Worked arithmetic: 137 / 1257 = 0.10899; 255 / 1257 = 0.20286; 765 / 1257 = 0.60859; 494.5 / 1257 = 0.39340. The demo of every record prints the same total as its math proof, so a fresh run of any demo verifies its proof exactly.

Section 3: Science proof

S = pixel / 1257. In plain words, this equation turns a pixel coordinate into a share of the whole signature width: with 137 over 1257, the arithmetic gives 0.10899 S, and every record's demo prints that same kind of value, so the claim can be checked by arithmetic alone.
