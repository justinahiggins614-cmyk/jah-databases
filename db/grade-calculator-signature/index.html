A Grade From Weighted Scores Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A grade calculator website: the visitor enters a score and a weight for each piece of work, and the page works out a weighted average and a letter grade from a plain table, showing the scores, the weights, and the table it used. Every figure is labeled an estimate, never an official grade, and the site keeps no learner records and asks for no personal data. This record covers A Grade From Weighted Scores.

A grade from weighted scores is fair only when the weights are shown: a test worth half the course must count for half the grade, and homework worth a tenth must count for a tenth. Without weights, a learner who aces the homework and fails the final test can end up with the same grade as a learner who did the opposite, and neither grade means what it says. The calculator fixes this by multiplying each score by its weight, adding the results, and showing the working, so any learner can check the grade by hand.
