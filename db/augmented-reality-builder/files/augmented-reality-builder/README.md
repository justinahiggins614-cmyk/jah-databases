# Augmented Reality Builder Database — files (augmented-reality-builder)

- `demo-augmented-reality-builder.py` — runnable demo program (run with `python3 demo-augmented-reality-builder.py`).
- `augmented-reality-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/augmented-reality-builder/index.jsonl.gz` (24 records).
- The generator is `gen-augmented-reality-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
