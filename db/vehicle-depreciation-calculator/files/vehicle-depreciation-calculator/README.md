# Vehicle Depreciation Calculator Database — files (vehicle-depreciation-calculator)

- `demo-vehicle-depreciation-calculator.py` — runnable demo program (run with `python3 demo-vehicle-depreciation-calculator.py`).
- `vehicle-depreciation-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/vehicle-depreciation-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-vehicle-depreciation-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
