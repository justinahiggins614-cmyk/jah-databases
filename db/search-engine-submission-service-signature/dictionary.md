# Dictionary entries — The Search Engine Submission Service Database

Key terms of this database, defined in plain words.

## submission

Telling a search engine about a page, by sending its address, so the engine knows the page exists and can visit it.

## sitemap

A machine-readable list of a site's pages, with each page's address and the date it last changed.

## crawler

A program that visits pages one link at a time, reading each one so a search engine can index it.

## index

The search engine's own list of pages it has read, kept so that a question can be answered from the list instead of the whole web.

## robots file

A small file at a site's root that tells crawlers which parts of the site they may visit and which they must leave alone.

## canonical address

The one chosen address for a page that can be reached by several addresses, so the page is counted once, not many times.

## discovery

The moment a search engine first learns that a page exists, by a submission, a sitemap, or a link from a page it already knows.

## acceptance

The engine's answer that a submitted page was received and will be considered, which is not a promise that it will be listed.

## change date

The date a page last changed, written in the sitemap, so the crawler knows whether a fresh visit is worthwhile.

## queue

The ordered list of submitted pages waiting for a visit, worked through in order, with the oldest waiting longest.

## coverage

The share of submitted pages that ended up in the index, counted so that missing pages are known, not guessed.

## ledger

The service's own written record of every submission, every visit, and every acceptance, kept in order.
