Full Spec — Universe in a Chip Database

The complete specification of this database: what it holds, how it is built, how its AI works, and where its files live.

Purpose
The Universe in a Chip Database is a master index architecture for physical knowledge: cosmological parameters, particles, stars, galaxies, and planets — each entry compressed to its essential numbers and relations, honestly labeled as an index architecture rather than a literal claim of containing everything. A teaching ladder from the Hubble constant to exoplanet catalogs. Marching to a million records.
Record schema
id, title, ladder_rank (1-15), category, description, fields, demo{language, program, run_steps, expected_output}, march, provenance, licensing, source_edition, last_verified.
Demos
Every record ships a runnable JavaScript demo program, executed at build time; expected_output captured from the real run.
Generator
Boundless generator with self-regulation: hard stop at 1,000,000,000,000 records, max 50 generations/minute, every record validated and drift-checked, all output labeled simulated. Version jahdb-universe-in-a-chip-database-1.0.
AI
Universe in a Chip AI — archive-aware; fresh session per user; can also build a personal assistant like Manon’s via the assistant maker.
Simulator
No simulator; demos run in the Demo Lab and as-is on any PC with node.
Provenance policy
Public records: fact-checked public knowledge. Signature records: his originals, clearly labeled, never presented as public record. Generated records: labeled simulated for weeding.
Files
