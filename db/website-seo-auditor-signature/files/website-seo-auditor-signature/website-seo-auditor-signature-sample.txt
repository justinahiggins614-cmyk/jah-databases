Website SEO Auditor Database (website-seo-auditor-signature)

A website SEO auditor is a rule-based local demo: it reads set toy pages, and counts the marks. The auditor reads 3 pages. The page home holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
