# Ratio Calculator Database — files (ratio-calculator)

- `demo-ratio-calculator.py` — runnable demo program (run with `python3 demo-ratio-calculator.py`).
- `ratio-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/ratio-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-ratio-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
