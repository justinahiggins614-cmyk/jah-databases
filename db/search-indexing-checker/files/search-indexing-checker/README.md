# Search Indexing Checker Database — files (search-indexing-checker)

- `demo-search-indexing-checker.py` — runnable demo program (run with `python3 demo-search-indexing-checker.py`).
- `search-indexing-checker-sample.txt` — a plain-text sample of the database.
- The full database is `data/search-indexing-checker/index.jsonl.gz` (24 records).
- The generator is `gen-search-indexing-checker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
