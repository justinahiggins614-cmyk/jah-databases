History
A static site is a set of finished pages, written once and served as they are, with no program running behind them. Deployment is the act of carrying those finished pages from the maker's desk to the public place where readers find them, checking every file on the way. The practice grew from copying files by hand to tested, repeatable releases, and this database is built on the public standards behind it. Deploying many pages at once means carrying a whole release together, in one atomic step, instead of page by page.
