# Sales Tracker Database — files (sales-tracker)

- `demo-sales-tracker.py` — runnable demo program (run with `python3 demo-sales-tracker.py`).
- `sales-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/sales-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-sales-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
