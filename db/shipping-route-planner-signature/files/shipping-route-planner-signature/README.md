# Shipping Route Planner Database — files (shipping-route-planner-signature)

- `demo-shipping-route-planner-signature.py` — runnable demo program (run with `python3 demo-shipping-route-planner-signature.py`).
- `shipping-route-planner-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/shipping-route-planner-signature/index.jsonl.gz` (24 records).
- The generator is `gen-shipping-route-planner-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
