# Vector Graphics Editor Database — files (vector-graphics-editor)

- `demo-vector-graphics-editor.py` — runnable demo program (run with `python3 demo-vector-graphics-editor.py`).
- `vector-graphics-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/vector-graphics-editor/index.jsonl.gz` (24 records).
- The generator is `gen-vector-graphics-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
