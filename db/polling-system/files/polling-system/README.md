# Polling System Database — files (polling-system)

- `demo-polling-system.py` — runnable demo program (run with `python3 demo-polling-system.py`).
- `polling-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/polling-system/index.jsonl.gz` (24 records).
- The generator is `gen-polling-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
