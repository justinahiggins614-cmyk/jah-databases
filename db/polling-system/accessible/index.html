The Polling System Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. A polling system asks a question, offers choices, and counts the votes. The demo on this page is a LOCAL DEMO ONLY: the votes live only in this page, 0 real votes are cast, and real voting is BLOCKED. A real polling system needs a server, and this page honestly says so. Nothing is sent anywhere.

    Science proof: A polling system works because a poll is a question with choices, and each vote adds one to a choice: 5 + 3 + 2 is 10 votes in all, and 5 of 10 is 50 percent.
