This record covers A First Lesson in Measuring Wood.

A first lesson in measuring wood must teach the rule every trade worker learns first: measure twice, cut once. The portal must teach a beginner to hold a tape straight, read the marks plainly, write the number down, and check it again before any cut is made, with safety rules written first. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Every lesson is generic and written for this portal, never copied from a real course, and no lesson names a real school, a real employer, or a real certificate. This record covers A Daily Trade Lesson Everyone Shares.

A daily trade lesson gives every learner the same lesson on the same day, so learners in many workshops can compare notes and talk about the same steps. The portal must publish one lesson each morning, keep it the same for everyone, and show the day's progress plainly. Without a shared day, every learner faces a different lesson, and there is nothing to talk about. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Daily lessons grew out of evening classes, where one lesson a day gave a whole town the same thing to practice.
