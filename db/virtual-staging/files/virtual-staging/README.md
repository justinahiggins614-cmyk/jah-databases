# Virtual Staging Database — files (virtual-staging)

- `demo-virtual-staging.py` — runnable demo program (run with `python3 demo-virtual-staging.py`).
- `virtual-staging-sample.txt` — a plain-text sample of the database.
- The full database is `data/virtual-staging/index.jsonl.gz` (24 records).
- The generator is `gen-virtual-staging.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
