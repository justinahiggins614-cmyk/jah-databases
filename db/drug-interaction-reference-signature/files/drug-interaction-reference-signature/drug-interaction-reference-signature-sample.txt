Drug Interaction Reference Database (drug-interaction-reference-signature)

A drug interaction reference is a rule-based local demo: it lists set toy pairs, and counts the marks. Reference only: general information, no specific dosing, no cure claims, no diagnosis claims. The reference reads 3 pairs. The pair alpha holds 24 marks. The largest holds 24 marks. Everything runs in this browser; no data leaves the page.
