# Drug Interaction Reference Database — files (drug-interaction-reference-signature)

- `demo-drug-interaction-reference-signature.py` — runnable demo program (run with `python3 demo-drug-interaction-reference-signature.py`).
- `drug-interaction-reference-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/drug-interaction-reference-signature/index.jsonl.gz` (24 records).
- The generator is `gen-drug-interaction-reference-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
