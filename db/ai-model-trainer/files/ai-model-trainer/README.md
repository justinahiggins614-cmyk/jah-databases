# AI Model Trainer Database — files (ai-model-trainer)

- `demo-ai-model-trainer.py` — runnable demo program (run with `python3 demo-ai-model-trainer.py`).
- `ai-model-trainer-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-model-trainer/index.jsonl.gz` (24 records).
- The generator is `gen-ai-model-trainer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
