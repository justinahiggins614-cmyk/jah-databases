Neon Range Patrol Rank 1 · simple · gallery shooter · beginner

Neon Range Patrol is an original gallery shooter. a harbor patrol shooter in which officers defend a neon-lit dock district from waves of drone smugglers slipping between cranes and containers.

The rules are simple to learn and hard to master: targets appear one round at a time on a ten-by-ten grid, and a shot scores when it lands on or beside the target square. Drone targets weaving between dock cranes and stacked containers. High-value targets are worth chasing, but a wild shot earns nothing.

The best strategy is patience under pressure. Let the target pattern settle for a beat, aim at the cluster rather than the single square, and keep a steady rhythm so the late rounds do not slip away on rushed shots.

Original game note: This is an original arcade-style game created for this Signature edition, with its own title, rules, and play.

How to play

Type shoot X Y for each round (grid 0-9), quit to stop.

Working demo program

Save the code below as game.py and run python3 game.py --play to play it. Running it without arguments replays the scripted session whose output is stored with the record.

import sys
PARAMS = {'targets': [[9, 5, 20], [0, 7, 20], [8, 6, 50], [9, 2, 20], [1, 6, 20], [5, 9, 20], [3, 1, 50], [8, 8, 10], [1, 4, 20], [8, 1, 50], [4, 9, 20]]}
AUTO = ['shoot 9 5', 'shoot 1 7', 'shoot 8 6', 'shoot 5 6', 'shoot 1 6', 'shoot 5 9', 'shoot 2 1', 'shoot 8 8', 'shoot 1 4', 'shoot 4 5', 'shoot 3 9']

def auto_play():
    score, hits = 0, 0
    print("Gallery tribute: auto session")
    for i, target in enumerate(PARAMS["targets"]):
        shot = AUTO[i] if i < len(AUTO) else "shoot 0 0"
        parts = shot.split()
        sx, sy = int(parts[1]), int(parts[2])
        tx, ty, pts = target
        hit = abs(sx - tx) <= 1 and abs(sy - ty) <= 1
        if hit:
            score += pts
            hits += 1
        print("Round %d: target %s shot (%d,%d) %s score %d" % (i + 1, (tx, ty), sx, sy, "HIT" if hit else "MISS", score))
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d" % (hits, len(PARAMS["targets"])))

def play():
    score, hits = 0, 0
    print("Gallery tribute: type 'shoot X Y' each round, or quit. Targets are on a 0-9 grid.")
    for i, target in enumerate(PARAMS["targets"]):
        print("Round %d: a target has appeared somewhere on the 0-9 grid." % (i + 1))
        got = False
        for line in sys.stdin:
            cmd = line.strip().lower()
            if cmd == "quit":
                print("FINAL SCORE: %d" % score)
                print("RESULT: HITS %d/%d" % (hits, len(PARAMS["targets"])))
                return
            parts = cmd.split()
            if len(parts) != 3 or parts[0] != "shoot":
                print("Use: shoot X Y")
                continue
            try:
                sx, sy = int(parts[1]), int(parts[2])
            except ValueError:
                print("Use numbers: shoot X Y")
                continue
            tx, ty, pts = target
            hit = abs(sx - tx) <= 1 and abs(sy - ty) <= 1
            if hit:
                score += pts
                hits += 1
            print("%s score %d" % ("HIT" if hit else "MISS", score))
            got = True
            break
        if not got:
            break
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d" % (hits, len(PARAMS["targets"])))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()
