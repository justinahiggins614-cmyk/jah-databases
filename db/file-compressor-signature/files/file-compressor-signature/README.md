# File Compressor Database — files (file-compressor-signature)

- `demo-file-compressor-signature.py` — runnable demo program (run with `python3 demo-file-compressor-signature.py`).
- `file-compressor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/file-compressor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-file-compressor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
