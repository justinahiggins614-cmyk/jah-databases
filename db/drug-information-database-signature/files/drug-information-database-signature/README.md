# Drug Information Database Database — files (drug-information-database-signature)

- `demo-drug-information-database-signature.py` — runnable demo program (run with `python3 demo-drug-information-database-signature.py`).
- `drug-information-database-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/drug-information-database-signature/index.jsonl.gz` (24 records).
- The generator is `gen-drug-information-database-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
