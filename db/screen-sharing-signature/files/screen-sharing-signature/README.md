# Screen Sharing Database — files (screen-sharing-signature)

- `demo-screen-sharing-signature.py` — runnable demo program (run with `python3 demo-screen-sharing-signature.py`).
- `screen-sharing-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/screen-sharing-signature/index.jsonl.gz` (24 records).
- The generator is `gen-screen-sharing-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
