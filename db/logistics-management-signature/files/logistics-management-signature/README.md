# Logistics Management Database — files (logistics-management-signature)

- `demo-logistics-management-signature.py` — runnable demo program (run with `python3 demo-logistics-management-signature.py`).
- `logistics-management-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/logistics-management-signature/index.jsonl.gz` (24 records).
- The generator is `gen-logistics-management-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
