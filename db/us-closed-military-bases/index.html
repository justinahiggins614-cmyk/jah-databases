Sixteen full us closed base record records, ordered simple to compounded to complex, drawn from the public record only. Anything not in the public record is marked "not in public record". Everything is free forever, with no payments and no upsells.

Specialist AI: JAH Closed Base Guide

JAH Closed Base Guide answers questions about these records, explains each public role in plain sentences, and helps a visitor move between records without confusing public record with speculation.

Boundless generator

The generator below is seeded and deterministic, throttled to at most 100 records per call, duplicate-checked, and hard-stopped at 10^15 records. Every generated record is labeled src "generated". Open the page script to use window.UsClosedMilitaryBasesTools.generateRecord(seed).

Validation engine

Each record is checked for a complete title, its own record kind, its own edition slug and id prefix, a public-record source, and a demo whose stored output byte-matches a fresh run.

import math
TITLE = 'Fort Ord'
LAT, LON = 36.64, -121.78
REF_NAME, REF_LAT, REF_LON = 'Sacramento, California', 38.58, -121.49
def haversine(lat1, lon1, lat2, lon2):
    r = math.radians
    dlat = r(lat2 - lat1); dlon = r(lon2 - lon1)
    a = math.sin(dlat/2)**2 + math.cos(r(lat1)) * math.cos(r(lat2)) * math.sin(dlon/2)**2
    return 6371.0 * 2 * math.asin(math.sqrt(a))
def to_dms(x, pos, neg):
    hemi = pos if x >= 0 else neg
    a = abs(x); d = int(a); m = int((a - d) * 60); s = round(((a - d) * 60 - m) * 60, 1)
    return '%d deg %d min %.1f sec %s' % (d, m, s, hemi)
def main():
    print(TITLE + ' - working demo')
    print('Approximate public coordinates: %.2f, %.2f' % (LAT, LON))
    print('Latitude DMS: ' + to_dms(LAT, 'N', 'S'))
    print('Longitude DMS: ' + to_dms(LON, 'E', 'W'))
    print('Distance to %s (%.2f, %.2f): %.1f km' % (REF_NAME, REF_LAT, REF_LON, haversine(LAT, LON, REF_LAT, REF_LON)))
