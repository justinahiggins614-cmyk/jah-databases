# Lead Generator Database — files (lead-generator)

- `demo-lead-generator.py` — runnable demo program (run with `python3 demo-lead-generator.py`).
- `lead-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/lead-generator/index.jsonl.gz` (24 records).
- The generator is `gen-lead-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
