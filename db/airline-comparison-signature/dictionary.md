# Dictionary entries — The Airline Comparison Database

Key terms of this database, defined in plain words.

## comparison

The act of laying the same flight from different airlines side by side, on the same points, so that their differences can be seen in the same words.

## airline

A business that flies passengers on scheduled flights, named beside every flight in the comparison, so that every fare and time can be traced to who flies it.

## flight

One scheduled journey of an aircraft from one airport to another, named by its number, its places, and its times, so that the comparison is a table of flights, each with its own airline.

## fare

The price stated for a flight, recorded with its amount, its date, and its airline, so that every fare in the table can be traced to when and where it was recorded. No payment is taken here.

## route

The pair of airports a flight joins, written as departure and arrival, so that only flights joining the same two airports are compared with one another.

## schedule

The written list of an airline's flights on a route, with their times, kept beside the comparison, so that the times in the table can be checked against the flights as scheduled.

## aircraft

The aeroplane that flies a flight, named by its type in the comparison, so that a reader can see what kind of aircraft serves each flight.

## seat class

The named level of seat on a flight, such as economy or business, written beside the fare, so that fares are compared only between the same class of seat.

## baggage allowance

The amount of luggage a fare allows a passenger to carry, stated beside the fare, so that a fare that allows little and a fare that allows much are never compared as if they were the same.

## on-time record

The kept count of how often an airline's flights arrive as scheduled, stated with its period, so that the record of punctuality can be read beside the fare.

## service

What an airline provides on a flight beyond the seat, such as meals or entertainment, named in the comparison, so that the service can be read beside the fare it comes with.

## comparison table

The table that lays the same flight from each airline side by side, on the same points, kept whole, so that a comparison can be re-read later exactly as it stood when it was made.
