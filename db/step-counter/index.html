1. Description

A step counter is a rule-based local demo: it reads set toy days, and counts the steps. The counter reads 3 days. The day monday holds 8000 steps. The largest holds 8000 steps. Everything runs in this browser; no data leaves the page.

3. Science proof

A step counter is a rule-based local demo works because each value is plain arithmetic: The counter counts 8000 steps. The days average 6500 steps. 100 days: 58 busy days and 42 quiet days.
