Operation Wolf Rank 1 · simple · gallery shooter · beginner

Operation Wolf, released in 1987, is a military light-gun game in which the player fights through enemy territory with a mounted gun controller, clearing screens of soldiers, vehicles, and bases on the way to a rescue mission.

The tribute demo recreates that feel on a ten-by-ten grid: fast-moving soldier and vehicle targets that must be cleared before they return fire. Each round presents one target, and a shot counts as a hit when it lands on or beside the target square, so near misses still score while wild shots do not. The demo is an original program inspired by the mechanics, not the arcade game itself.

Good gallery play is about reading the round, not just firing fast. Watch where targets cluster, spend the accurate shots on the high-value squares, and accept a miss rather than spraying the grid. The scoring rewards steady accuracy over lucky bursts.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Operation Wolf (1987). It is not Operation Wolf (1987), and it uses no art, music, or code from that game.

How to play

Type shoot X Y for each round (grid 0-9), quit to stop.

Working demo program

Save the code below as game.py and run python3 game.py --play to play it. Running it without arguments replays the scripted session whose output is stored with the record.

import sys
PARAMS = {'targets': [[2, 7, 30], [2, 6, 20], [6, 8, 10], [8, 1, 10], [7, 4, 10], [3, 5, 20], [4, 3, 20], [2, 3, 20], [5, 6, 20]]}
AUTO = ['shoot 1 7', 'shoot 2 6', 'shoot 5 8', 'shoot 8 1', 'shoot 6 4', 'shoot 4 5', 'shoot 4 3', 'shoot 2 3', 'shoot 5 6']

def auto_play():
    score, hits = 0, 0
    print("Gallery tribute: auto session")
    for i, target in enumerate(PARAMS["targets"]):
        shot = AUTO[i] if i < len(AUTO) else "shoot 0 0"
        parts = shot.split()
        sx, sy = int(parts[1]), int(parts[2])
        tx, ty, pts = target
        hit = abs(sx - tx) <= 1 and abs(sy - ty) <= 1
        if hit:
            score += pts
            hits += 1
        print("Round %d: target %s shot (%d,%d) %s score %d" % (i + 1, (tx, ty), sx, sy, "HIT" if hit else "MISS", score))
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d" % (hits, len(PARAMS["targets"])))

def play():
    score, hits = 0, 0
    print("Gallery tribute: type 'shoot X Y' each round, or quit. Targets are on a 0-9 grid.")
    for i, target in enumerate(PARAMS["targets"]):
        print("Round %d: a target has appeared somewhere on the 0-9 grid." % (i + 1))
        got = False
        for line in sys.stdin:
            cmd = line.strip().lower()
            if cmd == "quit":
                print("FINAL SCORE: %d" % score)
                print("RESULT: HITS %d/%d" % (hits, len(PARAMS["targets"])))
                return
            parts = cmd.split()
            if len(parts) != 3 or parts[0] != "shoot":
                print("Use: shoot X Y")
                continue
            try:
                sx, sy = int(parts[1]), int(parts[2])
            except ValueError:
                print("Use numbers: shoot X Y")
                continue
            tx, ty, pts = target
            hit = abs(sx - tx) <= 1 and abs(sy - ty) <= 1
            if hit:
                score += pts
                hits += 1
            print("%s score %d" % ("HIT" if hit else "MISS", score))
            got = True
            break
        if not got:
            break
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d" % (hits, len(PARAMS["targets"])))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()
