# Website Change Detector Database — files (website-change-detector-signature)

- `demo-website-change-detector-signature.py` — runnable demo program (run with `python3 demo-website-change-detector-signature.py`).
- `website-change-detector-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/website-change-detector-signature/index.jsonl.gz` (24 records).
- The generator is `gen-website-change-detector-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
