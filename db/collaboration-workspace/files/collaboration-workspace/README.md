# Collaboration Workspace Database — files (collaboration-workspace)

- `demo-collaboration-workspace.py` — runnable demo program (run with `python3 demo-collaboration-workspace.py`).
- `collaboration-workspace-sample.txt` — a plain-text sample of the database.
- The full database is `data/collaboration-workspace/index.jsonl.gz` (24 records).
- The generator is `gen-collaboration-workspace.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
