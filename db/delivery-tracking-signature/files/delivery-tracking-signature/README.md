# Delivery Tracking Database — files (delivery-tracking-signature)

- `demo-delivery-tracking-signature.py` — runnable demo program (run with `python3 demo-delivery-tracking-signature.py`).
- `delivery-tracking-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/delivery-tracking-signature/index.jsonl.gz` (24 records).
- The generator is `gen-delivery-tracking-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
