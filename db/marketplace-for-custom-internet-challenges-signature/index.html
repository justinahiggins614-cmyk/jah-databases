The website form grows out of that habit, adding a plain listing for each challenge and a marketplace a visitor can browse. Field guides and indexes are as old as books themselves: a table of contents that tells a reader where everything lives. This index follows that habit, listing the twenty-three content records of this database in the order a reader should meet them.

Proposed solution

Add a Signature tournament bracket with rounds, divisions, and a season; Add a Signature creator studio so visitors can build a new internet challenge; Add a Signature review step so every new internet challenge is checked before it is published; Add the Signature internet challenge in many languages, with the same rules in each; Add a Signature offline pack so the internet challenge works with no connection.

Dependencies

What must exist first: a list of generic kinds of challenges, plain rules for each challenge, a way to finish and share a result, and a review step before publishing. A tournament system, a creator studio, a review step, translations, and an offline pack are also needed before the complex internet challenges open.

Feasibility

buildable-now — The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

Verification path

A tournament runs a full season, a creator publishes a new internet challenge through the review step, and the offline pack is tried with no connection. The demo program prints the same total as the math proof, and every step is checked by a second reader.
