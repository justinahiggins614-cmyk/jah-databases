# Data Clustering Database — files (data-clustering)

- `demo-data-clustering.py` — runnable demo program (run with `python3 demo-data-clustering.py`).
- `data-clustering-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-clustering/index.jsonl.gz` (24 records).
- The generator is `gen-data-clustering.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
