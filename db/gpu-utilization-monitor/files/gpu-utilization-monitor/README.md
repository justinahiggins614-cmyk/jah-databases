# GPU Utilization Monitor Database — files (gpu-utilization-monitor)

- `demo-gpu-utilization-monitor.py` — runnable demo program (run with `python3 demo-gpu-utilization-monitor.py`).
- `gpu-utilization-monitor-sample.txt` — a plain-text sample of the database.
- The full database is `data/gpu-utilization-monitor/index.jsonl.gz` (24 records).
- The generator is `gen-gpu-utilization-monitor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
