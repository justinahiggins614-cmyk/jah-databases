# Medical Image Annotation Database — files (medical-image-annotation)

- `demo-medical-image-annotation.py` — runnable demo program (run with `python3 demo-medical-image-annotation.py`).
- `medical-image-annotation-sample.txt` — a plain-text sample of the database.
- The full database is `data/medical-image-annotation/index.jsonl.gz` (24 records).
- The generator is `gen-medical-image-annotation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
