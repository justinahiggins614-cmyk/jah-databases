# Icon Creator Database — files (icon-creator)

- `demo-icon-creator.py` — runnable demo program (run with `python3 demo-icon-creator.py`).
- `icon-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/icon-creator/index.jsonl.gz` (24 records).
- The generator is `gen-icon-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
