1. Description

An icon creator draws small pictures on a grid of pixels: pick a size, draw on the grid, and download the icon. An icon grid of 16 by 16 has 256 pixels. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

An icon grid of 16 by 16 has 256 pixels. An icon grid of 32 by 32 has 1024 pixels. An icon grid of 8 by 8 has 64 cells. An icon grid of 24 by 24 has 576 pixels. An icon grid of 48 by 48 has 2304 pixels.

3. Science proof

An icon creator works because an icon is a grid of pixels, and each pixel is one square of colour: an icon of 256 pixels with 100 filled has 156 empty pixels, and a star icon has 5 points. Growing an icon from 16 to 32 doubles the side: 256 pixels become 1024 pixels. That is why the local demo shows the grid and the icon together, and runs 0 creations on a server.

4. Working demo

Try it: icon creator (draws on a grid, downloads a file)

Pick a grid size, press Draw, and see the icon. Click a cell to fill it or empty it. Press Download to save the icon as a file. The demo runs 0 creations on a server: it runs in the browser.
