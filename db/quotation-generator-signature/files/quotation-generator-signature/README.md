# Quotation Generator Database — files (quotation-generator-signature)

- `demo-quotation-generator-signature.py` — runnable demo program (run with `python3 demo-quotation-generator-signature.py`).
- `quotation-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/quotation-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-quotation-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
