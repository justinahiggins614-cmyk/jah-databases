# Audio Mixer Database — files (audio-mixer)

- `demo-audio-mixer.py` — runnable demo program (run with `python3 demo-audio-mixer.py`).
- `audio-mixer-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-mixer/index.jsonl.gz` (24 records).
- The generator is `gen-audio-mixer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
