# Dictionary entries — The Live Classroom Platforms Database

Key terms of this database, defined in plain words.

## live classroom platform

The recorded system that holds live lessons taught at one hour to learners in many places, so that a class can meet, speak, and learn together without sharing a building.

## live lesson

A lesson taught at a stated hour with teacher and learners present together, kept in the record with its time and its class, so that the meeting can be proved from the paper.

## teacher

The person who teaches a live lesson, named in the record with the lesson and the class, so that who taught the lesson can be read plainly.

## learner

A person who joins a live lesson, recorded under a name and a number so that every paper for that learner can be matched to the same person.

## classroom

The room, real or held over distance, in which a lesson is taught, named in the record with the lesson, so that where the teaching happened can be read plainly.

## session

One meeting of a live class at a stated hour, kept in the record with its date and its lesson, so that the meeting can be followed step by step.

## attendance

The written list of learners present at a live lesson, kept in the record with the session, so that who attended can be read from the list itself.

## recording

The kept copy of a live lesson, held in the record with the session it covers, so that the lesson can be heard or read again after the hour has passed.

## chat

The written messages exchanged by learners and teacher during a live lesson, kept in the record so that the talk of the lesson can be followed.

## screen share

The showing of a teacher screen to the learners of a live lesson, kept in the record with the session, so that what was shown can be matched to the lesson.

## breakout room

A smaller group room opened inside a live lesson, kept in the record with its learners, so that the group work can be followed.

## timetable

The written plan of live lessons for a class across the week, kept in the record with the class and the term, so that when each lesson falls can be read plainly.
