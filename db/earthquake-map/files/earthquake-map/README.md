# Earthquake Map Database — files (earthquake-map)

- `demo-earthquake-map.py` — runnable demo program (run with `python3 demo-earthquake-map.py`).
- `earthquake-map-sample.txt` — a plain-text sample of the database.
- The full database is `data/earthquake-map/index.jsonl.gz` (24 records).
- The generator is `gen-earthquake-map.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
