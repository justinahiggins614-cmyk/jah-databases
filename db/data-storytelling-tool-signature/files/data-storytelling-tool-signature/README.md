# Data Storytelling Tool Database — files (data-storytelling-tool-signature)

- `demo-data-storytelling-tool-signature.py` — runnable demo program (run with `python3 demo-data-storytelling-tool-signature.py`).
- `data-storytelling-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-storytelling-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-data-storytelling-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
