# AI Mathematician Database — files (ai-mathematician)

- `demo-ai-mathematician.py` — runnable demo program (run with `python3 demo-ai-mathematician.py`).
- `ai-mathematician-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-mathematician/index.jsonl.gz` (24 records).
- The generator is `gen-ai-mathematician.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
