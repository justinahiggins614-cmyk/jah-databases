About this data base

Archive
This database's grounding-judgment archive (JAH-GROUND records): answers labeled for factual grounding with error types and sources, preserved as structured, searchable data.
Record schema
id · judgment_id · question · answer · sources[] · grounded · error_type · severity · title
Generator
jahdb-grounding-judgments-1.0 — deterministic; builds a question and answer from a fact bank, optionally injecting a labeled grounding error; the validator enforces that grounded is false exactly when the error type is not "none".
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent validator.
Cross-database
The generator can borrow a theme from any of the other live databases when you tick the box.
AI
JAH Fact-Checker Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
