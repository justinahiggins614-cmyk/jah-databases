# Video Compressor Database — files (video-compressor)

- `demo-video-compressor.py` — runnable demo program (run with `python3 demo-video-compressor.py`).
- `video-compressor-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-compressor/index.jsonl.gz` (24 records).
- The generator is `gen-video-compressor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
