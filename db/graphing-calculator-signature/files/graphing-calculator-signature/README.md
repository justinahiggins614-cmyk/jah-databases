# Graphing Calculator Database — files (graphing-calculator-signature)

- `demo-graphing-calculator-signature.py` — runnable demo program (run with `python3 demo-graphing-calculator-signature.py`).
- `graphing-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/graphing-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-graphing-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
