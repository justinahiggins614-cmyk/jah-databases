# Automated Insight Generator Database — files (automated-insight-generator)

- `demo-automated-insight-generator.py` — runnable demo program (run with `python3 demo-automated-insight-generator.py`).
- `automated-insight-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/automated-insight-generator/index.jsonl.gz` (24 records).
- The generator is `gen-automated-insight-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
