# Wishlist Database — files (wishlist-signature)

- `demo-wishlist-signature.py` — runnable demo program (run with `python3 demo-wishlist-signature.py`).
- `wishlist-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/wishlist-signature/index.jsonl.gz` (24 records).
- The generator is `gen-wishlist-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
