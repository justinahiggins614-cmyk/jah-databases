Evolutionary Computation Tool Database (evolutionary-computation-tool-signature)

An evolutionary computation tool is a rule-based local demo: it reads set toy steps, and counts the marks. The tool reads 3 steps. The step alpha holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
