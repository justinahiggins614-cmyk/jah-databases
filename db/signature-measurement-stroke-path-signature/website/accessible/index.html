Honesty: pixel measurements are exact from the file 1939_0_0or1.jpg (1536 by 1024 px, ink darker than 128, 37,277 ink px). The 150 mm render width is an ASSUMPTION, stated wherever it is used. Atom numbers are scaled equivalents carried down the Signature scale, never direct physical measurements of ink atoms. The smallest resolvable unit in the file is 1 pixel. Nothing is invented.

1. Description and history

The Stroke Path Way traces each of the seven ink components of Manon's signature along its centreline, measuring the path the pen travelled. It thins each component to a one-pixel skeleton with Zhang-Suen thinning and measures the longest centreline path through that skeleton, in pixels, in Signature units (S), and in atoms. Manon uploaded his signature image on 2026-11-23 and asked for it to be measured many ways, as accurately as the Signature system allows, down toward atom scale. The numbers were measured from the file, verified twice, and recomputed for this wave with identical results.

2. Math proof

2,378.1 px = 758.7 + 747.9 + 486.7 + 384.8 px. In Signature units 2,378.1 / 1,257 = 1.8919 S. In atoms 2,378.1 x 1,193,317.42 = 2,837,828,162 atoms. The demo of every record prints the same kind of total as its math proof, so a fresh run of any demo verifies its proof.

3. Science proof

Thinning a shape to its skeleton preserves its topology while reducing it to a centreline, so the skeleton length measures the path the pen travelled. Zhang-Suen thinning is standard image analysis, validated here on synthetic shapes before it was run on the signature.
