Section 1: Description and history

The Stroke Path Way traces each of the seven ink components of Manon's signature along its centreline, measuring the path the pen travelled. It thins each component to a one-pixel skeleton with Zhang-Suen thinning and measures the longest centreline path through that skeleton, in pixels, in Signature units (S), and in atoms. Manon uploaded his signature image on 2026-11-23 and asked for it to be measured many ways, as accurately as the Signature system allows, down toward atom scale. The parent agent measured the file the same day, the coordinator verified the numbers twice, and this wave recomputed them again before building, with identical results. Twenty-four full records, ordered simple to compounded to complex, each written in human-readable sentences and paragraphs, each carrying a history and description, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, a scientific equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

Section 2: Math proof

2,378.1 px = 758.7 + 747.9 + 486.7 + 384.8 px. In Signature units 2,378.1 / 1,257 = 1.8919 S. In atoms 2,378.1 x 1,193,317.42 = 2,837,828,162 atoms. The demo of every record prints the same kind of total as its math proof, so a fresh run of any demo verifies its proof.

Section 3: Science proof

Thinning a shape to its skeleton preserves its topology while reducing it to a centreline, so the skeleton length measures the path the pen travelled. Zhang-Suen thinning is standard image analysis, validated here on synthetic shapes before it was run on the signature.

How the Paths Were Found: Zhang-Suen Thinning

JAH-SMSPS-000002 · simple · Feasibility: buildable-now

Signature-line version of this measurement: the same numbers, measured the same way, presented as Manon's own Signature-line record. The Stroke Path Way traces each of the seven ink components of Manon's signature along its centreline, measuring the path the pen travelled. It thins each component to a one-pixel skeleton with Zhang-Suen thinning and measures the longest centreline path through that skeleton, in pixels, in Signature units (S), and in atoms. Zhang-Suen thinning peels a shape one pixel layer at a time, deleting only border pixels whose removal cannot break the shape apart or erase an endpoint, until a one-pixel skeleton is left. It was run here in Python on the 37,277 ink pixels of the signature file, component by component, and it was first validated on synthetic shapes: a 100 by 20 px bar thins to a single 80 px line, a filled circle of radius 20 thins to a single pixel, and a diagonal bar thins to a 51 px line. The implementation deletes in two alternating sub-iterations so that two-pixel-wide lines are never erased whole, and it converges when a full pass deletes nothing. Cross-Check One: Path Length Against Perimeter Halved

JAH-SMSPS-000011 · compounded · Feasibility: buildable-now

Signature-line version of this measurement: the same numbers, measured the same way, presented as Manon's own Signature-line record. The Stroke Path Way traces each of the seven ink components of Manon's signature along its centreline, measuring the path the pen travelled. It thins each component to a one-pixel skeleton with Zhang-Suen thinning and measures the longest centreline path through that skeleton, in pixels, in Signature units (S), and in atoms. For a simple stroke of uniform width, the path length should be near half the perimeter, because the perimeter runs down both long edges. The four strokes give path lengths of 758.7, 747.9, 486.7 and 384.8 px against perimeter halves of 629.0, 614.0, 580.5 and 351.5 px, ratios of 1.21, 1.22, 0.84 and 1.09. They do not agree exactly, and the reason is honest: these are looped, self-touching signature strokes, so where the pen path crosses itself the ink merges and the perimeter undercounts the true travel, and where the stroke widens the perimeter overcounts it. The cross-check therefore bounds the paths rather than confirming them exactly, and it passes because every path sits within a factor of 1.22 of its perimeter half. Turning Angles: How Much Each Stroke Turns

JAH-SMSPS-000013 · compounded · Feasibility: buildable-now

Signature-line version of this measurement: the same numbers, measured the same way, presented as Manon's own Signature-line record. The Stroke Path Way traces each of the seven ink components of Manon's signature along its centreline, measuring the path the pen travelled. It thins each component to a one-pixel skeleton with Zhang-Suen thinning and measures the longest centreline path through that skeleton, in pixels, in Signature units (S), and in atoms. Total turning angle measures how much a stroke's direction changes along its path. The centreline is first smoothed with a 9-node moving average, then resampled every 8th node, and the absolute heading changes are added. Smoothing matters: the raw resampled sum is not only inflated by pixel staircase jitter, it also depends on the thinning implementation (the long left sweep reads 101.0 degrees one way and 147.9 the other), while the smoothed values agree within 6 degrees between two independently written thinning implementations. The four strokes turn 235.4 degrees (tall right), 242.6 degrees (tall left), 151.1 degrees (long right sweep) and 48.8 degrees (long left sweep). The tall strokes turn the most because they curl at their tops; the long left sweep turns the least because it runs nearly straight. The smoothed value is the honest one, and its method is stated here. The Staircase Note: Why 8-Connected Skeletons Count Extra Neighbours

JAH-SMSPS-000020 · complex · Feasibility: buildable-now

Signature-line version of this measurement: the same numbers, measured the same way, presented as Manon's own Signature-line record. The Stroke Path Way traces each of the seven ink components of Manon's signature along its centreline, measuring the path the pen travelled. It thins each component to a one-pixel skeleton with Zhang-Suen thinning and measures the longest centreline path through that skeleton, in pixels, in Signature units (S), and in atoms. A diagonal line on a pixel grid is a staircase, and in 8-connectivity the pixels of a staircase touch diagonally as well as orthogonally, so a skeleton pixel on a diagonal run can have three or four graph neighbours while still lying on a single clean centreline. The tall right stroke's skeleton shows hundreds of pixels with three or four graph neighbours, yet a rendered picture of it is one unbroken red line down the middle of the stroke. Because of this, the naive edge-sum length, which counts every graph edge, overcounts badly: 1,415.9 px for the tall right stroke against its true 758.7 px main path. This database therefore reports the diameter-path length, not the edge sum, and reports the edge sums here so the difference is visible and checkable.
