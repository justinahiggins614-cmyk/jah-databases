Plumbing Layout Designer Database (plumbing-layout-designer)

A plumbing layout designer is a rule-based local demo: it designs set toy pipes, and counts the marks. The designer reads 3 pipes. The pipe alpha holds 18 marks. The largest holds 18 marks. Everything runs in this browser; no data leaves the page.
