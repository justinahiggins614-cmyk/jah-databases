Property Listing Manager Database (property-listing-manager-signature)

A property listing manager is a rule-based local demo: it manages set toy listings, and counts the marks. The manager reads 3 listings. The listing maple holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
