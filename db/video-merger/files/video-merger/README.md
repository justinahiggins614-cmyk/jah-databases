# Video Merger Database — files (video-merger)

- `demo-video-merger.py` — runnable demo program (run with `python3 demo-video-merger.py`).
- `video-merger-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-merger/index.jsonl.gz` (24 records).
- The generator is `gen-video-merger.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
