# Database Optimizer Database — files (database-optimizer)

- `demo-database-optimizer.py` — runnable demo program (run with `python3 demo-database-optimizer.py`).
- `database-optimizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-optimizer/index.jsonl.gz` (24 records).
- The generator is `gen-database-optimizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
