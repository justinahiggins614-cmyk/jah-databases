Calculus: Limits and How Functions Approach Values

Record identifier: JAH-CCALC-000001. Ladder rank: 1 of 24. Subject: limits of functions.

A limit is the value a function approaches as its input approaches a given number. We write the limit of f(x) as x approaches a equals L when f(x) can be made as close to L as we like by taking x close enough to a. A limit describes approach, not arrival: the function need not equal L at a. The limit laws let limits be computed piece by piece: the limit of a sum is the sum of the limits. A function is continuous at a point when its limit there equals its value there. The squeeze theorem finds a limit by trapping a function between two functions with the same limit. Calculus: The Derivative as a Rate of Change

Record identifier: JAH-CCALC-000002. Ladder rank: 2 of 24. Subject: the derivative as a rate of change.

The derivative of a function at a point is the instantaneous rate of change of the function there, defined as the limit of the average rate of change as the interval shrinks to zero. Geometrically it is the slope of the tangent line (the line that just touches the graph at that point). The derivative of x to the power n is n times x to the power n - 1. A function must be continuous where it is differentiable, but continuity alone does not guarantee differentiability: a corner has no derivative. The derivative of a constant is zero, and the derivative of a sum is the sum of the derivatives. Calculus: The Product, Quotient, and Chain Rules

Record identifier: JAH-CCALC-000003. Ladder rank: 3 of 24. Subject: the product, quotient, and chain rules.

The product rule says the derivative of a product is the derivative of the first times the second plus the first times the derivative of the second. The quotient rule handles division. The chain rule differentiates a composition (a function inside a function): differentiate the outer function, then multiply by the derivative of the inner function. The product rule: (fg)' = f'g + fg'. The quotient rule: (f/g)' = (f'g - fg') / g squared. The chain rule: the derivative of f(g(x)) is f'(g(x)) times g'(x). Calculus: The Definite Integral and Area

Record identifier: JAH-CCALC-000006. Ladder rank: 6 of 24. Subject: the definite integral and area.

The definite integral of a function from a to b is the limit of Riemann sums (sums of the areas of thin rectangles under the graph) as the rectangles get thinner. When the function is positive, the integral is the area under its graph; in general it is the signed area, with parts below the axis counted negatively. A Riemann sum approximates the integral by rectangles; the integral is the limit as their width goes to zero. The integral of a sum is the sum of the integrals, and constants factor out. The average value of a function on an interval is its integral divided by the interval's length. Calculus: The Fundamental Theorem of Calculus

Record identifier: JAH-CCALC-000007. Ladder rank: 7 of 24. Subject: the fundamental theorem of calculus.

The fundamental theorem of calculus has two parts. The first says that the derivative of the integral of a function, as a function of its upper limit, is the original function: differentiation undoes integration. The second says that the definite integral of a function equals the difference of the values of any antiderivative at the endpoints: integration undoes differentiation. Part one: the derivative of the integral from a to x of f(t) dt is f(x). Part two: the integral from a to b of f(x) dx is F(b) - F(a), where F is any antiderivative of f. The theorem is why integrals are usually computed by finding antiderivatives rather than by limits of sums. Calculus: Integration by Substitution

Record identifier: JAH-CCALC-000008. Ladder rank: 8 of 24. Subject: integration by substitution.

Integration by substitution is the chain rule in reverse: when the integrand contains a function and (up to a constant) its derivative, substitute a new variable for the inner function, turning the integral into a simpler one. The differential dx is replaced by du over the derivative of the substitution. Choose the substitution u = g(x), then du = g'(x) dx. For a definite integral, change the limits to the u values as well. The substitution is undone at the end, replacing u by g(x). Calculus: Integration by Parts

Record identifier: JAH-CCALC-000009. Ladder rank: 9 of 24. Subject: integration by parts.

Integration by parts is the product rule in reverse: the integral of u times dv equals u times v minus the integral of v times du. It trades one integral for another, and it is chosen when the new integral is easier than the old one, typically when one factor becomes simpler on differentiating and the other is easy to integrate. Choose u to be the factor that simplifies on differentiating, and dv the factor that is easy to integrate. The formula is: integral of u dv = u v - integral of v du. Repeated parts handles products of polynomials with exponentials or trigonometric functions. Calculus: Sequences and Series Convergence Tests

Record identifier: JAH-CCALC-000011. Ladder rank: 11 of 24. Subject: convergence tests for series.

A convergence test is a rule that decides whether a series has a finite sum. The comparison test compares with a known series; the ratio test looks at the limit of the ratio of successive terms; the root test looks at the n-th root of the n-th term; the integral test compares with an improper integral. The ratio test: if the limit of |a(n+1)/a(n)| is below 1, the series converges absolutely. The integral test applies to positive decreasing terms and compares the series with an integral. The alternating series test: a series with decreasing terms tending to zero converges, with error below the first omitted term. Calculus: Taylor Series and Approximation

Record identifier: JAH-CCALC-000012. Ladder rank: 12 of 24. Subject: Taylor series and approximation.

A Taylor series represents a function as an infinite sum of powers of (x - a), with coefficients given by the function's derivatives at a: the n-th coefficient is the n-th derivative at a divided by n factorial. The partial sums are polynomial approximations, and Taylor's theorem bounds the error of stopping early. The Taylor series of e^x about 0 is 1 + x + x squared/2! + x cubed/3! + ... The Taylor series of sin(x) about 0 is x - x cubed/3! + x to the fifth/5! - ... Taylor's theorem with remainder bounds the error by the next term's size when the derivatives are bounded. Calculus: Partial Derivatives

Record identifier: JAH-CCALC-000013. Ladder rank: 13 of 24. Subject: partial derivatives.

A partial derivative is the derivative of a function of several variables with respect to one variable, holding the others fixed. The partial derivative with respect to x measures how the function changes when only x changes. The gradient is the vector of all the partial derivatives, pointing in the direction of steepest increase. To compute a partial derivative with respect to x, treat the other variables as constants. Clairaut's theorem says mixed partial derivatives are equal when they are continuous. The gradient points in the direction of steepest increase, and its size is the steepest rate. Calculus: Multiple Integrals

Calculus: Vector Calculus and the Theorems of Green, Stokes, and Gauss

Record identifier: JAH-CCALC-000015. Ladder rank: 15 of 24. Subject: vector calculus and its great theorems.

Vector calculus studies vector fields (assignments of a vector to each point in space). The theorems of Green, Stokes, and Gauss relate an integral over a region to an integral over its boundary: Green relates a line integral around a closed curve to a double integral over the region inside; Stokes extends this to surfaces; Gauss relates a surface integral to a triple integral over the volume inside. Green's theorem: the line integral of a field around a closed curve equals the double integral of the field's curl over the region. Stokes' theorem: the line integral around the boundary of a surface equals the surface integral of the curl. Gauss' divergence theorem: the surface integral of a field over a closed surface equals the triple integral of the divergence over the volume. Calculus: Improper Integrals

Record identifier: JAH-CCALC-000016. Ladder rank: 16 of 24. Subject: improper integrals.

An improper integral is an integral over an unbounded interval, or of a function that becomes infinite inside the interval. It is defined as a limit: integrate up to a finite point, then let that point go to infinity, or let it approach the trouble spot, and take the limit if it exists. The integral of 1/x squared from 1 to infinity converges to 1. The integral of 1/x from 1 to infinity diverges: it grows like the logarithm. The p-test says the integral of 1/x to the power p from 1 to infinity converges exactly when p is greater than 1. Calculus: Lagrange Multipliers

Record identifier: JAH-CCALC-000018. Ladder rank: 18 of 24. Subject: Lagrange multipliers.

Lagrange multipliers solve constrained optimisation: maximising a function f subject to a constraint g = c. At the optimum, the gradient of f is parallel to the gradient of g, so the gradient of f equals lambda times the gradient of g, for some number lambda (the Lagrange multiplier), together with the constraint itself. The multiplier lambda measures how much the optimum value changes if the constraint is relaxed. The method gives candidates; each must be checked against the constraint and against the others. With several constraints, one multiplier is introduced per constraint. Calculus: The Mean Value Theorem

Record identifier: JAH-CCALC-000019. Ladder rank: 19 of 24. Subject: the mean value theorem.

The mean value theorem says: if a function is continuous on a closed interval and differentiable on the open interval, then there is a point inside where the instantaneous rate of change equals the average rate of change over the whole interval. Geometrically, some tangent line is parallel to the secant line (the line joining the endpoints). The theorem is the bridge between local information (derivatives) and global information (net change). Rolle's theorem is the special case where the endpoint values are equal: then some derivative is zero. The theorem proves that a function with zero derivative everywhere is constant. Calculus: Volumes of Revolution

Record identifier: JAH-CCALC-000021. Ladder rank: 21 of 24. Subject: volumes of revolution.

A volume of revolution is the volume of a solid made by rotating a region around an axis. The disk method slices the solid into thin disks perpendicular to the axis, each with volume pi times radius squared times thickness, and integrates. The washer method extends this to regions with a hole, subtracting the inner radius squared. The shell method: volume is the integral of 2 pi times radius times height, with respect to the other variable. Calculus: Arc Length and Surface Area

Record identifier: JAH-CCALC-000022. Ladder rank: 22 of 24. Subject: arc length and surface area.

Arc length is the length of a curve, computed by integrating the length of infinitesimal (infinitely small) pieces: the integral of the square root of 1 plus the square of the derivative. Surface area of a surface of revolution is computed similarly, integrating the circumference of each circular slice. The arc length of y = f(x) from a to b is the integral of sqrt(1 + (f'(x)) squared) dx. The surface area of the surface made by rotating the curve around the x-axis is the integral of 2 pi y times the arc-length element. Many arc-length integrals have no elementary closed form and are computed numerically. // own demo, ported from Python), then a determinism check: the lines
// are hashed twice and the two digests must match.
'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
