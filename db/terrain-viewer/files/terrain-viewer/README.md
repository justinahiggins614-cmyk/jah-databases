# Terrain Viewer Database — files (terrain-viewer)

- `demo-terrain-viewer.py` — runnable demo program (run with `python3 demo-terrain-viewer.py`).
- `terrain-viewer-sample.txt` — a plain-text sample of the database.
- The full database is `data/terrain-viewer/index.jsonl.gz` (24 records).
- The generator is `gen-terrain-viewer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
