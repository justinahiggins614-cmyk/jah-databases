Grounding Verification — What It Is is a Signature-made grounding-verification method, an original design created for this database and not a copy of any outside product or service. Grounding verification is the independent check of whether an outside AI's answer actually matches a real JAH record. As a Signature design, it is presented as a method for checking answers against JAH records, with its limits stated in this record.

This Signature design is an original creation for this database, made to sit alongside the public description of the same step without copying any outside product. It carries no endorsement from any outside party, and this record does not state a creation date for it.

The check works by splitting an answer into individual claims, then searching the JAH records for each claim's subject, numbers, and wording. A claim that matches a record is grounded; a claim with no matching record is flagged as unsupported. The result is a score and a list of which claims passed and which failed, so the reader can see exactly where the answer stands.

Worked example: 41 of 50 = 41/50 x 100 = 82.0%. Remaining: 50 - 41 = 9.

Signature-made grounding-verification method: an original design for this database, not a copy of any outside product or service; never presented as an established outside method. Not endorsed by any outside party.

The grounding remediation loop is the process that follows a failed grounding check: the report names the failed claims, the answer is corrected against the records, and the corrected answer is checked again. As a Signature design, it is presented as a method for checking answers against JAH records, with its limits stated in this record.

This Signature design is an original creation for this database, made to sit alongside the public description of the same step without copying any outside product. It carries no endorsement from any outside party, and this record does not state a creation date for it.

The loop works by taking the list of failed claims from the report, correcting each one from the record it should have matched, and running the full grounding check on the corrected answer. The new score is compared with the old score, and the loop stops when the score reaches the passing level or the round limit is reached. Success is measured as failures fixed divided by failures found, reported as a percentage.
