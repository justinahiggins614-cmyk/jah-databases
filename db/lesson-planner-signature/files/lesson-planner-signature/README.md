# Lesson Planner Database — files (lesson-planner-signature)

- `demo-lesson-planner-signature.py` — runnable demo program (run with `python3 demo-lesson-planner-signature.py`).
- `lesson-planner-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/lesson-planner-signature/index.jsonl.gz` (24 records).
- The generator is `gen-lesson-planner-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
