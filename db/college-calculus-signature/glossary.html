Glossary — Wave 1, 100 College-Level Resources Program

Every network term used in this wave's records and reports, defined in

plain words. No acronym is used without its full expansion first.

API
Application Programming Interface. A documented way for one program to ask another program for data or work, with exact request and response formats. "Live read-only API" means the network's data can be read through such an interface without changing anything.
boundless generator
A program that creates new records on demand from a deterministic seed, up to a hard stop, instead of storing every possible record as a file. Each record it makes is a scale of its database.
ceiling
The maximum a generator is allowed to produce: 1,000,000,000 (one billion) scales per file, generated on demand by the file AI — not stored files.
deterministic
Same input always gives the same output, byte for byte. Every demo and generator in this wave is deterministic: run it twice and the outputs match exactly, which is what the `Deterministic: MATCH` line proves.
demo
A short working program (Python) stored on a record that runs and prints the record's worked example. Its printed output is stored as `expected_output` and re-executed byte-identically at validation time.
design-study
The evidence label on Signature-edition records. It means the record is a Signature-made design (a study of how a thing could be designed), not an established public fact. Never presented as authentic public record.
documented
The evidence label on public-edition records. It means the record states established college-level knowledge backed by cited sources.
edition
One of the two versions of a database pair: `public` (established knowledge, fact-checked, sourced) or `signature` (Signature-made design studies).
expected output
The exact text a demo prints when it runs, as recorded at build time. Validation re-runs the demo and compares its output to this string byte for byte.
generator gate
The set of checks a generator must pass before it counts as verified: `node --check` (syntax), `runTests` (11 built-in tests), and seed-42 determinism (same seed twice gives identical output).
hard stop
The generator's absolute production limit: 1,000,000,000 scales per file. It stops there no matter what.
JCC
JAH Condensed Code, version 1. A short key that points to one record: `JAHDB/<slug>#<id>`, for example `JAHDB/college-mathematics#JAH-COLMATH-000001`. The matching `jcc_key` (`k=` + 8 hex characters) is a fingerprint of the record's contents, so the code round-trips: recompute the fingerprint from the record and it must match.
ladder rank
The record's position (1–24) on its pair's teaching ladder, from simple to compounded to most complex.
manifest
The network's master list of databases (`data/manifest.json` in the jah-databases repo), the single source of truth for which slugs and id prefixes exist and how many entries and records the network holds. At Wave 1 build time: HEAD `36cff9863`, 63,047 entries.
Master AI
The network's top-level AI that the specialist AIs connect to. Each database has its own specialist AI (for example the JAH College Mathematics Librarian) that explains its database; the Master AI coordinates across them.
MCP
Model Context Protocol. A standard way to plug a data source into an AI assistant so the assistant can read it directly.
pair
A public database and its Signature counterpart on the same subject, built together (24 records each, 48 per pair). Wave 1 has 9 pairs.
provenance
The recorded history of a record: where its facts came from (sources), when they were retrieved, and what changed in each version.
record
One full entry in a database: title, description, proofs, worked example, demo, program, sources, specification, and codes. Never a stub; every record carries the full file.
record_kind
The type label of a pair's records, for example `college mathematics record`.
retrieval
Fetching a source (a web page, a paper, a dataset) and recording what it establishes, its URL, and the retrieval date (2026-11-17 for this wave).
scale
One generated output of a boundless generator: a record produced on demand at a given seed and scale level (A1 micro, A2 file, A3 system).
SHA-256
Secure Hash Algorithm 256. A fingerprint function: feed it any text and it returns a fixed 64-character fingerprint. The JCC key uses the first 8 hex characters of the SHA-256 of the record's canonical form.
slug
The short hyphenated identifier of a database, used in URLs and file paths, for example `college-mathematics`. Signature editions add `-signature`.
source
A cited reference for a record's facts: name, URL, what it establishes, and retrieval date. Every record has at least two, and every URL was verified to return HTTP 200 at validation time.
specialist AI
The AI that belongs to one database and explains it in detail (for example the JAH Calculus Librarian). Every pair has one per edition.
SQLite
A small file-based database format (one file per database) used for local, offline querying of network data.
throttle
The generator's per-call limit: at most 100 scales produced per call, so generation never overloads the host.
UNREACHABLE
The mark a source would carry if its URL failed to respond at validation time, with the reason recorded. No source in this wave needed it: all 113 cited URLs returned HTTP 200.

Extension — website program (2026-11-17)

Every further acronym and all-caps term that appears in the Wave 1

records or on the Wave 1 websites, defined in plain words. Roman

numerals II and III (as in "Calculus I–III") are numbers, not acronyms.

AB
The product of matrix A and matrix B. In linear algebra AB usually differs from BA: matrix multiplication is not commutative.
ADD
A processor instruction that adds two numbers (computer architecture).
AI
Artificial Intelligence. A program that performs tasks that usually need human thought, such as answering questions, recognising patterns, or explaining a subject.
ALU
Arithmetic Logic Unit. The part of a processor (CPU) that does arithmetic (adding, subtracting) and logic (comparing).
ARM
Advanced RISC Machines. A family of processor designs used in most phones and many small computers.
ARPANET
Advanced Research Projects Agency Network. The early research network (1969) from which the internet grew.
AU
Astronomical Unit. The average distance from the Earth to the Sun, about 150 million kilometres; used to measure distances in space.
AVL
Adelson-Velsky and Landis. A kind of balanced binary search tree named after its two inventors; it keeps itself balanced so searches stay fast.
BA
The product of matrix B and matrix A. In linear algebra BA usually differs from AB.
BCE
Before the Common Era. The years counted before year 1 in the common calendar (the same years once called BC).
BC
Before Christ. The older name for the years now called BCE (Before the Common Era).
BFS
Breadth-First Search. Searching a graph (a network of points joined by lines) level by level, visiting all neighbours before going deeper.
BST
Binary Search Tree. A tree-shaped data structure where each node has at most two children and smaller values sit to the left.
CISC
Complex Instruction Set Computer. A processor design with many complex instructions, each doing a lot of work (the older x86 family is CISC).
CPI
Cycles Per Instruction. The average number of processor clock cycles one instruction takes.
CPU
Central Processing Unit. The processor: the part of a computer that executes instructions.
CSS
Cascading Style Sheets. The language that describes how a web page looks (colours, layout, type) separately from its content.
CUDA
Compute Unified Device Architecture. NVIDIA's platform for running general programs on a graphics processor (GPU).
DFS
Depth-First Search. Searching a graph (a network of points joined by lines) by going as deep as possible along one path before backtracking.
DMA
Direct Memory Access. A way for a device to move data to and from memory without the processor handling every byte.
DNA
Deoxyribonucleic Acid. The molecule that carries genetic instructions in living things.
DP
Dynamic Programming. Solving a problem by breaking it into smaller overlapping subproblems, solving each once, and reusing the answers.
DRAM
Dynamic Random-Access Memory. The main memory of a computer; it must be refreshed regularly or it forgets.
ECC
Error-Correcting Code. Extra stored information that lets a memory or disk detect and fix small errors.
EDSAC
Electronic Delay Storage Automatic Calculator. One of the first stored-program computers (Cambridge, 1949).
EDVAC
Electronic Discrete Variable Automatic Computer. An early stored-program computer design (1945–1951).
FFT
Fast Fourier Transform. A fast algorithm for turning a signal into its frequency parts (and back).
FIFO
First-In, First-Out. A queue rule: the first item added is the first removed.
FIT
Failures In Time. A failure-rate unit: 1 FIT means one failure per billion device-hours.
GB
Gigabyte. About one billion bytes of storage or memory.
GCD
Greatest Common Divisor. The largest whole number that divides two given numbers exactly.
GM
The product of the gravitational constant G and a mass M; it sets the strength of that mass's gravity.
GPS
Global Positioning System. The satellite system that tells a receiver its position on Earth.
GPU
Graphics Processing Unit. A processor built to do many similar calculations at once, first for graphics, now also for general computing.
HBM
High Bandwidth Memory. Memory stacked in layers close to a processor for very fast data transfer.
HDD
Hard Disk Drive. Storage that keeps data on spinning magnetic disks.
HEAD
In version control (git), the latest commit on the current branch.
HTTP
Hypertext Transfer Protocol. The protocol (agreed rules) a browser uses to fetch a web page.
HTML
HyperText Markup Language. The language web pages are written in: text with tags marking headings, paragraphs, and links.
IBM
International Business Machines. The computer company.
IEEE
Institute of Electrical and Electronics Engineers. The professional body that publishes standards such as IEEE 754 for floating-point arithmetic.
ILP
Instruction-Level Parallelism. Doing several instructions at once inside one processor by overlapping their steps.
IP
Internet Protocol. The addressing and routing rules of the internet.
IPC
Instructions Per Cycle. How many instructions a processor completes per clock cycle on average.
IPL
Information Processing Language. An early list-processing language (1950s) used for the first artificial-intelligence programs.
ISA
Instruction Set Architecture. The set of instructions a processor understands, and how programs use them.
JAH
Justin Addam Higgins. The maker's name; the Signature network's author mark.
JAHDB
JAH Database. The prefix of a JAH Condensed Code (JCC code): `JAHDB/<slug>#<id>`.
JSON
JavaScript Object Notation. A plain-text format for structured data: objects with named fields, lists, numbers, and strings.
KB
Kilobyte. About one thousand bytes.
KMP
Knuth-Morris-Pratt. A fast string-search algorithm named after its three inventors.
LIFO
Last-In, First-Out. A stack rule: the last item added is the first removed.
LU
LU factorisation. Writing a matrix A as the product of a lower-triangular matrix L and an upper-triangular matrix U, used to solve linear systems.
LW
Load Word. A MIPS processor instruction that loads one word (a fixed-size number) from memory into a register.
MATCH
The word a demo prints when its two runs produce identical output (`Deterministic: MATCH`).
MB
Megabyte. About one million bytes.
MIPS
Million Instructions Per Second. A rough speed measure for a processor; also the name of a processor family (Microprocessor without Interlocked Pipeline Stages).
MST
Minimum Spanning Tree. The cheapest set of edges that connects all points of a graph (a network of points joined by lines) without cycles.
NP
Nondeterministic Polynomial time. The class of problems whose proposed solutions can be checked quickly, even if finding one is hard.
NVIDIA
The company that makes graphics processors (GPUs) and the CUDA platform.
PARC
Palo Alto Research Center. Xerox's research centre where Ethernet and many personal-computing ideas began.
QR
QR factorisation. Writing a matrix A as the product of an orthogonal matrix Q and an upper-triangular matrix R, used to solve least-squares problems.
RAID
Redundant Array of Independent Disks. Several disks working together so data survives a disk failure.
RAID-5
One level of RAID: data and parity (error-checking information) are spread across the disks, so any one disk can fail without data loss.
RAM
Random-Access Memory. Memory a processor can read and write quickly; it forgets when power is off.
RAMAC
Random Access Method of Accounting and Control. IBM's first hard disk drive (1956).
RISC
Reduced Instruction Set Computer. A processor design with a small set of simple, fast instructions.
RISC-CISC
The pair of processor design choices, RISC versus CISC, compared side by side.
RISC-V
An open instruction set architecture (ISA) in the RISC family, free for anyone to implement.
ROB
Reorder Buffer. A buffer that holds finished instructions until they can be committed in the original program order.
RS/6000
IBM RISC System/6000. IBM's workstation and server line (1990) that introduced superscalar execution.
RSA
Rivest–Shamir–Adleman. A public-key cryptosystem named after its three inventors; its security rests on factoring large numbers being hard.
SAT
Boolean Satisfiability (problem). The question of whether a logical formula can be made true; the first problem proved NP-complete.
SIMD
Single Instruction, Multiple Data. One instruction applied to many numbers at once (data-level parallelism).
SPEC
Standard Performance Evaluation Corporation. The body that publishes standard computer performance benchmarks.
SSD
Solid-State Drive. Storage with no moving parts, kept in flash memory chips.
SVD
Singular Value Decomposition. Writing a matrix as three factors that expose its most important directions; used for compression and data analysis.
SW
Store Word. A MIPS processor instruction that stores one word from a register into memory.
TB
Terabyte. About one trillion bytes.
TFLOPS
Trillion Floating-Point Operations Per Second. A speed measure: how many trillion arithmetic operations a machine does per second.
TLB
Translation Lookaside Buffer. A small fast cache that remembers recent virtual-to-physical address translations.
TSP
Travelling Salesman Problem. Finding the shortest tour that visits each city once; a classic hard (NP-hard) problem.
URL
Uniform Resource Locator. A web address: the full string that names where a resource lives.
VLIW
Very Long Instruction Word. A processor design where each instruction word bundles several independent operations.
