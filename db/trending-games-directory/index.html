A Directory of Maze Games Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A directory website: entries are grouped by generic kind, such as maze games, word games, building games, and number puzzles, and each entry is a clearly labeled illustrative sample that shows the shape of a listing, with a plain-word description of how that kind of game is played. The directory names no real game, copies no real listing, and makes no claim that any sample entry is a real game. This record covers A Directory of Maze Games.

A directory of maze games gathers one kind of game in one place: games where a player guides a small light through a maze to the far door before the timer ends. Without a directory, a person who needs a game must search the whole web and guess which result is a real game and which is only an advert. The directory lists generic kinds only, and every entry is a clearly labeled illustrative sample, never a real game, so the reader learns the shape of the kind without being sent anywhere false.
