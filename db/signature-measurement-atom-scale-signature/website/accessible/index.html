Section 1: Description and history

Manon ordered the Signature system to measure his signature more accurately, as an alternative measurement system, as close to atom scale as can be, and to do it many ways, with a website and databases for each way. This site is the Atom-Scale way, built from his uploaded signature file on 2026-11-23. The signature file is 1,536 by 1,024 pixels; the ink is 37,277 pixels, 2.370 percent of the image; the ink box is 1,257 by 480 pixels from (137, 255) to (1393, 734); there are 7 connected components, 1,505 horizontal ink runs with a median of 23 pixels and a maximum of 80 pixels.

Section 2: Math proof

Atoms per pixel = (150 mm / 1,257 px) / 0.1 nm = 1,193,317.42. Whole width = 1,257 x 1,193,317.42 = 1,500,000,000 atoms. Whole height = 480 x 1,193,317.42 = 572,792,363 atoms.

atoms = pixels x 1,193,317.42 (at the assumed 150 mm render width, 0.1 nm per atom).

Section 3: Science proof

The atom scale is the pixel grid carried down by one exact multiplication. The 150 mm render width is an assumption, labeled everywhere, and 0.1 nm is the standard order-of-magnitude atom diameter. The result is a scaled equivalent, never a direct measurement of ink atoms.

Section 6: Working demo

Upload any dark-on-light image, set a render width (default 150 mm — an assumption, labeled as such), and the demo converts every length to atoms at 0.1 nm per atom — the Atom-Scale measurement, run live in your browser. Your image never leaves your computer.

How the demo works, step by step: open the main version of this page, choose an image file, and the page reads it in your browser, counts every pixel darker than 128 as ink, finds the bounding box, counts the horizontal ink runs, and labels the connected components. It then reports the result in the Atom-Scale way. Your image never leaves your computer. The published measurements of Manon's signature are the expected output: For Manon's signature file at 150 mm the demo reports a whole width of 1,500,000,000 atoms and 1,193,317 atoms per pixel.
