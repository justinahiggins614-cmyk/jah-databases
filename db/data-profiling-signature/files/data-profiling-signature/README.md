# Data Profiling Database — files (data-profiling-signature)

- `demo-data-profiling-signature.py` — runnable demo program (run with `python3 demo-data-profiling-signature.py`).
- `data-profiling-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-profiling-signature/index.jsonl.gz` (24 records).
- The generator is `gen-data-profiling-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
