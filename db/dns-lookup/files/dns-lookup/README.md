# DNS Lookup Database — files (dns-lookup)

- `demo-dns-lookup.py` — runnable demo program (run with `python3 demo-dns-lookup.py`).
- `dns-lookup-sample.txt` — a plain-text sample of the database.
- The full database is `data/dns-lookup/index.jsonl.gz` (24 records).
- The generator is `gen-dns-lookup.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
