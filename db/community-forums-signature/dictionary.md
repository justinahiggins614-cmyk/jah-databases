# Dictionary entries — The Community Forums Database

Key terms of this database, defined in plain words.

## forum

A set of boards, each about one thing, where questions are asked once and answered where everyone can read them.

## board

One subject's place in a forum, holding all its threads, so that a reader can find everything about one thing in one place.

## thread

One discussion, started by one post, with every reply kept beside it in order, so the whole talk can be read from start to finish.

## post

One written note in a thread, carrying words, its writer, and its time, kept in the order it was written.

## reply

A post written in answer to another post, kept beside the one it answers, so the talk can be followed in order.

## moderator

A member trusted to keep a board in order: to move posts to the right board, to remove what breaks the rules, and to settle disputes.

## member

One person in a forum, who can read its boards, write posts, and leave whenever they choose.

## sticky

A thread pinned to the top of its board, because it answers a question asked again and again, so that new readers find it first.

## search

Looking through a forum's posts for words, so that a question already answered is found, not asked again.

## answer

The reply that settles a question, marked as the answer, so that later readers can find it without reading the whole thread.

## rules

The written rules a forum agrees to: what may be said, what may not, and what happens when a rule is broken.

## ledger

The forum's own written record of every post, every member, and every change, kept in order.
