# AI Summarizer Database — files (ai-summarizer-signature)

- `demo-ai-summarizer-signature.py` — runnable demo program (run with `python3 demo-ai-summarizer-signature.py`).
- `ai-summarizer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-summarizer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-summarizer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
