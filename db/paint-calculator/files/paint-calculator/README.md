# Paint Calculator Database — files (paint-calculator)

- `demo-paint-calculator.py` — runnable demo program (run with `python3 demo-paint-calculator.py`).
- `paint-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/paint-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-paint-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
