# Matrix Calculator Database — files (matrix-calculator)

- `demo-matrix-calculator.py` — runnable demo program (run with `python3 demo-matrix-calculator.py`).
- `matrix-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/matrix-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-matrix-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
