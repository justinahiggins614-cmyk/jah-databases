# Scientific Data Visualization Database — files (scientific-data-visualization)

- `demo-scientific-data-visualization.py` — runnable demo program (run with `python3 demo-scientific-data-visualization.py`).
- `scientific-data-visualization-sample.txt` — a plain-text sample of the database.
- The full database is `data/scientific-data-visualization/index.jsonl.gz` (24 records).
- The generator is `gen-scientific-data-visualization.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
