# Factorization Tool Database — files (factorization-tool-signature)

- `demo-factorization-tool-signature.py` — runnable demo program (run with `python3 demo-factorization-tool-signature.py`).
- `factorization-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/factorization-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-factorization-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
