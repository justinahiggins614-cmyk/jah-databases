# Research Assistant Database — files (research-assistant)

- `demo-research-assistant.py` — runnable demo program (run with `python3 demo-research-assistant.py`).
- `research-assistant-sample.txt` — a plain-text sample of the database.
- The full database is `data/research-assistant/index.jsonl.gz` (24 records).
- The generator is `gen-research-assistant.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
