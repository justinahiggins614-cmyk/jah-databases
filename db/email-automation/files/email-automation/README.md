# Email Automation Database — files (email-automation)

- `demo-email-automation.py` — runnable demo program (run with `python3 demo-email-automation.py`).
- `email-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/email-automation/index.jsonl.gz` (24 records).
- The generator is `gen-email-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
