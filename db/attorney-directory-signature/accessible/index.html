Overview

The Signature Attorney Directory Database holds 24 full attorney directory record records, in a teaching ladder: 8 simple, 8 compounded, 8 most complex. This edition is the Signature edition. It expands the live database community-legal-clinic-directory, which holds 34 records; this pair links to it and never rebuilds it. This database carries the specification, models, test suites and verification records; it is not a running service.

The Design/System

The design is one database per subject, with a public edition and a Signature edition side by side. Every record gives its history, its full content, its methods, its results as reported, and its skeptical analysis. Every technical term is defined in plain words where it first appears, and the glossary defines them all again. Each Signature record is a design study, labeled as a design, never presented as established fact.

The Generator

The boundless generator for this database is the file gen-attorney-directory-signature.js. It is seeded and deterministic: the same seed always gives the same record, and different seeds differ. It is throttled to 100 records per call, it stops at 1,000,000,000 records per file, and every generated record is labeled generated, never presented as an archive record.

The AI

The archive-aware AI for this database is JAH Signature Attorney Directory Designer. It explains this database in plain sentences, answers questions about every record, and can generate new records in this database's family. Its full specification is downloadable: attorney-directory-signature-ai.json.

Math Proof

The counting argument is exact: 24 records, 8 simple, 8 compounded, 8 most complex, and 8 + 8 + 8 = 24. The formal statement is: directory(attorney) = one true record per attorney listed, with their standing, their practice areas, and their contact as published, or a named gap, never a silent gap (stated, not machine-checked) The scientific statement is: directory completeness = attorneys fully recorded / all attorneys listed (stated, not machine-checked) Both are stated, not machine-checked, and the record-level proofs are in each record's math proof.
