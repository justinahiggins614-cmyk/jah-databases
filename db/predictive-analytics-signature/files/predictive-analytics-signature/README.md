# Predictive Analytics Database — files (predictive-analytics-signature)

- `demo-predictive-analytics-signature.py` — runnable demo program (run with `python3 demo-predictive-analytics-signature.py`).
- `predictive-analytics-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/predictive-analytics-signature/index.jsonl.gz` (24 records).
- The generator is `gen-predictive-analytics-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
