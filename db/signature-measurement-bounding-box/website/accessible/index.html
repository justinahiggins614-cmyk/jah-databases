Bounding boxes for Manon's signature: widths, heights, aspect ratios, areas, and centers for the whole signature and each of its seven parts.

HONESTY LABEL: Pixel measurements are exact from the file 1939_0_0or1.jpg (1536 x 1024 px, ink = pixel darker than 128). The reference render width of 150 mm is an ASSUMPTION, stated on every page and record that uses it. Atom numbers are scaled equivalents carried down the Signature scale from that assumed 150 mm width at 0.1 nm per atom; they are never direct physical measurements of ink atoms. The smallest resolvable unit in the file is 1 pixel. Nothing is invented.

Section 1: Description and history

Manon ordered the Signature system to measure his signature more accurately, as an alternative measurement system, as close to atom scale as can be, and to do it many ways, with a website and databases for each way. This site is the Bounding Box way, built from his uploaded signature file on 2026-11-23. The signature file is 1,536 by 1,024 pixels; the ink is 37,277 pixels, 2.370 percent of the image; the ink box is 1,257 by 480 pixels from (137, 255) to (1393, 734); there are 7 connected components, 1,505 horizontal ink runs with a median of 23 pixels and a maximum of 80 pixels.

Section 2: Math proof

Box area = width x height = 1,257 x 480 = 603,360 px^2. Aspect ratio = width / height = 1,257 / 480 = 2.6188. Center = ((137+1,393)/2, (255+734)/2) = (765, 494.5).

box(part) = [min x, max x] x [min y, max y]; area = width x height.

Section 3: Science proof

A bounding box is the smallest axis-aligned rectangle holding a set of ink pixels. It is the standard frame of binary image measurement, and it is read directly from the counted extremes of the ink.

Section 6: Working demo

Upload any dark-on-light image and the demo finds the bounding box of the whole mark and of each connected component, with widths, heights, aspect ratios, areas, and centers — the Bounding Box measurement, run live in your browser. Your image never leaves your computer.

How the demo works, step by step: open the main version of this page, choose an image file, and the page reads it in your browser, counts every pixel darker than 128 as ink, finds the bounding box, counts the horizontal ink runs, and labels the connected components. It then reports the result in the Bounding Box way. Your image never leaves your computer. The published measurements of Manon's signature are the expected output: For Manon's signature file the demo reports a whole box of 1,257 by 480 pixels, aspect ratio 2.6188, center (765, 494.5).
