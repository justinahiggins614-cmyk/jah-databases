1. Description

A code optimizer reads code and writes a smaller file that does the same work: blank lines out, duplicates out, sums folded in advance. The demo on this page optimizes code in the browser and measures every change, with no server and no connection.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Removing 2 blank lines shrinks 10 lines to 8 lines. Optimizing saves 40 characters of 200: 20 percent smaller. Before and after: 200 characters becomes 160 characters. Optimizing twice: 200 characters to 160, then to 128 characters.

3. Science proof

A code optimizer works because a file's size is its lines and characters, and each rule takes some away: removing 2 blank lines shrinks 10 lines to 8 lines, and folding '2 + 3' into '5' saves 4 characters. Every change is measured, so the saving of 40 characters of 200 can be checked. That is why the local demo shows the before and the after side by side, and runs 0 optimizations on a server.
