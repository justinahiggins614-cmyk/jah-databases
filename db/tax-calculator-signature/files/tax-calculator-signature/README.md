# Tax Calculator Database — files (tax-calculator-signature)

- `demo-tax-calculator-signature.py` — runnable demo program (run with `python3 demo-tax-calculator-signature.py`).
- `tax-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/tax-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-tax-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
