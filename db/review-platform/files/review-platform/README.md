# Review Platform Database — files (review-platform)

- `demo-review-platform.py` — runnable demo program (run with `python3 demo-review-platform.py`).
- `review-platform-sample.txt` — a plain-text sample of the database.
- The full database is `data/review-platform/index.jsonl.gz` (24 records).
- The generator is `gen-review-platform.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
