JAH-WPROG-PUB-PRESENTATI-000003 — Presentation Creator — Working reference implementation

ladder rank 5 public

The complete working implementation of the presentation Creator is attached to this record as code, and every demo on this page executes it. Read it as the executable specification: what the tool is, is what this code does.

Working implementation

function deckNew(title){return {title:title,slides:[]};}
function deckAdd(d,title,bullets){d.slides.push({title:title,bullets:bullets||[]});return d;}
function deckHtml(d){function esc(s){return String(s).replace(/&/g,'&amp;').replace(/</g,'&lt;');}
return '<!DOCTYPE html><html><body><h1>'+esc(d.title)+'</h1>'+d.slides.map(function(s,i){return '<section><h2>Slide '+(i+1)+': '+esc(s.title)+'</h2><ul>'+s.bullets.map(function(b){return '<li>'+esc(b)+'</li>';}).join('')+'</ul></section>';}).join('')+'</body></html>';}
function deckOutline(d){return d.slides.map(function(s){return s.title+' ('+s.bullets.length+' bullets)';});}
