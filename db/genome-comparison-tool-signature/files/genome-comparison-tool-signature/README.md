# Genome Comparison Tool Database — files (genome-comparison-tool-signature)

- `demo-genome-comparison-tool-signature.py` — runnable demo program (run with `python3 demo-genome-comparison-tool-signature.py`).
- `genome-comparison-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/genome-comparison-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-genome-comparison-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
