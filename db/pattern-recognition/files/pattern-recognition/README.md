# Pattern Recognition Database — files (pattern-recognition)

- `demo-pattern-recognition.py` — runnable demo program (run with `python3 demo-pattern-recognition.py`).
- `pattern-recognition-sample.txt` — a plain-text sample of the database.
- The full database is `data/pattern-recognition/index.jsonl.gz` (24 records).
- The generator is `gen-pattern-recognition.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
