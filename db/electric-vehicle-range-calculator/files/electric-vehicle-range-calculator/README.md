# Electric Vehicle Range Calculator Database — files (electric-vehicle-range-calculator)

- `demo-electric-vehicle-range-calculator.py` — runnable demo program (run with `python3 demo-electric-vehicle-range-calculator.py`).
- `electric-vehicle-range-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/electric-vehicle-range-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-electric-vehicle-range-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
