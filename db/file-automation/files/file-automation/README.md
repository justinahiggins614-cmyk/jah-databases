# File Automation Database — files (file-automation)

- `demo-file-automation.py` — runnable demo program (run with `python3 demo-file-automation.py`).
- `file-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/file-automation/index.jsonl.gz` (24 records).
- The generator is `gen-file-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
