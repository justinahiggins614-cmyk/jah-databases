# Regulation Search Database — files (regulation-search)

- `demo-regulation-search.py` — runnable demo program (run with `python3 demo-regulation-search.py`).
- `regulation-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/regulation-search/index.jsonl.gz` (24 records).
- The generator is `gen-regulation-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
