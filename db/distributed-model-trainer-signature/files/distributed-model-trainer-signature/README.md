# Distributed Model Trainer Database — files (distributed-model-trainer-signature)

- `demo-distributed-model-trainer-signature.py` — runnable demo program (run with `python3 demo-distributed-model-trainer-signature.py`).
- `distributed-model-trainer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/distributed-model-trainer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-distributed-model-trainer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
