# Vocabulary Trainer Database — files (vocabulary-trainer)

- `demo-vocabulary-trainer.py` — runnable demo program (run with `python3 demo-vocabulary-trainer.py`).
- `vocabulary-trainer-sample.txt` — a plain-text sample of the database.
- The full database is `data/vocabulary-trainer/index.jsonl.gz` (24 records).
- The generator is `gen-vocabulary-trainer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
