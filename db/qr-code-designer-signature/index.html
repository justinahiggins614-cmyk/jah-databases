Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

A QR code is a square of modules: version 1 is 21 by 21, which is 441 modules, version 2 is 25 by 25, which is 625, and version 3 is 29 by 29, which is 841. In version 1, level L keeps 7 error codewords, M keeps 10, Q keeps 13 and H keeps 17. A message of 40 characters needs version 3 at level L, because version 2 holds 32 and version 3 holds 53.

3. Science proof

A QR code works because the message is written as bits with error-correction codewords beside it, so the code still reads when part of it is damaged, and finder patterns in three corners tell a camera where the code is and which way is up. A mask flips some modules by a rule so the pattern does not confuse the camera, and fifteen format bits name the error level and the mask. That is why the encoder in this page follows the same steps as the published reference, and the two agree module for module.

JAH-QRCD-S-000023 — Eleven characters, twenty-one by twenty-one modules, one code. Eleven characters, 21 by 21 modules, 1 code: 'HELLO WORLD' becomes one QR code.
Math proof: A QR code is a square of modules: version 1 is 21 by 21, which is 441 modules, version 2 is 25 by 25, which is 625, and version 3 is 29 by 29, which is 841. In version 1, level L keeps 7 error codewords, M keeps 10, Q keeps 13 and H keeps 17. A message of 40 characters needs version 3 at level L, because version 2 holds 32 and version 3 holds 53.
Science proof: A QR code works because the message is written as bits with error-correction codewords beside it, so the code still reads when part of it is damaged, and finder patterns in three corners tell a camera where the code is and which way is up. A mask flips some modules by a rule so the pattern does not confuse the camera, and fifteen format bits name the error level and the mask. That is why the encoder in this page follows the same steps as the published reference, and the two agree module for module.
