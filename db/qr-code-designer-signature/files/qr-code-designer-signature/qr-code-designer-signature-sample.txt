QR Code Designer Database (qr-code-designer-signature)

A QR code designer draws real QR codes: type words or a link, pick an error level, and download the code as a picture. The encoder in this page is a real QR encoder (byte mode, versions 1 to 3, four error levels, eight masks), checked against a published reference implementation: the code for HELLO WORLD matches it exactly. Everything runs in this browser.

Worked example: A QR code is a square of black and white modules that a camera can read.
