Section 1: Description and history

What Is This Thing? is a guessing game for strange objects: a visitor is shown a picture of a thing with no name and no label, and must guess what it is, what it does, and where it belongs. Every object is a clearly labeled design study of a generic kind of thing, and the game never claims a pictured object is a real product or a real antique. Asking what a strange thing is for is an old habit: a tool found in a drawer, a part left over after a repair, a shape nobody in the house can name. The website form grows out of that habit, adding a plain picture, plain clues, and a written answer for each thing. Every record below carries its own history section, so the description and the history of each design are told together, in full sentences and paragraphs, never as stubs.

The website form grows out of that habit, adding a plain picture, plain clues, and a written answer for each thing. Field guides and indexes are as old as books themselves: a table of contents that tells a reader where everything lives. This index follows that habit, listing the twenty-three content records of this database in the order a reader should meet them.

Proposed solution

Add a Signature tournament bracket with rounds, divisions, and a season; Add a Signature creator studio so visitors can build a new mystery object; Add a Signature review step so every new mystery object is checked before it is published; Add the Signature mystery object in many languages, with the same rules in each; Add a Signature offline pack so the mystery object works with no connection.

Dependencies

What must exist first: a list of generic kinds of objects, a plain picture and plain clues for each object, three guesses, a written answer, and a review step before publishing. A tournament system, a creator studio, a review step, translations, and an offline pack are also needed before the complex mystery objects open.

Feasibility

buildable-now — The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

Verification path

A tournament runs a full season, a creator publishes a new mystery object through the review step, and the offline pack is tried with no connection. The demo program prints the same total as the math proof, and every step is checked by a second reader.
