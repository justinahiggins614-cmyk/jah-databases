The Signature What Is This Thing? Database

Accessible version: plain text, no scripts, no sign-in, free forever. What Is This Thing? is a guessing game for strange objects: a visitor is shown a picture of a thing with no name and no label, and must guess what it is, what it does, and where it belongs. Every object is a clearly labeled design study of a generic kind of thing, and the game never claims a pictured object is a real product or a real antique.

Twenty-four full records, ordered simple to compounded to complex.
