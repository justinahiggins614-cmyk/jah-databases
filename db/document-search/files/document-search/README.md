# Document Search Database — files (document-search)

- `demo-document-search.py` — runnable demo program (run with `python3 demo-document-search.py`).
- `document-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/document-search/index.jsonl.gz` (24 records).
- The generator is `gen-document-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
