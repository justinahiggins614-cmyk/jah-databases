# Grammar Checker Database — files (grammar-checker)

- `demo-grammar-checker.py` — runnable demo program (run with `python3 demo-grammar-checker.py`).
- `grammar-checker-sample.txt` — a plain-text sample of the database.
- The full database is `data/grammar-checker/index.jsonl.gz` (24 records).
- The generator is `gen-grammar-checker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
