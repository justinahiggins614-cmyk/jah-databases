# Material Properties Database Database — files (material-properties-database-signature)

- `demo-material-properties-database-signature.py` — runnable demo program (run with `python3 demo-material-properties-database-signature.py`).
- `material-properties-database-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/material-properties-database-signature/index.jsonl.gz` (24 records).
- The generator is `gen-material-properties-database-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
