1. Description and History

An AI personal organizer keeps one person's tasks, appointments, notes, and deadlines in one place, sorts them by what matters first, reminds the user before things are due, and explains every suggestion it makes in plain sentences. This database designs that organizer one record at a time, from a single day's list to a whole project planned from one goal statement, and every record is a design, never a real product.

Personal organizers began as paper diaries and printed planners, then moved to calendar software and task lists on phones and computers. Each step added a new ability — reminders, recurring tasks, shared lists — but the pieces stayed separate, so a person still had to carry the plan in their head. The design in this database brings the pieces together and adds an AI that sorts, predicts, and explains, while keeping the user's data under the user's control.

Every record here is a design, never a real product. Public records are fact-checked, real, and legal-only; Signature records are the Signature original version of the same subject; speculative material is labeled design-study, never as fact. Photo tools work on the user's own photos only, never anyone else's private images.

This record grows out of that history directly: A morning plan rarely survives the afternoon, because new work arrives and old work slips. This record designs priorities that re-sort when the day changes, and it shows the user exactly why the order changed.
