AI Code Reader: Performance and Scale Limits

The AI Code Reader states its limits honestly: how many records it holds comfortably, how many requests it answers at once, how long a search takes on a full database, and what happens when those limits are reached. It never claims speed it has not measured, and it degrades gracefully — slower, never wrong — when loaded. This record gives the measured or honestly estimated limits, the test that measured them, and the plan for when growth outgrows them.
