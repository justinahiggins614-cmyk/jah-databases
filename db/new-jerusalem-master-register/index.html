Boundless generator

The generator below is seeded and deterministic, throttled to at most 100 records per call, duplicate-checked, and hard-stopped at 10^15 records. Every generated record is labeled src "generated". Open the page script to use window.NewJerusalemMasterRegisterTools.generateRecord(seed).

Validation engine

Each record is checked for a complete title, its own record kind, its own edition slug and id prefix, a status label, a text-faithful view kept distinct from its engineering view, a ladder rank, and a demo program whose expected output was produced by executing it.

Evidence links

Initial location: Revelation 21:9–27 and Revelation 22:1–5; Jerusalem, the originating place and source of the design brief. Every record links its quantities, materials, and tests to that brief and to the companion pairs in this suite.

Tool connections

Page tools are exposed as window.NewJerusalemMasterRegisterTools: search, generate, batch, validate, and runTests.

Testing suite

The generator's runTests suite checks record kind, slug, id prefix, src label, validation acceptance, duplicate rejection, batch throttling, and title search. Run it from the page script.
