Color Palette Generator Database (color-palette-generator-signature)

A colour palette generator makes colours that go together, from one starting colour: complements, analogues and triads, with real contrast ratios for every pair. The demo on this page uses real colour maths in the browser, with no server and no connection. Everything runs in this browser; no data leaves the page.
