# Color Palette Generator Database — files (color-palette-generator-signature)

- `demo-color-palette-generator-signature.py` — runnable demo program (run with `python3 demo-color-palette-generator-signature.py`).
- `color-palette-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/color-palette-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-color-palette-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
