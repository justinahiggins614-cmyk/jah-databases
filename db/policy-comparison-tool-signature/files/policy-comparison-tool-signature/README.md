# Policy Comparison Tool Database — files (policy-comparison-tool-signature)

- `demo-policy-comparison-tool-signature.py` — runnable demo program (run with `python3 demo-policy-comparison-tool-signature.py`).
- `policy-comparison-tool-signature-sample.txt` — a plain-text sample of the database.

- The generator is `gen-policy-comparison-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
