# Workflow Manager Database — files (workflow-manager)

- `demo-workflow-manager.py` — runnable demo program (run with `python3 demo-workflow-manager.py`).
- `workflow-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/workflow-manager/index.jsonl.gz` (24 records).
- The generator is `gen-workflow-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
