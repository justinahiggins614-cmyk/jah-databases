# Physics Simulator Database — files (physics-simulator)

- `demo-physics-simulator.py` — runnable demo program (run with `python3 demo-physics-simulator.py`).
- `physics-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/physics-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-physics-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
