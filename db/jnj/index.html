About this data base

Archive
This database’s signature product archive archive (JAH-JNJ- records), preserved as structured, searchable data.
Record schema
id · signature_name · alludes_to · class · category · specs{} · description · year
Classes
Class 1 — Signature versions of the company’s actual products (nominative reference only). Class 2 — original projected concepts; titles read “Class 2: …”.
Generator
jahdb-jnj-1.0 — deterministic, every record validated by an independent checker before acceptance.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent checker.
AI
JAH JNJ Creator — archive-aware creator. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
