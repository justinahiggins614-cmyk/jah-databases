# Chemistry Simulator Database — files (chemistry-simulator-signature)

- `demo-chemistry-simulator-signature.py` — runnable demo program (run with `python3 demo-chemistry-simulator-signature.py`).
- `chemistry-simulator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/chemistry-simulator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-chemistry-simulator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
