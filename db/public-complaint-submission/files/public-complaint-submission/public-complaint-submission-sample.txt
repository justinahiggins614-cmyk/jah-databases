Public Complaint Submission Database (public-complaint-submission)

A public complaint submission is a rule-based local demo: it reads set toy notes, and counts the marks. The submission reads 3 notes. The note pothole holds 24 marks. The largest holds 24 marks. Everything runs in this browser; no data leaves the page.
