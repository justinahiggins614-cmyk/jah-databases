# Flashcard Creator Database — files (flashcard-creator-signature)

- `demo-flashcard-creator-signature.py` — runnable demo program (run with `python3 demo-flashcard-creator-signature.py`).
- `flashcard-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/flashcard-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-flashcard-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
