# Email Subject Tester Database — files (email-subject-tester-signature)

- `demo-email-subject-tester-signature.py` — runnable demo program (run with `python3 demo-email-subject-tester-signature.py`).
- `email-subject-tester-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/email-subject-tester-signature/index.jsonl.gz` (24 records).
- The generator is `gen-email-subject-tester-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
