A Shared Shelf Anyone Can Browse Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A collection website: a community opens a shared shelf, members add items with a plain description and a credit to the person who added them, and anyone can browse the whole shelf. Every item is public, every addition is checked before it appears, and the shelf keeps a history of who added what and when. This record covers A Shared Shelf Anyone Can Browse.

A shared shelf anyone can browse is a shelf that belongs to the whole community, because a shelf that only a few can read is a shelf that only a few can love. The shelf should show every item, with its description and its credit, in plain words. Without a shelf anyone can browse, the collection is only a list kept by one person, and the community never sees what it owns together. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.
