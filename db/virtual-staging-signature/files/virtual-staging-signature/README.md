# Virtual Staging Database — files (virtual-staging-signature)

- `demo-virtual-staging-signature.py` — runnable demo program (run with `python3 demo-virtual-staging-signature.py`).
- `virtual-staging-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/virtual-staging-signature/index.jsonl.gz` (24 records).
- The generator is `gen-virtual-staging-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
