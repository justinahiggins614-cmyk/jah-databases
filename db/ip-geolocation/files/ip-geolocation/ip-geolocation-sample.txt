IP Geolocation Database (ip-geolocation)

An IP geolocation is a rule-based local demo: it reads set toy places, and counts the marks. The finder reads 3 places. The place north holds 16 marks. The largest holds 16 marks. Everything runs in this browser; no data leaves the page.
