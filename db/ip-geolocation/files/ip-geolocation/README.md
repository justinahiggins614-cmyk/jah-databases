# IP Geolocation Database — files (ip-geolocation)

- `demo-ip-geolocation.py` — runnable demo program (run with `python3 demo-ip-geolocation.py`).
- `ip-geolocation-sample.txt` — a plain-text sample of the database.
- The full database is `data/ip-geolocation/index.jsonl.gz` (24 records).
- The generator is `gen-ip-geolocation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
