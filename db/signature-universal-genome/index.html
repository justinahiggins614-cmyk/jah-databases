About this data base

Archive
This database's magazine archive (JAH-SUG- records): the Signature universal genome map — coordinate frame, locus typing, Signature-original genes, homology maps, and projections. Every record is the full entry, never a stub. Growing over time.
Record schema
id · name · title · description · magazine_name · publisher · founded · frequency · country · country_code · category · category_label · language · year · src · demo
Real vs sample
Seeded archive records with ✓ Public record are REAL magazines (Type 1 public info — name, founding year, publisher are public facts). Generated records are ✳ Signature-generated sample structural samples — never presented as real magazines.
Generator
jahdb-signature-universal-genome-1.0 — deterministic magazine-directory generator: same seed always makes the same sample listing. Every record validated by an independent checker before acceptance. Generated samples are always labeled, never real.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent checker.
Target
1,000,000 records. The archive marches toward the million mark with overload protection: 100-record chunks, lazy loading, and a collapsible per-category archive so no device ever renders everything at once.
AI
JAH Genome Cartographer — archive-aware, a genome specialist, and aware of the whole JAH Databases network through cross-database reasoning. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
