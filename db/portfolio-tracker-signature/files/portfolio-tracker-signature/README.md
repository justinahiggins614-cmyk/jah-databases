# Portfolio Tracker Database — files (portfolio-tracker-signature)

- `demo-portfolio-tracker-signature.py` — runnable demo program (run with `python3 demo-portfolio-tracker-signature.py`).
- `portfolio-tracker-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/portfolio-tracker-signature/index.jsonl.gz` (24 records).
- The generator is `gen-portfolio-tracker-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
