# Performance Profiler Database — files (performance-profiler)

- `demo-performance-profiler.py` — runnable demo program (run with `python3 demo-performance-profiler.py`).
- `performance-profiler-sample.txt` — a plain-text sample of the database.
- The full database is `data/performance-profiler/index.jsonl.gz` (24 records).
- The generator is `gen-performance-profiler.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
