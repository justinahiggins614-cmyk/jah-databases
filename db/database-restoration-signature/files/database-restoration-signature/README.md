# Database Restoration Database — files (database-restoration-signature)

- `demo-database-restoration-signature.py` — runnable demo program (run with `python3 demo-database-restoration-signature.py`).
- `database-restoration-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-restoration-signature/index.jsonl.gz` (24 records).
- The generator is `gen-database-restoration-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
