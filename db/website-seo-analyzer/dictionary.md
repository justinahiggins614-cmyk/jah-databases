# Dictionary entries — The Website SEO Analyzer Database

Key terms of this database, defined in plain words.

## analyzer

A program that reads a page and checks it against a written list of rules, reporting each check as passed or failed with the reason.

## title

The short line that names a page, shown in search results and in the browser's tab, which should say what the page is about.

## heading

A line that marks a part of a page, in order from the largest to the smallest, so that readers and crawlers can see the page's shape.

## description

The one or two sentences that sum up a page, shown beside its title in search results, which should be true and complete.

## link

A pointer from one page to another, which carries a reader and a crawler alike, and whose words should say where it leads.

## crawlable

Able to be visited and read by a crawler, which needs the page to answer, the robots file to allow it, and the links to work.

## speed

How quickly a page answers and finishes loading, which matters because slow pages are left unread and ranked lower.

## checklist

The written list of rules the analyzer checks, each with its own test, so that two runs of the same page give the same verdicts.

## verdict

The analyzer's word on one check: pass or fail, with the failing detail named in full, never a bare number.

## score

The share of checks a page passed, counted from the checklist, shown as a number beside the page, with the failures listed below it.

## recommendation

One fix named by the analyzer for one failed check, saying what to change and how to know the fix worked.

## ledger

The analyzer's own written record of every page checked, every verdict, and every score, kept in order.
