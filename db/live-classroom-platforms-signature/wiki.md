# The Live Classroom Platforms Database

The Live Classroom Platforms Database is the live classroom platforms record database in the Signature network. It holds 24 full live classroom platforms record records in the public edition and 24 in the Signature edition, in a teaching ladder of 8 simple, 8 compounded and 8 most complex records.

It expands the live database classroom-differentiation, which it links to and never rebuilds. The database carries the specification, models, test suites and verification records; it is not a running service.
