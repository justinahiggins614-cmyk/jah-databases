# Astronomy Calculator Database — files (astronomy-calculator)

- `demo-astronomy-calculator.py` — runnable demo program (run with `python3 demo-astronomy-calculator.py`).
- `astronomy-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/astronomy-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-astronomy-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
