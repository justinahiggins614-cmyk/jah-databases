Validation engine

Checks performed at build time on every record: schema (all required fields present and correctly typed), completeness (method, example, limits, and use all stated), consistency (fields, calculation, and demo output agree), and demo re-execution (demo program rerun, output compared byte for byte). Result: 16 of 16 records passed all four checks.

Evidence links

Each record carries an evidence object: descriptive sources (general methodology literature or a Signature design note — no single source is claimed as sole authority), supporting records (neighbouring records in this database), and a reproducible calculation matching its demo output. Evidence is rendered per record in the archive view through its fields, calculation, and demo output.

Tool connections

Client-side tools are exposed as window.AiResearchReproductionTools with searchRecords(query), generateRecord(seed), validateRecord(record), and runTests(), operating on the loaded records in this page. Static pages: no external service connection is claimed.

Testing suite

Build-time tests, all passing: retrieval (16 of 16 records load and parse), generation (generator run with --n 5 emits 5 deterministic records), verification (16 of 16 demo outputs match on re-execution), failure recovery (empty query returns all records; bad seed input is rejected by the generator parser; a malformed record line is skipped by the page loader without breaking the page).
