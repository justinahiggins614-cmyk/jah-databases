# Internal Website Search Database — files (internal-website-search)

- `demo-internal-website-search.py` — runnable demo program (run with `python3 demo-internal-website-search.py`).
- `internal-website-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/internal-website-search/index.jsonl.gz` (24 records).
- The generator is `gen-internal-website-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
