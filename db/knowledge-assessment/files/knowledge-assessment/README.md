# Knowledge Assessment Database — files (knowledge-assessment)

- `demo-knowledge-assessment.py` — runnable demo program (run with `python3 demo-knowledge-assessment.py`).
- `knowledge-assessment-sample.txt` — a plain-text sample of the database.
- The full database is `data/knowledge-assessment/index.jsonl.gz` (24 records).
- The generator is `gen-knowledge-assessment.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
