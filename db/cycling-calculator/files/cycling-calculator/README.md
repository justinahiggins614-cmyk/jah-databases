# Cycling Calculator Database — files (cycling-calculator)

- `demo-cycling-calculator.py` — runnable demo program (run with `python3 demo-cycling-calculator.py`).
- `cycling-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/cycling-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-cycling-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
