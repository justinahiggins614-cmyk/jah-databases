A First Goal Written in One Sentence Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

An achievement website: a person writes a goal in plain words, breaks it into small steps, and marks each step done as it happens. The tracker shows a simple count of finished steps and a streak of days with progress, and it keeps every note private to the person who wrote it. The tracker describes effort and progress only; it makes no health claim, gives no medical advice, and sets no target for any other person. This record covers A First Goal Written in One Sentence.

A first goal written in one sentence is a goal a person can remember: one line, in plain words, saying what will be done and by when. Without one sentence, a goal sprawls into a paragraph of wishes, and a person cannot tell whether it has been done or not. The sentence must name the result, not the effort, so the tracker can mark it finished on the day the result arrives. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.
