# Electrical Wiring Calculator Database — files (electrical-wiring-calculator)

- `demo-electrical-wiring-calculator.py` — runnable demo program (run with `python3 demo-electrical-wiring-calculator.py`).
- `electrical-wiring-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/electrical-wiring-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-electrical-wiring-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
