# CAD Designer Database — files (cad-designer)

- `demo-cad-designer.py` — runnable demo program (run with `python3 demo-cad-designer.py`).
- `cad-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/cad-designer/index.jsonl.gz` (24 records).
- The generator is `gen-cad-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
