DEF CON — Overview and history
Public edition. Public records, fact-checked reference. DEF CON is one of the world's largest and longest-running hacker conventions, held every summer in Las Vegas, Nevada, typically drawing around 30,000 attendees. It was founded in 1993 by Jeff Moss (known as The Dark Tangent) and is organized by the DEF CON Communications team. The convention features talks, hands-on Villages, contests, workshops, and Capture the Flag competitions, with a strong culture of defensive security research: many Villages teach defenders how to detect, harden, and respond, and the security community uses the event to advance responsible disclosure and public-interest security knowledge. In recent years the main venue has been the Las Vegas Convention Center West Hall.

DEF CON — Visiting, hours, and access
Public edition. Public records, fact-checked reference. DEF CON is open to the public; badges are sold at the door and online for the annual Las Vegas event each summer. Attendees should expect large crowds, long lines for popular Villages and contests, and a cash-friendly badge line tradition. First-time attendees are advised to review the published survival guides and the event code of conduct.

DEF CON — Support, careers, and community
Public edition. Public records, fact-checked reference. DEF CON is organized by a volunteer team (goons) plus community Village organizers. There is no traditional careers page; contributors join by volunteering, proposing talks and Villages, or participating in DEF CON Groups. Security professionals often cite DEF CON participation in resumes.
