About this data base

Archive
This database's game catalog (JAH-GAME records): 13 hand-built playable games plus a deterministic concept shelf marching to 1,000,000, computed live from the store's own catalog code.
Record schema
id · title · genre · era · concept · desc · controls · rules · win · difficulty · cover · ai
Generator
jahdb-games-1.0 — deterministic (mulberry32). Builds new concepts from the store's own genre/era/title/hook pools, ids above the 1M deterministic tail; an independent verifier rebuilds the title, description and cover-palette hash from the private pool indices.
Drift control
Every generated id must sit above the store's deterministic tail and must not collide with any archived record id.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Game Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
