# Scientific Graph Generator Database — files (scientific-graph-generator)

- `demo-scientific-graph-generator.py` — runnable demo program (run with `python3 demo-scientific-graph-generator.py`).
- `scientific-graph-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/scientific-graph-generator/index.jsonl.gz` (24 records).
- The generator is `gen-scientific-graph-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
