# AI Document Analyzer Database — files (ai-document-analyzer-signature)

- `demo-ai-document-analyzer-signature.py` — runnable demo program (run with `python3 demo-ai-document-analyzer-signature.py`).
- `ai-document-analyzer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-document-analyzer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-document-analyzer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
