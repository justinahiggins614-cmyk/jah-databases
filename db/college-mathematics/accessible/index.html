College Mathematics: Numbers and Sets

Record identifier: JAH-COLMATH-000001. Ladder rank: 1 of 24. Subject: numbers and sets.

A set is a collection of distinct objects, called its elements (the members of the collection). The natural numbers are 1, 2, 3, and so on; the integers add zero and the negatives; the rational numbers are fractions of integers; the real numbers fill in every point of a number line. A set is described by listing its elements or by a rule, and two sets are equal when they have exactly the same elements. The union of two sets holds everything in either set; the intersection holds only what is in both. The empty set, written with the symbol for an empty collection, has no elements at all and is a subset of every set. A subset is a set whose every element also belongs to a larger set. College Mathematics: Functions and Their Graphs

Record identifier: JAH-COLMATH-000002. Ladder rank: 2 of 24. Subject: functions and their graphs.

The graph of a function is the set of points (input, output) drawn in a plane, so the shape of the graph shows how the output changes as the input changes. The composition of two functions applies one after the other, and the inverse undoes the original where it exists. A function is increasing where larger inputs give larger outputs, and decreasing where they give smaller ones. College Mathematics: Logic and the Language of Proof

A counterexample is a single case that makes a universal claim false, and one counterexample is enough to disprove it. College Mathematics: Direct Proof and Proof by Contradiction

Record identifier: JAH-COLMATH-000004. Ladder rank: 4 of 24. Subject: proof by direct argument and by contradiction.

A direct proof starts from the assumptions and builds forward to the conclusion, one justified step at a time. A proof by contradiction assumes the opposite of what is to be proved and derives something impossible, which shows the assumption was false and the claim true. A direct proof of if P then Q assumes P and derives Q. A proof by contradiction assumes not Q together with P and derives a contradiction, such as 0 = 1 or a number being both even and odd. The square root of 2 is irrational: the classic proof by contradiction shows it cannot be written as a fraction of integers. College Mathematics: Mathematical Induction

Record identifier: JAH-COLMATH-000005. Ladder rank: 5 of 24. Subject: proof by induction.

Mathematical induction is a proof method for claims about all natural numbers. It has two steps: the base case, proving the claim for the first number (usually 1), and the inductive step, proving that if the claim holds for a number k, then it holds for k + 1. Together they prove the claim for every natural number, like a row of dominoes falling. The base case anchors the proof; without it, the inductive step proves nothing. The inductive hypothesis is the assumption that the claim holds for k, used to prove it for k + 1. Strong induction assumes the claim for all numbers up to k, which is sometimes needed. College Mathematics: Counting Permutations

Record identifier: JAH-COLMATH-000006. Ladder rank: 6 of 24. Subject: permutations and counting.

A permutation is an arrangement of objects in an order. Counting permutations answers how many ways objects can be ordered: if there are n distinct objects, there are n factorial (written n!, the product of all numbers from 1 to n) ways to arrange all of them, because the first place has n choices, the second n - 1, and so on. The product rule says: if one choice has a options and a second independent choice has b options, the pair has a times b options. The number of permutations of r objects chosen from n is n! / (n - r)!. Factorials grow very fast: 10! is 3,628,800. College Mathematics: Counting Combinations

Record identifier: JAH-COLMATH-000007. Ladder rank: 7 of 24. Subject: combinations and counting.

A combination is a choice of objects where order does not matter. The number of ways to choose r objects from n distinct objects is the binomial coefficient (written as n over r), equal to n! divided by r! times (n - r)!. It counts subsets, teams, and hands of cards. Choosing r objects from n is the same as choosing the n - r objects to leave out, so the counts are equal. The binomial coefficients are the entries of Pascal's triangle, where each entry is the sum of the two above it. The sum of all binomial coefficients for a fixed n is 2 to the power n, the number of subsets. College Mathematics: The Binomial Theorem

Record identifier: JAH-COLMATH-000008. Ladder rank: 8 of 24. Subject: the binomial theorem.

The binomial theorem says how to expand a power of a sum: (x + y) raised to the power n equals the sum over k from 0 to n of the binomial coefficient C(n, k) times x to the power n - k times y to the power k. Each term counts the ways to choose k of the n factors to contribute y. The coefficients in the expansion are the binomial coefficients, read from Pascal's triangle. Setting x = 1 and y = 1 gives the sum of the coefficients, 2 to the power n. Setting x = 1 and y = -1 gives the alternating sum, which is 0 for n greater than 0. Record identifier: JAH-COLMATH-000009. Ladder rank: 9 of 24. Subject: sequences and convergence.

Record identifier: JAH-COLMATH-000010. Ladder rank: 10 of 24. Subject: series and their sums.

College Mathematics: Real Numbers and Completeness

Record identifier: JAH-COLMATH-000011. Ladder rank: 11 of 24. Subject: real numbers and completeness.

College Mathematics: Relations and Equivalence

Record identifier: JAH-COLMATH-000013. Ladder rank: 13 of 24. Subject: relations and equivalence.

A relation on a set is a rule that says, for some pairs of elements, that the first is related to the second. An equivalence relation is a relation that is reflexive (every element is related to itself), symmetric (if a is related to b then b is related to a), and transitive (if a is related to b and b to c, then a is related to c). It splits the set into equivalence classes, groups of elements that are equivalent to each other. Equality is the finest equivalence relation: each class has one element. Congruence modulo n (two numbers are related when their difference is a multiple of n) splits the integers into n classes. A partial order is reflexive, antisymmetric, and transitive, and it ranks elements rather than grouping them. College Mathematics: The Pigeonhole Principle

Record identifier: JAH-COLMATH-000014. Ladder rank: 14 of 24. Subject: the pigeonhole principle.

The pigeonhole principle says: if more objects are put into fewer boxes than there are objects, then at least one box holds more than one object. The general form says that if n objects go into m boxes, some box holds at least the ceiling of n/m objects (the ceiling is the smallest whole number at least as large as the value). With 13 people, two share a birth month, because there are 12 months and 13 people. The principle proves existence only: it says a crowded box exists, not which one it is. It is a proof by contradiction in disguise: assuming every box holds at most one object contradicts the count. College Mathematics: Inclusion-Exclusion

Record identifier: JAH-COLMATH-000015. Ladder rank: 15 of 24. Subject: inclusion-exclusion counting.

Inclusion-exclusion is the method for counting a union of sets without double-counting: add the sizes of the sets, subtract the sizes of the pairwise intersections (the overlaps counted twice), add back the triple intersections (subtracted too many times), and continue alternating. It is the general form of the two-set union formula. For two sets, the union size is the sum of the sizes minus the intersection size. For three sets, add the three sizes, subtract the three pairwise intersections, and add the triple intersection. The principle also counts objects with none of several properties, by subtracting from the total. College Mathematics: The Language of Quantifiers

Record identifier: JAH-COLMATH-000017. Ladder rank: 17 of 24. Subject: quantifiers for all and there exists.

A quantifier says how many objects a statement is about. The universal quantifier, for all, says a statement holds for every object in the domain. The existential quantifier, there exists, says it holds for at least one object. Negating a quantified statement swaps the quantifier: the negation of for all is there exists a counterexample, and vice versa. To prove a for-all statement, take an arbitrary object and prove the claim for it. To prove a there-exists statement, exhibit one object and check it works. The order of quantifiers matters: for every x there is a y is not the same as there is a y for every x. Record identifier: JAH-COLMATH-000021. Ladder rank: 21 of 24. Subject: the greatest common divisor.

The greatest common divisor (GCD) of two integers is the largest integer that divides both of them. Euclid's algorithm finds it by repeated division with remainder: replace the pair (a, b) by (b, the remainder of a divided by b) until the remainder is zero; the last non-zero remainder is the GCD. Two numbers are coprime (relatively prime) when their GCD is 1. The GCD can be written as a combination a times x plus b times y for some integers x and y. The least common multiple of a and b is a times b divided by their GCD. College Mathematics: Numbers and Sets

// own demo, ported from Python), then a determinism check: the lines
// are hashed twice and the two digests must match.
'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
