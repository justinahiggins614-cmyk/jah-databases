  1. A Project Board Anyone Can Join

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    The collaborative projects platform is a public board where anyone can join a project: task lists with clear owners and dates, a shared file shelf, and a checklist before launch. A project board anyone can join gives every visitor a door into a project: the board shows what the project is, what needs doing, and who is already helping. The board needs to be public, so any visitor can read it without signing in, and it needs a welcome for new joiners, so a stranger can help without guessing. Without an open board, a project is a closed room, and the visitor who would have helped never finds the door. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.     History: People have always built things together in public, from barn raisings and parish projects to open workshops and community builds. The website form grows out of that history, adding a task list with clear owners, a file shelf with version history, and a checklist that every project passes before it is launched. Open project boards are an old habit of workshops and town halls, where a list of jobs on the wall invited anyone to help.
