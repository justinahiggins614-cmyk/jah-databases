This record covers A Project Board Anyone Can Join.

A project board anyone can join gives every visitor a door into a project: the board shows what the project is, what needs doing, and who is already helping. The board needs to be public, so any visitor can read it without signing in, and it needs a welcome for new joiners, so a stranger can help without guessing. This record covers A Fair-Play System Against Spam and Harassment.

Spam and harassment are the two poisons of a project platform: spam fills the boards with noise, and harassment drives members away. A fair-play system needs to notice when posts arrive too fast, when the same words appear in many posts, and when a member is being targeted.
