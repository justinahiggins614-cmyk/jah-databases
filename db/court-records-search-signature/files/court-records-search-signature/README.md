# Court Records Search Database — files (court-records-search-signature)

- `demo-court-records-search-signature.py` — runnable demo program (run with `python3 demo-court-records-search-signature.py`).
- `court-records-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/court-records-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-court-records-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
