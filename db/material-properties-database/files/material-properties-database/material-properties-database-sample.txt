Material Properties Database Database (material-properties-database)

A material properties database holds plain reference values for common materials and the arithmetic that uses them. Type a material, press Look Up, and read the value. A steel block of 78.5 kilograms in 0.01 cubic metres has density 7850 kilograms per cubic metre. A push of 10000 newtons on 0.0001 square metres gives stress 100 megapascals. Heating 2 kilograms of steel by 50 degrees takes 45000 joules. Everything runs in this browser; no data leaves the page.
