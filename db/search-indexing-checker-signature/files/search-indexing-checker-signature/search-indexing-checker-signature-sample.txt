Search Indexing Checker Database (search-indexing-checker-signature)

A search indexing checker is a rule-based local demo: it checks set toy pages, and counts the marks. The checker reads 3 pages. The page alpha holds 33 marks. The largest holds 33 marks. Everything runs in this browser; no data leaves the page.
