About this data base

Archive
This database's fix-it archive: step-by-step fix guides with symptoms, diagnosis, and ranked solutions across 12 repair fields (JAH-FIX records), preserved as structured, searchable data.
Record schema
id · type · field · field_id · title · symptoms[] · diagnosis[] · solutions[{rank,kind,title,steps[],difficulty,time,cost,tools[],parts[]}] · safety · warnings[] · difficulty · content_hash · created · status · version · stamp
Generator
jahdb-fixit-1.0 — deterministic (mulberry32). Builds each guide constructively from real field vocab (devices, problems, tools, parts), then an independent re-builder reconstructs every derived field from the raw picks to verify the record.
Drift control
Every generated title is checked against an archive sample for exact duplicates and re-verified by the independent re-builder.
Cross-database
The generator can borrow a theme from any of the other 36 databases when you tick the box.
AI
JAH Fix-It Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
