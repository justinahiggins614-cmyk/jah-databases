# Web Crawler Database — files (web-crawler)

- `demo-web-crawler.py` — runnable demo program (run with `python3 demo-web-crawler.py`).
- `web-crawler-sample.txt` — a plain-text sample of the database.
- The full database is `data/web-crawler/index.jsonl.gz` (24 records).
- The generator is `gen-web-crawler.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
