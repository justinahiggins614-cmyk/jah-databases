# Distance Calculator Database — files (distance-calculator-signature)

- `demo-distance-calculator-signature.py` — runnable demo program (run with `python3 demo-distance-calculator-signature.py`).
- `distance-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/distance-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-distance-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
