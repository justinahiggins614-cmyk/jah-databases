Distance Calculator Database (distance-calculator-signature)

A distance calculator is a rule-based local demo: it measures the gap between set toy points, and counts the steps. The calculator measures 2 points. The point is 3, 4. The distances add to 28 in total. Everything runs in this browser; no data leaves the page.
