# Code Documentation Generator Database — files (code-documentation-generator)

- `demo-code-documentation-generator.py` — runnable demo program (run with `python3 demo-code-documentation-generator.py`).
- `code-documentation-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-documentation-generator/index.jsonl.gz` (24 records).
- The generator is `gen-code-documentation-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
