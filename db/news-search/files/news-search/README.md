# News Search Database — files (news-search)

- `demo-news-search.py` — runnable demo program (run with `python3 demo-news-search.py`).
- `news-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/news-search/index.jsonl.gz` (24 records).
- The generator is `gen-news-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
