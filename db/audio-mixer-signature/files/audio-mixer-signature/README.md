# Audio Mixer Database — files (audio-mixer-signature)

- `demo-audio-mixer-signature.py` — runnable demo program (run with `python3 demo-audio-mixer-signature.py`).
- `audio-mixer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-mixer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-audio-mixer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
