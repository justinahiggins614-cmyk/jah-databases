Geocoding Tool Database (geocoding-tool)

A geocoding tool is a rule-based local demo: it turns set toy addresses into set toy codes, and counts the addresses. The tool turns 3 addresses. The address main holds code 120. The largest holds 120 codes. Everything runs in this browser; no data leaves the page.
