Security Monitoring Database (security-monitoring)

Security monitoring is a defensive local demo: it watches event lines, counts the failures, and raises an alert past a limit. 3 of 5 events are failures. 3 failures past a limit of 2 raise an alert: True. 2 of 5 logins failed. Everything runs in this browser; no data leaves the page.
