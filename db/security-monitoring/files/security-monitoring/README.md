# Security Monitoring Database — files (security-monitoring)

- `demo-security-monitoring.py` — runnable demo program (run with `python3 demo-security-monitoring.py`).
- `security-monitoring-sample.txt` — a plain-text sample of the database.
- The full database is `data/security-monitoring/index.jsonl.gz` (24 records).
- The generator is `gen-security-monitoring.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
