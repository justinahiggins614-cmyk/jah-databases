Transformer Architecture Explorer Database (transformer-architecture-explorer)

A transformer architecture explorer is a rule-based local demo: it explores set toy architectures, and counts the marks. The explorer reads 3 architectures. The architecture alpha holds 90 marks. The largest holds 90 marks. Everything runs in this browser; no data leaves the page.
