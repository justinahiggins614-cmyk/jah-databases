# 3D Graphing Tool Database — files (3d-graphing-tool)

- `demo-3d-graphing-tool.py` — runnable demo program (run with `python3 demo-3d-graphing-tool.py`).
- `3d-graphing-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/3d-graphing-tool/index.jsonl.gz` (24 records).
- The generator is `gen-3d-graphing-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
