3D Graphing Tool Database (3d-graphing-tool)

A 3D graphing tool draws points, lines and surfaces in three dimensions: type a point, press Draw, and read the graph. A 3D point has three numbers: (1, 2, 3). The point (1, 2, 3) is 3.74 from the origin. A cube of side 3 has volume 27. Everything runs in this browser; no data leaves the page.

Worked example: A 3D point has three numbers: (1, 2, 3)
