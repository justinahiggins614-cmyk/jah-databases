# Math Tutor Database — files (math-tutor)

- `demo-math-tutor.py` — runnable demo program (run with `python3 demo-math-tutor.py`).
- `math-tutor-sample.txt` — a plain-text sample of the database.
- The full database is `data/math-tutor/index.jsonl.gz` (24 records).
- The generator is `gen-math-tutor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
