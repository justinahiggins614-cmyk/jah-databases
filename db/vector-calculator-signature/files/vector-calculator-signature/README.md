# Vector Calculator Database — files (vector-calculator-signature)

- `demo-vector-calculator-signature.py` — runnable demo program (run with `python3 demo-vector-calculator-signature.py`).
- `vector-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/vector-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-vector-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
