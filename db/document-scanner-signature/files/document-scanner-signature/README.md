# Document Scanner Database — files (document-scanner-signature)

- `demo-document-scanner-signature.py` — runnable demo program (run with `python3 demo-document-scanner-signature.py`).
- `document-scanner-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/document-scanner-signature/index.jsonl.gz` (24 records).
- The generator is `gen-document-scanner-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
