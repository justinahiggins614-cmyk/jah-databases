# Dictionary entries — The Patent Filing Assistance Database

Key terms of this database, defined in plain words.

## patent filing assistance

The recorded help given to an inventor about the published requirements for filing a patent application, so that the papers, the fees, and the steps can be read in plain view.

## patent

The written grant from a public office that gives an inventor exclusive rights in an invention for a stated term, kept in the record so that what was granted can be read plainly.

## patent application

The written request for a patent, naming the invention and its inventor, kept with the papers it carries, so that the request and its papers can be read together.

## invention

A new device, process, or improvement named in a patent application, written in the record so that what was invented can be read plainly.

## claim

The written statement in a patent application that defines what the inventor seeks to protect, kept in the record so that the scope can be read in full.

## specification

The written description of an invention in a patent application, kept in the record so that how the invention works can be read in full.

## inventor

The person who made the invention named in a patent application, written in the record so that who invented can be traced to the paper.

## patent office

The public office that receives patent applications and grants patents, named in the record with the application, so that where the papers were filed can be read plainly.

## prior art

The published knowledge that existed before an invention, named in the record so that what came before can be read plainly.

## prosecution

The published process by which a patent application is examined and answered, kept in the record so that each step can be followed.

## filing date

The date on which a patent application was filed, written in the record with the application, so that the day of filing can be read plainly.

## assistance letter

The written note sent after patent filing assistance is given, naming the invention, the requirements discussed, and the answers given, so that the help can be proved from the paper.
