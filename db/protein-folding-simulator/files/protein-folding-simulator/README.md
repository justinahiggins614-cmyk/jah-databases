# Protein Folding Simulator Database — files (protein-folding-simulator)

- `demo-protein-folding-simulator.py` — runnable demo program (run with `python3 demo-protein-folding-simulator.py`).
- `protein-folding-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/protein-folding-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-protein-folding-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
