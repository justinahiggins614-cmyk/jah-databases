  1. Anonymous Posts With a Public Moderation Log

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    The anonymous discussion platform lets anyone post without a name, while moderation stays public: written rules, a queue anyone can audit, and no private messages. An anonymous post with a public moderation log lets anyone speak without a name while everyone can see how the speaking is governed. The log shows every action: what was removed, why it was removed, and which rule it broke, so anonymity never becomes a hiding place for harm. Without a public log, anonymous posts are moderated in secret, and the readers must take the moderators' word for everything, which is no basis for trust. Worked example: in a website built this way, anonymous posts with a public moderation log runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

    History: Anonymous discussion is an old public habit: a letter to a newspaper signed with a pen name, a note pinned to a board with no name on it, a question asked aloud in a hall. The website form grows out of that habit, adding a moderation queue that anyone can audit and rules that are written down before the first post is made. Public moderation logs grew out of the old habit of posting the rules and the punishments where everyone could read them.
