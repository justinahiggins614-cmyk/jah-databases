Soil Analysis Database (soil-analysis)

A soil analysis is a rule-based local demo: it analyzes set toy samples, and counts the marks. Sample-data analysis only: no cultivation how-to, no grow schedules, no yield instructions. Sample data only, no real soil is read. The analyzer reads 3 samples. The sample alpha holds 198 marks. The largest holds 198 marks. Everything runs in this browser; no data leaves the page.
