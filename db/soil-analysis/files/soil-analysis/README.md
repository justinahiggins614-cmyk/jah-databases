# Soil Analysis Database — files (soil-analysis)

- `demo-soil-analysis.py` — runnable demo program (run with `python3 demo-soil-analysis.py`).
- `soil-analysis-sample.txt` — a plain-text sample of the database.
- The full database is `data/soil-analysis/index.jsonl.gz` (24 records).
- The generator is `gen-soil-analysis.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
