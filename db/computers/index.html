About this data base

Archive
This database's computer systems archive (JAH-PC records) — historic, signature, modern, predicted, mixes, materials, quantum, and generated systems — preserved as structured, searchable data.
Record schema
id · slug · name · system_type · category · design_family · summary · specs{form, cpu, ram_gb, storage, year} · note · stamp
Generator
jahdb-computers-1.0 — deterministic (mulberry32), assembles each system from name and spec pools, then an independent verifier rebuilds the name, summary, and every spec from the private pool indices before acceptance.
Drift control
Every generated system is checked against an archive sample for duplicate names and re-verified by the independent verifier.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Systems Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
