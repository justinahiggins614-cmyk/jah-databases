Website Archive Viewer Database (website-archive-viewer)

A website archive viewer is a rule-based local demo: it views set toy snapshots, and counts the marks. The viewer reads 3 snapshots. The snapshot alpha holds 45 marks. The largest holds 45 marks. Everything runs in this browser; no data leaves the page.
