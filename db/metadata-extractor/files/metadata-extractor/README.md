# Metadata Extractor Database — files (metadata-extractor)

- `demo-metadata-extractor.py` — runnable demo program (run with `python3 demo-metadata-extractor.py`).
- `metadata-extractor-sample.txt` — a plain-text sample of the database.
- The full database is `data/metadata-extractor/index.jsonl.gz` (24 records).
- The generator is `gen-metadata-extractor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
