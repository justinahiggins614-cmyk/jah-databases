# Property Tax Calculator Database — files (property-tax-calculator)

- `demo-property-tax-calculator.py` — runnable demo program (run with `python3 demo-property-tax-calculator.py`).
- `property-tax-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/property-tax-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-property-tax-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
