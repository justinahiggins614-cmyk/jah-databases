# Checklist Creator Database — files (checklist-creator)

- `demo-checklist-creator.py` — runnable demo program (run with `python3 demo-checklist-creator.py`).
- `checklist-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/checklist-creator/index.jsonl.gz` (24 records).
- The generator is `gen-checklist-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
