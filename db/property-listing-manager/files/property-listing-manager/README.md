# Property Listing Manager Database — files (property-listing-manager)

- `demo-property-listing-manager.py` — runnable demo program (run with `python3 demo-property-listing-manager.py`).
- `property-listing-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/property-listing-manager/index.jsonl.gz` (24 records).
- The generator is `gen-property-listing-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
