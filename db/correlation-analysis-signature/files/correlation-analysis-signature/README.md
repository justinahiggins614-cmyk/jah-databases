# Correlation Analysis Database — files (correlation-analysis-signature)

- `demo-correlation-analysis-signature.py` — runnable demo program (run with `python3 demo-correlation-analysis-signature.py`).
- `correlation-analysis-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/correlation-analysis-signature/index.jsonl.gz` (24 records).
- The generator is `gen-correlation-analysis-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
