Decentralized Application Builder Database (decentralized-application-builder-signature)

A decentralized application builder is a rule-based local demo: it reads set toy apps, and counts the marks. The builder reads 3 apps. The app alpha holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
