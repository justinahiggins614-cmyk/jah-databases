# SSL Expiration Checker Database — files (ssl-expiration-checker)

- `demo-ssl-expiration-checker.py` — runnable demo program (run with `python3 demo-ssl-expiration-checker.py`).
- `ssl-expiration-checker-sample.txt` — a plain-text sample of the database.
- The full database is `data/ssl-expiration-checker/index.jsonl.gz` (24 records).
- The generator is `gen-ssl-expiration-checker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
