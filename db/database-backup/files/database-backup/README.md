# Database Backup Database — files (database-backup)

- `demo-database-backup.py` — runnable demo program (run with `python3 demo-database-backup.py`).
- `database-backup-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-backup/index.jsonl.gz` (24 records).
- The generator is `gen-database-backup.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
