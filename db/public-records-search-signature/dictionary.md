# Dictionary entries — The Public Records Search Database

Key terms of this database, defined in plain words.

## public records search

The recorded searching of the records a government has made open, holding the query, the results, and the citations together, so that what was found can be read and proved.

## search query

The written words used to search a public records index, kept with the search so that the question asked can be read beside the answers found.

## record index

The ordered list of the public records held by an archive, naming each record, so that any record can be found without reading the whole store.

## record citation

The written reference naming a public record by its archive, its series, and its number, so that the record can be found again by anyone.

## access note

The written note naming whether a public record is open or closed, kept with the record so that the terms of access can be read beside the record.

## redaction note

The written note naming the parts of a public record that have been hidden, kept with the copy so that what was hidden can be read as a gap and not as a missing page.

## archive request

The written request sent to an archive for a copy of a public record, naming the record and the requester, kept with the reply so that the asking and the answer can be read together.

## search result

One record found by a public records search, named with its citation, so that what the search found can be counted and checked.

## digital copy

A copy of a public record made in digital form, kept beside the citation of the original, so that the record can be read without handling the paper.

## paper original

The paper record itself as kept in the archive, named by its citation, so that the copy can be checked against the original it came from.

## public notice

The written notice a government publishes to tell the public of a decision or a meeting, kept in the record so that the notice can be read as it was published.

## search log

The ordered list of the searches made in a public records index, kept by date, so that every search can be found and followed.
