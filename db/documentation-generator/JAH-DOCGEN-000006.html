Documentation Generator: Command Line and Batch Use

JAH-DOCGEN-000006 — documentation generator record

The Documentation Generator also works from the command line and in batches: the same job the screen does can be run without a screen, one item at a time or many at once, so that repeated work can be scripted and scheduled. Batch runs read their input from a file, write their results to a file, and report a summary line for every item — passed, failed, or held — so that a run of a thousand items is as checkable as a run of one.
