Documentation Generator: Versioning and Change History

JAH-DOCGEN-000022 — documentation generator record

The Documentation Generator is versioned: every change gets a version number, a date, and a note saying what changed and why, and old versions stay readable so that past results can still be understood. A new version never silently changes an old answer: where behaviour changes, the change is stated in the version note and the old behaviour is kept available until the next major version. This record specifies the versioning rules and the current version. In this public edition the program offers 8 capabilities (generating full documentation from code and a specification (1); defining every technical term on first use (2); documenting every interface with inputs and outputs (3); listing every test with what it proves (4); a glossary of every term the document uses (5); plain-text documentation readable without JavaScript (6); an API other programs use to generate documentation (7); re-generating docs when the program changes (8)), 6 interfaces (Document form — program name, purpose, interfaces, and tests; Section list — every section the document will hold; Document view — the full document, readable and downloadable; Glossary view — every term defined in plain words; Generator API — machine-readable documentation generation for other programs; Plain-text mode — the document as readable plain text), and 8 data fields (program — the program documented; purpose — its purpose in plain words; interfaces — every interface with inputs and outputs; terms — every technical term defined; tests — every test with what it proves; glossary — the glossary of terms used; generated_date — the date the document was generated; version — the program version documented).
