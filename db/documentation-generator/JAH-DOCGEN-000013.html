Documentation Generator: Export: Taking Data Out

JAH-DOCGEN-000013 — documentation generator record

The Documentation Generator takes data out: it exports its records as plain text, JSON, or JSONL, so that the data can be read, checked, and used anywhere without the program itself. An export includes the record's full content — never a summary, never a bare name — plus its source and its date, so that exported data stays checkable after it leaves. This record specifies the export formats, what each one includes, and how an export is verified complete. In this public edition the program offers 8 capabilities (generating full documentation from code and a specification (1); defining every technical term on first use (2); documenting every interface with inputs and outputs (3); listing every test with what it proves (4); a glossary of every term the document uses (5); plain-text documentation readable without JavaScript (6); an API other programs use to generate documentation (7); re-generating docs when the program changes (8)), 6 interfaces (Document form — program name, purpose, interfaces, and tests; Section list — every section the document will hold; Document view — the full document, readable and downloadable; Glossary view — every term defined in plain words; Generator API — machine-readable documentation generation for other programs; Plain-text mode — the document as readable plain text), and 8 data fields (program — the program documented; purpose — its purpose in plain words; interfaces — every interface with inputs and outputs; terms — every technical term defined; tests — every test with what it proves; glossary — the glossary of terms used; generated_date — the date the document was generated; version — the program version documented). This record is number 13 of 24 in the public edition of the Documentation Generator database pair, and it specifies the export: taking data out topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
