Documentation Generator: Logging and Audit Trail

JAH-DOCGEN-000011 — documentation generator record

The Documentation Generator keeps a log: every important action is written down with its date, who or what did it, what went in, and what came out, so that any result can be traced back to its cause. The log is append-only — entries are added, never rewritten — and it is readable as plain text. This record specifies what is logged, what is never logged (keys, secrets, and personal data are never written to a log), and how long entries are kept. In this public edition the program offers 8 capabilities (generating full documentation from code and a specification (1); defining every technical term on first use (2); documenting every interface with inputs and outputs (3); listing every test with what it proves (4); a glossary of every term the document uses (5); plain-text documentation readable without JavaScript (6); an API other programs use to generate documentation (7); re-generating docs when the program changes (8)), 6 interfaces (Document form — program name, purpose, interfaces, and tests; Section list — every section the document will hold; Document view — the full document, readable and downloadable; Glossary view — every term defined in plain words; Generator API — machine-readable documentation generation for other programs; Plain-text mode — the document as readable plain text), and 8 data fields (program — the program documented; purpose — its purpose in plain words; interfaces — every interface with inputs and outputs; terms — every technical term defined; tests — every test with what it proves; glossary — the glossary of terms used; generated_date — the date the document was generated; version — the program version documented). This record is number 11 of 24 in the public edition of the Documentation Generator database pair, and it specifies the logging and audit trail topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
