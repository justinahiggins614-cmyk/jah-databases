# AI Database Creator Database — files (ai-database-creator-signature)

- `demo-ai-database-creator-signature.py` — runnable demo program (run with `python3 demo-ai-database-creator-signature.py`).
- `ai-database-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-database-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-database-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
