Section 1: Description and history

Signature edition: Manon's own original version of every record in this database. Bounding boxes for Manon's signature: widths, heights, aspect ratios, areas, and centers for the whole signature and each of its seven parts. Twenty-four full records, ordered simple to compounded to complex, each written in human-readable sentences and paragraphs, each carrying a history and description, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, a scientific equation, a proof sketch, a runnable demo program, and two named specialist AIs.

Manon ordered the Signature system to measure his signature more accurately, as an alternative measurement system, as close to atom scale as can be, and to do it many ways, with a website and databases for each way. This site is the Bounding Box way, built from his uploaded signature file on 2026-11-23. The signature file is 1,536 by 1,024 pixels; the ink is 37,277 pixels, 2.370 percent of the image; the ink box is 1,257 by 480 pixels from (137, 255) to (1393, 734); there are 7 connected components, 1,505 horizontal ink runs with a median of 23 pixels and a maximum of 80 pixels.

Section 2: Math proof

Box area = width x height = 1,257 x 480 = 603,360 px^2. Aspect ratio = width / height = 1,257 / 480 = 2.6188. Center = ((137+1,393)/2, (255+734)/2) = (765, 494.5).

box(part) = [min x, max x] x [min y, max y]; area = width x height.

Section 3: Science proof

A bounding box is the smallest axis-aligned rectangle holding a set of ink pixels. It is the standard frame of binary image measurement, and it is read directly from the counted extremes of the ink.
