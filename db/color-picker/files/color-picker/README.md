# Color Picker Database — files (color-picker)

- `demo-color-picker.py` — runnable demo program (run with `python3 demo-color-picker.py`).
- `color-picker-sample.txt` — a plain-text sample of the database.
- The full database is `data/color-picker/index.jsonl.gz` (24 records).
- The generator is `gen-color-picker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
