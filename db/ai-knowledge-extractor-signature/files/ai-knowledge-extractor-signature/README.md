# AI Knowledge Extractor Database — files (ai-knowledge-extractor-signature)

- `demo-ai-knowledge-extractor-signature.py` — runnable demo program (run with `python3 demo-ai-knowledge-extractor-signature.py`).
- `ai-knowledge-extractor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-knowledge-extractor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-knowledge-extractor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
