# AI App Builder Database — files (ai-app-builder)

- `demo-ai-app-builder.py` — runnable demo program (run with `python3 demo-ai-app-builder.py`).
- `ai-app-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-app-builder/index.jsonl.gz` (24 records).
- The generator is `gen-ai-app-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
