# Water Consumption Calculator Database — files (water-consumption-calculator-signature)

- `demo-water-consumption-calculator-signature.py` — runnable demo program (run with `python3 demo-water-consumption-calculator-signature.py`).
- `water-consumption-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/water-consumption-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-water-consumption-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
