# Promotional Pricing Calculator Database — files (promotional-pricing-calculator)

- `demo-promotional-pricing-calculator.py` — runnable demo program (run with `python3 demo-promotional-pricing-calculator.py`).
- `promotional-pricing-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/promotional-pricing-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-promotional-pricing-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
