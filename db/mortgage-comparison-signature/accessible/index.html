Accessible version: plain text, no scripts, no sign-in, free forever. A mortgage comparison is a rule-based local demo: it reads set toy loans, and counts the marks. The comparison reads 3 loans. The loan fixed holds 45 marks. The largest holds 45 marks. Everything runs in this browser; no data leaves the page.
