The Qubit and Superposition JAH-FUQ-000001 · simple

A qubit is the basic unit of quantum information.

A qubit is the basic unit of quantum information. Unlike a classical bit, which is 0 or 1, a qubit can exist in a superposition of both states at once, described by amplitudes whose squared magnitudes give the measurement probabilities. Superposition is what lets a quantum computer explore many possibilities in parallel, though reading the result collapses the state to a single outcome.

Working demo program

import math
amps = [0.6, 0.8]
norm = math.sqrt(sum(a * a for a in amps))
probs = [(a / norm) ** 2 for a in amps]
print('Amplitudes: %s' % amps)
print('Norm: %.4f' % norm)
for i, pr in enumerate(probs):
    print('State %d probability: %.4f' % (i, pr))
print('Total probability: %.4f' % sum(probs))

Demo output

Entanglement and Bell Pairs JAH-FUQ-000002 · simple

Entanglement links two qubits so that measuring one instantly constrains the other, even at a distance.

Entanglement links two qubits so that measuring one instantly constrains the other, even at a distance. A Bell pair is the simplest entangled state: (|00> + |11>)/sqrt(2), in which the two qubits always agree when measured in the same basis. Bell tests beginning with Aspect in 1982, and the 2022 Nobel Prize work of Aspect, Clauser and Zeilinger, confirmed that no local hidden-variable theory explains these correlations.

Working demo program

probs = {'00': 0.5, '01': 0.0, '10': 0.0, '11': 0.5}
print('Bell state |Phi+> = (|00> + |11>) / sqrt(2)')
for k, v in probs.items():
    print('Outcome %s probability: %.2f' % (k, v))
print('Correlated outcomes (00 or 11): %.2f' % (probs['00'] + probs['11']))

Quantum Gates: Hadamard and CNOT JAH-FUQ-000003 · simple

Quantum gates rotate qubit states instead of flipping bits.

Quantum gates rotate qubit states instead of flipping bits. The Hadamard gate turns |0> into an equal superposition (|0> + |1>)/sqrt(2), and the CNOT gate flips a target qubit only when its control qubit is |1>, which is how entanglement is created in a circuit. Every quantum algorithm is a sequence of such gates followed by measurement.

Grover's Search Algorithm JAH-FUQ-000004 · intermediate

Grover's algorithm, published by Lov Grover in 1996, searches an unstructured database of N items in about (pi/4)sqrt(N) steps, a quadratic speedup over the classical average of N/2 checks.

Grover's algorithm, published by Lov Grover in 1996, searches an unstructured database of N items in about (pi/4)sqrt(N) steps, a quadratic speedup over the classical average of N/2 checks. It works by amplifying the amplitude of the marked item and suppressing the rest. The speedup is quadratic, not exponential, and it needs a working quantum computer at the size of the search space.

Working demo program

import math
N = 1000000
iters = round(math.pi / 4 * math.sqrt(N))
classical = N // 2
print('Search space: %d items' % N)
print('Grover iterations: %d' % iters)
print('Classical average checks: %d' % classical)
print('Speedup factor: %.1f' % (classical / iters))

Demo output

Speedup factor: 636.9

Source

Grover, Proceedings of STOC (1996); Nielsen and Chuang (2010), as published October 2026.

Shor's Factoring Algorithm JAH-FUQ-000005 · advanced

Shor's algorithm, published by Peter Shor in 1994, factors large integers in polynomial time, which would break the RSA encryption that protects much of the internet.

Shor's algorithm, published by Peter Shor in 1994, factors large integers in polynomial time, which would break the RSA encryption that protects much of the internet. It works by finding the period of a modular function with a quantum Fourier transform. Factoring a 2048-bit RSA key would need thousands of logical qubits and millions of physical qubits, far beyond any machine built so far, which is why post-quantum cryptography is being standardized now.

Quantum Error Correction and the Surface Code JAH-FUQ-000006 · intermediate

Quantum states are fragile: noise flips qubits and destroys superpositions.

Quantum states are fragile: noise flips qubits and destroys superpositions. Quantum error correction spreads one logical qubit over many physical qubits, so errors can be detected and fixed without measuring the data itself. The surface code is the leading scheme, and in 2022-2023 Google and others demonstrated logical qubits whose error rate falls as the code distance grows, the key milestone on the road to fault tolerance.

Fault Tolerance and Error Thresholds JAH-FUQ-000007 · advanced

Fault tolerance means a quantum computer can run arbitrarily long computations despite imperfect parts, provided the physical error rate sits below a threshold.

Fault tolerance means a quantum computer can run arbitrarily long computations despite imperfect parts, provided the physical error rate sits below a threshold. For the surface code the threshold is around 1% error per operation: below it, larger codes suppress errors exponentially. Current hardware is approaching that threshold, but no machine has yet run a large fault-tolerant algorithm.
