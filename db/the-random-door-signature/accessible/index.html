The Signature The Random Door Database

Accessible version: plain text, no scripts, no sign-in, free forever. The random door is one door that opens onto somewhere new each time: a beach, a library, a garden, a bakery, each place described in plain words so a visitor can step through in imagination. Every door is a clearly labeled design study, never a claim about a real place.

Twenty-four full records, ordered simple to compounded to complex.
