# Expense Tracker Database — files (expense-tracker)

- `demo-expense-tracker.py` — runnable demo program (run with `python3 demo-expense-tracker.py`).
- `expense-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/expense-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-expense-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
