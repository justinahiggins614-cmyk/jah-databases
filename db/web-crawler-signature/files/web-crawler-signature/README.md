# Web Crawler Database — files (web-crawler-signature)

- `demo-web-crawler-signature.py` — runnable demo program (run with `python3 demo-web-crawler-signature.py`).
- `web-crawler-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/web-crawler-signature/index.jsonl.gz` (24 records).
- The generator is `gen-web-crawler-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
