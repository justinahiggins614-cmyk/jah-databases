# QR Code Designer Database — files (qr-code-designer)

- `demo-qr-code-designer.py` — runnable demo program (run with `python3 demo-qr-code-designer.py`).
- `qr-code-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/qr-code-designer/index.jsonl.gz` (24 records).
- The generator is `gen-qr-code-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
