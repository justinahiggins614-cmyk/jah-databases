# Data Sampling Database — files (data-sampling)

- `demo-data-sampling.py` — runnable demo program (run with `python3 demo-data-sampling.py`).
- `data-sampling-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-sampling/index.jsonl.gz` (24 records).
- The generator is `gen-data-sampling.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
