# AI Tutor Database — files (ai-tutor-signature)

- `demo-ai-tutor-signature.py` — runnable demo program (run with `python3 demo-ai-tutor-signature.py`).
- `ai-tutor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-tutor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-tutor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
