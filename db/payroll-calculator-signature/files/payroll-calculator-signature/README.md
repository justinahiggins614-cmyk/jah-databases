# Payroll Calculator Database — files (payroll-calculator-signature)

- `demo-payroll-calculator-signature.py` — runnable demo program (run with `python3 demo-payroll-calculator-signature.py`).
- `payroll-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/payroll-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-payroll-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
