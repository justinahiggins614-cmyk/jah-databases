Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

An event website: each event has a written schedule, a public guest list, and a discussion room where guests talk before the event and share notes after it. Events are public, with no private messages anywhere on the site, and every event has written rules and a public moderation log. This record covers An Event With a Written Schedule.

An event with a written schedule is an event people can attend, because a guest who knows the hour, the length, and the order of the day can plan around it. The schedule should name each part of the event, the time it starts, and how long it lasts. Without a written schedule, guests arrive at the wrong hour, miss the part they came for, and do not come back. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.
