  1. An Event With a Written Schedule

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    Online event communities gather people around events they attend together online: a shared schedule, a public guest list, and a room where the event is talked about before and after. An event with a written schedule is an event people can attend, because a guest who knows the hour, the length, and the order of the day can plan around it. The schedule should name each part of the event, the time it starts, and how long it lasts. Without a written schedule, guests arrive at the wrong hour, miss the part they came for, and do not come back. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design. Worked example: in a website built this way, an event with a written schedule runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

    History: People have always gathered for events, from fairs and lectures to concerts and classes. The website form grows out of that history, adding a shared schedule anyone can read, a public guest list, and a room where the event is talked about before and after. Writing the schedule down is an old habit of every good event, from the fair's program to the lecture's timetable.

    Proposed solution: Name the event circle and what a visitor does in it; Write the rules in plain sentences a new visitor can follow; Give every event circle the same fair start: the same clues, the same time, the same scoring; Let a visitor try one event circle without signing in; Check the event circle works the same way on a phone and on a computer.

    Dependencies: What must exist first: an event schedule, a public guest list, a discussion room per event, and a public moderation log. Nothing else is needed to open the first event circle.

  13. Event Suggestions That Match Guests to Events They Would Enjoy

    Record 13 of 24. compounded. Feasibility: research-stage. Active public research exists on automatic event suggestions that match guests to events they would enjoy, results are published, but no working system at the needed scale yet.

    Online event communities gather people around events they attend together online: a shared schedule, a public guest list, and a room where the event is talked about before and after. Event suggestions that match guests to events they would enjoy need to read a guest's past choices and guess their next one, which is harder than it sounds, because a guest who loved one event may dislike the next one like it. Public research on event suggestions is active, with results published, but no working system yet matches guests fairly at the needed scale. Until that research matures, the site must show every event in the open and let guests choose for themselves.
