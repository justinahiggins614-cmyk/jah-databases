# Educational Game Database — files (educational-game)

- `demo-educational-game.py` — runnable demo program (run with `python3 demo-educational-game.py`).
- `educational-game-sample.txt` — a plain-text sample of the database.
- The full database is `data/educational-game/index.jsonl.gz` (24 records).
- The generator is `gen-educational-game.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
