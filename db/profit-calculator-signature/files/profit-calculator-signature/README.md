# Profit Calculator Database — files (profit-calculator-signature)

- `demo-profit-calculator-signature.py` — runnable demo program (run with `python3 demo-profit-calculator-signature.py`).
- `profit-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/profit-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-profit-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
