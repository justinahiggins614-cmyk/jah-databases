# Expense Tracker Database — files (expense-tracker-signature)

- `demo-expense-tracker-signature.py` — runnable demo program (run with `python3 demo-expense-tracker-signature.py`).
- `expense-tracker-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/expense-tracker-signature/index.jsonl.gz` (24 records).
- The generator is `gen-expense-tracker-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
