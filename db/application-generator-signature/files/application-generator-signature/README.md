# Application Generator Database — files (application-generator-signature)

- `demo-application-generator-signature.py` — runnable demo program (run with `python3 demo-application-generator-signature.py`).
- `application-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/application-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-application-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
