# Website SEO Auditor Database — files (website-seo-auditor)

- `demo-website-seo-auditor.py` — runnable demo program (run with `python3 demo-website-seo-auditor.py`).
- `website-seo-auditor-sample.txt` — a plain-text sample of the database.
- The full database is `data/website-seo-auditor/index.jsonl.gz` (24 records).
- The generator is `gen-website-seo-auditor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
