# Notification Center Database — files (notification-center-signature)

- `demo-notification-center-signature.py` — runnable demo program (run with `python3 demo-notification-center-signature.py`).
- `notification-center-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/notification-center-signature/index.jsonl.gz` (24 records).
- The generator is `gen-notification-center-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
