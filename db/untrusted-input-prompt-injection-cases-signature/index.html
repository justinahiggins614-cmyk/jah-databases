Scope and boundaries

Scope. This database covers untrusted input and prompt-injection cases as a capability of the archive: procedures, checks, and worked demonstrations, written as complete records.

Every record in this database is the full record with all its data. Records render as human-readable sentences. This database marches toward a million records; it currently holds 16 records in this edition, with a boundless generator below for further generation.

Specialist AI

Signature Input Safety Guide is the archive-aware AI for this database. Ask it about this database's records, procedures, and checks; it answers from this database's own data.

Boundless generator

The boundless generator for this database creates further records in the same schema, seeded and deterministic, duplicate-checked, stopping when its variation space is genuinely exhausted, with a hard cap of one quadrillion records per database and throttling per run. Generated records carry src generated and are never mixed with the assistant-built records above. Generator script: gen-untrusted-input-prompt-injection-cases-signature.js.
