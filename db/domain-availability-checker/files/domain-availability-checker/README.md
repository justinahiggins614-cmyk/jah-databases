# Domain Availability Checker Database — files (domain-availability-checker)

- `demo-domain-availability-checker.py` — runnable demo program (run with `python3 demo-domain-availability-checker.py`).
- `domain-availability-checker-sample.txt` — a plain-text sample of the database.
- The full database is `data/domain-availability-checker/index.jsonl.gz` (24 records).
- The generator is `gen-domain-availability-checker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
