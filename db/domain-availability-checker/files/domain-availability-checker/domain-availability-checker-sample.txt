Domain Availability Checker Database (domain-availability-checker)

A domain availability checker is a rule-based local demo: it reads set toy names, and counts the marks. The checker reads 3 names. The name blue holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
