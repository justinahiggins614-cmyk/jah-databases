# Audio Waveform Visualizer Database — files (audio-waveform-visualizer)

- `demo-audio-waveform-visualizer.py` — runnable demo program (run with `python3 demo-audio-waveform-visualizer.py`).
- `audio-waveform-visualizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-waveform-visualizer/index.jsonl.gz` (24 records).
- The generator is `gen-audio-waveform-visualizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
