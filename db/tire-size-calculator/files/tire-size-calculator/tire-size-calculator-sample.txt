Tire Size Calculator Database (tire-size-calculator)

A tire size calculator is a rule-based local demo: it reads set toy tires, and counts the marks. The calculator reads 3 tires. The tire small holds 36 marks. The largest holds 36 marks. Everything runs in this browser; no data leaves the page.
