# Tire Size Calculator Database — files (tire-size-calculator)

- `demo-tire-size-calculator.py` — runnable demo program (run with `python3 demo-tire-size-calculator.py`).
- `tire-size-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/tire-size-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-tire-size-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
