# Report Automation Database — files (report-automation)

- `demo-report-automation.py` — runnable demo program (run with `python3 demo-report-automation.py`).
- `report-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/report-automation/index.jsonl.gz` (24 records).
- The generator is `gen-report-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
