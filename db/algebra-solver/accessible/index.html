  1. Solving x plus 3 equals 7

    Record 1 of 24. simple. Feasibility: buildable-now. Subtracting the same number from both sides keeps the balance and frees x. x plus 3 equals 7 gives x equals 4.

    Math proof: A linear equation ax plus b equals 0 solves as x equals minus b over a. A quadratic ax squared plus bx plus c equals 0 solves by the quadratic formula: x equals minus b plus or minus the square root of b squared minus 4ac, all over 2a. The discriminant b squared minus 4ac tells the story: positive means two real roots, zero means one root, negative means none.

    Science proof: Solving works because an equation is a balance: doing the same thing to both sides keeps it balanced. Undoing operations in reverse order frees x step by step. Checking the answer by putting it back into the equation proves the work, because both sides must agree.
