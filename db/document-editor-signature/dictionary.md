# Dictionary entries — The Document Editor Database

Key terms of this database, defined in plain words.

## document

A named set of words, kept in order, with a beginning and an end, which can be read, changed, and saved without losing what was written.

## editor

A program where words can be written, moved, and changed, with the changes shown at once, so that the writer always sees the true document.

## cursor

The place in a document where the next word will go, shown as a mark, which the writer moves to the place they mean to change.

## selection

The words a writer has marked, by dragging or by keys, so that one change can be made to all of them at once.

## undo

Taking back the last change, in the order changes were made, so that a mistake can be undone without losing the good work around it.

## save

Writing the document as it stands to storage, so that it survives closing, with the time of the save recorded beside it.

## version

One saved state of a document, kept beside the others, so that any earlier state can be read again and compared with the present one.

## formatting

The look of the words: bold, headings, lists, and spacing, which say how the words should be read, never changing what they say.

## comment

A note left beside a document's words, by a reader, which is not part of the document itself and can be answered or removed.

## collaboration

Several writers working on one document at once, each seeing the others' changes, with every change marked by its writer.

## export

Turning a document into another shape, such as a printed page or a plain file, without changing the words it holds.

## ledger

The editor's own written record of every document, every version, and every save, kept in order.
