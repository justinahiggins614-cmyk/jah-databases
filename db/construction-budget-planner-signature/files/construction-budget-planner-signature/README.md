# Construction Budget Planner Database — files (construction-budget-planner-signature)

- `construction-budget-planner-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/construction-budget-planner-signature/index.jsonl.gz` (24 records).
- The generator is `gen-construction-budget-planner-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
