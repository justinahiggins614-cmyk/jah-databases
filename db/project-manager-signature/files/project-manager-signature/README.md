# Project Manager Database — files (project-manager-signature)

- `demo-project-manager-signature.py` — runnable demo program (run with `python3 demo-project-manager-signature.py`).
- `project-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/project-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-project-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
