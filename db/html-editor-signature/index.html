1. Description

An HTML editor writes tags and shows the page they make, side by side: type the tags, press Preview, and see the page. The editor counts the tags, finds broken tags, and fixes them. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Counting the tags gives 6 tags. A table with 2 rows and 2 columns has 4 cells. Heading levels run from 1 to 6: 6 levels. A page with 1 line break has 2 lines. A preview shows 1 page from 3 tags.

3. Science proof

An HTML editor works because a page is tags in order, and each tag wraps its words: a paragraph tag wraps a paragraph, a heading tag wraps a heading, and a list tag wraps 3 items. The preview reads the tags and shows the page they make. That is why the editor shows the tags and the preview side by side, so every change can be seen at once.
