# HTML Editor Database — files (html-editor-signature)

- `demo-html-editor-signature.py` — runnable demo program (run with `python3 demo-html-editor-signature.py`).
- `html-editor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/html-editor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-html-editor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
