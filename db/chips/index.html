About this data base

Archive
This database's chip archive (JAH-CHIP records across 16 chip families) — preserved as structured, searchable data.
Record schema
id · fam · era · name
Generator
jahdb-chips-1.0 — deterministic (mulberry32), derives each chip name from archive-harvested core names and suffixes per family, then an independent re-builder re-derives the name from the private parameters before acceptance.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent verifier.
Cross-database
The generator can borrow a theme from any of the other 36 data bases when you tick the box.
AI
JAH Chip Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
