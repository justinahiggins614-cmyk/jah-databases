History
Learners have sought a first place of work for as long as trades have taken apprentices, because a skill learned in class must be tried in a real workplace before it is truly known. Internship discovery grew beside the internship itself: a written search through the places offered by employers, colleges, and public bodies, so that each learner could read which places were open to them and on what terms. From the hand-written list of placements pinned to a college notice board to the record kept in a database, the honest practice has been the same — write the finding down whole. This database is built on that public practice of recording every internship discovery true. It is a record of published places only, and it gives no advice about any application.
