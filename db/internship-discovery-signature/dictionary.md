# Dictionary entries — The Internship Discovery Database

Key terms of this database, defined in plain words.

## internship discovery

The recorded search of published internships, so that each place, its host, and its terms can be read from the record rather than remembered.

## internship

A stated span of work offered to a learner by a host, kept in the record with its host, its terms, and its span, so that the place can be read plainly.

## host

The employer or body that offers an internship, named in the record with the place, so that where the work sits can be read plainly.

## applicant

The person who asks for an internship, recorded under a name and a number so that every paper for that applicant can be matched to the same person.

## terms

The stated conditions attached to an internship, such as the hours and the duties, written in the record so that the limits of the place can be read in full.

## span

The stated length of an internship, written in the record with the place, so that how long the work lasts can be read plainly.

## placement

The act of putting a learner into an internship, kept in the record with the date and the host, so that the placing can be proved from the paper.

## mentor

The person at a host who guides an intern, named in the record with the internship, so that who guided the learner can be read plainly.

## application

The written request for an internship, naming the applicant and the place sought, kept with the papers it carries, so that the request and its papers can be read together.

## reference

The written account of an intern work given by a host, kept in the record with the intern, so that the account can be proved from the paper.

## stipend

A sum of money paid to an intern, written in the record with the internship and the amount, so that what was paid can be counted.

## notice board

The place where internships are published for learners to read, named in the record with the places listed, so that where the finding was made can be read plainly.
