# JavaScript Playground Database — files (javascript-playground)

- `demo-javascript-playground.py` — runnable demo program (run with `python3 demo-javascript-playground.py`).
- `javascript-playground-sample.txt` — a plain-text sample of the database.
- The full database is `data/javascript-playground/index.jsonl.gz` (24 records).
- The generator is `gen-javascript-playground.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
