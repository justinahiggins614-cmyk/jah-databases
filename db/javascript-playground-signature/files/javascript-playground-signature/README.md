# JavaScript Playground Database — files (javascript-playground-signature)

- `demo-javascript-playground-signature.py` — runnable demo program (run with `python3 demo-javascript-playground-signature.py`).
- `javascript-playground-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/javascript-playground-signature/index.jsonl.gz` (24 records).
- The generator is `gen-javascript-playground-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
