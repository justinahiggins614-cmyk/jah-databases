# Freight Cost Calculator Database — files (freight-cost-calculator-signature)

- `freight-cost-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/freight-cost-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-freight-cost-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
