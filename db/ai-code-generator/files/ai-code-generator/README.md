# AI Code Generator Database — files (ai-code-generator)

- `demo-ai-code-generator.py` — runnable demo program (run with `python3 demo-ai-code-generator.py`).
- `ai-code-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-code-generator/index.jsonl.gz` (24 records).
- The generator is `gen-ai-code-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
