# Paint Calculator Database — files (paint-calculator-signature)

- `demo-paint-calculator-signature.py` — runnable demo program (run with `python3 demo-paint-calculator-signature.py`).
- `paint-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/paint-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-paint-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
