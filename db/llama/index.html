About this data base

Archive
This database's tool-library index (125 libraries across 13 categories) plus the model versions SIGLLAMA-V1 and SIGLLAMA-V2 — preserved as structured, searchable data.
Record schema
id · name · title · profile · engine{model_id, params, layers, heads} · sampling · libraries[{id,name,version}] · build_hash · mix_lineage · stamp
Generator
jahdb-llama-1.0 — deterministic (mulberry32), assembles each build only from the archive's real engine versions and real tool libraries, then an independent verifier rebuilds the build from its private parts (engine spec, library ids, sampling, hash) before acceptance.
Drift control
Every generated build is checked against an archive sample for duplicate build hashes and re-verified by the independent verifier.
Cross-database
The generator can borrow a numeric theme from any of the other 36 databases when you tick the box.
AI
JAH Llama Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
