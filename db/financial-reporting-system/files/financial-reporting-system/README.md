# Financial Reporting System Database — files (financial-reporting-system)

- `demo-financial-reporting-system.py` — runnable demo program (run with `python3 demo-financial-reporting-system.py`).
- `financial-reporting-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/financial-reporting-system/index.jsonl.gz` (24 records).
- The generator is `gen-financial-reporting-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
