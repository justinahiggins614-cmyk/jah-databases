# Inventory Manager Database — files (inventory-manager-signature)

- `demo-inventory-manager-signature.py` — runnable demo program (run with `python3 demo-inventory-manager-signature.py`).
- `inventory-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/inventory-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-inventory-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
