# Messaging Platform Database — files (messaging-platform-signature)

- `demo-messaging-platform-signature.py` — runnable demo program (run with `python3 demo-messaging-platform-signature.py`).
- `messaging-platform-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/messaging-platform-signature/index.jsonl.gz` (24 records).
- The generator is `gen-messaging-platform-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
