# GPS Coordinate Converter Database — files (gps-coordinate-converter)

- `demo-gps-coordinate-converter.py` — runnable demo program (run with `python3 demo-gps-coordinate-converter.py`).
- `gps-coordinate-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/gps-coordinate-converter/index.jsonl.gz` (24 records).
- The generator is `gen-gps-coordinate-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
