# Geological Mapping Tool Database — files (geological-mapping-tool)

- `demo-geological-mapping-tool.py` — runnable demo program (run with `python3 demo-geological-mapping-tool.py`).
- `geological-mapping-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/geological-mapping-tool/index.jsonl.gz` (24 records).
- The generator is `gen-geological-mapping-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
