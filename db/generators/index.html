About this data base

Archive
This database's generator-output archive (JAH-GEN records across 21 families: jets, cars, robots, games and more) — preserved as structured, searchable data.
Record schema
id · type · title · desc
Generator
jahdb-generators-1.0 — deterministic (mulberry32), assembles each output from archive-harvested title/description vocab per family, then an independent re-builder re-derives the title and description from the private parameters before acceptance.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent verifier.
Cross-database
The generator can borrow a theme from any of the other 36 data bases when you tick the box.
AI
JAH Generator Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
