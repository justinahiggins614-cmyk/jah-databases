Scope and boundaries

METHODOLOGY ONLY. This database stores reference patterns for credential references, such as vault-path patterns, naming conventions, and rotation procedures. It contains no credential value, token, password, or secret-like value anywhere in its records, demos, or pages.

Every record in this database is the full record with all its data. Records render as human-readable sentences. This database marches toward a million records; it currently holds 16 records in this edition, with a boundless generator below for further generation.

Boundless generator

The boundless generator for this database creates further records in the same schema, seeded and deterministic, duplicate-checked, stopping when its variation space is genuinely exhausted, with a hard cap of one quadrillion records per database and throttling per run. Generated records carry src generated and are never mixed with the assistant-built records above. Generator script: gen-secrets-credential-reference-registry.js.
