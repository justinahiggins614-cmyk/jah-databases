# Job Description Generator Database — files (job-description-generator)

- `demo-job-description-generator.py` — runnable demo program (run with `python3 demo-job-description-generator.py`).
- `job-description-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/job-description-generator/index.jsonl.gz` (24 records).
- The generator is `gen-job-description-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
