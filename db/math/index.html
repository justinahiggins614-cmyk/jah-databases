About this data base

Source archive
Signature Math's encoding-system records (JAH-MATHDATA) — base systems, mixes, visual codes, text encodings, geometry, cryptography and more — preserved as structured, searchable data.
Record schema
id · title · cat · grid · bitstring · encodings{hex, base64, ascii_art} · popcount · symmetric180 · note · stamp
Generator
jahdb-math-1.0 — deterministic (mulberry32), builds each record from a raw 144-bit grid, then an independent re-encoder rebuilds the bitstring, hex, base64, ASCII-art, popcount, and symmetry from the raw bits before acceptance.
Drift control
Every generated grid is checked against an archive sample for duplicate bitstrings and re-encoded by the independent verifier.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Math Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
