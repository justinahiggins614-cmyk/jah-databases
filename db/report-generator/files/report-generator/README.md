# Report Generator Database — files (report-generator)

- `demo-report-generator.py` — runnable demo program (run with `python3 demo-report-generator.py`).
- `report-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/report-generator/index.jsonl.gz` (24 records).
- The generator is `gen-report-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
