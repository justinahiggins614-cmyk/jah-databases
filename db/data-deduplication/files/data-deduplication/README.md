# Data Deduplication Database — files (data-deduplication)

- `demo-data-deduplication.py` — runnable demo program (run with `python3 demo-data-deduplication.py`).
- `data-deduplication-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-deduplication/index.jsonl.gz` (24 records).
- The generator is `gen-data-deduplication.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
