Earthquake Map Database (earthquake-map-signature)

An earthquake map is a rule-based local demo: it reads set toy regions, and counts the quakes. The map reads 3 regions. The region north holds 14 quakes. The largest holds 14 quakes. Everything runs in this browser; no data leaves the page.
