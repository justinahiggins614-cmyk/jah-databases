# Earthquake Map Database — files (earthquake-map-signature)

- `demo-earthquake-map-signature.py` — runnable demo program (run with `python3 demo-earthquake-map-signature.py`).
- `earthquake-map-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/earthquake-map-signature/index.jsonl.gz` (24 records).
- The generator is `gen-earthquake-map-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
