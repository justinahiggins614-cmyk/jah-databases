Meta-Generator Builder: Search and Retrieval Inside the Program

The Meta-Generator Builder finds what it holds: search looks inside the contents of its records, not only their titles, and returns its hits ranked with the reason each one matched. A search that finds nothing says so plainly and suggests what to try next, instead of pretending the thing does not exist. This record specifies what is searchable, how ranking works, and how a user narrows a search without losing a true hit.
