Meta-Generator Builder: Logging and Audit Trail

JAH-MGB-000011 — meta generator builder record

The Meta-Generator Builder keeps a log: every important action is written down with its date, who or what did it, what went in, and what came out, so that any result can be traced back to its cause. The log is append-only — entries are added, never rewritten — and it is readable as plain text. This record specifies what is logged, what is never logged (keys, secrets, and personal data are never written to a log), and how long entries are kept. In this public edition the program offers 8 capabilities (creating a builder for a generator kind (1); builders that produce seeded, bounded, tested generators (2); the same seed giving the same builder and the same generators (3); a hard stop inherited by every generator built (4); a test for the builder and for each generator it builds (5); registration of every builder and generator (6); an API other programs use to build meta-generators (7); a plain-text build report (8)), 6 interfaces (Meta form — generator kind, in plain words; Builder view — the builder program, readable and downloadable; Test run — run the builder's tests and see the result; Built generators — every generator this builder has made; Meta API — machine-readable meta-generator building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (kind — what the built generators will make; builder_code — the builder program's code; generators — the generators the builder has made; hard_stop — the ceiling inherited by every generator; tests — the test result for the builder and its generators; registry — the registration of builder and generators; seed — the starting number; samples — sample generators and their sample outputs). This record is number 11 of 24 in the public edition of the Meta-Generator Builder database pair, and it specifies the logging and audit trail topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
