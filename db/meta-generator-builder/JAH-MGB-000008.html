Meta-Generator Builder: Input Validation and Error Handling

JAH-MGB-000008 — meta generator builder record

The Meta-Generator Builder checks every input before it trusts it: a missing value, a wrong type, or a value outside its allowed range is refused with a message that names the field and the rule it broke. Refused input changes nothing — no partial write, no half-built record, no silent correction. This record lists the validation rules for each input, the exact error each broken rule produces, and the recovery path: what the user or calling program does next to put it right. In this public edition the program offers 8 capabilities (creating a builder for a generator kind (1); builders that produce seeded, bounded, tested generators (2); the same seed giving the same builder and the same generators (3); a hard stop inherited by every generator built (4); a test for the builder and for each generator it builds (5); registration of every builder and generator (6); an API other programs use to build meta-generators (7); a plain-text build report (8)), 6 interfaces (Meta form — generator kind, in plain words; Builder view — the builder program, readable and downloadable; Test run — run the builder's tests and see the result; Built generators — every generator this builder has made; Meta API — machine-readable meta-generator building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (kind — what the built generators will make; builder_code — the builder program's code; generators — the generators the builder has made; hard_stop — the ceiling inherited by every generator; tests — the test result for the builder and its generators; registry — the registration of builder and generators; seed — the starting number; samples — sample generators and their sample outputs).
