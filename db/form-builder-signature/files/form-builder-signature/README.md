# Form Builder Database — files (form-builder-signature)

- `demo-form-builder-signature.py` — runnable demo program (run with `python3 demo-form-builder-signature.py`).
- `form-builder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/form-builder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-form-builder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
