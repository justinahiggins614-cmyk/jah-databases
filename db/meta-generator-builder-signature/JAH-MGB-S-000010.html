Meta-Generator Builder: Signature Access Control

JAH-MGB-S-000010 — meta generator builder record

Signature access control is defensive by design: reading Signature designs is open, and every action that changes, builds, or publishes anything requires the right permission, checked before the action. Denied actions are refused with a clear message and written to the log. This record names the Signature permission levels and the rule that the program never grants access it was not asked to grant. In this Signature edition the program offers 8 capabilities (creating a builder for a generator kind (1); builders that produce seeded, bounded, tested generators (2); the same seed giving the same builder and the same generators (3); a hard stop inherited by every generator built (4); a test for the builder and for each generator it builds (5); registration of every builder and generator (6); an API other programs use to build meta-generators (7); a plain-text build report (8)), 6 interfaces (Meta form — generator kind, in plain words; Builder view — the builder program, readable and downloadable; Test run — run the builder's tests and see the result; Built generators — every generator this builder has made; Meta API — machine-readable meta-generator building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (kind — what the built generators will make; builder_code — the builder program's code; generators — the generators the builder has made; hard_stop — the ceiling inherited by every generator; tests — the test result for the builder and its generators; registry — the registration of builder and generators; seed — the starting number; samples — sample generators and their sample outputs).
