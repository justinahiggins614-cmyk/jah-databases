# Public Complaint Submission Database — files (public-complaint-submission-signature)

- `demo-public-complaint-submission-signature.py` — runnable demo program (run with `python3 demo-public-complaint-submission-signature.py`).
- `public-complaint-submission-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/public-complaint-submission-signature/index.jsonl.gz` (24 records).
- The generator is `gen-public-complaint-submission-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
