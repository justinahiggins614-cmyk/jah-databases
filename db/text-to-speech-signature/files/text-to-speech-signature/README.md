# Text-to-Speech Database — files (text-to-speech-signature)

- `demo-text-to-speech-signature.py` — runnable demo program (run with `python3 demo-text-to-speech-signature.py`).
- `text-to-speech-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/text-to-speech-signature/index.jsonl.gz` (24 records).
- The generator is `gen-text-to-speech-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
