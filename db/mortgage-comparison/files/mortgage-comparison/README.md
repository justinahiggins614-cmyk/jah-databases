# Mortgage Comparison Database — files (mortgage-comparison)

- `demo-mortgage-comparison.py` — runnable demo program (run with `python3 demo-mortgage-comparison.py`).
- `mortgage-comparison-sample.txt` — a plain-text sample of the database.
- The full database is `data/mortgage-comparison/index.jsonl.gz` (24 records).
- The generator is `gen-mortgage-comparison.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
