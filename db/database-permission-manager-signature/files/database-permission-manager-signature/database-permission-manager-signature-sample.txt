Database Permission Manager Database (database-permission-manager-signature)

A database permission manager is a rule-based local demo: it checks set toy rules, and counts the marks. The manager reads 3 rules. The rule alpha holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
