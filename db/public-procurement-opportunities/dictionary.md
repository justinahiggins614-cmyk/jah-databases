# Dictionary entries — The Public Procurement Opportunities Database

Key terms of this database, defined in plain words.

## public procurement opportunities

The recorded chances a government publishes for firms to supply goods, works, or services, holding the tender notice, the terms, and the deadline together, so that any opportunity can be found and read.

## tender notice

The written notice by which a government asks firms to bid for a contract, naming the work, the terms, and the deadline, so that the chance can be read as it was published.

## contract record

The written account of a contract awarded by a government, naming the contract, the supplier, and the value, so that the award can be read as it was made.

## bid record

The written account of a bid made for a public contract, naming the bidder and the price, so that the offers can be counted and compared.

## award notice

The written notice telling the public which bidder won a contract, naming the winner and the value, so that the award can be read as it was published.

## framework agreement

The written agreement under which a government may call on suppliers over a period, naming the suppliers and the terms, so that the standing arrangement can be read.

## supplier register

The written list of the firms registered to supply a government, naming each firm and what it supplies, so that the pool of suppliers can be counted.

## evaluation criteria

The written list of the measures by which bids for a contract are judged, kept with the tender so that the judging can be read before it is done.

## addendum

The written addition to a tender notice, naming the tender and the change, so that the correction can be read with the notice it changes.

## specification document

The written document describing in full what a government wants bought, kept with the tender so that the need can be read as it was stated.

## opportunity search

The recorded searching of the published procurement opportunities, holding the query and the results together, so that what was found can be read and proved.

## annual plan

The yearly written plan of the contracts a government means to tender, naming each one, so that the year can be read before it begins.
