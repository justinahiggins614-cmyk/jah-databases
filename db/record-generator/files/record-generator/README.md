# Record Generator Database — files (record-generator)

- `demo-record-generator.py` — runnable demo program (run with `python3 demo-record-generator.py`).
- `record-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/record-generator/index.jsonl.gz` (24 records).
- The generator is `gen-record-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
