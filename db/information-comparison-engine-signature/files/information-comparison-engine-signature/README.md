# Information Comparison Engine Database — files (information-comparison-engine-signature)

- `demo-information-comparison-engine-signature.py` — runnable demo program (run with `python3 demo-information-comparison-engine-signature.py`).
- `information-comparison-engine-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/information-comparison-engine-signature/index.jsonl.gz` (24 records).
- The generator is `gen-information-comparison-engine-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
