# Dictionary entries — The Travel Itinerary Creation Database

Key terms of this database, defined in plain words.

## itinerary

The written plan of a journey, listing the places, the days, and the order, kept as one record, so that the whole journey can be read from the plan in order.

## travel plan

The full written account of a journey before it begins, naming the places, the travel between them, and the stays, so that the journey can be followed as planned.

## destination

One place a journey visits, named in the itinerary with its dates, so that every place on the journey can be read in order.

## day plan

The plan for one day of a journey, naming what is to be done and where, kept inside the itinerary, so that each day of the journey can be read on its own.

## route

The ordered path a journey follows from place to place, written in the itinerary, so that how the journey moves can be read plainly.

## stopover

A planned stop on a journey, shorter than a stay, written in the itinerary with its place and its length, so that the stops between the main places are part of the plan.

## stay

A planned number of nights in one place on a journey, written in the itinerary with the place and the dates, so that where the traveller rests each night can be read.

## travel leg

One stretch of travel between two places on a journey, written in the itinerary with its start, its end, and its way of travelling, so that every move is part of the plan.

## guidebook

A printed or written book that describes places for travellers, named in the itinerary when it is the source of the plan, so that where the plan came from can be read.

## sightseeing

The visiting of sights in a place, listed in the day plan with the sights named, so that what the day holds can be read beside where the day is spent.

## travel date

One date on which a journey or part of it happens, written in the itinerary, so that the plan can be read against the calendar.

## itinerary version

One numbered form of an itinerary, kept when the plan changes, so that the history of the plan shows every change in order.
