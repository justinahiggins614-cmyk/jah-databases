# The Travel Itinerary Creation Database

The Travel Itinerary Creation Database is the travel itinerary creation record database in the Signature network. It holds 24 full travel itinerary creation record records in the public edition and 24 in the Signature edition, in a teaching ladder of 8 simple, 8 compounded and 8 most complex records.

It expands the live database really-fun-creations, which it links to and never rebuilds. The database carries the specification, models, test suites and verification records; it is not a running service.
