# Marketing Automation Database — files (marketing-automation-signature)

- `demo-marketing-automation-signature.py` — runnable demo program (run with `python3 demo-marketing-automation-signature.py`).
- `marketing-automation-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/marketing-automation-signature/index.jsonl.gz` (24 records).
- The generator is `gen-marketing-automation-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
