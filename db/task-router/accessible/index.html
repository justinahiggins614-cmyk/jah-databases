Overview

The Task Router Database holds 24 full task router record records, in a teaching ladder: 8 simple, 8 compounded, 8 most complex. This edition is the public edition. It expands the live database ai-build-build-tool-router, which holds 25 records; this pair links to it and never rebuilds it. The Design/System

The design is one database per subject, with a public edition and a Signature edition side by side. Every record gives its history, its full content, its methods, its results as reported, and its skeptical analysis. Every technical term is defined in plain words where it first appears, and the glossary defines them all again. Each public record is a verified public fact with its source cited, retrieved 2026-11-23.

The Generator

The boundless generator for this database is the file gen-task-router.js. It is seeded and deterministic: the same seed always gives the same record, and different seeds differ. It is throttled to 100 records per call, it stops at 1,000,000,000 records per file, and every generated record is labeled generated, never presented as an archive record.

The AI

The archive-aware AI for this database is JAH Task Router Archivist. It explains this database in plain sentences, answers questions about every record, and can generate new records in this database's family. Its full specification is downloadable: task-router-ai.json.

Math Proof

The counting argument is exact: 24 records, 8 simple, 8 compounded, 8 most complex, and 8 + 8 + 8 = 24. The formal statement is: route(task) = the worker that can do it soonest (stated, not machine-checked) The scientific statement is: throughput = tasks finished / time (stated, not machine-checked) Both are stated, not machine-checked, and the record-level proofs are in each record's math proof.
