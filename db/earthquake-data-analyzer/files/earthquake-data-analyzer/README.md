# Earthquake Data Analyzer Database — files (earthquake-data-analyzer)

- `demo-earthquake-data-analyzer.py` — runnable demo program (run with `python3 demo-earthquake-data-analyzer.py`).
- `earthquake-data-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/earthquake-data-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-earthquake-data-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
