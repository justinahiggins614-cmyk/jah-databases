# Inventory Manager Database — files (inventory-manager)

- `demo-inventory-manager.py` — runnable demo program (run with `python3 demo-inventory-manager.py`).
- `inventory-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/inventory-manager/index.jsonl.gz` (24 records).
- The generator is `gen-inventory-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
