# Flowchart Creator Database — files (flowchart-creator)

- `demo-flowchart-creator.py` — runnable demo program (run with `python3 demo-flowchart-creator.py`).
- `flowchart-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/flowchart-creator/index.jsonl.gz` (24 records).
- The generator is `gen-flowchart-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
