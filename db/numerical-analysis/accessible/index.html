Numerical Analysis: Error and Its Sources

Record identifier: JAH-NUMANA-000001. Ladder rank: 1 of 24. Subject: error and its sources.

Error is the difference between a computed value and the true value. Absolute error is the size of the difference; relative error is the absolute error divided by the size of the true value. Errors come from rounding (a computer stores finitely many digits), truncation (a method stops early), and the data itself (measurements are inexact). Absolute error measures the difference; relative error measures it against the size of the answer. Rounding error comes from finite-precision arithmetic; truncation error comes from stopping a process early. Errors can amplify: subtracting nearly equal numbers loses significant digits (catastrophic cancellation). Numerical Analysis: Floating-Point Arithmetic

Record identifier: JAH-NUMANA-000002. Ladder rank: 2 of 24. Subject: floating-point arithmetic.

Floating-point arithmetic is how computers store real numbers: a number is stored as a significand (its digits) times a power of 2, with a fixed number of bits. Double precision (the usual format) has 53 bits of significand, about 16 decimal digits, and a relative rounding error of about 2.2 times 10^-16 per operation (the machine epsilon). Double precision has about 16 decimal digits and machine epsilon about 2.2e-16. Adding a tiny number to a large one can lose the tiny number entirely. The order of operations changes the rounding, so the same computation can give different answers. Numerical Analysis: Bisection

Record identifier: JAH-NUMANA-000003. Ladder rank: 3 of 24. Subject: bisection for root finding.

Bisection finds a root (a point where a function is zero) by halving an interval that brackets it: if a continuous function changes sign on an interval, it has a root inside (the intermediate value theorem). Evaluate the midpoint; keep the half where the sign still changes; repeat. Each step halves the error. Bisection needs a sign change on the starting interval. Each step halves the interval, so n steps reduce the error by a factor of 2^n. Bisection is slow but certain: it always converges when the hypotheses hold. Numerical Analysis: Newton's Method

Record identifier: JAH-NUMANA-000004. Ladder rank: 4 of 24. Subject: Newton's method for root finding.

Newton's method finds a root by following tangent lines: from a guess x, the next guess is x - f(x)/f'(x), the point where the tangent line at x crosses the axis. Near a simple root it converges quadratically: the number of correct digits roughly doubles at each step. The iteration is x(n+1) = x(n) - f(x(n))/f'(x(n)). Numerical Analysis: The Secant Method

Record identifier: JAH-NUMANA-000005. Ladder rank: 5 of 24. Subject: the secant method for root finding.

The secant method is Newton's method without the derivative: it approximates the derivative by the slope of the secant line through the last two points. The iteration uses x(n+1) = x(n) - f(x(n)) times (x(n) - x(n-1)) / (f(x(n)) - f(x(n-1))). It converges superlinearly (faster than linear, slower than quadratic) and needs no derivative. The secant method needs two starting points, not one. Its order of convergence is about 1.618 (the golden ratio). It is used when the derivative is unavailable or expensive. Numerical Analysis: Gaussian Elimination and LU Factorisation

Record identifier: JAH-NUMANA-000006. Ladder rank: 6 of 24. Subject: Gaussian elimination and LU factorisation.

Gaussian elimination solves a linear system by row operations, turning the matrix into triangular form. LU factorisation writes A as L times U, where L is lower triangular (non-zero entries only on and below the diagonal, with 1s on the diagonal) and U is upper triangular. LU factorisation separates the work: factor once, solve many times. Partial pivoting (swapping rows to put the largest entry on the diagonal) controls rounding error. The Jacobi method updates all unknowns from the old values; Gauss-Seidel updates them one by one, using the newest values. Iterative methods are used for large sparse systems (mostly zeros), where elimination is too expensive. Numerical Analysis: The Condition Number

Record identifier: JAH-NUMANA-000008. Ladder rank: 8 of 24. Subject: the condition number.

The condition number of a matrix measures how much the solution of a linear system can change when the data change a little. For the 2-norm, it is the largest singular value divided by the smallest. A condition number near 1 means a well-conditioned problem; a large one (say 10^6) means the answer can lose about 6 decimal digits to rounding. The condition number is the ratio of the largest to the smallest singular value. A relative error in the data is amplified by at most the condition number. A singular matrix has infinite condition number. Numerical Analysis: Euler's Method for ODEs

Record identifier: JAH-NUMANA-000012. Ladder rank: 12 of 24. Subject: Euler's method for ordinary differential equations.

Euler's method approximates the solution of dy/dx = f(x, y) step by step: from (x, y), the next point is (x + h, y + h f(x, y)), moving along the tangent line. The local error per step is proportional to h squared, and the global error after a fixed interval is proportional to h. It is the simplest method, and the baseline against which better methods are measured. Each step moves along the tangent line by h times the slope. The global error is proportional to h: halving h halves the error. Euler's method is explicit (the next value is computed directly) and first-order. Monte Carlo integration estimates an integral by random sampling: the average of the function at random points, times the volume of the region, estimates the integral. Variance reduction (such as importance sampling) makes the estimate more accurate for the same N. // One summary line per record (the same computation as each record's
// own demo, ported from Python), then a determinism check: the lines
// are hashed twice and the two digests must match.
'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
