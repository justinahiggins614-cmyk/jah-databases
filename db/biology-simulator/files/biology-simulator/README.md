# Biology Simulator Database — files (biology-simulator)

- `demo-biology-simulator.py` — runnable demo program (run with `python3 demo-biology-simulator.py`).
- `biology-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/biology-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-biology-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
