# Report Automation Database — files (report-automation-signature)

- `demo-report-automation-signature.py` — runnable demo program (run with `python3 demo-report-automation-signature.py`).
- `report-automation-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/report-automation-signature/index.jsonl.gz` (24 records).
- The generator is `gen-report-automation-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
