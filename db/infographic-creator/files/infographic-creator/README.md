# Infographic Creator Database — files (infographic-creator)

- `demo-infographic-creator.py` — runnable demo program (run with `python3 demo-infographic-creator.py`).
- `infographic-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/infographic-creator/index.jsonl.gz` (24 records).
- The generator is `gen-infographic-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
