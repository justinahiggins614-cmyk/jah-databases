# Portfolio Tracker Database — files (portfolio-tracker)

- `demo-portfolio-tracker.py` — runnable demo program (run with `python3 demo-portfolio-tracker.py`).
- `portfolio-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/portfolio-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-portfolio-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
