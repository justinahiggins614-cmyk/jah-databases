1. Description

A QR code factory turns any text into a square pattern of dark and light modules that a camera can read: it picks the encoding mode, the version, and the error correction level, lays out the finder patterns, masks the data, and prints a code that scans.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

A QR Code version sets its size: modules per side equal 17 plus 4 times the version, so version 1 is 21 modules across and version 40 is 177 modules across. Error correction is a fraction of the codewords: level L restores about 7 in 100, level M about 15 in 100, level Q about 25 in 100, and level H about 30 in 100. Capacity grows with the version: version 40 at level L holds 2,953 bytes, 4,296 alphanumeric characters, or 7,089 numeric digits, while version 1 at level L holds 17 bytes. A quiet zone adds 4 modules on every side, so a version 1 code with its quiet zone spans 29 modules across.

3. Science proof

A QR Code works because a reader can find it, orient it, and correct its mistakes. Three finder patterns mark three corners, so the reader finds the code at any rotation; timing patterns tell it the module grid; and Reed-Solomon error correction rebuilds data from the codewords that survive, which is why a code with a torn corner can still be read. High contrast between dark and light modules lets a camera tell the two states apart, and the quiet zone keeps nearby print from confusing the reader. That is why a small square of black and white modules can carry a whole address, a network login, or a calendar event.

Try it: QR-style matrix generator

This is a QR-style display model, not a verified scannable code. It shows the layout and the sizing rules; it does not claim to be a registered or guaranteed-scannable code.

Error correction is a fraction of the codewords: level L restores about 7 in 100, level M about 15 in 100, level Q about 25 in 100, and level H about 30 in 100. Capacity grows with the version: version 40 at level L holds 2,953 bytes, 4,296 alphanumeric characters, or 7,089 numeric digits, while version 1 at level L holds 17 bytes. A quiet zone adds 4 modules on every side, so a version 1 code with its quiet zone spans 29 modules across.

Science proof: A QR Code works because a reader can find it, orient it, and correct its mistakes. Three finder patterns mark three corners, so the reader finds the code at any rotation; timing patterns tell it the module grid; and Reed-Solomon error correction rebuilds data from the codewords that survive, which is why a code with a torn corner can still be read. High contrast between dark and light modules lets a camera tell the two states apart, and the quiet zone keeps nearby print from confusing the reader. That is why a small square of black and white modules can carry a whole address, a network login, or a calendar event.
