# Image Search Database — files (image-search)

- `demo-image-search.py` — runnable demo program (run with `python3 demo-image-search.py`).
- `image-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/image-search/index.jsonl.gz` (24 records).
- The generator is `gen-image-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
