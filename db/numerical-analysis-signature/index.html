Full official specification (long version, in full)

The Signature Numerical Analysis design specification. This is a design-study specification: it specifies Signature-made designs for teaching and using Numerical Analysis. Every design in it is a proposal, labelled design-study, and no design here is presented as established fact or as an authentic public record.

1. Purpose and scope. Numerical analysis is the study of algorithms (step-by-step procedures) that solve mathematical problems approximately on a computer, and of the errors those approximations carry. It answers how close an answer is, not just what it is. The database covers the subject at college level: its core ideas, its standard methods, its worked examples, and its honest limits. It does not claim to cover graduate or doctoral material, and it does not present generated content as authentic public record. The public edition records established college-level knowledge, fact-checked against cited sources; the Signature edition records Signature-made designs, labelled design-study throughout.

2. Prerequisites. A reader needs school-level algebra and arithmetic, comfort with symbols and with reading a definition carefully, and a willingness to work examples by hand before trusting a program. No prior college course in the subject is assumed. Where a unit needs an earlier unit, the record says so in plain words, and the earlier unit is linked. A reader who can follow a worked example step by step can follow this database.

3. Learning outcomes. After working through the database, a learner will be able to: 1. Measure error: absolute, relative, and the error bound of a method. 2. Analyse floating-point arithmetic and its rounding behaviour. 3. Find roots of equations by bisection, Newton, and secant methods. 4. Solve linear systems by direct and iterative methods and judge conditioning. 5. Interpolate data and approximate functions by polynomials and splines. 6. Integrate numerically and state the error of the rule used. 7. Solve ordinary differential equations numerically and judge stability. 8. Fit data by least squares and judge the quality of the fit.

4. Syllabus. The subject is taught in eight units. Unit 1, Error and floating point: Sources of error, rounding, and the floating-point model of computer arithmetic. Unit 2, Root finding: Bisection, fixed-point iteration, Newton, and secant methods with convergence rates. Unit 3, Linear systems: Elimination, factorisation, iterative methods, and the condition number. Unit 4, Interpolation and approximation: Polynomial interpolation, splines, and least-squares approximation. Unit 5, Numerical integration: Trapezoidal, Simpson, and Gaussian rules with error bounds. Unit 6, Ordinary differential equations: Euler, Runge-Kutta, and multistep methods with stability regions. Unit 7, Eigenvalue computation: Power iteration and the QR algorithm for eigenvalues. Unit 8, Optimisation: Gradient descent and Newton methods for minimising functions.

5. Content and record requirements. The database holds 24 records in the public edition and 24 records in the Signature edition, 48 records in the pair. Every record is a full record, never a stub: at least 800 words of prose plus this full specification, a worked example with numbers, a demo that is executed at build time, a working program, at least two cited sources with their URLs and retrieval date, a version-1 JCC code (JAHDB/slug#id) that round-trips, and a stated evidence label. Data is added, never reduced: a record that is corrected keeps its history, and a correction is recorded as a new version, never as a silent edit. Every technical term is defined in plain words on first use, and no acronym (a shortened form made from initial letters) is used before its full expansion. Records render as human-readable sentences and paragraphs, never garbled text.

The demo sums and averages a named figure table, prints the results, and prints a SHA-256 digest (a 256-bit fingerprint of the result text) of two separate runs; the runs must match, which proves the computation is deterministic (the same input always gives the same output). // Edition demo for the The Signature Numerical Analysis Database (numerical-analysis-signature).
// One summary line per record (the same computation as each record's
// own demo, ported from Python), then a determinism check: the lines
// are hashed twice and the two digests must match.
'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
