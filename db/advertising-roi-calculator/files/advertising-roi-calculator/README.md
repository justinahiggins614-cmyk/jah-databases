# Advertising ROI Calculator Database — files (advertising-roi-calculator)

- `demo-advertising-roi-calculator.py` — runnable demo program (run with `python3 demo-advertising-roi-calculator.py`).
- `advertising-roi-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/advertising-roi-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-advertising-roi-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
