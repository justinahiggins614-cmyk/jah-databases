# Zoning Lookup Database — files (zoning-lookup-signature)

- `demo-zoning-lookup-signature.py` — runnable demo program (run with `python3 demo-zoning-lookup-signature.py`).
- `zoning-lookup-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/zoning-lookup-signature/index.jsonl.gz` (24 records).
- The generator is `gen-zoning-lookup-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
