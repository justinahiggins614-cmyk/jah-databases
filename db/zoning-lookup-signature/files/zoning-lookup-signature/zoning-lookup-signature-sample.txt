Zoning Lookup Database (zoning-lookup-signature)

A zoning lookup is a rule-based local demo: it looks up set toy zones, and counts the marks. The lookup reads 3 zones. The zone alpha holds 51 marks. The largest holds 51 marks. Everything runs in this browser; no data leaves the page.
