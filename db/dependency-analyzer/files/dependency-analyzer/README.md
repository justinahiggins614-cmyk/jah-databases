# Dependency Analyzer Database — files (dependency-analyzer)

- `demo-dependency-analyzer.py` — runnable demo program (run with `python3 demo-dependency-analyzer.py`).
- `dependency-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/dependency-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-dependency-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
