A Signature design for teaching the prime definition: one rule, one exclusion, and a table that cannot drift from it.

The Signature prime table design starts where the public record starts, with the definition, but it designs the table around the definition instead of listing numbers first. The design question is how to make a table that cannot silently include 1 or a composite: the answer is a definition card pinned to the top of every table page, stating that a prime is a whole number greater than 1 with no divisors except 1 and itself, and a build rule that every entry must pass trial division before it is written. The design also plans the failure mode: if a later generator proposes 1 as a prime, the definition card rejects it, and the rejection is logged. This record designs the card, the build rule, and the rejection log, so the Signature tables inherit the definition instead of re-arguing it.

A Signature builder opens the design and reads the card: 29 is prime because no divisor up to its square root divides it. The builder then runs the gate on a candidate list that mistakenly includes 1: the gate rejects 1 with the reason greater than 1 required, logs the rejection, and the table is built without it. The same builder tests 27: the gate finds 3 as a divisor, rejects it, and logs composite with witness 3. The table that results contains exactly the primes, and the log shows every rejection, so the table's correctness is visible rather than assumed.

History

The Signature design takes the definition from Euclid and the exclusion of 1 from the nineteenth-century settlement, and it treats both as fixed inputs rather than open questions. The design step is new: instead of a table that happens to follow the definition, the Signature table is generated from the definition by a rule, so the table and the definition cannot drift apart. The design was drafted for the Signature system in November 2026 as the first record of this pair, and it sets the pattern every later Signature record in the pair follows: state the public fact, then design the Signature mechanism that keeps it true.
