# Web Hosting Control Panel Database — files (web-hosting-control-panel)

- `demo-web-hosting-control-panel.py` — runnable demo program (run with `python3 demo-web-hosting-control-panel.py`).
- `web-hosting-control-panel-sample.txt` — a plain-text sample of the database.
- The full database is `data/web-hosting-control-panel/index.jsonl.gz` (24 records).
- The generator is `gen-web-hosting-control-panel.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
