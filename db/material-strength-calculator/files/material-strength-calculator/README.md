# Material Strength Calculator Database — files (material-strength-calculator)

- `demo-material-strength-calculator.py` — runnable demo program (run with `python3 demo-material-strength-calculator.py`).
- `material-strength-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/material-strength-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-material-strength-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
