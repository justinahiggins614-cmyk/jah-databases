# Health Record Organizer Database — files (health-record-organizer)

- `demo-health-record-organizer.py` — runnable demo program (run with `python3 demo-health-record-organizer.py`).
- `health-record-organizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/health-record-organizer/index.jsonl.gz` (24 records).
- The generator is `gen-health-record-organizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
