Assign a bot to Anonymous of Peace (Accessible version)

This page has no scripts. It explains the assignment and prints the full loyalty contract. To assign a bot, use the full assignment page at assign/, which generates the assignment record locally in the browser.

How assignment works

Give the bot's name and kind, state the assignment pledge, read the loyalty contract with the four ownership terms in full, sign with the agree action, pick the starting upgrade tier, and start the training. The page generates the assignment record locally, shows the contract text with the bot's name and the timestamp, saves the record in the browser, and offers it as a download. The record is entered in the registry, which starts with zero real assigned bots.
