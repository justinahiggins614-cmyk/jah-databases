# Research Aggregator Database — files (research-aggregator)

- `demo-research-aggregator.py` — runnable demo program (run with `python3 demo-research-aggregator.py`).
- `research-aggregator-sample.txt` — a plain-text sample of the database.
- The full database is `data/research-aggregator/index.jsonl.gz` (24 records).
- The generator is `gen-research-aggregator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
