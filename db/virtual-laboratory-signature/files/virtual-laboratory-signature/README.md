# Virtual Laboratory Database — files (virtual-laboratory-signature)

- `demo-virtual-laboratory-signature.py` — runnable demo program (run with `python3 demo-virtual-laboratory-signature.py`).
- `virtual-laboratory-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/virtual-laboratory-signature/index.jsonl.gz` (24 records).
- The generator is `gen-virtual-laboratory-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
