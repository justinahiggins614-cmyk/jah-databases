1. Description

An equation solver finds the unknown number: type an equation, and it shows the steps and the answer, then checks the answer by putting it back. Linear equations and quadratics both work, in this browser, with no sign-in.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

A linear equation ax + b = c gives x = (c - b) / a: with 2x + 3 = 11, x is (11 - 3) / 2, which is 4. A quadratic ax squared + bx + c = 0 is solved by the quadratic formula, with the discriminant b squared minus 4ac: for x squared - 5x + 6 = 0 the discriminant is 25 - 24, which is 1, and the answers are 2 and 3. Checking is substitution: putting x = 4 into 2x + 3 gives 11, which matches.

3. Science proof

Solving works because an equation stays true when the same step is done to both sides: take the same number from both sides, divide both sides by the same number, and the equality holds. That is why undoing in reverse order finds the unknown, and why substitution checks the answer: a right answer makes both sides agree.

JAH-EQUS-S-000024 — This record is the field guide index for the whole equation solver database: it lists all twenty-three content records in ladder order, simple to working to advanced, and tells a reader where to start. Records: What an Equation Is; A Linear Equation; Solving by Undoing; Solving by Dividing; Two Steps, Two Moves; Checking by Substituting; An Equation With x on Both Sides; A Quadratic Equation; The Quadratic Formula; A Quadratic With One Answer; A Quadratic With No Real Answer; The Discriminant; Solving a Pair; An Equation From Words; Fractions in Equations; Decimals in Equations; A Negative Answer; An Equation With Brackets; Solving by Graphing; A Cubic, Solved by Trying; The Local Solver; Keeping Every Step; From Equation to Answer.
Math proof: A linear equation ax + b = c gives x = (c - b) / a: with 2x + 3 = 11, x is (11 - 3) / 2, which is 4. A quadratic ax squared + bx + c = 0 is solved by the quadratic formula, with the discriminant b squared minus 4ac: for x squared - 5x + 6 = 0 the discriminant is 25 - 24, which is 1, and the answers are 2 and 3. Checking is substitution: putting x = 4 into 2x + 3 gives 11, which matches.
Science proof: Solving works because an equation stays true when the same step is done to both sides: take the same number from both sides, divide both sides by the same number, and the equality holds. That is why undoing in reverse order finds the unknown, and why substitution checks the answer: a right answer makes both sides agree.
