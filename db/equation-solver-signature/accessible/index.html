The Equation Solver Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. An equation solver finds the unknown number: type an equation, and it shows the steps and the answer, then checks the answer by putting it back. Linear equations and quadratics both work, in this browser, with no sign-in.

  1. What an Equation Is

    Record 1 of 24. simple. Feasibility: buildable-now. An equation says two sides are equal, with a number to find. In x + 5 = 12, the answer is x = 7.

    Math proof: A linear equation ax + b = c gives x = (c - b) / a: with 2x + 3 = 11, x is (11 - 3) / 2, which is 4. A quadratic ax squared + bx + c = 0 is solved by the quadratic formula, with the discriminant b squared minus 4ac: for x squared - 5x + 6 = 0 the discriminant is 25 - 24, which is 1, and the answers are 2 and 3. Checking is substitution: putting x = 4 into 2x + 3 gives 11, which matches.

    Science proof: Solving works because an equation stays true when the same step is done to both sides: take the same number from both sides, divide both sides by the same number, and the equality holds. That is why undoing in reverse order finds the unknown, and why substitution checks the answer: a right answer makes both sides agree.
