# Public Information Portal Database — files (public-information-portal)

- `demo-public-information-portal.py` — runnable demo program (run with `python3 demo-public-information-portal.py`).
- `public-information-portal-sample.txt` — a plain-text sample of the database.
- The full database is `data/public-information-portal/index.jsonl.gz` (24 records).
- The generator is `gen-public-information-portal.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
