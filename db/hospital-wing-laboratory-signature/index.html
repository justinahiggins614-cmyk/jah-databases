Science

Critical-value reporting is the science behind this design. When a laboratory result is dangerously abnormal, the result must reach the responsible provider at once, by phone, not by routine report flow — that immediate-call rule is standard hospital safety practice (Joint Commission National Patient Safety Goal 2). The demo applies it to potassium: above 6.0 mmol/L it is treated as critical, because high potassium can disturb heart rhythm. The demo’s thresholds (low 2.8, high 6.0 mmol/L) are the prototype’s own thresholds, stated here as the prototype’s values, not as a clinical reference range.

Math proof

Arithmetic recomputed from the demo’s thresholds. Low threshold 2.8 mmol/L, high threshold 6.0 mmol/L, so the critical range is 6.0 − 2.8 = 3.2 mmol/L wide. The demo value 6.4 mmol/L exceeds the high threshold by 6.4 − 6.0 = 0.4 mmol/L, which is 0.4/6.0 = 6.7% above it, so the alert is CRITICAL HIGH. The low case 2.0 mmol/L is 2.8 − 2.0 = 0.8 mmol/L below the low threshold, so the alert is CRITICAL LOW. The normal case 4.5 mmol/L lies inside 2.8–6.0, so no alert fires. def critical_value_alert(test, value, low, high, unit):
