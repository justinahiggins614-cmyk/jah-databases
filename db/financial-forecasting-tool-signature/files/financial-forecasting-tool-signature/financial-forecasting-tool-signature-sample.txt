Financial Forecasting Tool Database (financial-forecasting-tool-signature)

A financial forecasting tool is a rule-based local demo: it reads set toy monthly amounts, and counts the forecast. The tool reads 3 months. The month jan holds 12000. The largest holds 13500 amounts. Everything runs in this browser; no data leaves the page.
