# Financial Forecasting Tool Database — files (financial-forecasting-tool-signature)

- `demo-financial-forecasting-tool-signature.py` — runnable demo program (run with `python3 demo-financial-forecasting-tool-signature.py`).
- `financial-forecasting-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/financial-forecasting-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-financial-forecasting-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
