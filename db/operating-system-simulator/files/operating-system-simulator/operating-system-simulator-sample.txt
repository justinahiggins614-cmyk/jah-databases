Operating System Simulator Database (operating-system-simulator)

An operating system simulator is a rule-based local demo: it runs set toy processes in order, adds the waits, and reports the average wait. The simulator runs 3 processes: waits of 0, 120 and 200 milliseconds. The process render bursts for 120 milliseconds. The processes wait 320 milliseconds in total. Everything runs in this browser; no data leaves the page.
