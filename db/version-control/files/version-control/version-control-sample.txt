Version Control Database (version-control)

Version control tracks changes to text across commits with real diffs. Type the text, press Commit, and read the history. A repository holds 3 commits. A commit of 'hello' hashes to aaf4c61. A diff of the two versions adds 2 lines and removes 1. Everything runs in this browser; no data leaves the page.
