# Version Control Database — files (version-control)

- `demo-version-control.py` — runnable demo program (run with `python3 demo-version-control.py`).
- `version-control-sample.txt` — a plain-text sample of the database.
- The full database is `data/version-control/index.jsonl.gz` (24 records).
- The generator is `gen-version-control.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
