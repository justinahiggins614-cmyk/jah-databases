# Candidate Comparison Database — files (candidate-comparison-signature)

- `demo-candidate-comparison-signature.py` — runnable demo program (run with `python3 demo-candidate-comparison-signature.py`).
- `candidate-comparison-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/candidate-comparison-signature/index.jsonl.gz` (24 records).
- The generator is `gen-candidate-comparison-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
