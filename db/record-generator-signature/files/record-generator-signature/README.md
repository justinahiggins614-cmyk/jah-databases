# Record Generator Database — files (record-generator-signature)

- `demo-record-generator-signature.py` — runnable demo program (run with `python3 demo-record-generator-signature.py`).
- `record-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/record-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-record-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
