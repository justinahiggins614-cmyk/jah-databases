# Audit Log Viewer Database — files (audit-log-viewer)

- `demo-audit-log-viewer.py` — runnable demo program (run with `python3 demo-audit-log-viewer.py`).
- `audit-log-viewer-sample.txt` — a plain-text sample of the database.
- The full database is `data/audit-log-viewer/index.jsonl.gz` (24 records).
- The generator is `gen-audit-log-viewer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
