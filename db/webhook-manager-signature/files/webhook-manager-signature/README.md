# Webhook Manager Database — files (webhook-manager-signature)

- `demo-webhook-manager-signature.py` — runnable demo program (run with `python3 demo-webhook-manager-signature.py`).
- `webhook-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/webhook-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-webhook-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
