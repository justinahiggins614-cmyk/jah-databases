# Candidate Comparison Database — files (candidate-comparison)

- `demo-candidate-comparison.py` — runnable demo program (run with `python3 demo-candidate-comparison.py`).
- `candidate-comparison-sample.txt` — a plain-text sample of the database.
- The full database is `data/candidate-comparison/index.jsonl.gz` (24 records).
- The generator is `gen-candidate-comparison.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
