# Knowledge Assessment Database — files (knowledge-assessment-signature)

- `demo-knowledge-assessment-signature.py` — runnable demo program (run with `python3 demo-knowledge-assessment-signature.py`).
- `knowledge-assessment-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/knowledge-assessment-signature/index.jsonl.gz` (24 records).
- The generator is `gen-knowledge-assessment-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
