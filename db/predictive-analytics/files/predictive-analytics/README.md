# Predictive Analytics Database — files (predictive-analytics)

- `demo-predictive-analytics.py` — runnable demo program (run with `python3 demo-predictive-analytics.py`).
- `predictive-analytics-sample.txt` — a plain-text sample of the database.
- The full database is `data/predictive-analytics/index.jsonl.gz` (24 records).
- The generator is `gen-predictive-analytics.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
