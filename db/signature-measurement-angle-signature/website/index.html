Section 1: Description and history

The Angle Way measures the angle of every stroke of Manon's signature by linear regression, in image coordinates where y increases downward, so the physical-page angle (y up) is the negative of every value given here. Manon uploaded his signature image on 2026-11-23 and asked for it to be measured many ways, as accurately as the Signature system allows, down toward atom scale. The parent agent measured the file the same day, the coordinator verified the numbers twice, and this wave recomputed them again before building, with identical results. Twenty-four full records, ordered simple to compounded to complex, each written in human-readable sentences and paragraphs, each carrying a history and description, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, a scientific equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

Section 2: Math proof

angle = arctan(slope). tan(-52.37 degrees) = -1.2972; tan(-43.38 degrees) = -0.9451; tan(-15.23 degrees) = -0.2722; tan(-16.70 degrees) = -0.3001. Whole signature: arctan(-0.1328) = -7.57 degrees. The demo of every record prints the same kind of total as its math proof, so a fresh run of any demo verifies its proof.

Section 3: Science proof

Least-squares regression finds the line that minimises the squared vertical distance to a cloud of pixels: it is the fairest single direction a spread-out stroke can be given, and it uses every pixel rather than two chosen endpoints. Angles are dimensionless, so they need no render-width assumption at all.

How the Angles Were Found: Linear Regression

JAH-SMANS-000014 · compounded · Feasibility: buildable-now

Signature-line version of this measurement: the same numbers, measured the same way, presented as Manon's own Signature-line record. The Angle Way measures the angle of every stroke of Manon's signature by linear regression, in image coordinates where y increases downward, so the physical-page angle (y up) is the negative of every value given here. Each angle was found by linear regression of y on x over the component's ink pixels: the slope is the covariance of x and y divided by the variance of x, and the angle is the arctangent of the slope. The regression uses every ink pixel of the component, 12,841 for the tall right stroke down to 246 for dot C, so the angle is a property of the whole component rather than of two chosen endpoints. The computation was done twice, by the parent agent and by the coordinator, and recomputed again for this wave with identical results to two decimal places.
