# Land Measurement Tool Database — files (land-measurement-tool-signature)

- `demo-land-measurement-tool-signature.py` — runnable demo program (run with `python3 demo-land-measurement-tool-signature.py`).
- `land-measurement-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/land-measurement-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-land-measurement-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
