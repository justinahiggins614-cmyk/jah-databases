# Dashboard Builder Database — files (dashboard-builder)

- `demo-dashboard-builder.py` — runnable demo program (run with `python3 demo-dashboard-builder.py`).
- `dashboard-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/dashboard-builder/index.jsonl.gz` (24 records).
- The generator is `gen-dashboard-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
