# Webhook Manager Database — files (webhook-manager)

- `demo-webhook-manager.py` — runnable demo program (run with `python3 demo-webhook-manager.py`).
- `webhook-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/webhook-manager/index.jsonl.gz` (24 records).
- The generator is `gen-webhook-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
