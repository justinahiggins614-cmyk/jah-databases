# Cache Management Database — files (cache-management)

- `demo-cache-management.py` — runnable demo program (run with `python3 demo-cache-management.py`).
- `cache-management-sample.txt` — a plain-text sample of the database.
- The full database is `data/cache-management/index.jsonl.gz` (24 records).
- The generator is `gen-cache-management.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
