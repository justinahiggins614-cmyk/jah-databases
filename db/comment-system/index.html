1. Description

A comment system lets readers leave notes under a page: comments, replies, likes and flags, with a moderator keeping the thread kind. The demo on this page is a LOCAL DEMO ONLY: the comments live only in this page, 0 comments are sent to a server, and real posting is BLOCKED. A real comment system needs a server, and this page honestly says so.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

The first comment is 'Hello, great page!' with 18 characters. Counting the comments gives 5 comments. A long comment has 23 words. Deleting a comment takes 5 comments to 4. A comment count of 7 comments and 3 replies. Sorting by likes puts 'Lovely work' first with 5 likes.

3. Science proof

A comment system works because a thread is a list of notes, each with a name, words and likes: adding a comment grows the list, a reply answers one comment, and a flagged comment is hidden until a moderator looks at it. The local demo keeps the list only in the page, so nothing is sent anywhere. That is why the page says plainly that it posts 0 real comments.
