# Flooring Calculator Database — files (flooring-calculator-signature)

- `demo-flooring-calculator-signature.py` — runnable demo program (run with `python3 demo-flooring-calculator-signature.py`).
- `flooring-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/flooring-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-flooring-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
