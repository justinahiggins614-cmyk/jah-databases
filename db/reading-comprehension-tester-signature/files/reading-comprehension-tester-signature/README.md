# Reading Comprehension Tester Database — files (reading-comprehension-tester-signature)

- `demo-reading-comprehension-tester-signature.py` — runnable demo program (run with `python3 demo-reading-comprehension-tester-signature.py`).
- `reading-comprehension-tester-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/reading-comprehension-tester-signature/index.jsonl.gz` (24 records).
- The generator is `gen-reading-comprehension-tester-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
