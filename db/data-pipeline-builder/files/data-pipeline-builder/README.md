# Data Pipeline Builder Database — files (data-pipeline-builder)

- `demo-data-pipeline-builder.py` — runnable demo program (run with `python3 demo-data-pipeline-builder.py`).
- `data-pipeline-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-pipeline-builder/index.jsonl.gz` (24 records).
- The generator is `gen-data-pipeline-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
