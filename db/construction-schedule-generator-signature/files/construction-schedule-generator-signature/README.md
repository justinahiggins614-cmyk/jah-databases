# Construction Schedule Generator Database — files (construction-schedule-generator-signature)

- `demo-construction-schedule-generator-signature.py` — runnable demo program (run with `python3 demo-construction-schedule-generator-signature.py`).
- `construction-schedule-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/construction-schedule-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-construction-schedule-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
