# AI Database Creator Database — files (ai-database-creator)

- `demo-ai-database-creator.py` — runnable demo program (run with `python3 demo-ai-database-creator.py`).
- `ai-database-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-database-creator/index.jsonl.gz` (24 records).
- The generator is `gen-ai-database-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
