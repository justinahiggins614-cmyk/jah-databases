# Delivery Tracking Database — files (delivery-tracking)

- `demo-delivery-tracking.py` — runnable demo program (run with `python3 demo-delivery-tracking.py`).
- `delivery-tracking-sample.txt` — a plain-text sample of the database.
- The full database is `data/delivery-tracking/index.jsonl.gz` (24 records).
- The generator is `gen-delivery-tracking.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
