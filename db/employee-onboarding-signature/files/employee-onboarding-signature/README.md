# Employee Onboarding Database — files (employee-onboarding-signature)

- `demo-employee-onboarding-signature.py` — runnable demo program (run with `python3 demo-employee-onboarding-signature.py`).
- `employee-onboarding-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/employee-onboarding-signature/index.jsonl.gz` (24 records).
- The generator is `gen-employee-onboarding-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
