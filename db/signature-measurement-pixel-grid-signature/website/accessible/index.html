Section 1: Description and history

Manon ordered the Signature system to measure his signature more accurately, as an alternative measurement system, as close to atom scale as can be, and to do it many ways, with a website and databases for each way. This site is the Pixel Grid way, built from his uploaded signature file on 2026-11-23. The signature file is 1,536 by 1,024 pixels; the ink is 37,277 pixels, 2.370 percent of the image; the ink box is 1,257 by 480 pixels from (137, 255) to (1393, 734); there are 7 connected components, 1,505 horizontal ink runs with a median of 23 pixels and a maximum of 80 pixels.

Section 2: Math proof

37,277 ink pixels counted / 1,572,864 image pixels = 0.02370, and 37,277 / 603,360 bounding-box pixels = 0.06178. Every count is a direct count from the file.

ink = {p : grey(p) < 128}; count(ink) = 37,277.

Section 3: Science proof

Thresholding at grey 128 turns the photograph into an ink-or-blank grid, and 8-connected component analysis separates the ink into 7 disjoint parts. The method is the standard binary image analysis used in document measurement, and it is repeatable on the same file.

Section 6: Working demo

Upload any dark-on-light image and the demo counts its ink pixels, finds its bounding box, counts its horizontal ink runs, and labels its connected components — the Pixel Grid measurement, run live in your browser. Your image never leaves your computer.

How the demo works, step by step: open the main version of this page, choose an image file, and the page reads it in your browser, counts every pixel darker than 128 as ink, finds the bounding box, counts the horizontal ink runs, and labels the connected components.
