# SEO Content Analyzer Database — files (seo-content-analyzer)

- `demo-seo-content-analyzer.py` — runnable demo program (run with `python3 demo-seo-content-analyzer.py`).
- `seo-content-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/seo-content-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-seo-content-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
