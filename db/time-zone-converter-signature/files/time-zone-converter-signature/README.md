# Time Zone Converter Database — files (time-zone-converter-signature)

- `demo-time-zone-converter-signature.py` — runnable demo program (run with `python3 demo-time-zone-converter-signature.py`).
- `time-zone-converter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/time-zone-converter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-time-zone-converter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
