# Beam Calculator Database — files (beam-calculator)

- `demo-beam-calculator.py` — runnable demo program (run with `python3 demo-beam-calculator.py`).
- `beam-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/beam-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-beam-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
