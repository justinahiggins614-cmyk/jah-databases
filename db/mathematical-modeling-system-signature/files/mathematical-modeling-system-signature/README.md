# Mathematical Modeling System Database — files (mathematical-modeling-system-signature)

- `demo-mathematical-modeling-system-signature.py` — runnable demo program (run with `python3 demo-mathematical-modeling-system-signature.py`).
- `mathematical-modeling-system-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/mathematical-modeling-system-signature/index.jsonl.gz` (24 records).
- The generator is `gen-mathematical-modeling-system-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
