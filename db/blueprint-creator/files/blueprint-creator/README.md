# Blueprint Creator Database — files (blueprint-creator)

- `demo-blueprint-creator.py` — runnable demo program (run with `python3 demo-blueprint-creator.py`).
- `blueprint-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/blueprint-creator/index.jsonl.gz` (24 records).
- The generator is `gen-blueprint-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
