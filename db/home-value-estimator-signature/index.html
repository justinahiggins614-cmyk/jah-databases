This record covers An Estimate From the Number of Rooms.

An estimate from the number of rooms gives a home a first value in plain numbers: count the rooms, give each kind of room its weight, and add the weights into a range. The estimator must say plainly what each room adds, so a reader can see why a four-room home is valued above a two-room home, and why a home with an extra bedroom is valued above one without. Without the room count, the estimator guesses at size, and a guess at size is a poor way to value a home.
