# Calculus Solver Database — files (calculus-solver)

- `demo-calculus-solver.py` — runnable demo program (run with `python3 demo-calculus-solver.py`).
- `calculus-solver-sample.txt` — a plain-text sample of the database.
- The full database is `data/calculus-solver/index.jsonl.gz` (24 records).
- The generator is `gen-calculus-solver.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
