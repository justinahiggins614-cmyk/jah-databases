# Code Debugger Database — files (code-debugger-signature)

- `demo-code-debugger-signature.py` — runnable demo program (run with `python3 demo-code-debugger-signature.py`).
- `code-debugger-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-debugger-signature/index.jsonl.gz` (24 records).
- The generator is `gen-code-debugger-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
