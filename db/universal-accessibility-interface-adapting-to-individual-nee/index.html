A Profile for Larger Text Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

An accessibility interface website: a visitor answers plain questions about how they read best, and the interface offers a profile, larger text, stronger contrast, a slower pace, with a plain reason for each setting. Every profile is a design study, and the interface never claims to know a real person or to judge a person's needs. This record covers A Profile for Larger Text.

A profile that makes text larger and keeps the lines readable. The design for this record must state the idea in plain sentences, name what a visitor does first, and say what good looks like when it works, so a reader can judge the design without building anything. Without that plain statement, the idea stays vague, a visitor cannot tell what the design promises, and a promising idea is lost because nobody could explain it in words a newcomer can follow. A reader who can follow the design in words can also check it, and a design that can be checked is a design worth building.

Worked example: in a website built this way, a profile for larger text runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
