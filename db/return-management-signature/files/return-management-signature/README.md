# Return Management Database — files (return-management-signature)

- `demo-return-management-signature.py` — runnable demo program (run with `python3 demo-return-management-signature.py`).
- `return-management-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/return-management-signature/index.jsonl.gz` (24 records).
- The generator is `gen-return-management-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
