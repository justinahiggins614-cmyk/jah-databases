# Data Anonymizer Database — files (data-anonymizer)

- `demo-data-anonymizer.py` — runnable demo program (run with `python3 demo-data-anonymizer.py`).
- `data-anonymizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-anonymizer/index.jsonl.gz` (24 records).
- The generator is `gen-data-anonymizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
