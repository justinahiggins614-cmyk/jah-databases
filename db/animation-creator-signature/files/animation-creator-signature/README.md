# Animation Creator Database — files (animation-creator-signature)

- `demo-animation-creator-signature.py` — runnable demo program (run with `python3 demo-animation-creator-signature.py`).
- `animation-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/animation-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-animation-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
