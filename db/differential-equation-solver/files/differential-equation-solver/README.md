# Differential Equation Solver Database — files (differential-equation-solver)

- `demo-differential-equation-solver.py` — runnable demo program (run with `python3 demo-differential-equation-solver.py`).
- `differential-equation-solver-sample.txt` — a plain-text sample of the database.
- The full database is `data/differential-equation-solver/index.jsonl.gz` (24 records).
- The generator is `gen-differential-equation-solver.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
