# Database AI Assistant Database — files (database-ai-assistant)

- `demo-database-ai-assistant.py` — runnable demo program (run with `python3 demo-database-ai-assistant.py`).
- `database-ai-assistant-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-ai-assistant/index.jsonl.gz` (24 records).
- The generator is `gen-database-ai-assistant.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
