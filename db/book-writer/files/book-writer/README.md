# Book Writer Database — files (book-writer)

- `demo-book-writer.py` — runnable demo program (run with `python3 demo-book-writer.py`).
- `book-writer-sample.txt` — a plain-text sample of the database.
- The full database is `data/book-writer/index.jsonl.gz` (24 records).
- The generator is `gen-book-writer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
