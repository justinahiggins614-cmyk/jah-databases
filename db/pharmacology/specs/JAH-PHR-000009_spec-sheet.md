## Spec
- **Mechanism:** Fluoroquinolones are drugs whose mechanism of action is: inhibit bacterial DNA gyrase and topoisomerase, blocking DNA replication. Example drugs include ciprofloxacin, levofloxacin, moxifloxacin. Like all medicines, this class carries risks and interactions that clinicians weigh before use. Therapeutic uses include urinary infections, anthrax exposure, pneumonia. Educational reference only; not medical advice. No dosage information is stored in this database.
