# Sulfonylureas: therapeutic uses (R-10021) — Spec sheet

Record JAH-PHR-000021 — Public edition, pharmacology.
JCC v1 code: JAHDB/pharmacology#JAH-PHR-000021

## Spec
- **Mechanism:** Sulfonylureas are drugs whose mechanism of action is: stimulate the pancreas to release more insulin. Therapeutic uses include type 2 diabetes. Prescribers choose this class when these conditions call for its mechanism. Example drugs include glipizide, glyburide, glimepiride.
