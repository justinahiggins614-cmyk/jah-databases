## Spec
- **Mechanism:** Tetracyclines are drugs whose mechanism of action is: bind the bacterial 30S ribosomal subunit, blocking protein synthesis; broad spectrum. Example drugs include doxycycline, tetracycline, minocycline. Like all medicines, this class carries risks and interactions that clinicians weigh before use. Therapeutic uses include acne, Lyme disease, respiratory infections. Educational reference only; not medical advice. No dosage information is stored in this database.
