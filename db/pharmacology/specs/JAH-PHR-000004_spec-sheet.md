# Antifungals: overview (R-10004) — Spec sheet

Record JAH-PHR-000004 — Public edition, pharmacology.

## Spec
- **Mechanism:** Antifungals are drugs whose mechanism of action is: disrupt fungal cell membranes or cell walls. Example drugs include fluconazole, amphotericin B, terbinafine. Therapeutic uses include yeast infections, systemic mycoses, athlete’s foot. Naming hint: members of this class often carry the suffix -azole.
