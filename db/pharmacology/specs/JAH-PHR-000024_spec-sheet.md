## Spec
- **Mechanism:** General anesthetics are drugs whose mechanism of action is: produce reversible unconsciousness and insensitivity to pain for surgery. Example drugs include propofol, sevoflurane, ketamine. Therapeutic uses include surgery, procedural sedation. This class has no single naming suffix.
