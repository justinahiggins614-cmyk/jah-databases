# H2 blockers: overview (R-10013) — Spec sheet

Record JAH-PHR-000013 — Public edition, pharmacology.
JCC v1 code: JAHDB/pharmacology#JAH-PHR-000013

## Spec
- **Mechanism:** H2 blockers are drugs whose mechanism of action is: block histamine H2 receptors in the stomach, reducing acid secretion. Example drugs include famotidine, cimetidine, nizatidine. Therapeutic uses include heartburn, ulcers, GERD. Naming hint: members of this class often carry the suffix -tidine.
