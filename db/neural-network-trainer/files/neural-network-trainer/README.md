# Neural Network Trainer Database — files (neural-network-trainer)

- `demo-neural-network-trainer.py` — runnable demo program (run with `python3 demo-neural-network-trainer.py`).
- `neural-network-trainer-sample.txt` — a plain-text sample of the database.
- The full database is `data/neural-network-trainer/index.jsonl.gz` (24 records).
- The generator is `gen-neural-network-trainer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
