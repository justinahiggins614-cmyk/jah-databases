  1. A Hilltop View Reached by a Marked Path

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    Attraction discovery helps a visitor find a kind of place worth visiting, in plain words, with the distance, the time needed, and the cost written out before the visitor sets out. Every listing is a clearly labeled illustrative sample of a generic kind of place, never a real attraction, and no real place is named. A hilltop view is only worth the climb if the path is marked, because a walker who cannot find the way will turn back halfway and miss the view entirely. The listing must say how long the climb takes, where the path starts, and what it costs, so a walker can judge whether to set out. Without those plain facts, the hill belongs only to those who already know the way, and every new visitor is left at the bottom.
