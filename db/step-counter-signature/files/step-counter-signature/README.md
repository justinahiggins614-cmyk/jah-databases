# Step Counter Database — files (step-counter-signature)

- `demo-step-counter-signature.py` — runnable demo program (run with `python3 demo-step-counter-signature.py`).
- `step-counter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/step-counter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-step-counter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
