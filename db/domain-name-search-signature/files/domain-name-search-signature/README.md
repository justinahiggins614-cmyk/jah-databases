# Domain Name Search Database — files (domain-name-search-signature)

- `demo-domain-name-search-signature.py` — runnable demo program (run with `python3 demo-domain-name-search-signature.py`).
- `domain-name-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/domain-name-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-domain-name-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
