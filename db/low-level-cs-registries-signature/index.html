A Signature design for a float inspector: one tool that reads any IEEE 754 value and shows its sign, exponent, and mantissa in plain words.

The Signature float inspector design takes the IEEE 754 standard as a fixed input and designs a teaching tool around it: a reader that accepts a 32-bit or 64-bit pattern and reports the sign, the exponent, and the mantissa, with a plain-English reading of what the number is. The design question is how to make the standard's rules visible instead of hidden inside a chip: the answer is a display that shows the three fields separately, states the bias, and names the value class, normal, subnormal, zero, infinity, or NaN, before it ever prints the decimal. The design also plans the failure mode: if a user feeds in a pattern with an all-ones exponent and a nonzero mantissa, the inspector reports NaN and explains why the value is not a number, instead of printing a garbage decimal. This record designs the inspector's fields, its classification step, and its plain-English output, so the Signature system teaches the standard by showing it.

A Signature builder opens the inspector and types the binary32 pattern 3fc00000. The same builder types 7f800000: the exponent is all ones and the mantissa is zero, so the inspector reports positive infinity and explains that an all-ones exponent with a zero mantissa is infinity, not a number. A third pattern, 7fc00000, is reported as NaN, with the explanation that an all-ones exponent with a nonzero mantissa is not a number at all.
