# File Compressor Database — files (file-compressor)

- `demo-file-compressor.py` — runnable demo program (run with `python3 demo-file-compressor.py`).
- `file-compressor-sample.txt` — a plain-text sample of the database.
- The full database is `data/file-compressor/index.jsonl.gz` (24 records).
- The generator is `gen-file-compressor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
