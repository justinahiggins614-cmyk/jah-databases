# Dictionary entries — The Learning Management Systems Database

Key terms of this database, defined in plain words.

## learning management system

The recorded system that holds courses, lessons, learners, and marks in one place, so that a whole course can be followed from its first lesson to its last.

## course

A stated set of lessons on one subject, kept in the record with its name, its lessons, and its learners, so that the teaching can be followed in order.

## lesson

A single unit of teaching within a course, kept in the record with its title and its place in the course, so that the order of the teaching can be read plainly.

## learner

A person enrolled on a course in a learning management system, recorded under a name and a number so that every paper for that learner can be matched to the same person.

## module

A grouped set of lessons within a course, kept in the record with its name and its lessons, so that the parts of the course can be read in order.

## enrollment

The recorded entry of a learner on a course, kept with the date and the course, so that the taking of the place can be proved from the record.

## assignment

A piece of work set for a learner in a course, kept in the record with its title and its due date, so that what was set and when it was due can be read plainly.

## mark

The recorded result given for a piece of work or a course, kept with the learner, the work, and the date, so that the result can be proved from the paper.

## discussion board

The written place in a learning management system where learners and teachers leave messages for the course, kept in the record so that the talk of the course can be followed.

## course catalogue

The ordered list of all courses offered by a school or college, kept so that any course can be found by its place in the list.

## certificate

The written statement that a learner has finished a course, kept in the record with the learner and the course, so that the finishing can be proved from the paper.

## teacher

The person who teaches a course in a learning management system, named in the record with the course, so that who taught the course can be read plainly.
