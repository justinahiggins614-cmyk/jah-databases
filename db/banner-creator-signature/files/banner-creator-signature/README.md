# Banner Creator Database — files (banner-creator-signature)

- `demo-banner-creator-signature.py` — runnable demo program (run with `python3 demo-banner-creator-signature.py`).
- `banner-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/banner-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-banner-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
