# Chemical Equation Balancer Database — files (chemical-equation-balancer-signature)

- `demo-chemical-equation-balancer-signature.py` — runnable demo program (run with `python3 demo-chemical-equation-balancer-signature.py`).
- `chemical-equation-balancer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/chemical-equation-balancer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-chemical-equation-balancer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
