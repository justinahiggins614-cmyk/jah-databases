# Geocoding Tool Database — files (geocoding-tool-signature)

- `demo-geocoding-tool-signature.py` — runnable demo program (run with `python3 demo-geocoding-tool-signature.py`).
- `geocoding-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/geocoding-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-geocoding-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
