The Automatic Application Conversion Between Operating Systems Database

Accessible version: plain text, no scripts, no sign-in, free forever. Automatic application conversion is a research concept: a system that takes an application written for one operating system and rebuilds it for another, keeping what it does, how it looks, and how it answers. This database is a design study of that concept, and it labels feasibility honestly: converting a small plain application is research-stage, and converting every application is breakthrough-dependent.

Twenty-four full records, ordered simple to compounded to complex.
