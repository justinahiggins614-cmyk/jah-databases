About this data base

Archive
This database's finished books (JAH-BOOK records) — 16 genres, full chapters — preserved as structured, searchable data.
Record schema
id · title · author · genre · gkey · desc · words · chapters[{t, b}] · note · sources · origin · creation_mode · stamp
Generator
jahdb-books-1.0 — deterministic (mulberry32), assembles each book combinatorially from clean pools, computes the real word count, then an independent verifier rebuilds the title, description, and every chapter from the private pool indices before acceptance.
Drift control
Every generated book is checked against an archive sample for duplicate titles and re-verified by the independent verifier.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Book Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
