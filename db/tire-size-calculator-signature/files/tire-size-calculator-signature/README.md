# Tire Size Calculator Database — files (tire-size-calculator-signature)

- `demo-tire-size-calculator-signature.py` — runnable demo program (run with `python3 demo-tire-size-calculator-signature.py`).
- `tire-size-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/tire-size-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-tire-size-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
