# AI Mathematician Database — files (ai-mathematician-signature)

- `demo-ai-mathematician-signature.py` — runnable demo program (run with `python3 demo-ai-mathematician-signature.py`).
- `ai-mathematician-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-mathematician-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-mathematician-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
