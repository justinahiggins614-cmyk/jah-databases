# Government Records Search Database — files (government-records-search-signature)

- `demo-government-records-search-signature.py` — runnable demo program (run with `python3 demo-government-records-search-signature.py`).
- `government-records-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/government-records-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-government-records-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
