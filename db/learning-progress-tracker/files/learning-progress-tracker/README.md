# Learning Progress Tracker Database — files (learning-progress-tracker)

- `demo-learning-progress-tracker.py` — runnable demo program (run with `python3 demo-learning-progress-tracker.py`).
- `learning-progress-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/learning-progress-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-learning-progress-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
