# Image Cropper Database — files (image-cropper)

- `demo-image-cropper.py` — runnable demo program (run with `python3 demo-image-cropper.py`).
- `image-cropper-sample.txt` — a plain-text sample of the database.
- The full database is `data/image-cropper/index.jsonl.gz` (24 records).
- The generator is `gen-image-cropper.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
