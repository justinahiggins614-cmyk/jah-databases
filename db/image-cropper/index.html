1. Description

An image cropper cuts away the edges of a picture and keeps only the chosen rectangle. Upload a picture, set the rectangle, and download the cropped copy. The original file is never changed; everything happens on a canvas in this browser.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

A crop rectangle is four numbers: left, top, width and height. The kept picture is width by height pixels, and the kept pixel count is width times height. Cropping an 800 by 600 picture to 400 by 300 keeps 120,000 of 480,000 pixels, exactly one quarter.

3. Science proof

A picture is a grid of pixels, and cropping keeps a sub-grid of that grid. Cutting away edges removes distractions and moves the subject in the frame, which is why a crop can improve a picture without changing any pixel that remains. The canvas copies only the kept rectangle to a new picture.

6. Use

Upload a picture, type the left, top, width and height of the rectangle to keep, and press Crop. The preview shows the kept part, and Download saves it. Nothing is uploaded to any server.

The canvas copies only the kept rectangle to a new picture.
