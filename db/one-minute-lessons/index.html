Section 1: Description and history

Short lessons are an old teaching habit: one idea on a slate, one example told aloud, one question left for the walk home. The website form grows out of that habit, adding a timer, a library sorted by subject, and a streak for readers who return each day. Every record below carries its own history section, so the description and the history of each design are told together, in full sentences and paragraphs, never as stubs.

Section 2: Math proof

Every record carries a worked arithmetic proof: a count multiplied by a per-item amount gives a total, and the demo program prints that same total, so a fresh run of the demo verifies the proof exactly.
