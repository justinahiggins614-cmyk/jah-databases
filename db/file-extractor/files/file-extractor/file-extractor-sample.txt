File Extractor Database (file-extractor)

A file extractor lists and unpacks archives made locally. Pick an archive, press Extract, and read the entries. An archive holds 2 entries: hello.txt and notes.txt. The entry hello.txt holds 11 bytes. Entries of 11, 10 and 5 bytes total 26 bytes. Everything runs in this browser; no data leaves the page.

Worked example: An archive holds 2 entries: hello.txt and notes.txt
