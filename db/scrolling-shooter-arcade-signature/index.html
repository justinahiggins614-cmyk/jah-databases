Sky Serpent Run Rank 1 · simple · vertical scrolling shooter · beginner

A sky-serpent courier flies medicine over a mountain range, dodging storm-kites and bombing supply drops to villages below. The courier's serpent-ship fires wind-darts at air targets and drops medicine bundles on ground beacons.

The rules are simple: the ship starts on row 5 and enemies spawn on ticks 2, 6, 10, 14, 18, scrolling in from the right. The player moves between rows and shoots, scoring for every enemy destroyed and surviving the scroll with lives to spare.

Supply beacons must be bombed before they pass under the ship, so the courier plans drops a beat early. Storm-kites dive in pairs, and the courier clears the pair's leader first, since the follower breaks off when the leader falls.

Original game note: This is an original arcade-style game created for this Signature edition, with its own title, rules, and play.

How to play

Type up/down/left/right/shoot each tick to survive the scroll, quit to stop.

import sys
PARAMS = {'start_row': 5, 'spawns': [[2, 3], [6, 0], [10, 4], [14, 2], [18, 1]]}
AUTO = ['shoot', 'shoot', 'up', 'up', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot', 'shoot']

def auto_play():
    player = [2, PARAMS["start_row"]]
    enemies = []
    schedule = dict((t, r) for t, r in PARAMS["spawns"])
    score, lives = 0, 3
    print("Scrolling tribute: auto session")
    for tick, cmd in enumerate(AUTO):
        if tick in schedule:
            enemies.append([11, schedule[tick]])
        if cmd == "up":
            player[1] = max(0, player[1] - 1)
        elif cmd == "down":
            player[1] = min(5, player[1] + 1)
        elif cmd == "left":
            player[0] = max(0, player[0] - 1)
        elif cmd == "right":
            player[0] = min(11, player[0] + 1)
        elif cmd == "shoot":
            for e in list(enemies):
                if e[1] == player[1] and player[0] < e[0] <= player[0] + 4:
                    enemies.remove(e)
                    score += 100
                    break
        enemies = [[x - 1, y] for (x, y) in enemies]
        if any((x, y) == (player[0], player[1]) for (x, y) in enemies):
            lives -= 1
            enemies = [e for e in enemies if (e[0], e[1]) != (player[0], player[1])]
        score += 10
        print("Tick %d: %s player %s enemies %d score %d lives %d" % (tick + 1, cmd, tuple(player), len(enemies), score, lives))
        if lives <= 0:
            break
    print("FINAL SCORE: %d" % score)
    print("RESULT: %s" % ("SURVIVED" if lives > 0 else "OUT OF LIVES"))
