The Design/System

The design is one database per subject, with a public edition and a Signature edition side by side. The Generator

The boundless generator for this database is the file gen-healthcare-provider-directory.js. It is seeded and deterministic: the same seed always gives the same record, and different seeds differ. It is throttled to 100 records per call, it stops at 1,000,000,000 records per file, and every generated record is labeled generated, never presented as an archive record.
