API Builder: Integration with the Other 99 Programs

JAH-APIB-000015 — api builder record

The API Builder works with the other ninety-nine programs in the 100: it offers its own job through its API, and it uses the other programs' APIs where they do a job better — search through the Universal Search Engine, storage through the Database Builder, verification through the Software Testing Center. This record names the programs it depends on, the programs that depend on it, and the order they are built in, so that no program is built before the programs it needs. In this public edition the program offers 8 capabilities (creating an interface contract from a list of resources (1); generating working server code for the contract (2); documentation for every endpoint (3); a test for every endpoint (4); validation that rejects malformed calls with a clear error (5); versioning so old clients keep working (6); an API other programs use to build APIs (7); a plain-text build report (8)), 6 interfaces (Resource form — resources and their fields, in plain words; Endpoint list — every call the interface offers, with its inputs and outputs; Contract view — the machine-readable contract, readable and downloadable; Test run — run the endpoint tests and see the result; Builder API — machine-readable API building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (resources — the things the system holds; endpoints — the calls the interface offers; contract — the machine-readable OpenAPI specification; server_code — the working server code; documentation — what each endpoint does, in plain words; tests — the test result for every endpoint; version — the contract version; errors — how malformed calls are answered). This record is number 15 of 24 in the public edition of the API Builder database pair, and it specifies the integration with the other 99 programs topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
