# Reaction Predictor Database — files (reaction-predictor)

- `demo-reaction-predictor.py` — runnable demo program (run with `python3 demo-reaction-predictor.py`).
- `reaction-predictor-sample.txt` — a plain-text sample of the database.
- The full database is `data/reaction-predictor/index.jsonl.gz` (24 records).
- The generator is `gen-reaction-predictor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
