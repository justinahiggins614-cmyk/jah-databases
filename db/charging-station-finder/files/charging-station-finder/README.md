# Charging Station Finder Database — files (charging-station-finder)

- `demo-charging-station-finder.py` — runnable demo program (run with `python3 demo-charging-station-finder.py`).
- `charging-station-finder-sample.txt` — a plain-text sample of the database.
- The full database is `data/charging-station-finder/index.jsonl.gz` (24 records).
- The generator is `gen-charging-station-finder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
