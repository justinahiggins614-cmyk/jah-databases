# Decentralized Application Builder Database — files (decentralized-application-builder)

- `demo-decentralized-application-builder.py` — runnable demo program (run with `python3 demo-decentralized-application-builder.py`).
- `decentralized-application-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/decentralized-application-builder/index.jsonl.gz` (24 records).
- The generator is `gen-decentralized-application-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
