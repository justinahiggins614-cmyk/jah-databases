Asteroids Rank 1 · simple · vector graphics · beginner

Asteroids, Atari's 1979 vector classic, puts the player in a lone ship drifting through an asteroid field rendered in glowing lines. Thrust rotates and pushes the ship with real momentum, so stopping takes as long as starting, and every large rock splits into smaller, faster fragments when shot. The saucer that occasionally crosses the screen adds a moving threat to the drifting rocks.

The tribute demo is an original vector-style miniature: a ship starts at [4, 5] among 4 drifting rocks on a glowing grid, thrusting with momentum, turning, and firing at rocks that split when hit. It captures the feel of the arcade original's line-drawn space without copying its code, art, or sound.

Momentum is the whole skill: a player who thrusts in short taps keeps the ship controllable, while long burns send it sliding across the field. Clearing large rocks near the edges first keeps the center open, and the hyperspace jump is a last resort, since it can drop the ship onto a rock.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Asteroids (1979). It is not Asteroids (1979), and it uses no art, music, or code from that game.

How to play

Type thrust/left/right/shoot to fly and fire, quit to stop.

import sys
PARAMS = {'w': 20, 'h': 16, 'ship': [4, 5], 'rocks': [[3, 2, -1, 0, 2], [8, 5, 1, 1, 1], [13, 8, -1, 1, 1], [4, 11, 1, 0, 2]]}
AUTO = ['thrust', 'thrust', 'shoot', 'right', 'thrust', 'shoot', 'left', 'thrust', 'shoot', 'shoot', 'right', 'thrust', 'shoot', 'left', 'shoot', 'thrust']

DIRS_V = [(1, 0), (0, 1), (-1, 0), (0, -1)]

def auto_play():
    W, H = PARAMS["w"], PARAMS["h"]
    ship = list(PARAMS["ship"])
    heading = 0
    rocks = [list(r) for r in PARAMS["rocks"]]
    score, lives = 0, 3
    print("Vector tribute: auto session")
    for i, cmd in enumerate(AUTO):
        if cmd == "left":
            heading = (heading - 1) % 4
        elif cmd == "right":
            heading = (heading + 1) % 4
        elif cmd == "thrust":
            dx, dy = DIRS_V[heading]
            ship[0] = (ship[0] + dx * 2) % W
            ship[1] = (ship[1] + dy * 2) % H
        elif cmd == "shoot":
            dx, dy = DIRS_V[heading]
            for k in range(1, 4):
                target = ((ship[0] + dx * k) % W, (ship[1] + dy * k) % H)
                hit = None
                for rock in rocks:
                    if (rock[0], rock[1]) == target:
                        hit = rock
                        break
                if hit is not None:
                    rocks.remove(hit)
                    score += hit[4] * 20
                    if hit[4] == 2:
                        rocks.append([hit[0], hit[1], 1, 0, 1])
                        rocks.append([hit[0], hit[1], 0, 1, 1])
                    break
        new_rocks = []
        for rock in rocks:
            rock[0] = (rock[0] + rock[2]) % W
            rock[1] = (rock[1] + rock[3]) % H
            new_rocks.append(rock)
        rocks = new_rocks
        if any((rock[0], rock[1]) == (ship[0], ship[1]) for rock in rocks):
            lives -= 1
            rocks = [r for r in rocks if (r[0], r[1]) != (ship[0], ship[1])]
        print("Step %d: %s ship %s rocks %d score %d lives %d" % (i + 1, cmd, tuple(ship), len(rocks), score, lives))
        if not rocks or lives <= 0:
            break
    print("FINAL SCORE: %d" % score)
    print("RESULT: %s" % ("WIN" if not rocks else "OUT OF LIVES" if lives <= 0 else "ONGOING"))

Asteroids Deluxe Rank 2 · simple · vector graphics · beginner

Asteroids Deluxe, Atari's 1981 follow-up, keeps the drifting ship and splitting rocks but adds new hazards: a shield that protects the ship briefly, and killer satellites that break apart into hunter drones. The graphics are sharper, the rocks are more varied, and the pace is noticeably faster than the original.

The tribute demo is an original vector-style miniature: a ship starts at [5, 6] among 5 drifting rocks on a glowing grid, thrusting with momentum, turning, and firing at rocks that split when hit. The shield changes the risk calculus, letting a player survive a collision that would have ended a run in the original. Killer satellites should be broken at range, since their hunter drones are far more dangerous up close than the satellite itself.

Battlezone Rank 3 · simple · vector graphics · beginner

Battlezone, Atari's 1980 vector tank game, is one of the first first-person arcade experiences. The player drives a tank across a wireframe plain, viewed through a periscope-style cabinet, and duels enemy tanks, missiles, and flying saucers that appear on the horizon. Its stark green lines and radar display made it feel like a genuine combat simulator.

The tribute demo is an original vector-style miniature: a ship starts at [6, 7] among 6 drifting rocks on a glowing grid, thrusting with momentum, turning, and firing at rocks that split when hit. The radar is as important as the viewport: enemies appear on radar before they are visible, so a good driver turns toward the blip early. Long-range shots work, but the enemy tanks dodge, so the winning habit is to fire, reposition, and fire again rather than trading shots head-on.

Tempest Rank 4 · simple · vector graphics · beginner

Tempest, Atari's 1981 tube shooter, wraps vector graphics around a tunnel the player views from one end. The player's claw-ship rides the rim of the tube, zapping enemies that crawl up from the far end, while spikes and flippers threaten from the sides. Its color vector display and escalating tube shapes were unlike anything else on the floor.

The tribute demo is an original vector-style miniature: a ship starts at [7, 8] among 7 drifting rocks on a glowing grid, thrusting with momentum, turning, and firing at rocks that split when hit. It captures the feel of the arcade original's line-drawn space without copying its code, art, or sound.

Riding the rim means the player is always choosing a lane, and the safest lane is usually the one with the fewest climbers. Zapper shots travel down the tube, so firing early at distant enemies clears them before they reach the rim and split into hazards.
