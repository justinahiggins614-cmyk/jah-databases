# Fraction Calculator Database — files (fraction-calculator-signature)

- `demo-fraction-calculator-signature.py` — runnable demo program (run with `python3 demo-fraction-calculator-signature.py`).
- `fraction-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/fraction-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-fraction-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
