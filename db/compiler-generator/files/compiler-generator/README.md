# Compiler Generator Database — files (compiler-generator)

- `demo-compiler-generator.py` — runnable demo program (run with `python3 demo-compiler-generator.py`).
- `compiler-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/compiler-generator/index.jsonl.gz` (24 records).
- The generator is `gen-compiler-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
