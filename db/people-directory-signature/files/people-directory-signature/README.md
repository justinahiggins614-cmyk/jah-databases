# People Directory Database — files (people-directory-signature)

- `demo-people-directory-signature.py` — runnable demo program (run with `python3 demo-people-directory-signature.py`).
- `people-directory-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/people-directory-signature/index.jsonl.gz` (24 records).
- The generator is `gen-people-directory-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
