Capabilities

Capability 1
Source ingestion: reads any file or database record and extracts teachable content.
Capability 2
Lecture outline synthesis: orders extracted content into a timed, logical lecture structure.
Capability 3
Narration script generation: writes a full spoken script for the lecture.
Capability 4
Slide deck structuring: generates slide-by-slide structure with titles and key points.
Capability 5
Source mixing: merges two or more databases into one unified lecture.
Capability 6
Pacing and timing: allocates minutes per section and keeps total lecture time on budget.
Capability 7
Comprehension checks: writes review questions and answers per lecture section.
Capability 8
Export formats: emits lecture as plain text, markdown outline, slide structure, and script.

Boundless generator

Generator script: gen-lecture-creator-signature.js — run node gen-lecture-creator-signature.js --n 5. Self-regulating: throttled, duplicate-checked, stops at 1015 or when complete. Generated output is labeled "generated" and never mixed with assistant-built records.

Demo program

Every record carries an executed demo program (Node.js, verified 2026-10-21). Example:

const pkg={outline:['intro','licenses','schemas','examples','review'],script:'spoken script text',slides:20,quiz:[{q:'What is a schema?',a:'field documentation'}]};
