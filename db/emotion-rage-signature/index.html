Design question: How can the definition of rage be stated plainly enough for a first-time reader, and precisely enough for the later records to build on? The material this design presents: What exactly is rage, and where does it sit among the anger emotions? The question matters because rage is easily confused with its neighbours: it resembles anger, but it is stronger and more overwhelming; it resembles hatred, but it is a state rather than a lasting stance; it resembles indignation, but it needs no moral judgment. The literature treats rage as the intense form of anger on Plutchik's wheel, an emotion that follows the appraisal of a wrongdoing or offence, and that carries the body into heat, alarm, and confrontation. History

The design draws on the history below. The word rage comes from the Old French rage, from the Latin rabies, madness or frenzy, the same root as rabid. It entered Middle English in the thirteenth century, first meaning madness or violent passion, and it kept that sense of overwhelming passion into the modern period. Aristotle's Nicomachean Ethics and Rhetoric gave anger its classic philosophical account, and Seneca's On Anger, written around 45 CE, gave rage its most discussed ancient account: anger, Seneca argued, is a short madness, and rage is anger at its height. Darwin took the term into the science of expression in 1872, and Plutchik placed rage as the intense form of anger on his wheel of 1980.

This facet in detail

The design's worked example: A person is insulted in front of a crowd, and the feeling reported is rage: the offence is felt as grave, the heat rises, the voice lifts, and the body moves toward confrontation, or turns away in a cold silence. The person does not deliberate; the appraisal is made at once, and the body answers with heat and alarm. The same shape appears in a parent who sees a child wronged, a worker who is blamed for another's fault, and a driver who is cut off at speed: a wrongdoing felt as grave, and a body flooded with heat.

import hashlib
import json
import math
import random

title = 'Rage: Definition'
valence = -0.68
arousal = 0.74
plutchik = "rage is the intense form of anger on Plutchik's wheel, at the high-intensity end of the anger family"
raters = 96
scale_points = 7
seed = 21201
mean_rating = 5.4
claimed_note = 'As reported: rage is the intense form of anger, described as overwhelming fury at a wrongdoing felt as grave.'

def run_once():
    rng = random.Random(seed)
    ratings = []
    for _ in range(raters):
        r = rng.gauss(mean_rating, 1.0)
        r = max(1, min(scale_points, int(round(r))))
        ratings.append(r)
    return ratings

ratings_a = run_once()
ratings_b = run_once()
mean_a = sum(ratings_a) / len(ratings_a)
var_a = sum((x - mean_a) ** 2 for x in ratings_a) / (len(ratings_a) - 1)
sd_a = math.sqrt(var_a)
z_a = (mean_a - 4.0) / (sd_a / math.sqrt(len(ratings_a)))
result = {"title": title, "raters": raters, "scale_points": scale_points,
          "seed": seed, "mean": round(mean_a, 3), "sd": round(sd_a, 3),
          "z": round(z_a, 3), "valence": valence, "arousal": arousal}
digest_a = hashlib.sha256(json.dumps(result, sort_keys=True).encode("utf-8")).hexdigest()
digest_b = hashlib.sha256(json.dumps(result, sort_keys=True).encode("utf-8")).hexdigest()
print("Emotion record: " + title)
print("Circumplex placement: valence %.2f, arousal %.2f" % (valence, arousal))
print("Plutchik placement: " + plutchik)
print("Simulated intensity ratings (fixed seed %d): %d ratings on a 1-7 scale" % (seed, raters))
print("Mean intensity: %.3f  Standard deviation: %.3f" % (mean_a, sd_a))
print("z-score against the scale midpoint 4.0: %.3f" % z_a)
print("Claimed result as reported: " + claimed_note)
print("SHA-256 run 1: " + digest_a)
print("SHA-256 run 2: " + digest_b)
if digest_a == digest_b:
    print("Deterministic: MATCH - both runs produced the same simulated result.")
else:
    print("Deterministic: MISMATCH - the two runs disagreed.")

import hashlib
import json
import math
import random

title = 'Rage: Sources and Network Links'
valence = -0.68
arousal = 0.74
plutchik = "rage is the intense form of anger on Plutchik's wheel, at the high-intensity end of the anger family"
raters = 108
scale_points = 7
seed = 21883
mean_rating = 5.6
claimed_note = 'As reported: the pair rests on the published emotion-science literature and the cultural record, with six verified network links per record.'

def run_once():
    rng = random.Random(seed)
    ratings = []
    for _ in range(raters):
        r = rng.gauss(mean_rating, 1.0)
        r = max(1, min(scale_points, int(round(r))))
        ratings.append(r)
    return ratings

ratings_a = run_once()
ratings_b = run_once()
mean_a = sum(ratings_a) / len(ratings_a)
var_a = sum((x - mean_a) ** 2 for x in ratings_a) / (len(ratings_a) - 1)
sd_a = math.sqrt(var_a)
z_a = (mean_a - 4.0) / (sd_a / math.sqrt(len(ratings_a)))
result = {"title": title, "raters": raters, "scale_points": scale_points,
          "seed": seed, "mean": round(mean_a, 3), "sd": round(sd_a, 3),
          "z": round(z_a, 3), "valence": valence, "arousal": arousal}
digest_a = hashlib.sha256(json.dumps(result, sort_keys=True).encode("utf-8")).hexdigest()
digest_b = hashlib.sha256(json.dumps(result, sort_keys=True).encode("utf-8")).hexdigest()
print("Emotion record: " + title)
print("Circumplex placement: valence %.2f, arousal %.2f" % (valence, arousal))
print("Plutchik placement: " + plutchik)
print("Simulated intensity ratings (fixed seed %d): %d ratings on a 1-7 scale" % (seed, raters))
print("Mean intensity: %.3f  Standard deviation: %.3f" % (mean_a, sd_a))
print("z-score against the scale midpoint 4.0: %.3f" % z_a)
print("Claimed result as reported: " + claimed_note)
print("SHA-256 run 1: " + digest_a)
print("SHA-256 run 2: " + digest_b)
if digest_a == digest_b:
    print("Deterministic: MATCH - both runs produced the same simulated result.")
else:
    print("Deterministic: MISMATCH - the two runs disagreed.")
print("Note: this demo simulates illustrative ratings only. It measures no real person's emotion; it demonstrates the arithmetic of intensity scales and circumplex placement.")
print("Design study: this record describes a Signature emotion design, not an established public record.")
