# Image Resizer Database — files (image-resizer)

- `demo-image-resizer.py` — runnable demo program (run with `python3 demo-image-resizer.py`).
- `image-resizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/image-resizer/index.jsonl.gz` (24 records).
- The generator is `gen-image-resizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
