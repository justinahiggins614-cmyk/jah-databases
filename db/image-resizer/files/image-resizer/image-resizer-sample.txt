Image Resizer Database (image-resizer)

An image resizer changes the width and height of a picture in pixels. Upload a picture, set a new size, and download the resized copy. The original file is never changed; everything happens on a canvas in this browser.

Worked example: A picture of 800 by 600 pixels resizes to 400 by 300 pixels.

Demo output:
800x600 -> 400x300; pixels 480000 -> 120000
