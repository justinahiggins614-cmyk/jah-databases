JAH-PLASMA-MEM-000001 — Plasma Computer Memory — Overview and definition

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. Memory in a plasma computer is stored configuration: a density pattern, a vortex, a trapped wave, or a self-organized structure that persists long enough to be useful. The idea has real roots — early computers used acoustic delay-line memory (bits as sound waves in mercury) and magnetic-core memory (bits as magnetized rings), both 'stored patterns in a medium' designs. Plasma memory is the same idea in the fourth state of matter: bits as stable configurations of ionized gas.

JAH-PLASMA-MEM-000002 — Plasma Computer Memory — Persistent plasma structures

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. Some plasma configurations are self-sustaining: spheromaks (self-organized toroidal plasma rings, studied in fusion research) and plasmoids can persist for many characteristic times without external drive. A trapped spheromak is a natural memory cell — its presence is 1, its absence 0, and its internal field twist could encode more. Using them as memory is a new proposal (labeled as such), but the structures themselves are established, reproducible plasma physics.

JAH-PLASMA-MEM-000003 — Plasma Computer Memory — Density-pattern memory

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. The simplest memory writes bits as a frozen density modulation: launch a standing wave, and its nodes and antinodes are a bit string written across the cell. Standing Langmuir waves are textbook physics; reading is done by scattering a probe wave off the pattern and measuring the echo. Density memory is fast to write (one wave period) and naturally parallel (a whole row of bits per wave).

Demo: Spheromak helicity 4-bit codec

const enc=v=>v&15,dec=s=>s&15;const vals=[0,1,7,15].map(v=>dec(enc(v)));J({roundtrip:vals});assert(vals.join(',')==='0,1,7,15','codec');

Verified output:

{"roundtrip":[0,1,7,15]}
JAH-PLASMA-MEM-000004 — Plasma Computer Memory — Vortex and filament memory

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. Rotating plasma vortices and current filaments are stable, long-lived, and easy to detect by their magnetic signature. A vortex's spin direction is a bit; a filament's position in a lattice is an address. Vortex lattices occur naturally in magnetized plasmas and superfluids, so the physics is familiar. Vortex memory is the plasma analog of bubble memory (1970s magnetic-bubble storage, a real shipped product) — bubbles of rotation instead of bubbles of magnetization.

JAH-PLASMA-MEM-000005 — Plasma Computer Memory — Reading and writing

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. Writing is launching: antennas and field pulses imprint patterns. Reading is sensing: Langmuir probes (thin wires measuring current versus voltage, the standard plasma diagnostic) detect local density, magnetic pickup coils sense vortices, and scattered probe waves read density patterns without touching the stored state. Reads must be non-destructive or include rewrite: the memory controller's job, exactly as in every memory technology since core.

JAH-PLASMA-MEM-000006 — Plasma Computer Memory — Retention, volatility, and refresh

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. Plasma memory is volatile: collisions and diffusion erase patterns on timescales from microseconds to milliseconds depending on density and temperature. That sounds short, but at a gigahertz plasma clock it is millions of cycles — plenty for cache and working memory, with refresh cycles rewriting patterns before they fade. This is exactly how DRAM works (capacitors leaking, rewritten thousands of times per second), so the refresh controller is a solved design problem wearing new clothes.

JAH-PLASMA-MEM-000007 — Plasma Computer Memory — Memory hierarchy: cache, main, archive

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. A real machine needs tiers: fast small cache (trapped-wave cells, nanosecond access), large main memory (vortex arrays, microsecond access), and cold archive (spheromak banks, refreshed rarely). The hierarchy is the same idea as registers, SRAM, DRAM, and disk — only the medium changed. Sizing the tiers is an engineering calculation: access time, capacity, and refresh power trade against each other exactly as in silicon design.

JAH-PLASMA-MEM-000008 — Plasma Computer Memory — Memory in the full stack

Public edition. Public physics and engineering knowledge, fact-checked reference. Speculative material is absent from this edition; anything not yet established science lives in the Signature twin. Memory serves logic: its interfaces are an address map (which cell holds what), access timing (read/write latency in plasma periods), and the refresh contract (how often the controller must rewrite). Beginner exercise: given a 1-microsecond pattern lifetime and a 9-gigahertz clock, compute how many operations fit between refreshes (about nine million). That number is why volatile plasma memory is practical, not a dealbreaker.
