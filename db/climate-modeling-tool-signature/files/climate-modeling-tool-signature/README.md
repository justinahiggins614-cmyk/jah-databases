# Climate Modeling Tool Database — files (climate-modeling-tool-signature)

- `demo-climate-modeling-tool-signature.py` — runnable demo program (run with `python3 demo-climate-modeling-tool-signature.py`).
- `climate-modeling-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/climate-modeling-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-climate-modeling-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
