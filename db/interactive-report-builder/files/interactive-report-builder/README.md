# Interactive Report Builder Database — files (interactive-report-builder)

- `demo-interactive-report-builder.py` — runnable demo program (run with `python3 demo-interactive-report-builder.py`).
- `interactive-report-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/interactive-report-builder/index.jsonl.gz` (24 records).
- The generator is `gen-interactive-report-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
