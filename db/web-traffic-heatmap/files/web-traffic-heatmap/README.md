# Web Traffic Heatmap Database — files (web-traffic-heatmap)

- `demo-web-traffic-heatmap.py` — runnable demo program (run with `python3 demo-web-traffic-heatmap.py`).
- `web-traffic-heatmap-sample.txt` — a plain-text sample of the database.
- The full database is `data/web-traffic-heatmap/index.jsonl.gz` (24 records).
- The generator is `gen-web-traffic-heatmap.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
