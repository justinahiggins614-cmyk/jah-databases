Web Traffic Heatmap Database (web-traffic-heatmap)

A web traffic heatmap is a rule-based local demo: it maps set toy pages, and counts the marks. The heatmap reads 3 pages. The page alpha holds 33 marks. The largest holds 33 marks. Everything runs in this browser; no data leaves the page.
