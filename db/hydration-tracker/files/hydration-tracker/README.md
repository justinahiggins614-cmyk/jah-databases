# Hydration Tracker Database — files (hydration-tracker)

- `demo-hydration-tracker.py` — runnable demo program (run with `python3 demo-hydration-tracker.py`).
- `hydration-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/hydration-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-hydration-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
