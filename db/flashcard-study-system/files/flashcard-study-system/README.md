# Flashcard Study System Database — files (flashcard-study-system)

- `demo-flashcard-study-system.py` — runnable demo program (run with `python3 demo-flashcard-study-system.py`).
- `flashcard-study-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/flashcard-study-system/index.jsonl.gz` (24 records).
- The generator is `gen-flashcard-study-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
