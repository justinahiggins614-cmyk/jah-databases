About this data base

Archive
This database’s math record archive (JAH-UMATH- records), preserved as structured, searchable data.
Record schema
id · title · group · ladder · description · program · demo_output · src
Teaching ladder
Every record carries a ladder rank: 1 simple, 2 compounded, 3 complex. Start at rank 1 with no background and climb to rank 3.
Generator
umath-gen-1.0 — deterministic, every record validated by an independent checker before acceptance.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent checker.
Public records
Records capture real, checkable public knowledge with sources and verification dates.
AI
JAH Universal Math Tutor — archive-aware and network-aware across all JAH Databases. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
