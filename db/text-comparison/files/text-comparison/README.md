# Text Comparison Database — files (text-comparison)

- `demo-text-comparison.py` — runnable demo program (run with `python3 demo-text-comparison.py`).
- `text-comparison-sample.txt` — a plain-text sample of the database.
- The full database is `data/text-comparison/index.jsonl.gz` (24 records).
- The generator is `gen-text-comparison.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
