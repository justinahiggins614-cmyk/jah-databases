Public Records Search Database (public-records-finder-signature)

A public records search is a rule-based local demo: it reads set toy files, and counts the matches. The search reads 3 files. The file deed wins 90 matches. The largest holds 90 matches. Everything runs in this browser; no data leaves the page.
