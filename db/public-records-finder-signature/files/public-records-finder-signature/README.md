# Public Records Search Database — files (public-records-finder-signature)

- `demo-public-records-finder-signature.py` — runnable demo program (run with `python3 demo-public-records-finder-signature.py`).
- `public-records-finder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/public-records-finder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-public-records-finder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
