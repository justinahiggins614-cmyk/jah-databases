# Voice Calling Database — files (voice-calling)

- `demo-voice-calling.py` — runnable demo program (run with `python3 demo-voice-calling.py`).
- `voice-calling-sample.txt` — a plain-text sample of the database.
- The full database is `data/voice-calling/index.jsonl.gz` (24 records).
- The generator is `gen-voice-calling.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
