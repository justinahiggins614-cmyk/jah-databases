# Webcam Recorder Database — files (webcam-recorder)

- `demo-webcam-recorder.py` — runnable demo program (run with `python3 demo-webcam-recorder.py`).
- `webcam-recorder-sample.txt` — a plain-text sample of the database.
- The full database is `data/webcam-recorder/index.jsonl.gz` (24 records).
- The generator is `gen-webcam-recorder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
