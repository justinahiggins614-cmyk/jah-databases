# Logo Creator Database — files (logo-creator-signature)

- `demo-logo-creator-signature.py` — runnable demo program (run with `python3 demo-logo-creator-signature.py`).
- `logo-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/logo-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-logo-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
