Property Boundary Mapping Database (property-boundary-mapping)

A property boundary mapping is a rule-based local demo: it maps set toy corners, and counts the marks. The mapper reads 3 corners. The corner alpha holds 39 marks. The largest holds 39 marks. Everything runs in this browser; no data leaves the page.
