# Property Boundary Mapping Database — files (property-boundary-mapping)

- `demo-property-boundary-mapping.py` — runnable demo program (run with `python3 demo-property-boundary-mapping.py`).
- `property-boundary-mapping-sample.txt` — a plain-text sample of the database.
- The full database is `data/property-boundary-mapping/index.jsonl.gz` (24 records).
- The generator is `gen-property-boundary-mapping.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
