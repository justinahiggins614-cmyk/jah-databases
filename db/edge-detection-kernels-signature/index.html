JAH-KER-000101 — JAH heavy-anchor kernel — doubling the middle row's vote

This is a Signature experiment by JAH — his own original kernel, not a public operator. The question he asked: Sobel trusts the middle row twice as much as the outer rows, and that has worked since 1968. What happens if you trust it twice as much again — middle row weight 4 instead of 2? The kernel becomes [[-1,0,1],[-4,0,4],[-1,0,1]], which JAH calls the heavy-anchor kernel because the middle row anchors the measurement so hard the outer rows barely matter.

The demo runs it against classic Sobel on the identical step edge. The heavy-anchor peaks at 1140 where Sobel peaks at 760 — the row-weight total went from 4 to 6, and the response follows exactly. On a clean edge it is simply louder. The honest trade, which JAH notes in his lab commentary, is the one the middle-number story predicts: a single noisy pixel now shouts at weight 4 instead of 2, so this kernel is for clean line-art and synthetic images, not grainy photographs.

Every Signature record in this database is JAH's own work: original kernels, original experiments, original commentary. They are clearly labeled Signature throughout, and they live alongside — never mixed into — the public records of the established operators.

JAH-KER-000102 — JAH diagonal kernel — tuned for diagonal edges

Sobel finds vertical and horizontal edges; Roberts finds diagonals but with no smoothing at all. JAH's diagonal kernel is his own middle path: a 3x3 with the weights arranged along the main diagonal, [[-2,-1,0],[-1,0,1],[0,1,2]]. Read it as 'bright along the down-right diagonal minus dark along the up-left diagonal', with the zeros placed on the anti-diagonal so edges running the other way cancel out.

The demo is a selectivity test, and selectivity is the whole point of a directional kernel. Run on a diagonal step edge, the kernel fires hard along the diagonal band. Run on a plain vertical step edge, it barely whispers — the anti-diagonal zeros eat the response. A good directional kernel is defined as much by what it ignores as by what it finds, and this one ignores vertical and horizontal edges almost completely.

JAH's lab note on this design: diagonal edges are the ones Sobel measures least accurately (the Scharr record explains why), so a cheap dedicated diagonal pass can be worth more than a fancier general kernel. Signature experiment, Signature-labeled, original to JAH.

JAH-KER-000103 — JAH point-and-corner kernel

Not every interesting feature is an edge. Sometimes you want the lone bright pixel — a star in a telescope image, a hot pixel on a sensor, the corner where two edges meet. JAH's point-and-corner kernel is his own take on the idea: every neighbor votes -1 and the center votes +8, so the kernel computes 'eight times the center minus everything around it'.

The demo shows why the arithmetic works. On a flat field with one bright pixel of 200 in a sea of 100, the kernel answers 800 exactly at the pixel and 0 everywhere else — the eight -1 votes cancel the eight 100s, and the +8 multiplies the 100 of difference. On a step edge it also fires, but weaker and smeared, which is JAH's honest caveat in the lab notes: this is a point detector first and an edge detector a distant second.

It sums to zero like every respectable detector (8 - 8 = 0), so flat regions stay silent. Signature original, Signature-labeled, executed live below.

JAH-KER-000104 — JAH soft Sobel — half-strength smoothing experiment

The heavy-anchor record pushed Sobel's middle number up; this Signature experiment pushes everything down. JAH's soft Sobel halves every weight of the Sobel Gy kernel: [[-0.5,-1,-0.5],[0,0,0],[0.5,1,0.5]]. The shape of the response is identical to Sobel's — same edges, same zeros — at exactly half the volume. So why bother? Because of what happens next in a real pipeline.

The demo runs both kernels on a horizontal step edge with random-looking speckle noise added (a fixed deterministic pattern, so the experiment repeats exactly). Both kernels find the edge; the question is the noise floor. JAH's lab note frames it as a downstream argument: thresholding stages like Canny's work on relative values, and a kernel whose raw numbers stay small keeps every later multiplication — especially the squared terms in gradient magnitude — further from overflow and rounding trouble in fixed-point hardware. It is a small, practical, unglamorous improvement, which is exactly the kind JAH likes to test.

Signature original, Signature-labeled. The demo prints both response maps and both peaks so the halving is verifiable, not claimed.

JAH-KER-000105 — JAH corner-first kernel

Edges are lines; corners are where lines meet, and they need their own detector. JAH's corner-first kernel arranges its votes in a checkerboard of its own: +1 on the four corners, -2 on the four edge-adjacent pixels, +4 in the center — [[1,-2,1],[-2,4,-2],[1,-2,1]]. It sums to zero (4 + 4 - 8 = 0), so flat fields stay silent, and it is symmetric under ninety-degree rotations, so it has no favorite direction.

The demo is a three-way lineup: a flat field, a step edge, and a 2x2 checkerboard patch. The flat field answers all zeros. The step edge gets a moderate response. The checkerboard — alternating bright and dark in exactly the kernel's positive/negative pattern — gets the maximum response of all. That ordering is the experiment's result: the kernel prefers corners over edges over flats, which is precisely what a corner detector should do.

JAH's lab note is candid about the limitation: real-world corners are rarely perfect checkerboards, so this kernel is a first-pass candidate finder, not a final answer — the Harris corner detector's structure-tensor approach remains the professional tool. Signature original, Signature-labeled, executed live.

JAH-KER-000106 — JAH vertical-stripe detector

Most kernels in this database hunt boundaries between regions. JAH's stripe detector hunts texture inside a region: the kernel [[-1,2,-1],[-1,2,-1],[-1,2,-1]] asks 'is the middle column brighter than both its neighbors?' at every position. A single bright vertical line on a dark field makes it sing; a plain edge makes it murmur; a flat field silences it completely since each row sums to zero.

The demo runs the three-way test: vertical pinstripes (alternating bright/dark columns), a solid step edge, and a flat field. The stripes produce the maximum response, the step edge a weaker one, the flat field zeros. JAH's lab note gives the practical motive: fabrics, barcodes, wood grain, and screen-door patterns are all stripes first and edges second, and a dedicated stripe pass can segment them before any edge detector runs.

Rotate it ninety degrees and you get the horizontal-stripe version for free — JAH leaves that as the reader's first exercise with the boundless generator at the bottom of the page. Signature original, Signature-labeled, executed live.

JAH-KER-000107 — JAH Sobel-plus-Laplacian fusion experiment

Sobel finds steps; the Laplacian finds thin lines and dots. JAH's fusion experiment simply adds them: at every pixel, take the absolute Sobel Gx response plus the absolute Laplacian response. It is not a new kernel — it is two old kernels cooperating, and JAH's lab note is explicit that the credit belongs to the combination, not to any single set of nine numbers.

The demo builds a test image with both features: a vertical step edge on the left half and a thin one-pixel bright line on the right half. Sobel alone finds the step and nearly misses the line (a line has no sustained slope). The Laplacian alone finds the line and marks the step with its zero-crossing lobes. The fused map shows both features at full strength in a single picture.

The honest caveat, printed by the demo itself: fusion also fuses the noise — both kernels' false alarms add up too. JAH's conclusion is that fusion belongs after denoising, never before it. Signature experiment, Signature-labeled, executed live.

JAH-KER-000108 — JAH kernel-tuning notebook — choosing the middle number by measurement

The public middle-number record ends with 'pick your number by picking what you value'. This Signature record is JAH's answer to the follow-up question: how do you measure what you value? His tuning notebook sweeps the middle weight w through 1, 2, 3, 4, 5 — Prewitt territory, Sobel territory, and three stops beyond — and for each one measures two numbers: the response to a clean step edge (the signal) and the response to a single-pixel spike in a flat field (the noise). The score is the ratio.

The demo prints the full table, and the result is the kind only measurement gives: the edge response grows linearly with w, the noise response grows linearly too, and the ratio actually favors the smaller weights — w=1 scores 5.70 while w=5 scores 2.66 — but w=1 also gives the weakest absolute edge signal (570 vs 1330). JAH's written conclusion in the notebook: the ratio alone cannot settle the middle number, because signal strength and noise rejection pull in opposite directions; it is settled by harder tests like rotation accuracy (where Scharr wins) or downstream threshold behavior.

That is the Signature spirit JAH wants in this database: run the experiment, print the numbers, and report what the numbers actually say — even when they say 'no winner'. The notebook's sweep code is written so the reader can add their own third test (a diagonal edge, a blurred edge) and re-run. Signature original, Signature-labeled, executed live.

def convolve(image, kernel):
    kh, kw = len(kernel), len(kernel[0])
    rows, cols = len(image), len(image[0])
    out = []
    for i in range(rows - kh + 1):
        r = []
        for j in range(cols - kw + 1):
            s = 0
            for a in range(kh):
                for b in range(kw):
                    s += kernel[a][b] * image[i + a][j + b]
            r.append(s)
        out.append(r)
    return out

def grid(values, label):
    print(label)
    for row in values:
        print(" ".join("%8s" % (round(v, 1) if isinstance(v, float) else v) for v in row))
    print()

def step_v(rows=6, cols=8, dark=10, bright=200, edge_at=4):
    return [[bright if c >= edge_at else dark for c in range(cols)] for r in range(rows)]

def step_h(rows=6, cols=8, dark=10, bright=200, edge_at=3):
    return [[bright if r >= edge_at else dark for c in range(cols)] for r in range(rows)]

SOBEL = [[-1,0,1],[-2,0,2],[-1,0,1]]
HEAVY = [[-1,0,1],[-4,0,4],[-1,0,1]]   # JAH heavy-anchor: middle row doubled again
img = step_v()
rs = convolve(img, SOBEL); rh = convolve(img, HEAVY)
