Code Execution Sandbox Database (code-execution-sandbox)

A code execution sandbox is a defensive local demo: it runs set toy commands from an allowlist only, and blocks the rest. The sandbox allows 3 commands and blocks 2. The command add 2 3 gives 5. The sandbox runs 5 commands in total. Everything runs in this browser; no data leaves the page.
