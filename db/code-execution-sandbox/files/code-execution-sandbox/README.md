# Code Execution Sandbox Database — files (code-execution-sandbox)

- `demo-code-execution-sandbox.py` — runnable demo program (run with `python3 demo-code-execution-sandbox.py`).
- `code-execution-sandbox-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-execution-sandbox/index.jsonl.gz` (24 records).
- The generator is `gen-code-execution-sandbox.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
