# Email Subject Tester Database — files (email-subject-tester)

- `demo-email-subject-tester.py` — runnable demo program (run with `python3 demo-email-subject-tester.py`).
- `email-subject-tester-sample.txt` — a plain-text sample of the database.
- The full database is `data/email-subject-tester/index.jsonl.gz` (24 records).
- The generator is `gen-email-subject-tester.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
