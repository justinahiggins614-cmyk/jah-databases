The Signature Software That Can Reconstruct a Documented Application's Architecture Database

Accessible version: plain text, no scripts, no sign-in, free forever. The software that can reconstruct a documented application's architecture reads the written documents of an application, its manual, its help pages, its feature list, and draws a diagram of its parts and how they join. It works only from documents, never from copied code, and every reconstruction is a design study, never a claim that the diagram is complete.

Twenty-four full records, ordered simple to compounded to complex.
