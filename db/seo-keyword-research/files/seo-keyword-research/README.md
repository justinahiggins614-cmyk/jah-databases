# SEO Keyword Research Database — files (seo-keyword-research)

- `demo-seo-keyword-research.py` — runnable demo program (run with `python3 demo-seo-keyword-research.py`).
- `seo-keyword-research-sample.txt` — a plain-text sample of the database.
- The full database is `data/seo-keyword-research/index.jsonl.gz` (24 records).
- The generator is `gen-seo-keyword-research.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
