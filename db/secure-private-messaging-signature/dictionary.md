# Dictionary entries — The Secure Private Messaging Database

Key terms of this database, defined in plain words.

## private messaging

Sending written messages that only the sender and the receiver can read, with no one in the middle able to read them.

## end-to-end encryption

A seal on a message that only the sender and the receiver hold the keys to, so the service carrying it cannot read it.

## key

A secret number used to seal and unseal a message; whoever holds the key can read what it sealed.

## forward secrecy

The rule that each message uses a fresh key, so that one stolen key opens one message at most, never the whole history.

## verification

Checking that the person you talk to is really who they say they are, by comparing a code or a fingerprint of their key.

## metadata

Data about a message, such as when it was sent and how large it is, which is not the message itself but can still say a lot.

## disappearing message

A message that deletes itself after a set time, so that it leaves no copy behind on either device.

## group message

One message sent to several people at once, sealed so that only the members of the group can read it.

## delivery receipt

A small note back saying a message arrived, without saying anything about what it said.

## blocking

Refusing all further messages from one sender, so that their messages never reach you again.

## backup

A copy of messages kept for safety, sealed with its own key, so that a lost device does not mean lost words.

## open standard

A public rule for how programs talk to each other, published openly so that any program can follow it.
