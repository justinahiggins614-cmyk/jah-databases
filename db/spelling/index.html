About this data base

Archive
This database's spell-check word archive (99,227 words, A–Z), preserved as structured, searchable data.
Record schema
id · word · misspelling · op · rule · letter
Generator
jahdb-spelling-1.0 — deterministic (mulberry32). Draws real words from the archive word list and applies a genuine mechanical edit operation (adjacent transposition, letter doubling, letter drop); an independent verifier re-applies the operation from scratch and requires the exact misspelling.
Drift control
Every generated record is checked against an archive sample: the misspelling must not itself be a real archive word, and the pair must not repeat.
Cross-database
The generator can borrow a theme word from any of the other 36 data bases when you tick the box.
AI
JAH Spelling Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
