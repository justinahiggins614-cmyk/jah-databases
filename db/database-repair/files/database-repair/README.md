# Database Repair Database — files (database-repair)

- `demo-database-repair.py` — runnable demo program (run with `python3 demo-database-repair.py`).
- `database-repair-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-repair/index.jsonl.gz` (24 records).
- The generator is `gen-database-repair.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
