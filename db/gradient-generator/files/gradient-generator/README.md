# Gradient Generator Database — files (gradient-generator)

- `demo-gradient-generator.py` — runnable demo program (run with `python3 demo-gradient-generator.py`).
- `gradient-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/gradient-generator/index.jsonl.gz` (24 records).
- The generator is `gen-gradient-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
