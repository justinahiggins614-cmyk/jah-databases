# Review System Database — files (review-system)

- `demo-review-system.py` — runnable demo program (run with `python3 demo-review-system.py`).
- `review-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/review-system/index.jsonl.gz` (24 records).
- The generator is `gen-review-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
