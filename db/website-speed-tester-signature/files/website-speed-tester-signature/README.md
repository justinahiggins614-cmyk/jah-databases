# Website Speed Tester Database — files (website-speed-tester-signature)

- `demo-website-speed-tester-signature.py` — runnable demo program (run with `python3 demo-website-speed-tester-signature.py`).
- `website-speed-tester-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/website-speed-tester-signature/index.jsonl.gz` (24 records).
- The generator is `gen-website-speed-tester-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
