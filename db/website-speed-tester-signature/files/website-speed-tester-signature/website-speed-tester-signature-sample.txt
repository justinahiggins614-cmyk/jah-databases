Website Speed Tester Database (website-speed-tester-signature)

A website speed tester is a rule-based local demo: it reads set toy pages, and counts the marks. The tester reads 3 pages. The page home holds 30 marks. The largest holds 30 marks. Everything runs in this browser; no data leaves the page.
