# Algebra Solver Database — files (algebra-solver-signature)

- `demo-algebra-solver-signature.py` — runnable demo program (run with `python3 demo-algebra-solver-signature.py`).
- `algebra-solver-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/algebra-solver-signature/index.jsonl.gz` (24 records).
- The generator is `gen-algebra-solver-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
