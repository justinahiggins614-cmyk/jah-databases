An algebra solver finds the value of x that makes an equation true, showing every step. It solves linear equations and quadratic equations in this browser, with the working shown so each step can be checked.

2. Math proof

A linear equation ax plus b equals 0 solves as x equals minus b over a. A quadratic ax squared plus bx plus c equals 0 solves by the quadratic formula: x equals minus b plus or minus the square root of b squared minus 4ac, all over 2a. The discriminant b squared minus 4ac tells the story: positive means two real roots, zero means one root, negative means none.
