1. Description

An AI knowledge base assistant is a rule-based local demo: it answers questions from a set knowledge base, and shows the answer it finds. Asking for the capital gives Paris. Asking for the planet gives Mars. Searching for ar finds 2 entries. Everything runs in this browser; no data leaves the page.
