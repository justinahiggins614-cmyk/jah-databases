# Elevation Calculator Database — files (elevation-calculator)

- `demo-elevation-calculator.py` — runnable demo program (run with `python3 demo-elevation-calculator.py`).
- `elevation-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/elevation-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-elevation-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
