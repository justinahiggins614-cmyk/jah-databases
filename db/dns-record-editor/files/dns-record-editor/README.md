# DNS Record Editor Database — files (dns-record-editor)

- `demo-dns-record-editor.py` — runnable demo program (run with `python3 demo-dns-record-editor.py`).
- `dns-record-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/dns-record-editor/index.jsonl.gz` (24 records).
- The generator is `gen-dns-record-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
