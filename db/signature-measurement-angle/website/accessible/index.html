No JavaScript is needed on this page. It is the plain-text version of the same database.

Honesty: pixel measurements are exact from the file 1939_0_0or1.jpg (1536 by 1024 px, ink darker than 128, 37,277 ink px). The 150 mm render width is an ASSUMPTION, stated wherever it is used. Atom numbers are scaled equivalents carried down the Signature scale, never direct physical measurements of ink atoms. The smallest resolvable unit in the file is 1 pixel. Nothing is invented. Angles are in image coordinates (y increases downward); the physical-page angle (y up) is the negative of the value given.

1. Description and history

The Angle Way measures the angle of every stroke of Manon's signature by linear regression, in image coordinates where y increases downward, so the physical-page angle (y up) is the negative of every value given here. Manon uploaded his signature image on 2026-11-23 and asked for it to be measured many ways, as accurately as the Signature system allows, down toward atom scale. The numbers were measured from the file, verified twice, and recomputed for this wave with identical results.

2. Math proof

angle = arctan(slope). tan(-52.37 degrees) = -1.2972; tan(-43.38 degrees) = -0.9451; tan(-15.23 degrees) = -0.2722; tan(-16.70 degrees) = -0.3001. Whole signature: arctan(-0.1328) = -7.57 degrees. The demo of every record prints the same kind of total as its math proof, so a fresh run of any demo verifies its proof.

3. Science proof

Least-squares regression finds the line that minimises the squared vertical distance to a cloud of pixels: it is the fairest single direction a spread-out stroke can be given, and it uses every pixel rather than two chosen endpoints. Angles are dimensionless, so they need no render-width assumption at all.
