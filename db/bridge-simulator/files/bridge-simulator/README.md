# Bridge Simulator Database — files (bridge-simulator)

- `demo-bridge-simulator.py` — runnable demo program (run with `python3 demo-bridge-simulator.py`).
- `bridge-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/bridge-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-bridge-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
