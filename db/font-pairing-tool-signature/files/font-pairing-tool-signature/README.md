# Font Pairing Tool Database — files (font-pairing-tool-signature)

- `demo-font-pairing-tool-signature.py` — runnable demo program (run with `python3 demo-font-pairing-tool-signature.py`).
- `font-pairing-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/font-pairing-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-font-pairing-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
