Font Pairing Tool Database (font-pairing-tool-signature)

A font pairing tool is a rule-based local demo: it joins one heading font with one body font, and counts the points between them. The heading is 32 points and the body is 16 points. The heading font is Georgia. The size ratio is 2.0. Everything runs in this browser; no data leaves the page.

Worked example: The heading is 32 points and the body is 16 points

Demo output:
The heading is 32 points and the body is 16 points
