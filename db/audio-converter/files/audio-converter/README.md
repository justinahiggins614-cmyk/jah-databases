# Audio Converter Database — files (audio-converter)

- `demo-audio-converter.py` — runnable demo program (run with `python3 demo-audio-converter.py`).
- `audio-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-converter/index.jsonl.gz` (24 records).
- The generator is `gen-audio-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
