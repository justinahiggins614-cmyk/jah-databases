# Dictionary entries — The Returns and Refunds Management Database

Key terms of this database, defined in plain words.

## return

The sending back of goods by a buyer to a seller, recorded with the goods, the date, and the reason, so that the return can be followed from report to answer.

## refund

Money given back to a buyer for returned goods, recorded with its amount, its method, and its date, so that what was given back can be counted and checked.

## replacement

New goods given in place of returned goods, recorded with what was sent and when, so that the exchange is complete on the record and not only in memory.

## return policy

The written rules of a seller about what may be returned, by when, and in what state, kept with the record, so that every return is judged by the same stated rules.

## return window

The stated number of days after purchase during which a return is accepted, written in the policy, so that a return inside the window and one outside it are handled by the same rule.

## reason code

A short stated reason for a return, such as faulty or wrong size, chosen from a fixed list, so that returns can be counted by reason and the counts can be read.

## return label

The label that carries returned goods back to the seller, naming the sender, the destination, and the return itself, so that the parcel can be followed on its way back.

## inspection

The checking of returned goods when they arrive, to see their state and whether the stated reason holds, recorded with what was found, so that the answer rests on what was seen.

## restocking

The work of putting returned goods that are fit to sell back into stock, recorded per item, so that the stock count agrees with the goods on the shelves.

## refund method

The way a refund is given back, such as the original payment method or a credit, named in the record, so that the buyer knows how the money returns and when.

## exchange

The giving of different goods in place of returned goods, recorded with both the goods sent back and the goods sent out, so that the exchange balances on the record.

## return receipt

The written acknowledgement that returned goods arrived, naming the goods and the date, kept with the return, so that the buyer has proof the goods came back.
