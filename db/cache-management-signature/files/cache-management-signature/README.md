# Cache Management Database — files (cache-management-signature)

- `demo-cache-management-signature.py` — runnable demo program (run with `python3 demo-cache-management-signature.py`).
- `cache-management-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/cache-management-signature/index.jsonl.gz` (24 records).
- The generator is `gen-cache-management-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
