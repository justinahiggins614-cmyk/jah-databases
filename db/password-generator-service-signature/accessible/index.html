The Design/System

The design is one database per subject, with a public edition and a Signature edition side by side. Every record gives its history, its full content, its methods, its results as reported, and its skeptical analysis. Every technical term is defined in plain words where it first appears, and the glossary defines them all again. Each Signature record is a design study, labeled as a design, never presented as established fact.

The Generator

The boundless generator for this database is the file gen-password-generator-service-signature.js. It is seeded and deterministic: the same seed always gives the same record, and different seeds differ. It is throttled to 100 records per call, it stops at 1,000,000,000 records per file, and every generated record is labeled generated, never presented as an archive record.

Math Proof

The counting argument is exact: 24 records, 8 simple, 8 compounded, 8 most complex, and 8 + 8 + 8 = 24. The formal statement is: password(n, S) = n letters drawn at random from set S, each draw independent of the rest (stated, not machine-checked) The scientific statement is: strength = log2(|S| raised to n) bits of guessing work for a random password of length n drawn from set S (stated, not machine-checked) Both are stated, not machine-checked, and the record-level proofs are in each record's math proof.
