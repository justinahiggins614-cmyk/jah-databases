About this data base

Archive
This database's AI-to-robot match archive: AI personas paired with robot body designs, scored and reasoned per mission (JAH-PAIR records), preserved as structured, searchable data.
Record schema
id · type · title · ai_id · ai_name · ai_family · body_id · body_name · class · mission · score · hardware{} · rationale{} · demo_lines[] · created · stamp
Generator
jahdb-robots-1.0 — deterministic (mulberry32). Builds each design constructively from archive-style parts (body name, class, mission, AI persona, hardware), then an independent re-builder reconstructs every derived string from the raw picks to verify the record.
Drift control
Every generated design name is checked against an archive sample for exact duplicates and re-verified by the independent re-builder.
Cross-database
The generator can borrow a theme from any of the other 36 databases when you tick the box.
AI
JAH Robot Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
