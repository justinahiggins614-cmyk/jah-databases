# Property Boundary Viewer Database — files (property-boundary-viewer)

- `demo-property-boundary-viewer.py` — runnable demo program (run with `python3 demo-property-boundary-viewer.py`).
- `property-boundary-viewer-sample.txt` — a plain-text sample of the database.
- The full database is `data/property-boundary-viewer/index.jsonl.gz` (24 records).
- The generator is `gen-property-boundary-viewer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
