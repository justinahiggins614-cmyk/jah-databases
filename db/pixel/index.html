About this data base

Archive
This database's generated-goods archive: creative product records with generation specs across 24 product categories (JAH-GOODS records), preserved as structured, searchable data.
Record schema
id · type · title · name · cat · desc · prompt · seed · palette · scene · kw[] · stamp
Generator
jahdb-pixel-1.0 — deterministic (mulberry32). Builds each creative record constructively from archive-style parts, then an independent re-builder reconstructs every derived field from the raw picks to verify the record. Metadata only — the emblem image is generated deterministically on view.
Drift control
Every generated title is checked against an archive sample for exact duplicates and re-verified by the independent re-builder.
Cross-database
The generator can borrow a theme from any of the other 36 data bases when you tick the box.
AI
JAH Pixel Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
