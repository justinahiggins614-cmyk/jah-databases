History
Learners have carried work home from school for as long as schools have set lessons, because a lesson learned in class must be practised alone before it is truly known. Homework assistance grew beside the homework itself: teachers, tutors, and parents who read the task aloud, showed the next step, and wrote down what was asked and what was answered. From the ruled exercise book carried home in a satchel to the record kept in a database, the honest practice has been the same — write the help down whole. This database is built on that public practice of recording every act of homework assistance true.
