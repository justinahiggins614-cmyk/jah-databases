# Case Law Search Database — files (case-law-search-signature)

- `demo-case-law-search-signature.py` — runnable demo program (run with `python3 demo-case-law-search-signature.py`).
- `case-law-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/case-law-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-case-law-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
