# Architecture Planner Database — files (architecture-planner-signature)

- `demo-architecture-planner-signature.py` — runnable demo program (run with `python3 demo-architecture-planner-signature.py`).
- `architecture-planner-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/architecture-planner-signature/index.jsonl.gz` (24 records).
- The generator is `gen-architecture-planner-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
