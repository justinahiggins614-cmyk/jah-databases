ConceptNet is a freely available semantic network that helps computers understand the meanings of words: a large multilingual graph of common-sense assertions, with word embeddings (Numberbatch) derived from it. Science proof

ConceptNet is a directed labeled multigraph whose edges are weighted common-sense assertions. Graph theory gives the working rules: a concept's degree is how many assertions mention it; a path between two concepts (apple -> Antonym -> orange, or apple -> HasA -> peel -> RelatedTo -> orange) is an explanation of how the words relate; and the weight on an edge is a confidence that prunes the graph for retrieval. The Numberbatch embeddings are a vector view of the same graph: concepts that share neighbours sit close together, so cosine similarity between two vectors measures how similarly the graph treats the two concepts. For this aspect (What It Is and Its Scope), the same graph theory rules decide what counts as a correct answer: the pattern must match the model, and the result must be checkable against the source.

Without the model, a query returns rows that look like noise; with it, the same rows read as answers. ConceptNet is a directed labeled multigraph whose edges are weighted common-sense assertions. The Numberbatch embeddings are a vector view of the same graph: concepts that share neighbours sit close together, so cosine similarity between two vectors measures how similarly the graph treats the two concepts. ConceptNet: the identifier scheme, and how to read an ID.

Every record in ConceptNet has an identifier, and the identifier is the only handle that never changes with the record's content. The scheme is: Concepts are URIs of the form /c/<language>/<term>, for example /c/en/fire. Relations are /r/<Name>, for example /r/UsedFor. Assertions are /a/[<relation>,<start>,<end>], for example /a/[/r/UsedFor/,/c/en/example/,/c/en/explain/]. Datasets are /d/<source>/<language>. Terms are lowercase, with spaces replaced by underscores. A reader who understands the scheme can read an ID and know what it names, which collection it belongs to, and how to fetch it. A reader who does not will confuse two records with similar names, cite the wrong one, or store a name where an ID belongs and watch the link break when the name changes. The rule is absolute: store the ID, display the name, and never use the name as the key.

The Numberbatch embeddings are a vector view of the same graph: concepts that share neighbours sit close together, so cosine similarity between two vectors measures how similarly the graph treats the two concepts. For this aspect (Science and Math Proof), the same graph theory rules decide what counts as a correct answer: the pattern must match the model, and the result must be checkable against the source.
