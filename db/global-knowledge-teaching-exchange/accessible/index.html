The Global Knowledge Teaching Exchange Database

Accessible version: plain text, no scripts, no sign-in, free forever. The global knowledge teaching exchange lets teachers lend lessons to each other across towns and countries: one teacher's lesson on reading maps, another's on planting seeds, each described once in plain words. Every exchange is a design study of a generic lesson, never a real classroom.

Twenty-four full records, ordered simple to compounded to complex.

  1. A Lesson on Reading Maps, Shared

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    The global knowledge teaching exchange lets teachers lend lessons to each other across towns and countries: one teacher's lesson on reading maps, another's on planting seeds, each described once in plain words. Every exchange is a design study of a generic lesson, never a real classroom. A lesson on reading maps, shared from one teacher to another, with the map and the questions written out in plain words. The design for this record must state the idea in plain sentences, name what a visitor does first, and say what good looks like when it works, so a reader can judge the design without building anything. Without that plain statement, the idea stays vague, a visitor cannot tell what the design promises, and a promising idea is lost because nobody could explain it in words a newcomer can follow. A reader who can follow the design in words can also check it, and a design that can be checked is a design worth building. Worked example: in a website built this way, a lesson on reading maps, shared runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

    History: A teacher lending a lesson to a teacher in another town is an old habit: a copied page, a borrowed plan, a lesson given back with thanks. The website form grows out of that habit, adding a plain description of each lesson and a list anyone can search. A Lesson on Reading Maps, Shared grows out of an older habit: a teacher lending a lesson to a teacher in another town, and getting a lesson back, and the website form adds a plain list, a search, and a written record for it.

    Proposed solution: Name the teaching exchange and what a visitor does in it; Write the rules in plain sentences a new visitor can follow; Give every teaching exchange the same fair start: the same clues, the same time, the same scoring; Let a visitor try one teaching exchange without signing in; Check the teaching exchange works the same way on a phone and on a computer.

    Dependencies: What must exist first: a list of generic subjects, a plain lesson for each subject, a search box, and a review step before publishing. Nothing else is needed to open the first teaching exchange.

    Verification path: A visitor opens one teaching exchange, follows the rules in plain sentences, and finishes it without help. The demo program prints the same total as the math proof, and a second visitor repeating the steps gets the same result.

    Science proof: total = count x each. In plain words, this equation turns counted quantities into one checkable number: with 4 items at 2 each, the arithmetic gives 8 exchanges, and the demo prints that same total, so the claim can be checked by arithmetic alone.

    Math proof: Worked arithmetic: 4 x 2 = 8. The demo sets count to 4 and each to 2, multiplies them, and prints Total: 8, so a fresh run of the demo verifies this proof exactly.
