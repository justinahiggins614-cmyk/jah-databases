# Background Remover Database — files (background-remover)

- `demo-background-remover.py` — runnable demo program (run with `python3 demo-background-remover.py`).
- `background-remover-sample.txt` — a plain-text sample of the database.
- The full database is `data/background-remover/index.jsonl.gz` (24 records).
- The generator is `gen-background-remover.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
