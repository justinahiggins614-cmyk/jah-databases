# Planetary Exploration Simulator Database — files (planetary-exploration-simulator)

- `demo-planetary-exploration-simulator.py` — runnable demo program (run with `python3 demo-planetary-exploration-simulator.py`).
- `planetary-exploration-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/planetary-exploration-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-planetary-exploration-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
