# Maintenance Request Manager Database — files (maintenance-request-manager-signature)

- `demo-maintenance-request-manager-signature.py` — runnable demo program (run with `python3 demo-maintenance-request-manager-signature.py`).
- `maintenance-request-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/maintenance-request-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-maintenance-request-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
