# Screen Recorder Database — files (screen-recorder)

- `demo-screen-recorder.py` — runnable demo program (run with `python3 demo-screen-recorder.py`).
- `screen-recorder-sample.txt` — a plain-text sample of the database.
- The full database is `data/screen-recorder/index.jsonl.gz` (24 records).
- The generator is `gen-screen-recorder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
