Git Repository Viewer Database (git-repository-viewer-signature)

A git repository viewer is a rule-based local demo: it reads set toy commit lists, and counts the commits and the authors. The viewer shows 3 commits. The latest commit says fix bug. The repository holds 2 branches. Everything runs in this browser; no data leaves the page.
