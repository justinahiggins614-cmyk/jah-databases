# Sound Effect Generator Database — files (sound-effect-generator)

- `demo-sound-effect-generator.py` — runnable demo program (run with `python3 demo-sound-effect-generator.py`).
- `sound-effect-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/sound-effect-generator/index.jsonl.gz` (24 records).
- The generator is `gen-sound-effect-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
