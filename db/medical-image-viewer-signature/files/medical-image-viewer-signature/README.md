# Medical Image Viewer Database — files (medical-image-viewer-signature)

- `demo-medical-image-viewer-signature.py` — runnable demo program (run with `python3 demo-medical-image-viewer-signature.py`).
- `medical-image-viewer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/medical-image-viewer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-medical-image-viewer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
