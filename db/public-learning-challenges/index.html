A First Challenge: Seven Days of Reading Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A public learning challenges website: each challenge is a public invitation with a plain goal, a day-by-day checklist, and a badge for finishing. Anyone can join with no sign-in and no payment, anyone can see who finished, and every challenge is written for this program, never copied from a real course or a real challenge. This record covers A First Challenge: Seven Days of Reading.

A first challenge must be small enough to finish in a week and clear enough to understand at once: read for fifteen minutes each day for seven days, and tick each day off. The program must give the goal in plain words, a checklist with seven boxes, and a badge for finishing. Without a small first challenge, a newcomer faces a month-long task on the first visit and gives up before the second day. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Worked example: in a website built this way, a first challenge: seven days of reading runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

This record covers An Offline Pack for Challengers.

An offline pack for challengers lets a visitor carry the program away from any connection: a printed set of challenges, with checklists and badges, all in one small pack. The program must offer the pack as a plain download, with the same challenges as the website, so a learner without a connection loses nothing. Without an offline pack, the program only works where the connection works, and many learners have no connection at all.

Worked example: in a website built this way, an offline pack for challengers runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

Offline packs grew out of printed challenge lists, which a learner could carry anywhere long before any website existed.
