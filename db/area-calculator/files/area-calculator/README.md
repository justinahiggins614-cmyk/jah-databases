# Area Calculator Database — files (area-calculator)

- `demo-area-calculator.py` — runnable demo program (run with `python3 demo-area-calculator.py`).
- `area-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/area-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-area-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
