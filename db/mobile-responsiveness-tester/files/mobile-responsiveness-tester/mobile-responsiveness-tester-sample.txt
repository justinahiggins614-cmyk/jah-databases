Mobile Responsiveness Tester Database (mobile-responsiveness-tester)

A mobile responsiveness tester is a rule-based local demo: it reads set toy screens, and counts the marks. The tester reads 3 screens. The screen phone holds 45 marks. The largest holds 45 marks. Everything runs in this browser; no data leaves the page.
