# Mobile Responsiveness Tester Database — files (mobile-responsiveness-tester)

- `demo-mobile-responsiveness-tester.py` — runnable demo program (run with `python3 demo-mobile-responsiveness-tester.py`).
- `mobile-responsiveness-tester-sample.txt` — a plain-text sample of the database.
- The full database is `data/mobile-responsiveness-tester/index.jsonl.gz` (24 records).
- The generator is `gen-mobile-responsiveness-tester.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
