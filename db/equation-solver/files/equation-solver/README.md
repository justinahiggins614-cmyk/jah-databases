# Equation Solver Database — files (equation-solver)

- `demo-equation-solver.py` — runnable demo program (run with `python3 demo-equation-solver.py`).
- `equation-solver-sample.txt` — a plain-text sample of the database.
- The full database is `data/equation-solver/index.jsonl.gz` (24 records).
- The generator is `gen-equation-solver.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
