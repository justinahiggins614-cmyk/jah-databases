# Reverse Geocoding Database — files (reverse-geocoding)

- `demo-reverse-geocoding.py` — runnable demo program (run with `python3 demo-reverse-geocoding.py`).
- `reverse-geocoding-sample.txt` — a plain-text sample of the database.
- The full database is `data/reverse-geocoding/index.jsonl.gz` (24 records).
- The generator is `gen-reverse-geocoding.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
