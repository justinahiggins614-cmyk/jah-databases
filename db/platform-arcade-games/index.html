Donkey Kong Rank 1 · simple · platform · beginner

Donkey Kong, Nintendo's 1981 breakthrough, introduced Mario as Jumpman, a carpenter rescuing Pauline from a giant ape at the top of a construction site. The player climbs girders, jumps barrels that roll down the scaffolding, and rides elevators and conveyor belts across four distinct stages. It established the platform genre and the character who would become gaming's most famous mascot.

The tribute demo runs a side-view course 18 steps long with obstacles at positions 5, 9, 14: the player types jump or run each tick, jumping over each obstacle to reach the end with lives to spare. It is an original miniature inspired by the platforming idea, not a copy of the arcade game.

Barrels roll down ladders as well as girders, so the safest climb is a ladder the barrels are not using. The hammer is a brief blessing: grabbing it clears barrels for a few seconds, but it also stops the player from climbing, so it should be used on flat ground, not mid-ladder.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Donkey Kong (1981). It is not Donkey Kong (1981), and it uses no art, music, or code from that game.

How to play

Type jump/run each tick to cross the course, quit to stop.

import sys
PARAMS = {'length': 18, 'obstacles': [[5, 'block'], [9, 'block'], [14, 'block']]}
AUTO = ['run', 'run', 'run', 'run', 'jump', 'run', 'run', 'run', 'jump', 'run', 'run', 'run', 'run', 'jump', 'run', 'run', 'run', 'run']

def auto_play():
    obstacles = dict((pos, kind) for pos, kind in PARAMS["obstacles"])
    length = PARAMS["length"]
    pos, lives, air, tick = 0, 3, 0, 0
    print("Platform tribute: auto session")
    for cmd in AUTO:
        tick += 1
        jumping = (cmd == "jump") or air > 0
        if cmd == "jump" and air == 0:
            air = 2
        pos += 1
        if air > 0:
            air -= 1
        crashed = False
        if pos in obstacles and not jumping:
            lives -= 1
            crashed = True
        print("Tick %d: %s pos %d %s lives %d" % (tick, cmd, pos, "CRASH" if crashed else "ok", lives))
        if pos >= length or lives <= 0:
            break
    score = pos * 10 + lives * 100
    print("FINAL SCORE: %d" % score)
    print("RESULT: %s" % ("WIN" if pos >= length else "OUT OF LIVES" if lives <= 0 else "ONGOING"))

def play():
    obstacles = dict((pos, kind) for pos, kind in PARAMS["obstacles"])
    length = PARAMS["length"]
    pos, lives, air = 0, 3, 0
    print("Platform tribute: type jump/run each tick, or quit. Jump over barrels and gaps to reach the end.")
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        if cmd not in ("jump", "run"):
            print("Unknown command: %s" % cmd)
            continue
        jumping = (cmd == "jump") or air > 0
        if cmd == "jump" and air == 0:
            air = 2
        pos += 1
        if air > 0:
            air -= 1
        crashed = False
        if pos in obstacles and not jumping:
            lives -= 1
            crashed = True
        print("pos %d %s lives %d" % (pos, "CRASH" if crashed else "ok", lives))
        if pos >= length or lives <= 0:
            break
    score = pos * 10 + lives * 100
    print("FINAL SCORE: %d" % score)
    print("RESULT: %s" % ("WIN" if pos >= length else "OUT OF LIVES" if lives <= 0 else "QUIT"))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()

Donkey Kong Jr. Rank 2 · simple · platform · beginner

Junior climbs by gripping two vines at once, slides down chains, and drops fruit onto enemies below. The vine-climbing mechanic made movement feel different from the original's ladders.

Two-vine climbing is faster than one-vine climbing, and speed matters when snapjaws patrol the vines. Dropping fruit is the safest attack, since it clears enemies below without Junior having to descend into their path.

Jump Bug, Hoei's 1981 platform game, is an early side-scrolling platformer where a car jumps over gaps and enemies across rolling hills and city streets. The game scrolls continuously, and the player must time jumps over pits and obstacles while shooting or avoiding hazards, making it a precursor to the scrolling platformers that followed.

The tribute demo runs a side-view course 24 steps long with obstacles at positions 4, 8, 13, 17, 21: the player types jump or run each tick, jumping over each obstacle to reach the end with lives to spare. It is an original miniature inspired by the platforming idea, not a copy of the arcade game.
