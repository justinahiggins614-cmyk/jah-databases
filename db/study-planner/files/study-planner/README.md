# Study Planner Database — files (study-planner)

- `demo-study-planner.py` — runnable demo program (run with `python3 demo-study-planner.py`).
- `study-planner-sample.txt` — a plain-text sample of the database.
- The full database is `data/study-planner/index.jsonl.gz` (24 records).
- The generator is `gen-study-planner.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
