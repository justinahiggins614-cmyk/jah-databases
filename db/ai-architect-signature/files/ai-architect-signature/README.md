# AI Architect Database — files (ai-architect-signature)

- `demo-ai-architect-signature.py` — runnable demo program (run with `python3 demo-ai-architect-signature.py`).
- `ai-architect-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-architect-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-architect-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
