# Number Theory Calculator Database — files (number-theory-calculator)

- `demo-number-theory-calculator.py` — runnable demo program (run with `python3 demo-number-theory-calculator.py`).
- `number-theory-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/number-theory-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-number-theory-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
