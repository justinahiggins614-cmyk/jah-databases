Space Invaders Rank 1 · simple · fixed shooter · beginner

Space Invaders, released in 1978 by Taito, is the fixed shooter that started the arcade invasion craze. Rows of alien invaders march side to side across the top of the screen, dropping lower with every pass, while the player slides a lone cannon along the bottom and fires upward. Four destructible shields sit between the cannon and the invaders, and the game ends when an invader reaches the ground or the player runs out of cannons.

The tribute demo recreates this idea on a 6-column grid with 2 rows of descending invaders: the player slides a cannon along the bottom, fires upward column by column, and must clear the whole formation before it marches down to row 10. It is an original miniature inspired by the mechanics, not a copy of the arcade game.

The last invader in a column speeds up dramatically, which is why a calm sweep feels safe until the final few aliens start sprinting across the screen. Clearing a column from one side keeps the formation predictable, and saving a shield gap for a retreat lane buys time when the descent quickens.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Space Invaders (1978). It is not Space Invaders (1978), and it uses no art, music, or code from that game.

PARAMS = {'cols': 6, 'rows': 2, 'start_col': 0, 'floor_row': 10}
AUTO = ['shoot', 'shoot', 'right', 'shoot', 'shoot', 'right', 'shoot', 'shoot', 'right', 'shoot', 'shoot', 'right', 'shoot', 'shoot', 'right', 'shoot', 'shoot']

def auto_play():
    cols = PARAMS["cols"]
    invaders = set()
    for r in range(PARAMS["rows"]):
        for c in range(cols):
            invaders.add((r, c))
    player = PARAMS["start_col"]
    score = 0
    turn = 0
    print("Fixed shooter tribute: auto session")
    for cmd in AUTO:
        turn += 1
        if cmd == "left":
            player = max(0, player - 1)
        elif cmd == "right":
            player = min(cols - 1, player + 1)
        elif cmd == "shoot":
            col_hits = [(r, c) for (r, c) in invaders if c == player]
            if col_hits:
                invaders.discard(max(col_hits))
                score += 50
        if turn % 3 == 0 and invaders:
            invaders = set((r + 1, c) for (r, c) in invaders)
        print("Turn %d: %s player col %d invaders %d score %d" % (turn, cmd, player, len(invaders), score))
        if not invaders or any(r >= PARAMS["floor_row"] for (r, c) in invaders):
            break
    deepest = max([r for (r, c) in invaders]) if invaders else -1
    print("DEEPEST ROW: %d / FLOOR: %d" % (deepest, PARAMS["floor_row"]))
    print("FINAL SCORE: %d" % score)
    if not invaders:
        print("RESULT: WIN")
    elif deepest >= PARAMS["floor_row"]:
        print("RESULT: OVERRUN")
    else:
        print("RESULT: SESSION END")

Galaxian Rank 3 · simple · fixed shooter · beginner

Its alien formation sits in neat ranks, but individual aliens break away and dive at the player in swooping paths while firing, so the screen is never a static target range. Diving aliens are the danger, not the parked formation, so a good player tracks the diver's curve rather than the rank it left. Holding fire until a diver crosses the cannon's column wastes fewer shots, and the brief pause between dives is the moment to clear stragglers.

Phoenix Rank 6 · compounded · fixed shooter · intermediate

Phoenix, released in 1980 by Amstar and distributed by Atari and Centuri, is a five-stage fixed shooter with a memorable cast of bird-like enemies.
