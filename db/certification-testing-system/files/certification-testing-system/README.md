# Certification Testing System Database — files (certification-testing-system)

- `demo-certification-testing-system.py` — runnable demo program (run with `python3 demo-certification-testing-system.py`).
- `certification-testing-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/certification-testing-system/index.jsonl.gz` (24 records).
- The generator is `gen-certification-testing-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
