3D Walkthrough Creator Database (3d-walkthrough-creator-signature)

A 3d walkthrough creator is a rule-based local demo: it creates set toy tours, and counts the marks. The creator reads 3 tours. The tour alpha holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
