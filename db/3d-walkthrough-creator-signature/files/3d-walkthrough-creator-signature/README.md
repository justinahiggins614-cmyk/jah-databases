# 3D Walkthrough Creator Database — files (3d-walkthrough-creator-signature)

- `demo-3d-walkthrough-creator-signature.py` — runnable demo program (run with `python3 demo-3d-walkthrough-creator-signature.py`).
- `3d-walkthrough-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/3d-walkthrough-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-3d-walkthrough-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
