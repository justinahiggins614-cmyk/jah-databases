  1. A Recommendation With a Written Reason

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    Community recommendations are lists of the best things a community has found: books, walks, recipes, or tools, each with the name of the member who recommends it and the reason why. A recommendation with a written reason is a recommendation a reader can judge, because a bare name tells the reader nothing, and a reason tells them whether the thing is for them. The recommendation should name the thing, the reason it is worth trying, and the member who recommends it, all in plain words. Without a written reason, the list is only a set of names, and a set of names helps nobody choose. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design. Worked example, Signature design: the same recommendation list is rebuilt from the Signature pattern, so a recommendation with a written reason runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

    History: Recommending things to each other is an old habit, from a neighbor praising a book to a club listing its favorite walks. The website form grows out of that habit, adding a written reason with every recommendation, a public vote, and a rule that no recommendation is ever paid for. Giving a reason with a recommendation is an old habit of neighbors, who always said why a book or a walk was worth trying.
