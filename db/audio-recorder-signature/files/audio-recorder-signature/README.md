# Audio Recorder Database — files (audio-recorder-signature)

- `demo-audio-recorder-signature.py` — runnable demo program (run with `python3 demo-audio-recorder-signature.py`).
- `audio-recorder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-recorder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-audio-recorder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
