# Contact Manager Database — files (contact-manager-signature)

- `demo-contact-manager-signature.py` — runnable demo program (run with `python3 demo-contact-manager-signature.py`).
- `contact-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/contact-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-contact-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
