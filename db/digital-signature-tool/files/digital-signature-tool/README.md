# Digital Signature Tool Database — files (digital-signature-tool)

- `demo-digital-signature-tool.py` — runnable demo program (run with `python3 demo-digital-signature-tool.py`).
- `digital-signature-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/digital-signature-tool/index.jsonl.gz` (24 records).
- The generator is `gen-digital-signature-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
