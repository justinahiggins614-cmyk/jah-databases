# Trend Analysis Database — files (trend-analysis)

- `demo-trend-analysis.py` — runnable demo program (run with `python3 demo-trend-analysis.py`).
- `trend-analysis-sample.txt` — a plain-text sample of the database.
- The full database is `data/trend-analysis/index.jsonl.gz` (24 records).
- The generator is `gen-trend-analysis.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
