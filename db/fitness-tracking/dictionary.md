# Dictionary entries — The Fitness Tracking Database

Key terms of this database, defined in plain words.

## fitness tracking

The recorded counting of the exercise a person does, holding the activity log, the step count, the workout records, and the summaries together, so that the exercise of a life can be read as a line.

## activity log

The written list of the activities done on each day, naming each one with its time and its duration, so that the exercise of the day can be read in full.

## step count

The written number of steps taken in a day, kept beside the date, so that the walking of the day can be counted.

## workout record

The written account of one session of exercise, naming the activity, the duration, and the distance or the repetitions, so that the session can be read as a whole.

## heart rate record

The written series of heart rates taken during exercise, kept beside the workout they belong to, so that the effort of the session can be read as numbers.

## rest day

A day named in the log as a day without exercise, written so that the days of rest can be counted beside the days of work.

## personal best

The best result recorded for a named activity, kept with its date, so that the high mark of the record can be read plainly.

## training plan

The written plan of the exercise for a week or a season, naming each session, so that the work can be read before it is done.

## warm-up note

The written note of the gentle exercise done before a workout, kept beside the workout so that the beginning of the session can be read.

## cool-down note

The written note of the gentle exercise done after a workout, kept beside the workout so that the end of the session can be read.

## route record

The written account of the path taken for a walk, run, or ride, naming the start, the end, and the distance, so that the journey can be read again.

## progress chart

The written chart of the results of exercise over time, kept in order, so that the change can be read as a line.
