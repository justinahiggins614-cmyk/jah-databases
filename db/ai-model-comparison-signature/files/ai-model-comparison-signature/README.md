# AI Model Comparison Database — files (ai-model-comparison-signature)

- `demo-ai-model-comparison-signature.py` — runnable demo program (run with `python3 demo-ai-model-comparison-signature.py`).
- `ai-model-comparison-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-model-comparison-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-model-comparison-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
