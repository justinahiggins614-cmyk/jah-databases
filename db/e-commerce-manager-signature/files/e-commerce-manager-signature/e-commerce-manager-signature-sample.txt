E-Commerce Manager Database (e-commerce-manager-signature)

An e-commerce manager is a rule-based local demo: it reads set toy orders, and counts the orders and the sales. The manager reads 3 products. The product shirts wins 45 orders. The largest holds 45 orders. Everything runs in this browser; no data leaves the page.
