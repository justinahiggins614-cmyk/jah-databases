# E-Commerce Manager Database — files (e-commerce-manager-signature)

- `demo-e-commerce-manager-signature.py` — runnable demo program (run with `python3 demo-e-commerce-manager-signature.py`).
- `e-commerce-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/e-commerce-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-e-commerce-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
