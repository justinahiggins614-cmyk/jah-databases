# Building Layout Designer Database — files (building-layout-designer)

- `demo-building-layout-designer.py` — runnable demo program (run with `python3 demo-building-layout-designer.py`).
- `building-layout-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/building-layout-designer/index.jsonl.gz` (24 records).
- The generator is `gen-building-layout-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
