# Planetary Simulator Database — files (planetary-simulator-signature)

- `demo-planetary-simulator-signature.py` — runnable demo program (run with `python3 demo-planetary-simulator-signature.py`).
- `planetary-simulator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/planetary-simulator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-planetary-simulator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
