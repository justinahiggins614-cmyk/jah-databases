# AI Document Analyzer Database — files (ai-document-analyzer)

- `demo-ai-document-analyzer.py` — runnable demo program (run with `python3 demo-ai-document-analyzer.py`).
- `ai-document-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-document-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-ai-document-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
