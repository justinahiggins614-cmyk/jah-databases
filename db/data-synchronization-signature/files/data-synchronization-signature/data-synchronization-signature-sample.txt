Data Synchronization Database (data-synchronization-signature)

A data synchronization is a rule-based local demo: it reads set toy copies, and counts the syncs. The sync reads 3 copies. The copy main holds 12 syncs. The largest holds 12 syncs. Everything runs in this browser; no data leaves the page.
