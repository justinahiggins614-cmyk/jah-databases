4. Relevant data

Browse the first 24 records

dynamic-programming (6)

Fibonacci (DP)

Classic dynamic programming: each Fibonacci number is the sum of the previous two; iterate once, keep two variables.

Full record

0/1 Knapsack

Each item is taken or skipped. DP over capacity: dp[c] = best value achievable with capacity c.

Full record

Longest Common Subsequence

Longest common subsequence of two strings via DP: match extends the diagonal, mismatch takes the best neighbor.

Full record

Edit Distance

Minimum insertions, deletions, substitutions to turn one string into another (Levenshtein DP).

Full record

Coin Change (min coins)

Fewest coins to make an amount: DP over amounts, trying each coin. -1 when impossible.

Full record

Longest Increasing Subsequence

Longest increasing subsequence via patience piles with binary search: O(n log n).

Full record
graphs (6)

Breadth-First Search

Explores a graph level by level from the start node using a queue. Finds shortest paths in unweighted graphs.

Full record

Depth-First Search

Explores as deep as possible along each branch before backtracking. Natural fit for recursion.

Full record

Dijkstra’s Algorithm

Expands the closest unvisited node first, settling shortest paths from the start. Requires non-negative weights.

Full record

Bellman-Ford Algorithm

Relaxes every edge V-1 times. Handles negative weights and detects negative cycles; slower than Dijkstra.

Full record

Kruskal’s Algorithm

Sorts edges by weight and adds each unless it forms a cycle (union-find). Builds a minimum spanning tree.

Full record

Topological Sort

Orders directed-acyclic-graph nodes so every edge points forward (Kahn’s algorithm). Fails if a cycle exists.

Full record
greedy (3)

Activity Selection

Greedy: sort activities by finish time, take each compatible one. Optimal for interval scheduling.

Full record

Fractional Knapsack

Greedy by value-per-weight ratio, taking fractions when needed. Optimal for the fractional variant.

Full record

Huffman Coding

Merges the two least-frequent symbols repeatedly, building an optimal prefix code. Frequent symbols get short codes.

Full record
searching (2)

Linear Search

Scans each element in turn until the target is found. Works on any list, unsorted or sorted.

Full record

Binary Search

Repeatedly halves a sorted array, discarding the half that cannot contain the target. Logarithmic.

Full record
sorting (7)

Bubble Sort

Repeatedly steps through the list, swapping adjacent out-of-order elements until no swaps remain. Simple but quadratic.

Full record

Insertion Sort

Builds the sorted list one element at a time, inserting each new element into its proper place. Fast on nearly-sorted data.

Full record

Selection Sort

Repeatedly selects the minimum of the unsorted region and moves it to the front. Always quadratic, minimal swaps.

Full record

Merge Sort

Divide and conquer: split the list, sort each half, then merge the sorted halves. Guaranteed n log n, needs extra space.

Full record

Quicksort

Picks a pivot, partitions around it, and recurses. Average n log n; degrades to quadratic on bad pivots.

Full record

Heapsort

Builds a max-heap, then repeatedly extracts the maximum. Guaranteed n log n, in place, but not stable.

Full record

Counting Sort

Counts occurrences of each value, then writes them out in order. Linear when the value range k is small.

Full record
