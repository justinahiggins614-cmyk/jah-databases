Interactive Report Builder Database (interactive-report-builder-signature)

An interactive report builder is a rule-based local demo: it reads set toy reports, and counts the marks. The builder reads 3 reports. The report alpha holds 21 marks. The largest holds 21 marks. Everything runs in this browser; no data leaves the page.
