# Citation Finder Database — files (citation-finder)

- `demo-citation-finder.py` — runnable demo program (run with `python3 demo-citation-finder.py`).
- `citation-finder-sample.txt` — a plain-text sample of the database.
- The full database is `data/citation-finder/index.jsonl.gz` (24 records).
- The generator is `gen-citation-finder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
