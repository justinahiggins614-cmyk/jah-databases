# Data Normalization Database — files (data-normalization-signature)

- `demo-data-normalization-signature.py` — runnable demo program (run with `python3 demo-data-normalization-signature.py`).
- `data-normalization-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-normalization-signature/index.jsonl.gz` (24 records).
- The generator is `gen-data-normalization-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
