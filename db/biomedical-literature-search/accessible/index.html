The Biomedical Literature Search Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. A biomedical literature search is a rule-based local demo: it searches set toy papers, and counts the marks. Reference only: general information, no specific dosing, no cure claims, no diagnosis claims. The searcher reads 3 papers. The paper alpha holds 75 marks. The largest holds 75 marks. Everything runs in this browser; no data leaves the page.
