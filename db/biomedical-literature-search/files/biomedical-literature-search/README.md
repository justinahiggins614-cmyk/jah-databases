# Biomedical Literature Search Database — files (biomedical-literature-search)

- `demo-biomedical-literature-search.py` — runnable demo program (run with `python3 demo-biomedical-literature-search.py`).
- `biomedical-literature-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/biomedical-literature-search/index.jsonl.gz` (24 records).
- The generator is `gen-biomedical-literature-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
