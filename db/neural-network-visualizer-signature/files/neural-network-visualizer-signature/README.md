# Neural Network Visualizer Database — files (neural-network-visualizer-signature)

- `demo-neural-network-visualizer-signature.py` — runnable demo program (run with `python3 demo-neural-network-visualizer-signature.py`).
- `neural-network-visualizer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/neural-network-visualizer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-neural-network-visualizer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
