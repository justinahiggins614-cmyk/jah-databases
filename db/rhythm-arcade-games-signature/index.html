Starlight Step Parade Rank 1 · simple · rhythm arcade · beginner

Starlight Step Parade is an original rhythm arcade game. a parade rhythm game where players march and step in time with a brass band rolling down a starlit avenue.

The rules are simple: a sixteen-beat chart scrolls by, and the player presses the matching key for each beat. Every hit scores one hundred points plus a combo bonus that grows with each consecutive hit, and a miss resets the combo to zero. The demo chart is a sixteen-beat excerpt, not a full song.

The way to a high score is recovery, not perfection. When a beat slips, drop it at once and catch the next one clean, because a rebuilt combo quickly outscores a cautious streak of safe single hits.

Original game note: This is an original arcade-style game created for this Signature edition, with its own title, rules, and play.

How to play

Type the key for each beat: left, up, down, or right; quit to stop.

Working demo program

Save the code below as game.py and run python3 game.py --play to play it. Running it without arguments replays the scripted session whose output is stored with the record.

import sys
PARAMS = {'chart': ['down', 'down', 'right', 'left', 'left', 'down', 'right', 'left', 'down', 'up', 'down', 'right', 'down', 'up', 'down', 'down']}
AUTO = ['down', 'down', 'right', 'left', 'left', 'right', 'right', 'left', 'down', 'up', 'up', 'right', 'down', 'up', 'down', 'down']

def auto_play():
    score, combo, maxcombo, hits = 0, 0, 0, 0
    print("Rhythm tribute: auto session")
    for i, key in enumerate(PARAMS["chart"]):
        pressed = AUTO[i] if i < len(AUTO) else "miss"
        hit = (pressed == key)
        if hit:
            combo += 1
            maxcombo = max(maxcombo, combo)
            score += 100 + combo * 10
            hits += 1
        else:
            combo = 0
        print("Beat %d: need %s pressed %s %s score %d" % (i + 1, key, pressed, "HIT" if hit else "MISS", score))
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d MAX COMBO %d" % (hits, len(PARAMS["chart"]), maxcombo))

def play():
    score, combo, maxcombo, hits = 0, 0, 0, 0
    print("Rhythm tribute: type the key for each beat (left/up/down/right), or quit.")
    for i, key in enumerate(PARAMS["chart"]):
        print("Beat %d: press a key." % (i + 1))
        pressed = None
        for line in sys.stdin:
            cmd = line.strip().lower()
            if cmd == "quit":
                print("FINAL SCORE: %d" % score)
                print("RESULT: HITS %d/%d MAX COMBO %d" % (hits, len(PARAMS["chart"]), maxcombo))
                return
            pressed = cmd
            break
        hit = (pressed == key)
        if hit:
            combo += 1
            maxcombo = max(maxcombo, combo)
            score += 100 + combo * 10
            hits += 1
        else:
            combo = 0
        print("%s score %d" % ("HIT" if hit else "MISS", score))
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d MAX COMBO %d" % (hits, len(PARAMS["chart"]), maxcombo))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()

                print("RESULT: HITS %d/%d MAX COMBO %d" % (hits, len(PARAMS["chart"]), maxcombo))
                return
            pressed = cmd
            break
        hit = (pressed == key)
        if hit:
            combo += 1
            maxcombo = max(maxcombo, combo)
            score += 100 + combo * 10
            hits += 1
        else:
            combo = 0
        print("%s score %d" % ("HIT" if hit else "MISS", score))
    print("FINAL SCORE: %d" % score)
    print("RESULT: HITS %d/%d MAX COMBO %d" % (hits, len(PARAMS["chart"]), maxcombo))
