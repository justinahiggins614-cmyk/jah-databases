AI Agent Builder: Data Model and Storage

JAH-AGTBLD-000007 — ai agent builder record

The AI Agent Builder stores its data in a defined model: every thing it holds has a name, a shape, and a place, and this record lists all eight fields with what each one means. Storage is a small file-based database (SQLite) or plain JSONL files — one JSON record per line — so that the data can be read, checked, and moved without special tools. No field is ever stored without a meaning, and no meaning is ever left undocumented. In this public edition the program offers 8 capabilities (creating a specialist agent from a name and duties (1); plain-words instructions the agent follows (2); tools the agent may use, named one by one (3); a test for every duty (4); registration in the AI Phone Book with lineage (5); agents that talk like a human and explain their duties (6); an API other programs use to build agents (7); a plain-text build report (8)), 6 interfaces (Agent form — name and duties, in plain words; Duty list — each duty with the tool it uses; Instruction view — the plain-words instructions, readable and editable; Test run — run the duty tests and see the result; Builder API — machine-readable agent building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (name — the agent's name; duties — the duties it performs; instructions — its plain-words instructions; tools — the tools it may use; tests — the test result for every duty; phone_book — its registration in the AI Phone Book; lineage — what it was built from; version — its version number). This record is number 7 of 24 in the public edition of the AI Agent Builder database pair, and it specifies the data model and storage topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
