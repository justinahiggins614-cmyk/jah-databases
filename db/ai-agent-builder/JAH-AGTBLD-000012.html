AI Agent Builder: Import: Bringing Data In

JAH-AGTBLD-000012 — ai agent builder record

The AI Agent Builder brings data in from outside: it reads files in the formats its users already have, checks each incoming record against the same validation rules as typed input, and reports exactly what was accepted, what was refused, and why. An import never overwrites existing data without saying so, and a failed import leaves the program exactly as it was. This record specifies the accepted formats, the checks each record passes through, and the report every import produces. In this public edition the program offers 8 capabilities (creating a specialist agent from a name and duties (1); plain-words instructions the agent follows (2); tools the agent may use, named one by one (3); a test for every duty (4); registration in the AI Phone Book with lineage (5); agents that talk like a human and explain their duties (6); an API other programs use to build agents (7); a plain-text build report (8)), 6 interfaces (Agent form — name and duties, in plain words; Duty list — each duty with the tool it uses; Instruction view — the plain-words instructions, readable and editable; Test run — run the duty tests and see the result; Builder API — machine-readable agent building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (name — the agent's name; duties — the duties it performs; instructions — its plain-words instructions; tools — the tools it may use; tests — the test result for every duty; phone_book — its registration in the AI Phone Book; lineage — what it was built from; version — its version number). This record is number 12 of 24 in the public edition of the AI Agent Builder database pair, and it specifies the import: bringing data in topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
