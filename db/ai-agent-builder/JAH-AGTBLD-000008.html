AI Agent Builder: Input Validation and Error Handling

JAH-AGTBLD-000008 — ai agent builder record

The AI Agent Builder checks every input before it trusts it: a missing value, a wrong type, or a value outside its allowed range is refused with a message that names the field and the rule it broke. Refused input changes nothing — no partial write, no half-built record, no silent correction. This record lists the validation rules for each input, the exact error each broken rule produces, and the recovery path: what the user or calling program does next to put it right. In this public edition the program offers 8 capabilities (creating a specialist agent from a name and duties (1); plain-words instructions the agent follows (2); tools the agent may use, named one by one (3); a test for every duty (4); registration in the AI Phone Book with lineage (5); agents that talk like a human and explain their duties (6); an API other programs use to build agents (7); a plain-text build report (8)), 6 interfaces (Agent form — name and duties, in plain words; Duty list — each duty with the tool it uses; Instruction view — the plain-words instructions, readable and editable; Test run — run the duty tests and see the result; Builder API — machine-readable agent building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (name — the agent's name; duties — the duties it performs; instructions — its plain-words instructions; tools — the tools it may use; tests — the test result for every duty; phone_book — its registration in the AI Phone Book; lineage — what it was built from; version — its version number).
