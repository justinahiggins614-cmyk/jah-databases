AI Agent Builder: Overview and Purpose

JAH-AGTBLD-000001 — ai agent builder record

The AI Agent Builder exists to do one job well, and this record states that job in full: what the program does, who it does it for, and what counts as done. Everything else in the program — every screen, every interface call, every test — is judged against this statement. If a feature does not serve the stated purpose, it does not belong in the program. This record is the anchor the other twenty-three records in this edition refer back to. In this public edition the program offers 8 capabilities (creating a specialist agent from a name and duties (1); plain-words instructions the agent follows (2); tools the agent may use, named one by one (3); a test for every duty (4); registration in the AI Phone Book with lineage (5); agents that talk like a human and explain their duties (6); an API other programs use to build agents (7); a plain-text build report (8)), 6 interfaces (Agent form — name and duties, in plain words; Duty list — each duty with the tool it uses; Instruction view — the plain-words instructions, readable and editable; Test run — run the duty tests and see the result; Builder API — machine-readable agent building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (name — the agent's name; duties — the duties it performs; instructions — its plain-words instructions; tools — the tools it may use; tests — the test result for every duty; phone_book — its registration in the AI Phone Book; lineage — what it was built from; version — its version number). This record is number 1 of 24 in the public edition of the AI Agent Builder database pair, and it specifies the overview and purpose topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
