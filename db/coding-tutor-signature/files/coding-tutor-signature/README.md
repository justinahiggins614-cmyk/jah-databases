# Coding Tutor Database — files (coding-tutor-signature)

- `demo-coding-tutor-signature.py` — runnable demo program (run with `python3 demo-coding-tutor-signature.py`).
- `coding-tutor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/coding-tutor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-coding-tutor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
