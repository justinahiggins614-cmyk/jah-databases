A Weekend Running Club Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A community sports directory website: a visitor picks a generic kind of community sport, such as a weekend running club or a bowls club, and the site shows illustrative sample entries of that kind, each with a plain description of what the sport holds, when it meets, and what it costs. The site names no real club, copies no real listing, and makes no claim that any sample entry is a real club. This record covers A Weekend Running Club.

A weekend running club gives neighbors a gentle run of three miles, a walkers group beside it, and tea after, with no cost and no fuss. The entry must say when the club meets, where the run begins, and how fast the group goes, so a new runner can judge whether the pace fits. Without those plain facts, a new runner may join a run too fast for them, and a run too fast is a poor first morning. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Worked example: in a website built this way, a weekend running club runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
