# Code Debugger Database — files (code-debugger)

- `demo-code-debugger.py` — runnable demo program (run with `python3 demo-code-debugger.py`).
- `code-debugger-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-debugger/index.jsonl.gz` (24 records).
- The generator is `gen-code-debugger.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
