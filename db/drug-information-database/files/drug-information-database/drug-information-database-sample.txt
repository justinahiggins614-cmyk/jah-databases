Drug Information Database Database (drug-information-database)

A drug information database is a rule-based local demo: it lists set toy drugs, and counts the marks. Reference only: general information, no specific dosing, no cure claims, no diagnosis claims. The database reads 3 drugs. The drug alpha holds 51 marks. The largest holds 51 marks. Everything runs in this browser; no data leaves the page.
