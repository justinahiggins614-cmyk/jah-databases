# The File Sharing Communications Database

The File Sharing Communications Database is the file sharing communications record database in the Signature network. It holds 24 full file sharing communications record records in the public edition and 24 in the Signature edition, in a teaching ladder of 8 simple, 8 compounded and 8 most complex records.

It expands the live database communication-aid-comparison, which it links to and never rebuilds. The database carries the specification, models, test suites and verification records; it is not a running service.
