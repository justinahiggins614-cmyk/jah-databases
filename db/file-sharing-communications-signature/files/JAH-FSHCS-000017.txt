History
Sharing a file once meant handing over a paper, a disk, or a tape, and waiting to learn whether it arrived whole. The network made the handing instant, but the old questions stayed: did the whole file arrive, did the right person receive it, and can the sender prove it? File sharing communications is the service that answers those questions in writing, for every file, every time.
