# JSON Editor Database — files (json-editor)

- `demo-json-editor.py` — runnable demo program (run with `python3 demo-json-editor.py`).
- `json-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/json-editor/index.jsonl.gz` (24 records).
- The generator is `gen-json-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
