The JSON Editor Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. A JSON editor writes, checks and formats JSON: type JSON, and it validates it, names the line of any error, formats it for reading or squeezes it to one line. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced.

  1. What JSON Is

    Record 1 of 24. simple. Feasibility: buildable-now. JSON is a way to write data as text: keys and values in braces, lists in brackets. {"name": "Ana", "age": 34} holds 2 keys.

    Math proof: JSON is counting and naming: an object of 4 keys has keys name, age, town, job, and a list of 3 numbers holds 3 numbers. A one-line JSON of 47 characters formats into 5 lines, and minifying brings 5 lines back to 1. Sorting keys puts age before name before town.

    Science proof: JSON works because data has a shape that text can carry: braces hold named values, brackets hold lists in order, and quotes mark words. A parser reads that shape and either builds the data or names the exact line where the shape breaks, which is why the editor can point at a missing comma instead of guessing.
