1. Description

A JSON editor writes, checks and formats JSON: type JSON, and it validates it, names the line of any error, formats it for reading or squeezes it to one line. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

JSON is counting and naming: an object of 4 keys has keys name, age, town, job, and a list of 3 numbers holds 3 numbers. A one-line JSON of 47 characters formats into 5 lines, and minifying brings 5 lines back to 1. Sorting keys puts age before name before town.

3. Science proof

JSON works because data has a shape that text can carry: braces hold named values, brackets hold lists in order, and quotes mark words. A parser reads that shape and either builds the data or names the exact line where the shape breaks, which is why the editor can point at a missing comma instead of guessing.
