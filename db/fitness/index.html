About this data base

Archive
This database’s fitness training entry archive (JAH-FIT- records), preserved as structured, searchable data and marching toward a 1,000,000-record target.
Record schema
id · title · description · category · src · spec{entry, muscles[], equipment, form_cues[], programming{sets, reps, rest_sec}}
Generator
jahdb-fitness-1.0 — deterministic, every record validated by an independent checker before acceptance.
Drift control
Every generated record is checked against an archive sample for exact duplicates and re-validated by the independent checker.
AI
JAH Fitness Creator — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
