# Sound Effect Generator Database — files (sound-effect-generator-signature)

- `demo-sound-effect-generator-signature.py` — runnable demo program (run with `python3 demo-sound-effect-generator-signature.py`).
- `sound-effect-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/sound-effect-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-sound-effect-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
