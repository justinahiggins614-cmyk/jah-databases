# Dictionary entries — The Public Infrastructure Reporting Database

Key terms of this database, defined in plain words.

## infrastructure

The shared things a town runs on: roads, lights, water, parks, and the pipes and wires beneath them.

## report

A message from a resident saying something is broken or unsafe, naming the thing, the place, and the problem.

## case

One report kept as a numbered record, followed from the day it is made until the day it is fixed.

## queue

The ordered line of open cases, first in, first out, except that emergencies jump the line.

## priority

How urgent a case is, judged by danger and by how many people it affects.

## confirmation

The message back to the reporter saying the case is received, carrying the case number.

## fix

The work that puts a broken thing right, recorded against the case with the date it was done.

## dashboard

A public board showing how many cases are open, how many are fixed, and how long each kind takes.

## anonymous report

A report made without a name, which is accepted the same way, because the broken thing matters more than the reporter.

## photo evidence

A picture sent with a report, showing the problem, kept beside the case so the crew can see what awaits them.

## crew

The team sent to fix a thing, named in the case so the reporter knows who is coming.

## ledger

The written record of every case and every fix, kept in order, so the town's work can be checked.
