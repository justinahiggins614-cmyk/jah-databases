# Dictionary entries — The Car Rental Booking Database

Key terms of this database, defined in plain words.

## car rental booking

The written record of a vehicle held for a stated rental, naming the renter, the vehicle, and the rate, kept as the single true record of the booking. It is a record only: no live booking and no payment happens here.

## renter

The person named on a booking as the one who will take the vehicle, recorded with the name written exactly as it stands on their driving licence.

## vehicle

The car held by a booking, named by its make, its model, and its class, so that the rental can be read against the vehicle it rests on.

## rental period

The days a vehicle is held, written with the pick-up and return dates, so that the length of the booking can be read from the record.

## daily rate

The price stated for one day with a vehicle, recorded with its amount and what it covers, so that the cost of a rental can be counted. No payment is taken here; the rate is a recorded figure only.

## mileage allowance

The distance a rental allows the renter to drive, stated beside the rate, so that a rental that allows little and one that allows much are never compared as if they were the same.

## pick-up location

The place where a renter takes the vehicle, written on the booking, so that the start of the rental can be read from the record.

## return location

The place where a renter gives the vehicle back, written on the booking, so that the end of the rental can be read from the record.

## booking reference

The one code given to a booking when it is made, written on every message about it, so that the booking can be found in the record at any moment.

## vehicle class

The named kind of vehicle, such as small or large, written on the booking, so that the vehicle held is the kind the renter asked for and the rate matches it.

## fuel policy

The written rules about the fuel in a vehicle at pick-up and at return, kept with the booking, so that the renter knows what is asked of them before they drive.

## rental agreement

The written terms under which a vehicle is let, naming the vehicle, the period, and the rate, kept with the booking, so that both sides can point to the same words.
