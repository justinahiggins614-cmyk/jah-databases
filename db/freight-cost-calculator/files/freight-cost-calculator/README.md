# Freight Cost Calculator Database — files (freight-cost-calculator)

- `demo-freight-cost-calculator.py` — runnable demo program (run with `python3 demo-freight-cost-calculator.py`).
- `freight-cost-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/freight-cost-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-freight-cost-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
