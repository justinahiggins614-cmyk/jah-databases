# Database Record Ranking Database — files (database-record-ranking)

- `demo-database-record-ranking.py` — runnable demo program (run with `python3 demo-database-record-ranking.py`).
- `database-record-ranking-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-record-ranking/index.jsonl.gz` (24 records).
- The generator is `gen-database-record-ranking.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
