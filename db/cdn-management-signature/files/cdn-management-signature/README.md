# CDN Management Database — files (cdn-management-signature)

- `demo-cdn-management-signature.py` — runnable demo program (run with `python3 demo-cdn-management-signature.py`).
- `cdn-management-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/cdn-management-signature/index.jsonl.gz` (24 records).
- The generator is `gen-cdn-management-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
