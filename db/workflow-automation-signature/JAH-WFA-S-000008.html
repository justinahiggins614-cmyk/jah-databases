Workflow Automation: Signature Validation and Error Handling

JAH-WFA-S-000008 — workflow automation record

The Signature edition validates input the same way as the public edition — and then checks one thing more: that no generated content is ever passed off as a public record. A Signature record that claims to be public is refused, and the refusal is logged. This record lists the Signature validation rules, the errors each broken rule produces, and the recovery path for each one. In this Signature edition the program offers 8 capabilities (running a list of steps in order (1); passing each step's result to the next step (2); recording every step's outcome with its evidence (3); stopping clearly at the first failing step (4); re-running a workflow from any step (5); a plain-text run report readable without JavaScript (6); an API other programs use to run workflows (7); approval gates on steps that change anything (8)), 6 interfaces (Workflow form — steps listed in order, in plain words; Step list — each step with its action and inputs; Run button — execute the workflow and watch each step report; Run report — every step with its result and evidence; Automation API — machine-readable workflow running for other programs; Plain-text mode — the run report as readable plain text), and 8 data fields (steps — the steps in order; results — each step's result; failed_step — the first step that failed, if any; evidence — what each step proved; approvals — the approvals given for steps that change things; run_date — the date the workflow ran; duration — how long the run took; verdict — pass only when every step passed).
