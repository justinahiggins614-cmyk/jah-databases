# AI Image Generator Database — files (ai-image-generator-signature)

- `demo-ai-image-generator-signature.py` — runnable demo program (run with `python3 demo-ai-image-generator-signature.py`).
- `ai-image-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-image-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-image-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
