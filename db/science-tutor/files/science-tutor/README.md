# Science Tutor Database — files (science-tutor)

- `demo-science-tutor.py` — runnable demo program (run with `python3 demo-science-tutor.py`).
- `science-tutor-sample.txt` — a plain-text sample of the database.
- The full database is `data/science-tutor/index.jsonl.gz` (24 records).
- The generator is `gen-science-tutor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
