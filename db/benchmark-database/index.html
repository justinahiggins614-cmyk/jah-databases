How this database works

Each record is a benchmark definition (target, metric, methodology, scoring) plus a runnable test program plus the honestly recorded measured results from executing it. Run any record program with node to reproduce the measurement.

Boundless generator

Generator script: gen-benchmark-database.js — run node gen-benchmark-database.js --n 5. Self-regulating: throttled, duplicate-checked, stops at 1015 or when complete. Generated output is labeled "generated" and never mixed with assistant-built records.
