JAH-MTRX-S-000020 — Any table of numbers with the same count in each row is a matrix. A table of 2 rows and 3 columns is a 2 by 3 matrix of 6 numbers.
Math proof: Adding and subtracting work entry by entry: [[1, 2], [3, 4]] plus [[5, 6], [7, 8]] is [[6, 8], [10, 12]]. Multiplying combines rows with columns: the same pair gives [[19, 22], [43, 50]]. The determinant of [[1, 2], [3, 4]] is 1 times 4 minus 2 times 3, which is -2, and the inverse is [[-2.0, 1.0], [1.5, -0.5]]. The trace is 1 + 4, which is 5.
Science proof: A matrix is a table of numbers, and matrix arithmetic is arithmetic on tables: adding lines up the entries, multiplying lines up rows against columns. The inverse undoes a matrix the way dividing undoes multiplying, which is why a matrix equation can be solved by multiplying by the inverse. That is why the calculator shows the working, not only the answer.
