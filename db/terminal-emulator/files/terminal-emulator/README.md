# Terminal Emulator Database — files (terminal-emulator)

- `demo-terminal-emulator.py` — runnable demo program (run with `python3 demo-terminal-emulator.py`).
- `terminal-emulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/terminal-emulator/index.jsonl.gz` (24 records).
- The generator is `gen-terminal-emulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
