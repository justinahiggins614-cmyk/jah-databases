# Room Measurement Tool Database — files (room-measurement-tool)

- `demo-room-measurement-tool.py` — runnable demo program (run with `python3 demo-room-measurement-tool.py`).
- `room-measurement-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/room-measurement-tool/index.jsonl.gz` (24 records).
- The generator is `gen-room-measurement-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
