# Webinar Platform Database — files (webinar-platform-signature)

- `demo-webinar-platform-signature.py` — runnable demo program (run with `python3 demo-webinar-platform-signature.py`).
- `webinar-platform-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/webinar-platform-signature/index.jsonl.gz` (24 records).
- The generator is `gen-webinar-platform-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
