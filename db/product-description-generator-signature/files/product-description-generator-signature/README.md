# Product Description Generator Database — files (product-description-generator-signature)

- `demo-product-description-generator-signature.py` — runnable demo program (run with `python3 demo-product-description-generator-signature.py`).
- `product-description-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/product-description-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-product-description-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
