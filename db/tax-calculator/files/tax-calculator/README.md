# Tax Calculator Database — files (tax-calculator)

- `demo-tax-calculator.py` — runnable demo program (run with `python3 demo-tax-calculator.py`).
- `tax-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/tax-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-tax-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
