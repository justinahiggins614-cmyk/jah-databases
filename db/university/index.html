About this data base

Archive
This database's university catalog: courses with modules, lessons, labs, and teachers across 11 colleges (JAH-COURSE records), preserved as structured, searchable data.
Record schema
id · type · code · title · college · college_key · level · credits · desc · modules[{m,lessons[]}] · readings[] · teacher{} · labs[] · prereq · stamp
Generator
jahdb-university-1.0 — deterministic (mulberry32). Builds each course constructively from real college vocab, then an independent re-builder reconstructs every derived field from the raw picks to verify the record.
Drift control
Every generated title is checked against an archive sample for exact duplicates and re-verified by the independent re-builder.
Cross-database
The generator can borrow a theme from any of the other 36 data bases when you tick the box.
AI
JAH University Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
