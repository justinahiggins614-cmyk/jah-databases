# API Integration Database — files (api-integration-signature)

- `demo-api-integration-signature.py` — runnable demo program (run with `python3 demo-api-integration-signature.py`).
- `api-integration-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/api-integration-signature/index.jsonl.gz` (24 records).
- The generator is `gen-api-integration-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
