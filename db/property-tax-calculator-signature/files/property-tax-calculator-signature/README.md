# Property Tax Calculator Database — files (property-tax-calculator-signature)

- `demo-property-tax-calculator-signature.py` — runnable demo program (run with `python3 demo-property-tax-calculator-signature.py`).
- `property-tax-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/property-tax-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-property-tax-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
