# Interactive Textbook Database — files (interactive-textbook-signature)

- `demo-interactive-textbook-signature.py` — runnable demo program (run with `python3 demo-interactive-textbook-signature.py`).
- `interactive-textbook-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/interactive-textbook-signature/index.jsonl.gz` (24 records).
- The generator is `gen-interactive-textbook-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
