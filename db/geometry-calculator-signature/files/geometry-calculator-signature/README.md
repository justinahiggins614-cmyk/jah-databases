# Geometry Calculator Database — files (geometry-calculator-signature)

- `demo-geometry-calculator-signature.py` — runnable demo program (run with `python3 demo-geometry-calculator-signature.py`).
- `geometry-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/geometry-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-geometry-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
