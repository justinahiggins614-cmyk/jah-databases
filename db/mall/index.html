About this data base

Archive
This database's product archive (JAH-MALL records), preserved as structured, searchable data.
Record schema
id · name · dept · price · src · stype · sid · blurb · seed
Generator
jahdb-mall-1.0 — deterministic (mulberry32). Builds each product name constructively from the department's real archive vocabulary; an independent verifier rebuilds the name from the word indices and checks every word against that department's vocabulary. Price is always 0 — free forever.
Drift control
Every generated record is checked against an archive sample for duplicate product names and re-validated by the independent checker.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Mall Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
