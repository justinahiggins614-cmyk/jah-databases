The Image Resizer Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. An image resizer changes the width and height of a picture in pixels. Upload a picture, set a new size, and download the resized copy. The original file is never changed; everything happens on a canvas in this browser.

Twenty-four full records, ordered simple to working to advanced.

  1. What Resizing Means

    Record 1 of 24. simple. Feasibility: buildable-now. Resizing changes the width and height of a picture in pixels, keeping the picture itself. A picture of 800 by 600 pixels resizes to 400 by 300 pixels.

    Math proof: Scaling by a factor s multiplies width and height by s, and the pixel count by s squared. Halving each side (s equals 0.5) quarters the pixels. Keeping the aspect ratio means width over height stays constant: a new width w gives a new height of w times old height over old width.

    Science proof: A picture is a grid of pixels, and resizing rebuilds that grid at a new size. Shrinking averages neighbouring pixels into fewer pixels, which keeps the picture recognisable. Stretching spreads pixels wider, which softens detail. The canvas in the browser does this arithmetic for every pixel.
