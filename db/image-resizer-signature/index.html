1. Description

An image resizer changes the width and height of a picture in pixels. Upload a picture, set a new size, and download the resized copy. The original file is never changed; everything happens on a canvas in this browser.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Scaling by a factor s multiplies width and height by s, and the pixel count by s squared. Halving each side (s equals 0.5) quarters the pixels. Keeping the aspect ratio means width over height stays constant: a new width w gives a new height of w times old height over old width.

3. Science proof

A picture is a grid of pixels, and resizing rebuilds that grid at a new size. Shrinking averages neighbouring pixels into fewer pixels, which keeps the picture recognisable. Stretching spreads pixels wider, which softens detail. The canvas in the browser does this arithmetic for every pixel.

What Resizing Means

JAH-IMGR-S-000001 — Resizing changes the width and height of a picture in pixels, keeping the picture itself. A picture of 800 by 600 pixels resizes to 400 by 300 pixels.

Math proof: Scaling by a factor s multiplies width and height by s, and the pixel count by s squared. Halving each side (s equals 0.5) quarters the pixels. Keeping the aspect ratio means width over height stays constant: a new width w gives a new height of w times old height over old width.

Science proof: A picture is a grid of pixels, and resizing rebuilds that grid at a new size. Shrinking averages neighbouring pixels into fewer pixels, which keeps the picture recognisable. Stretching spreads pixels wider, which softens detail. The canvas in the browser does this arithmetic for every pixel.

Runnable demo program
old_w, old_h = 800, 600
new_w = 400
new_h = round(new_w * old_h / old_w)
print(f'{old_w}x{old_h} -> {new_w}x{new_h}; pixels {old_w*old_h} -> {new_w*new_h}')

Output:

800x600 -> 400x300; pixels 480000 -> 120000
