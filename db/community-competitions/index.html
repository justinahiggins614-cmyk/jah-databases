A Contest With Rules Written Before It Starts Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A competition website: a community announces a contest with written rules, members enter in the open, entries are judged against the same rubric, and the scoreboard is public so every entrant can see how the result was reached. The contests are fair play only, with no real-money play of any kind, and every entry stays credited to its maker. This record covers A Contest With Rules Written Before It Starts.

A contest whose rules are written after it starts is a contest nobody trusts, because the winner can always be accused of winning by rules made up to suit them. The rules should be written before the first entry arrives, naming what counts, how it is judged, and what happens in a tie. Without rules written first, every result is argued about, and the argument lasts longer than the contest. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Worked example: in a website built this way, a contest with rules written before it starts runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

The website form grows out of that history, adding a public scoreboard, a judging rubric written before the contest starts, and entries anyone can read. Writing the rules first is an old habit of every fair contest, from the village race to the baking contest at the fair.
