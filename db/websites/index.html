About this data base

Archive
This database's 1-million website-options archive (JAH-TPL records): deterministic template entries across 20 categories and 8 styles, computed live from the Creator's own option generator.
Record schema
id · code · name · cat · style · palette · desc
Generator
jahdb-websites-1.0 — deterministic (mulberry32). Builds new build-concepts from the Creator's own category/style/word/palette pools, ids in the JAH-SITE- space (never colliding with JAH-TPL- option ids); an independent verifier rebuilds the name and description from the private pool indices.
Drift control
Every generated id is verified to live in the JAH-SITE- space, which the stored JAH-TPL- option archive never uses.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Web Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
