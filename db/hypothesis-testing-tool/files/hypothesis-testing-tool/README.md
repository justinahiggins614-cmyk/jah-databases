# Hypothesis Testing Tool Database — files (hypothesis-testing-tool)

- `demo-hypothesis-testing-tool.py` — runnable demo program (run with `python3 demo-hypothesis-testing-tool.py`).
- `hypothesis-testing-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/hypothesis-testing-tool/index.jsonl.gz` (24 records).
- The generator is `gen-hypothesis-testing-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
