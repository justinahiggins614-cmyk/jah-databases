# DNA Sequence Analyzer Database — files (dna-sequence-analyzer-signature)

- `dna-sequence-analyzer-signature-sample.txt` — a plain-text sample of the database.

- The generator is `gen-dna-sequence-analyzer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
