# Smart Contract Development Database — files (smart-contract-development)

- `demo-smart-contract-development.py` — runnable demo program (run with `python3 demo-smart-contract-development.py`).
- `smart-contract-development-sample.txt` — a plain-text sample of the database.
- The full database is `data/smart-contract-development/index.jsonl.gz` (24 records).
- The generator is `gen-smart-contract-development.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
