# Time Zone Converter Database — files (time-zone-converter)

- `demo-time-zone-converter.py` — runnable demo program (run with `python3 demo-time-zone-converter.py`).
- `time-zone-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/time-zone-converter/index.jsonl.gz` (24 records).
- The generator is `gen-time-zone-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
