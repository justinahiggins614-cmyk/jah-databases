# Blockchain Explorer Database — files (blockchain-explorer-signature)

- `demo-blockchain-explorer-signature.py` — runnable demo program (run with `python3 demo-blockchain-explorer-signature.py`).
- `blockchain-explorer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/blockchain-explorer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-blockchain-explorer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
