# Optimization Solver Database — files (optimization-solver)

- `demo-optimization-solver.py` — runnable demo program (run with `python3 demo-optimization-solver.py`).
- `optimization-solver-sample.txt` — a plain-text sample of the database.
- The full database is `data/optimization-solver/index.jsonl.gz` (24 records).
- The generator is `gen-optimization-solver.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
