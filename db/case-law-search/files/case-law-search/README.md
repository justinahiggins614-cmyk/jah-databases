# Case Law Search Database — files (case-law-search)

- `demo-case-law-search.py` — runnable demo program (run with `python3 demo-case-law-search.py`).
- `case-law-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/case-law-search/index.jsonl.gz` (24 records).
- The generator is `gen-case-law-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
