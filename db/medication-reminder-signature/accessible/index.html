Accessible version: plain text, no scripts, no sign-in, free forever. A medication reminder is a rule-based local demo: it reads set toy reminders, and counts the alarms. The reminder reads 3 reminders. The reminder dawn holds 3 alarms. The largest holds 3 alarms. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced.
