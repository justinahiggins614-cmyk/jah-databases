Code Interpreter Database (code-interpreter-signature)

A code interpreter reads code and runs it at once, line by line: type an expression, and it prints the answer. It runs only safe code in this browser: numbers, variables, loops and functions, with no files and no network. No sign-in, no data leaving the page.

Worked example: Interpreting 3 lines runs 3 lines
