# Exam Generator Database — files (exam-generator-signature)

- `demo-exam-generator-signature.py` — runnable demo program (run with `python3 demo-exam-generator-signature.py`).
- `exam-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/exam-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-exam-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
