# Live Streaming Studio Database — files (live-streaming-studio)

- `demo-live-streaming-studio.py` — runnable demo program (run with `python3 demo-live-streaming-studio.py`).
- `live-streaming-studio-sample.txt` — a plain-text sample of the database.
- The full database is `data/live-streaming-studio/index.jsonl.gz` (24 records).
- The generator is `gen-live-streaming-studio.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
