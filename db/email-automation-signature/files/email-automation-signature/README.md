# Email Automation Database — files (email-automation-signature)

- `demo-email-automation-signature.py` — runnable demo program (run with `python3 demo-email-automation-signature.py`).
- `email-automation-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/email-automation-signature/index.jsonl.gz` (24 records).
- The generator is `gen-email-automation-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
