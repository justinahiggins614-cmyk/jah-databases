# Dependency Analyzer Database — files (dependency-analyzer-signature)

- `demo-dependency-analyzer-signature.py` — runnable demo program (run with `python3 demo-dependency-analyzer-signature.py`).
- `dependency-analyzer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/dependency-analyzer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-dependency-analyzer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
