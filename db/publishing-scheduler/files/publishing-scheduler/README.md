# Publishing Scheduler Database — files (publishing-scheduler)

- `demo-publishing-scheduler.py` — runnable demo program (run with `python3 demo-publishing-scheduler.py`).
- `publishing-scheduler-sample.txt` — a plain-text sample of the database.
- The full database is `data/publishing-scheduler/index.jsonl.gz` (24 records).
- The generator is `gen-publishing-scheduler.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
