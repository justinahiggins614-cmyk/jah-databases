# Code Optimizer Database — files (code-optimizer)

- `demo-code-optimizer.py` — runnable demo program (run with `python3 demo-code-optimizer.py`).
- `code-optimizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-optimizer/index.jsonl.gz` (24 records).
- The generator is `gen-code-optimizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
