Workflow Automation: Integration with the Other 99 Programs

JAH-WFA-000015 — workflow automation record

The Workflow Automation works with the other ninety-nine programs in the 100: it offers its own job through its API, and it uses the other programs' APIs where they do a job better — search through the Universal Search Engine, storage through the Database Builder, verification through the Software Testing Center. This record names the programs it depends on, the programs that depend on it, and the order they are built in, so that no program is built before the programs it needs. In this public edition the program offers 8 capabilities (running a list of steps in order (1); passing each step's result to the next step (2); recording every step's outcome with its evidence (3); stopping clearly at the first failing step (4); re-running a workflow from any step (5); a plain-text run report readable without JavaScript (6); an API other programs use to run workflows (7); approval gates on steps that change anything (8)), 6 interfaces (Workflow form — steps listed in order, in plain words; Step list — each step with its action and inputs; Run button — execute the workflow and watch each step report; Run report — every step with its result and evidence; Automation API — machine-readable workflow running for other programs; Plain-text mode — the run report as readable plain text), and 8 data fields (steps — the steps in order; results — each step's result; failed_step — the first step that failed, if any; evidence — what each step proved; approvals — the approvals given for steps that change things; run_date — the date the workflow ran; duration — how long the run took; verdict — pass only when every step passed). This record is number 15 of 24 in the public edition of the Workflow Automation database pair, and it specifies the integration with the other 99 programs topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
