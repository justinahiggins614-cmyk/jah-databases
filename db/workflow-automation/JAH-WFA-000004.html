Workflow Automation: Main Screen: the Human Interface

JAH-WFA-000004 — workflow automation record

The main screen is the human face of the Workflow Automation: one page that shows the program's name, its purpose in plain words, and its main action, with every button doing what it says. A first-time user must be able to complete the program's main job from this screen without reading documentation first. This record specifies the screen's parts, the order they appear in, and what each control does when used — including what happens when the user makes a mistake. In this public edition the program offers 8 capabilities (running a list of steps in order (1); passing each step's result to the next step (2); recording every step's outcome with its evidence (3); stopping clearly at the first failing step (4); re-running a workflow from any step (5); a plain-text run report readable without JavaScript (6); an API other programs use to run workflows (7); approval gates on steps that change anything (8)), 6 interfaces (Workflow form — steps listed in order, in plain words; Step list — each step with its action and inputs; Run button — execute the workflow and watch each step report; Run report — every step with its result and evidence; Automation API — machine-readable workflow running for other programs; Plain-text mode — the run report as readable plain text), and 8 data fields (steps — the steps in order; results — each step's result; failed_step — the first step that failed, if any; evidence — what each step proved; approvals — the approvals given for steps that change things; run_date — the date the workflow ran; duration — how long the run took; verdict — pass only when every step passed). This record is number 4 of 24 in the public edition of the Workflow Automation database pair, and it specifies the main screen: the human interface topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
