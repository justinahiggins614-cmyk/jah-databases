Workflow Automation: Access Control and Permissions

JAH-WFA-000010 — workflow automation record

The Workflow Automation controls who may do what: reading is open where the data is public, and every action that changes, builds, or publishes anything requires the right permission — and the permission is checked before the action, not after. Denied actions are refused with a clear message and written to the log. This record names the permission levels, what each one may do, and the defensive rule that governs them all: the program never grants access it was not asked to grant. In this public edition the program offers 8 capabilities (running a list of steps in order (1); passing each step's result to the next step (2); recording every step's outcome with its evidence (3); stopping clearly at the first failing step (4); re-running a workflow from any step (5); a plain-text run report readable without JavaScript (6); an API other programs use to run workflows (7); approval gates on steps that change anything (8)), 6 interfaces (Workflow form — steps listed in order, in plain words; Step list — each step with its action and inputs; Run button — execute the workflow and watch each step report; Run report — every step with its result and evidence; Automation API — machine-readable workflow running for other programs; Plain-text mode — the run report as readable plain text), and 8 data fields (steps — the steps in order; results — each step's result; failed_step — the first step that failed, if any; evidence — what each step proved; approvals — the approvals given for steps that change things; run_date — the date the workflow ran; duration — how long the run took; verdict — pass only when every step passed). This record is number 10 of 24 in the public edition of the Workflow Automation database pair, and it specifies the access control and permissions topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
