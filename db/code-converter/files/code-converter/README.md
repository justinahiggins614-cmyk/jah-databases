# Code Converter Database — files (code-converter)

- `demo-code-converter.py` — runnable demo program (run with `python3 demo-code-converter.py`).
- `code-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-converter/index.jsonl.gz` (24 records).
- The generator is `gen-code-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
