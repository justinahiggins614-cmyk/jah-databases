1. Description

A code converter changes code from one language to another, keeping its work: Python to JavaScript, and JSON to columns. The demo on this page converts code in the browser, with no server and no connection. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Adding 1 and 2 gives 3 in both languages. Doubling 21 gives 42 in both languages. A JSON object with 3 keys becomes 3 columns. Converting twice: Python to JavaScript and back keeps 5 lines. Two languages: Python and JavaScript, 2 languages.

3. Science proof

A code converter works because two languages say the same work in different words: adding 1 and 2 gives 3 in both languages, and doubling 21 gives 42 in both languages. A list of 3 items stays 3 items, and a number stays a number: 42 in Python is 42 in JavaScript. That is why the local demo shows the code and the converted code side by side, and runs 0 conversions on a server.
