# Video Conferencing Database — files (video-conferencing)

- `demo-video-conferencing.py` — runnable demo program (run with `python3 demo-video-conferencing.py`).
- `video-conferencing-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-conferencing/index.jsonl.gz` (24 records).
- The generator is `gen-video-conferencing.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
