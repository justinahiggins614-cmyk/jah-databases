# Port Logistics Manager Database — files (port-logistics-manager)

- `demo-port-logistics-manager.py` — runnable demo program (run with `python3 demo-port-logistics-manager.py`).
- `port-logistics-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/port-logistics-manager/index.jsonl.gz` (24 records).
- The generator is `gen-port-logistics-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
