# DNS Record Editor Database — files (dns-record-editor-signature)

- `demo-dns-record-editor-signature.py` — runnable demo program (run with `python3 demo-dns-record-editor-signature.py`).
- `dns-record-editor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/dns-record-editor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-dns-record-editor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
