Tetris Rank 1 · simple · puzzle · beginner

Tetris reached arcades in 1988 as the arcade form of the falling-block classic, where players rotate and place seven shapes to complete and clear horizontal lines. Its cabinets attracted players who chased high scores, learned patterns by repetition, and returned to beat their own best runs.

This tribute demo reduces the puzzle to a short text session: a set of pieces arrives one at a time, and you slide, rotate, and drop each one to keep the board low. It is an original miniature inspired by the mechanics of Tetris, not a copy of that game.

The best habit is to keep the board low and even: a tall stack in one column leaves no room to fix mistakes.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Tetris (1988). It is not Tetris (1988), and it uses no art, music, or code from that game.

How to play

Type left, right, rotate or drop for each piece, or quit to stop.

Working demo program

Save the code below as game.py and run python3 game.py --play to play it. Running it without arguments replays the scripted session whose output is stored with the record.

import sys
PARAMS = {'pieces': ['square', 'line', 'tee', 'el', 'jay', 'ess', 'zee', 'square']}
AUTO = [['left', 'drop'], ['right', 'drop'], ['rotate', 'drop'], ['left', 'drop'], ['right', 'drop'], ['drop'], ['left', 'rotate', 'drop'], ['right', 'drop']]

def auto_play():
    heights = [0] * 6
    score, lines = 0, 0
    print("Puzzle tribute: auto session")
    for pi, piece in enumerate(PARAMS["pieces"]):
        cmds = AUTO[pi] if pi < len(AUTO) else ["drop"]
        col, vertical = 2, False
        for cmd in cmds:
            if cmd == "left":
                col = max(0, col - 1)
            elif cmd == "right":
                col = min(5, col + 1)
            elif cmd == "rotate":
                vertical = not vertical
            elif cmd == "drop":
                break
        if vertical:
            heights[col] += 2
        else:
            if col >= 5:
                col = 4
            heights[col] += 1
            heights[col + 1] += 1
        cleared = 0
        while min(heights) > 0:
            heights = [h - 1 for h in heights]
            cleared += 1
        lines += cleared
        score += cleared * 100 + 10
        print("Piece %d: %s col %d %s heights %s score %d" % (pi + 1, piece, col, "vertical" if vertical else "flat", heights, score))
    print("FINAL SCORE: %d" % score)
    print("RESULT: LINES %d" % lines)

def play():
    heights = [0] * 6
    score, lines = 0, 0
    print("Puzzle tribute: type left/right/rotate/drop per piece, or quit. Fill rows to clear them.")
    pi = 0
    col, vertical = 2, False
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        if pi >= len(PARAMS["pieces"]):
            break
        if cmd == "left":
            col = max(0, col - 1)
        elif cmd == "right":
            col = min(5, col + 1)
        elif cmd == "rotate":
            vertical = not vertical
        elif cmd == "drop":
            piece = PARAMS["pieces"][pi]
            if vertical:
                heights[col] += 2
            else:
                if col >= 5:
                    col = 4
                heights[col] += 1
                heights[col + 1] += 1
            cleared = 0
            while min(heights) > 0:
                heights = [h - 1 for h in heights]
                cleared += 1
            lines += cleared
            score += cleared * 100 + 10
            print("Piece %d: %s heights %s score %d" % (pi + 1, piece, heights, score))
            pi += 1
            col, vertical = 2, False
        else:
            print("Unknown command: %s" % cmd)
    print("FINAL SCORE: %d" % score)
    print("RESULT: LINES %d" % lines)

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()
