# AI Agent Automation Database — files (ai-agent-automation)

- `demo-ai-agent-automation.py` — runnable demo program (run with `python3 demo-ai-agent-automation.py`).
- `ai-agent-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-agent-automation/index.jsonl.gz` (24 records).
- The generator is `gen-ai-agent-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
