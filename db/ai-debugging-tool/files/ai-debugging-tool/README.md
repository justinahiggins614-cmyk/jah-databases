# AI Debugging Tool Database — files (ai-debugging-tool)

- `demo-ai-debugging-tool.py` — runnable demo program (run with `python3 demo-ai-debugging-tool.py`).
- `ai-debugging-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-debugging-tool/index.jsonl.gz` (24 records).
- The generator is `gen-ai-debugging-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
