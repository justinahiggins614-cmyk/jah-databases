AI Debugging Tool Database (ai-debugging-tool)

An AI debugging tool is a rule-based local demo: it reads entered code and a trace, finds the failing line, and says why it fails. Paste code, press Debug, and read the cause. A trace of 3 lines fails at line 3. A trace holds 3 frames. The fixed code gives 5.0. Everything runs in this browser; no data leaves the page.
