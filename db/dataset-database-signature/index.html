Capabilities

Capability 1
Dataset directory: searchable registry of public datasets with publisher, link, license, and access method.
Capability 2
License classification: labels each dataset open, public-domain, permissive, or restricted-review.
Capability 3
Schema records: carries each dataset's field/schema documentation as a full record.
Capability 4
Freshness tracking: records last-verified date and update cadence per dataset.
Capability 5
Signature datasets: original Signature-built datasets with full records and generators.
Capability 6
Access guides: step-by-step download and loading instructions per dataset.
Capability 7
Schema diffing: compares dataset versions field by field.
Capability 8
Join recommendations: suggests which datasets combine well and on which keys.

Boundless generator

Generator script: gen-dataset-database-signature.js — run node gen-dataset-database-signature.js --n 5. Self-regulating: throttled, duplicate-checked, stops at 1015 or when complete. Generated output is labeled "generated" and never mixed with assistant-built records.
