# DNA Sequence Analyzer Database — files (dna-sequence-analyzer)

- `demo-dna-sequence-analyzer.py` — runnable demo program (run with `python3 demo-dna-sequence-analyzer.py`).
- `dna-sequence-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/dna-sequence-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-dna-sequence-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
