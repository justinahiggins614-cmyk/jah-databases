# Employee Directory Database — files (employee-directory)

- `demo-employee-directory.py` — runnable demo program (run with `python3 demo-employee-directory.py`).
- `employee-directory-sample.txt` — a plain-text sample of the database.
- The full database is `data/employee-directory/index.jsonl.gz` (24 records).
- The generator is `gen-employee-directory.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
