# Video Cutter Database — files (video-cutter)

- `demo-video-cutter.py` — runnable demo program (run with `python3 demo-video-cutter.py`).
- `video-cutter-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-cutter/index.jsonl.gz` (24 records).
- The generator is `gen-video-cutter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
