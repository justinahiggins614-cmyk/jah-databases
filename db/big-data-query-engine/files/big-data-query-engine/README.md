# Big Data Query Engine Database — files (big-data-query-engine)

- `demo-big-data-query-engine.py` — runnable demo program (run with `python3 demo-big-data-query-engine.py`).
- `big-data-query-engine-sample.txt` — a plain-text sample of the database.
- The full database is `data/big-data-query-engine/index.jsonl.gz` (24 records).
- The generator is `gen-big-data-query-engine.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
