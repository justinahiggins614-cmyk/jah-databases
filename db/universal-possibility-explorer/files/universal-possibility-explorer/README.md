# The Universal Possibility Explorer Database — files (universal-possibility-explorer)

- `demo-universal-possibility-explorer.py` — runnable demo program (run with `python3 demo-universal-possibility-explorer.py`).
- `universal-possibility-explorer-sample.txt` — a plain-text sample of the database.
- The full database is `data/universal-possibility-explorer/index.jsonl.gz` (24 records).
- The generator is `gen-universal-possibility-explorer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
- Classification: FRONTIER — simulation and design-study tool.
