The Coin-Op Begins 1971-72 Rank 1 · simple · pong · beginner

In 1971 the first commercial coin-operated video game arrived in bars and arcades, a space duel played on a small black-and-white screen that asked players for a quarter and gave them a few minutes of electronic novelty. A year later a far simpler game changed everything: two paddles, one bouncing square ball, and a score counter. That second game was easy to learn in seconds, hard to put down, and it turned the video game from a curiosity into a fixture beside the jukebox.

This tribute recreates the paddle rally at the heart of that breakthrough. You guard the left wall with a short paddle while the ball bounces around the court, and every return you make adds to your score. The demo changes the original in one honest way: it is a scripted rally against the wall rather than a head-to-head match, so it shows the rhythm of the game without pretending to be the cabinet itself.

The strategy is patience. Keep the paddle near the middle of its travel, move in small steps, and let the ball come to you instead of chasing it across the court. Players who flailed lost quickly; players who waited for the return could rally for minutes, and that calm rally is what made crowds gather around the first machines.

def pong_session(cmds, verbose):
    paddle, ball, bdx, bdy = 4, [6, 5], 1, 1
    pscore, cscore = 0, 0
    serves = PARAMS["serves"]
    for tick, cmd in enumerate(cmds):
        if cmd == "up":
            paddle = max(0, paddle - 1)
        elif cmd == "down":
            paddle = min(7, paddle + 1)
        ball[0] += bdx
        ball[1] += bdy
        if ball[1] <= 0 or ball[1] >= 9:
            bdy = -bdy
            ball[1] = max(0, min(9, ball[1]))
        if ball[0] >= 11:
            bdx = -1
        if ball[0] <= 0:
            if paddle <= ball[1] <= paddle + 2:
                bdx = 1
                pscore += 1
            else:
                cscore += 1
                s = serves[(pscore + cscore) % len(serves)]
                ball, bdx, bdy = [6, s], 1, 1 if s % 2 == 0 else -1
        if verbose:
            print("Tick %d: %s paddle %d ball %s you %d cpu %d" % (tick + 1, cmd, paddle, tuple(ball), pscore, cscore))
    return pscore, cscore

def auto_play():

    pscore, cscore = pong_session(AUTO, True)
    print("FINAL SCORE: %d" % pscore)
    print("RESULT: YOU %d CPU %d" % (pscore, cscore))

The Maze Craze Rank 2 · simple · maze · beginner

In 1980 a maze chase game turned the arcade upside down by replacing shooting with eating. The player steered a round yellow hero through a maze, gobbling dots while four colorful ghosts patrolled the corridors and tried to cut him off. A few large flashing pellets briefly reversed the hunt, letting the hero chase the ghosts for bonus points, and that reversal became one of the most famous mechanics in all of games.

This tribute recreates the maze chase with a single pursuing ghost and a winding corridor map full of dots. The demo changes the original by shrinking the cast to one ghost and one maze, so the chase stays readable: eat dots, keep moving, and never let the ghost corner you. It is an original tribute inspired by the mechanics, not the game itself.

Good maze play is route planning. Clear the edges of the maze early, avoid dead ends when the ghost is near, and keep an escape corridor open behind you. The players who lasted longest treated the maze like a map to memorize, not a race to finish, and that habit turned a simple chase into a game people studied for years.

import sys
PARAMS = {'map': ['###########', '#P....#...#', '#.##..#.#.#', '#...#...#.#', '#.#.###.#.#', '#...#...#G#', '###########']}
AUTO = ['right', 'right', 'right', 'right', 'down', 'down', 'right', 'right', 'down', 'down', 'left', 'left']

def parse_map():
    walls, dots, player, ghost = set(), set(), None, None
    for y, row in enumerate(PARAMS["map"]):
        for x, ch in enumerate(row):
            if ch == "#":
                walls.add((x, y))
            elif ch == ".":
                dots.add((x, y))
            elif ch == "P":
                player = (x, y)
            elif ch == "G":
                ghost = (x, y)
    return walls, dots, player, ghost

DIRS = {"up": (0, -1), "down": (0, 1), "left": (-1, 0), "right": (1, 0)}

def step(state, cmd):
    walls, dots, player, ghost, score, lives = state
    dx, dy = DIRS.get(cmd, (0, 0))
    nx, ny = player[0] + dx, player[1] + dy
    if (nx, ny) not in walls:
        player = (nx, ny)
    if player in dots:
        dots = dots - {player}
        score += 10
    if ghost is not None:
        gx, gy = ghost
        best, bestd = ghost, abs(gx - player[0]) + abs(gy - player[1])
        for mx, my in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            cand = (gx + mx, gy + my)
            if cand in walls:
                continue
            d = abs(cand[0] - player[0]) + abs(cand[1] - player[1])
            if d < bestd:
                best, bestd = cand, d
        ghost = best
    if ghost is not None and player == ghost:
        lives -= 1
        walls, dots, player, ghost = reset_positions()
    return (walls, dots, player, ghost, score, lives)

def reset_positions():
    walls, dots, player, ghost = parse_map()
    return walls, dots, player, ghost

def result_of(state):
    walls, dots, player, ghost, score, lives = state
    if not dots:
        return "WIN"
    if lives <= 0:
        return "OUT OF LIVES"
    return "ONGOING"

def auto_play():
    walls, dots, player, ghost = parse_map()
    state = (walls, dots, player, ghost, 0, 3)
    print("Maze tribute: auto session")
    for i, cmd in enumerate(AUTO):
        state = step(state, cmd)
        walls, dots, player, ghost, score, lives = state
        print("Step %d: %s -> pos %s score %d dots %d lives %d" % (i + 1, cmd, player, score, len(dots), lives))
        if result_of(state) != "ONGOING":
            break
    print("FINAL SCORE: %d" % state[4])
    print("RESULT: %s" % result_of(state))

def play():
    walls, dots, player, ghost = parse_map()
    state = (walls, dots, player, ghost, 0, 3)
    print("Maze tribute: type up/down/left/right, or quit. Eat every dot, avoid the ghost.")
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        if cmd not in DIRS:
            print("Unknown command: %s" % cmd)
            continue
        state = step(state, cmd)
        walls, dots, player, ghost, score, lives = state
        print("pos %s score %d dots %d lives %d" % (player, score, len(dots), lives))
        if result_of(state) != "ONGOING":

    print("FINAL SCORE: %d" % state[4])
    print("RESULT: %s" % result_of(state))

The Invader Wave Rank 3 · simple · fixed-shooter · beginner

In 1978 rows of marching aliens descended from the top of the screen, and the arcade found its first true blockbuster. The player drove a lone cannon along the bottom, firing upward while the invaders crept lower with every step, their marching rhythm speeding up as their numbers thinned. The game kept a running high score on the cabinet, and suddenly strangers were competing for the top line.

This tribute recreates the fixed shooter: five columns of invaders in three rows, a cannon that slides left and right, and a shot that clears one invader at a time. The demo changes the original by giving the invaders a gentler descent, one row every third turn, so a new player can learn the column-clearing rhythm before the pressure builds.

The winning habit is column discipline. Empty one column completely before moving on, because a lone invader in a cleared column is easy to forget and hard to hit late. Work from the edges inward, keep the cannon moving between shots, and never let the lowest row drift past the middle of the screen.

Before colorful pixel graphics took over, a family of arcade machines drew their pictures with pure light: a beam tracing glowing lines on a dark screen. The most famous of these vector games put the player in a small triangular ship drifting through an asteroid field, where every rock shattered into smaller, faster fragments. The look was stark and elegant, and the motion felt like real drifting in space.

This tribute recreates vector flight: turn, thrust, and shoot across a dark field, with rocks that split when hit. Vector pilots learn to shoot from a distance and never chase a rock. Line up, fire, and let the shot travel while you drift clear of the fragments. The players who survived longest fired sparingly, moved constantly, and treated momentum as a tool rather than a nuisance.

A carpenter scaled a construction site of girders and ladders while barrels rolled down toward him, and reaching the top meant rescuing someone from a giant ape. The game introduced jumping as a central skill, and its hero went on to become the most famous character in games.

This tribute recreates the climb as a timed run: each tick you choose to run or jump, and obstacles must be jumped over or they cost a life. The demo changes the original by flattening the girders into a single track, so the jumping rhythm is easy to read: jump just before an obstacle, land, and keep running.

The key is jumping early. A jump covers two steps, so starting the jump one step before the obstacle carries you cleanly over it. Players who jumped late clipped the obstacle; players who jumped at the last instant every time found the rhythm and cleared the whole climb without losing a life.

def parse_dungeon():
    walls, monsters, treasures, start, exitc = set(), {}, set(), None, None
    for y, row in enumerate(PARAMS["map"]):
        for x, ch in enumerate(row):
            if ch == "#":
                walls.add((x, y))
            elif ch == "M":
                monsters[(x, y)] = PARAMS["monster_hp"]
            elif ch == "T":
                treasures.add((x, y))
            elif ch == "P":
                start = (x, y)
            elif ch == "E":
                exitc = (x, y)

def dungeon_step(state, cmd):
    walls, monsters, treasures, player, hp, score = state
    if cmd == "attack":
        for (mx, my) in list(monsters):
            if abs(mx - player[0]) + abs(my - player[1]) == 1:
                monsters[(mx, my)] -= 25
                if monsters[(mx, my)] <= 0:
                    del monsters[(mx, my)]
                    score += 30
                else:
                    hp -= 10
                break
        return (walls, monsters, treasures, player, hp, score)
    dx, dy = DIRS_D.get(cmd, (0, 0))
    nxt = (player[0] + dx, player[1] + dy)
    if nxt not in walls and nxt not in monsters:
        player = nxt
    if player in treasures:
        treasures = treasures - {player}
        score += 50
    return (walls, monsters, treasures, player, hp, score)

    walls, monsters, treasures, player, hp, score = state
    if player == exitc:
        return "WIN"
    if hp <= 0:
        return "DEFEATED"
    return "ONGOING"

        if dungeon_result(state, exitc) != "ONGOING":

    print("RESULT: %s" % dungeon_result(state, exitc))

AUTO = ['right', 'right', 'right', 'right', 'right', 'down', 'down', 'left', 'left', 'left', 'left', 'left', 'down', 'down', 'right', 'right', 'right', 'right']

def parse_map():
    walls, dots, player, ghost = set(), set(), None, None
    for y, row in enumerate(PARAMS["map"]):
        for x, ch in enumerate(row):
            if ch == "#":
                walls.add((x, y))
            elif ch == ".":
                dots.add((x, y))
            elif ch == "P":
                player = (x, y)
            elif ch == "G":
                ghost = (x, y)
    return walls, dots, player, ghost

DIRS = {"up": (0, -1), "down": (0, 1), "left": (-1, 0), "right": (1, 0)}

def step(state, cmd):
    walls, dots, player, ghost, score, lives = state
    dx, dy = DIRS.get(cmd, (0, 0))
    nx, ny = player[0] + dx, player[1] + dy
    if (nx, ny) not in walls:
        player = (nx, ny)
    if player in dots:
        dots = dots - {player}
        score += 10
    if ghost is not None:
        gx, gy = ghost
        best, bestd = ghost, abs(gx - player[0]) + abs(gy - player[1])
        for mx, my in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            cand = (gx + mx, gy + my)
            if cand in walls:
                continue
            d = abs(cand[0] - player[0]) + abs(cand[1] - player[1])
            if d < bestd:
                best, bestd = cand, d
        ghost = best
    if ghost is not None and player == ghost:
        lives -= 1
        walls, dots, player, ghost = reset_positions()
    return (walls, dots, player, ghost, score, lives)

def reset_positions():
    walls, dots, player, ghost = parse_map()
    return walls, dots, player, ghost

        return "WIN"
    if lives <= 0:
