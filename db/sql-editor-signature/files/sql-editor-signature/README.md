# SQL Editor Database — files (sql-editor-signature)

- `demo-sql-editor-signature.py` — runnable demo program (run with `python3 demo-sql-editor-signature.py`).
- `sql-editor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/sql-editor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-sql-editor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
