The SQL Editor Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. A SQL editor writes queries and shows the table they return: type a query, press Run, and read the rows. The demo on this page runs queries in the browser over a seeded table of books, with no server and no connection. A broken query is shown, not hidden.

Twenty-four full records, ordered simple to working to advanced.
