# Attendance Tracker Database — files (attendance-tracker)

- `demo-attendance-tracker.py` — runnable demo program (run with `python3 demo-attendance-tracker.py`).
- `attendance-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/attendance-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-attendance-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
