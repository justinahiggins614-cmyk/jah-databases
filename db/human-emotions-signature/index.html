Definition and triggers

In the Signature presentation, contentment is reported to follow the completion of a task done well, a meal shared without hurry, time in a familiar place, and the sense that what is present is enough. It is also reported after a worry resolves without drama, and in moments of rest following effort rather than during the effort itself.

Bodily signs as reported

In the Signature presentation, the literature reports lowered muscle tension, slower and deeper breathing, and a relaxed posture. Heart rate is reported as steady rather than raised. These signs are modest and overlap with rest, and the record states them as reported, not as a fixed pattern that every person shows.

Facial and vocal expression

In the Signature presentation, the face is described as relaxed: the mouth soft, the eyes unhurried, the brow smooth. The voice is reported as unhurried and even, without the lift that marks excitement. Neither the face nor the voice is dramatic, which is why contentment is often noticed by those nearby rather than announced.

Behavioral tendencies

In the Signature presentation, behaviour reported with contentment includes lingering where one is, savouring food or company without rushing, and a willingness to stay with the present task rather than start a new one. People are reported to be more open to conversation and less inclined to seek novelty in the moment.

Cultural variation

In the Signature presentation, some cultures praise contentment openly as a virtue, notably in Buddhist and Stoic traditions, while others treat ambition as the higher value and view contentment as settling. The English word has no exact match in every language, and the record notes where neighbouring words carry a different shade.

Related emotions

In the Signature presentation, contentment borders joy, which is brighter and more active; calm, which is restful without the sense of satisfaction; gratitude, which adds a sense of thanks toward a giver; and relief, which follows the end of a strain. Its opposite in the literature is longing, the sense that something missing matters.

Working demo program

import hashlib
import json
import math
import random

BASICS = {'joy': (0.8, 0.6), 'trust': (0.6, 0.1), 'fear': (-0.6, 0.7), 'surprise': (0.1, 0.8), 'sadness': (-0.7, -0.3), 'disgust': (-0.6, 0.2), 'anger': (-0.7, 0.6), 'anticipation': (0.4, 0.5)}
title = 'Contentment'
valence = 0.55
arousal = -0.35
seed = 101
trials = 20
choices = 5
claimed_note = 'Design study: a Signature design for presenting contentment as a quiet, low-arousal pleasant state.'

def compute():
    rng = random.Random(seed)
    pts = [(valence + rng.uniform(-0.05, 0.05),
            arousal + rng.uniform(-0.05, 0.05)) for _ in range(trials)]
    mv = sum(p[0] for p in pts) / trials
    ma = sum(p[1] for p in pts) / trials
    mag = math.hypot(mv, ma)
    nearest, dist = None, None
    for name, (bv, ba) in BASICS.items():
        d = math.hypot(mv - bv, ma - ba)
        if dist is None or d < dist:
            nearest, dist = name, d
    quadrant = ("pleasant" if mv >= 0 else "unpleasant") + ", " + ("activated" if ma >= 0 else "calm")
    levels = [round(mag * (k + 1) / choices, 3) for k in range(choices)]
    return {"title": title, "valence": round(mv, 3), "arousal": round(ma, 3),
            "magnitude": round(mag, 3), "nearest": nearest,
            "distance": round(dist, 3), "quadrant": quadrant, "levels": levels}

result_a = compute()
result_b = compute()
digest_a = hashlib.sha256(json.dumps(result_a, sort_keys=True).encode("utf-8")).hexdigest()
digest_b = hashlib.sha256(json.dumps(result_b, sort_keys=True).encode("utf-8")).hexdigest()
print("Record: " + title)
print("Circumplex point: valence %.2f, arousal %.2f" % (valence, arousal))
print("Sampled mean (%d jittered points, fixed seed %d): valence %.3f, arousal %.3f" % (trials, seed, result_a["valence"], result_a["arousal"]))
print("Quadrant: " + result_a["quadrant"])
print("Nearest basic emotion: %s (distance %.3f)" % (result_a["nearest"], result_a["distance"]))
print("Intensity scale (%d levels, mild to intense): %s" % (choices, ", ".join("%.3f" % v for v in result_a["levels"])))
print("Literature note: " + claimed_note)
print("SHA-256 run 1: " + digest_a)
print("SHA-256 run 2: " + digest_b)
if digest_a == digest_b:
    print("Deterministic: MATCH - both runs produced the same mapping.")
else:
    print("Deterministic: MISMATCH - the two runs disagreed.")
print("Note: educational demo only: this computation maps reported circumplex coordinates, it does not measure or assess any person's feelings.")
print("Design study: this record describes a Signature archive design, not an established public record.")

import hashlib
import json
import math
import random

BASICS = {'joy': (0.8, 0.6), 'trust': (0.6, 0.1), 'fear': (-0.6, 0.7), 'surprise': (0.1, 0.8), 'sadness': (-0.7, -0.3), 'disgust': (-0.6, 0.2), 'anger': (-0.7, 0.6), 'anticipation': (0.4, 0.5)}
title = 'Confusion'
valence = -0.1
arousal = 0.35
seed = 110
trials = 20
choices = 5
claimed_note = 'Design study: a Signature design for presenting confusion as the unsettled state of not knowing.'

def compute():
    rng = random.Random(seed)
    pts = [(valence + rng.uniform(-0.05, 0.05),
            arousal + rng.uniform(-0.05, 0.05)) for _ in range(trials)]
    mv = sum(p[0] for p in pts) / trials
    ma = sum(p[1] for p in pts) / trials
    mag = math.hypot(mv, ma)
    nearest, dist = None, None
    for name, (bv, ba) in BASICS.items():
        d = math.hypot(mv - bv, ma - ba)
        if dist is None or d < dist:
            nearest, dist = name, d
    quadrant = ("pleasant" if mv >= 0 else "unpleasant") + ", " + ("activated" if ma >= 0 else "calm")
    levels = [round(mag * (k + 1) / choices, 3) for k in range(choices)]
    return {"title": title, "valence": round(mv, 3), "arousal": round(ma, 3),
            "magnitude": round(mag, 3), "nearest": nearest,
            "distance": round(dist, 3), "quadrant": quadrant, "levels": levels}

result_a = compute()
result_b = compute()
digest_a = hashlib.sha256(json.dumps(result_a, sort_keys=True).encode("utf-8")).hexdigest()
digest_b = hashlib.sha256(json.dumps(result_b, sort_keys=True).encode("utf-8")).hexdigest()
print("Record: " + title)
print("Circumplex point: valence %.2f, arousal %.2f" % (valence, arousal))
print("Sampled mean (%d jittered points, fixed seed %d): valence %.3f, arousal %.3f" % (trials, seed, result_a["valence"], result_a["arousal"]))
print("Quadrant: " + result_a["quadrant"])
print("Nearest basic emotion: %s (distance %.3f)" % (result_a["nearest"], result_a["distance"]))
print("Intensity scale (%d levels, mild to intense): %s" % (choices, ", ".join("%.3f" % v for v in result_a["levels"])))
print("Literature note: " + claimed_note)
print("SHA-256 run 1: " + digest_a)
print("SHA-256 run 2: " + digest_b)
if digest_a == digest_b:
    print("Deterministic: MATCH - both runs produced the same mapping.")
else:
    print("Deterministic: MISMATCH - the two runs disagreed.")
print("Note: educational demo only: this computation maps reported circumplex coordinates, it does not measure or assess any person's feelings.")
print("Design study: this record describes a Signature archive design, not an established public record.")

import hashlib
import json
import math
import random

BASICS = {'joy': (0.8, 0.6), 'trust': (0.6, 0.1), 'fear': (-0.6, 0.7), 'surprise': (0.1, 0.8), 'sadness': (-0.7, -0.3), 'disgust': (-0.6, 0.2), 'anger': (-0.7, 0.6), 'anticipation': (0.4, 0.5)}
title = 'The Human Emotions Field Guide Index'
valence = 0.0
arousal = 0.0
seed = 124
trials = 20
choices = 5
claimed_note = 'Design study: a Signature design for presenting the field guide index as a map of the archive.'

def compute():
    rng = random.Random(seed)
    pts = [(valence + rng.uniform(-0.05, 0.05),
            arousal + rng.uniform(-0.05, 0.05)) for _ in range(trials)]
    mv = sum(p[0] for p in pts) / trials
    ma = sum(p[1] for p in pts) / trials
    mag = math.hypot(mv, ma)
    nearest, dist = None, None
    for name, (bv, ba) in BASICS.items():
        d = math.hypot(mv - bv, ma - ba)
        if dist is None or d < dist:
            nearest, dist = name, d
    quadrant = ("pleasant" if mv >= 0 else "unpleasant") + ", " + ("activated" if ma >= 0 else "calm")
    levels = [round(mag * (k + 1) / choices, 3) for k in range(choices)]
    return {"title": title, "valence": round(mv, 3), "arousal": round(ma, 3),
            "magnitude": round(mag, 3), "nearest": nearest,
            "distance": round(dist, 3), "quadrant": quadrant, "levels": levels}

result_a = compute()
result_b = compute()
digest_a = hashlib.sha256(json.dumps(result_a, sort_keys=True).encode("utf-8")).hexdigest()
digest_b = hashlib.sha256(json.dumps(result_b, sort_keys=True).encode("utf-8")).hexdigest()
print("Record: " + title)
print("Circumplex point: valence %.2f, arousal %.2f" % (valence, arousal))
print("Sampled mean (%d jittered points, fixed seed %d): valence %.3f, arousal %.3f" % (trials, seed, result_a["valence"], result_a["arousal"]))
print("Quadrant: " + result_a["quadrant"])
print("Nearest basic emotion: %s (distance %.3f)" % (result_a["nearest"], result_a["distance"]))
print("Intensity scale (%d levels, mild to intense): %s" % (choices, ", ".join("%.3f" % v for v in result_a["levels"])))
print("Literature note: " + claimed_note)
print("SHA-256 run 1: " + digest_a)
print("SHA-256 run 2: " + digest_b)
if digest_a == digest_b:
    print("Deterministic: MATCH - both runs produced the same mapping.")
else:
    print("Deterministic: MISMATCH - the two runs disagreed.")
