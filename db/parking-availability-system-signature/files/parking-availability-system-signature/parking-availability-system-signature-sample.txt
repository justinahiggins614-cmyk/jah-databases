Parking Availability System Database (parking-availability-system-signature)

A parking availability system is a rule-based local demo: it lists set toy spaces, and counts the marks. The system reads 3 spaces. The space alpha holds 36 marks. The largest holds 36 marks. Everything runs in this browser; no data leaves the page.
