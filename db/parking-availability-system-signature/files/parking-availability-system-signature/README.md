# Parking Availability System Database — files (parking-availability-system-signature)

- `demo-parking-availability-system-signature.py` — runnable demo program (run with `python3 demo-parking-availability-system-signature.py`).
- `parking-availability-system-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/parking-availability-system-signature/index.jsonl.gz` (24 records).
- The generator is `gen-parking-availability-system-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
