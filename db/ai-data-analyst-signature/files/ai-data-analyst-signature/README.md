# AI Data Analyst Database — files (ai-data-analyst-signature)

- `demo-ai-data-analyst-signature.py` — runnable demo program (run with `python3 demo-ai-data-analyst-signature.py`).
- `ai-data-analyst-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-data-analyst-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-data-analyst-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
