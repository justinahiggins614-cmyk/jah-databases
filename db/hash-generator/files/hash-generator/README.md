# Hash Generator Database — files (hash-generator)

- `demo-hash-generator.py` — runnable demo program (run with `python3 demo-hash-generator.py`).
- `hash-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/hash-generator/index.jsonl.gz` (24 records).
- The generator is `gen-hash-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
