# Utility Bill Analyzer Database — files (utility-bill-analyzer)

- `demo-utility-bill-analyzer.py` — runnable demo program (run with `python3 demo-utility-bill-analyzer.py`).
- `utility-bill-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/utility-bill-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-utility-bill-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
