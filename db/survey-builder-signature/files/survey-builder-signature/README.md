# Survey Builder Database — files (survey-builder-signature)

- `demo-survey-builder-signature.py` — runnable demo program (run with `python3 demo-survey-builder-signature.py`).
- `survey-builder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/survey-builder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-survey-builder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
