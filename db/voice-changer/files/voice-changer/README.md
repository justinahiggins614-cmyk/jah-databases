# Voice Changer Database — files (voice-changer)

- `demo-voice-changer.py` — runnable demo program (run with `python3 demo-voice-changer.py`).
- `voice-changer-sample.txt` — a plain-text sample of the database.
- The full database is `data/voice-changer/index.jsonl.gz` (24 records).
- The generator is `gen-voice-changer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
