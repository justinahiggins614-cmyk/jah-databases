# Elevation Calculator Database — files (elevation-calculator-signature)

- `demo-elevation-calculator-signature.py` — runnable demo program (run with `python3 demo-elevation-calculator-signature.py`).
- `elevation-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/elevation-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-elevation-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
