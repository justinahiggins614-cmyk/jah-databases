# Blog Editor Database — files (blog-editor)

- `demo-blog-editor.py` — runnable demo program (run with `python3 demo-blog-editor.py`).
- `blog-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/blog-editor/index.jsonl.gz` (24 records).
- The generator is `gen-blog-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
