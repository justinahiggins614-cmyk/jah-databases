Multi-Agent Coordination System Database (multi-agent-coordination-system-signature)

A multi-agent coordination system is a rule-based local demo: it shares tasks across agents in turn, and counts each agent’s share. 7 tasks across 3 agents give 2 tasks each and 1 left over. 6 tasks across 3 agents give 2 tasks each. Agent A passes 1 task to agent B, leaving 2 and 3. Everything runs in this browser; no data leaves the page.

Worked example: 7 tasks across 3 agents give 2 tasks each and 1 left over

Demo output:
7 tasks across 3 agents give 2 tasks each and 1 left over
