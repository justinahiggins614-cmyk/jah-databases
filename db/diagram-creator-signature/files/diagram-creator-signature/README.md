# Diagram Creator Database — files (diagram-creator-signature)

- `demo-diagram-creator-signature.py` — runnable demo program (run with `python3 demo-diagram-creator-signature.py`).
- `diagram-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/diagram-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-diagram-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
