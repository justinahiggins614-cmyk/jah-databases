# Data Classification Database — files (data-classification-signature)

- `demo-data-classification-signature.py` — runnable demo program (run with `python3 demo-data-classification-signature.py`).
- `data-classification-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-classification-signature/index.jsonl.gz` (24 records).
- The generator is `gen-data-classification-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
