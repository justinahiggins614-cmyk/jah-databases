# Trigonometry Calculator Database — files (trigonometry-calculator)

- `demo-trigonometry-calculator.py` — runnable demo program (run with `python3 demo-trigonometry-calculator.py`).
- `trigonometry-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/trigonometry-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-trigonometry-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
