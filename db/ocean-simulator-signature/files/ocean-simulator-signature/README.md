# Ocean Simulator Database — files (ocean-simulator-signature)

- `demo-ocean-simulator-signature.py` — runnable demo program (run with `python3 demo-ocean-simulator-signature.py`).
- `ocean-simulator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ocean-simulator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ocean-simulator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
