# Network Packet Analyzer Database — files (network-packet-analyzer)

- `demo-network-packet-analyzer.py` — runnable demo program (run with `python3 demo-network-packet-analyzer.py`).
- `network-packet-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/network-packet-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-network-packet-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
