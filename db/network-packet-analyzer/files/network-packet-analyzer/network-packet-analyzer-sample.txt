Network Packet Analyzer Database (network-packet-analyzer)

A network packet analyzer is a rule-based local demo: it reads set toy packets, adds the bytes, and reports the largest packet. The analyzer reads 3 packets: 120, 40 and 80 bytes. The packet goes from web to db with 120 bytes. The packets average 80 bytes. Everything runs in this browser; no data leaves the page.
