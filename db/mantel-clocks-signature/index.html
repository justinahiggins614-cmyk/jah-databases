Specialist AI

JAH Mantel Clock Signature Guide is the archive-aware specialist AI for this database. Duties: answer questions from this database's own records first, explain each record's specifications, mechanism, maintenance, and build guidance in plain sentences, generate new records in this database's schema on request, and route questions outside this database to the relevant related database or to the wider network. It can build an assistant like the user's personal assistant. It answers what it can from its own data and says plainly when a question falls outside it.

Boundless generator

Generator script: gen-mantel-clocks-signature.js — run node gen-mantel-clocks-signature.js --n 5. Seeded and deterministic; throttled; duplicate-checked; hard-stops at 1015 or when the topic space is genuinely exhausted. Generated records carry src: "generated" and are never mixed with assistant-built records.

Validation engine

Checks performed on every record at build time: schema completeness (all required fields present), field consistency (ID prefix, edition, and source label agree), teaching ladder placement (all three tiers present in each database), and demo re-execution (each demo program run and its stdout compared byte-for-byte with the stored demo output). Build-time result for this database: 16 of 16 records passed all checks; 0 failed.

Evidence links

Every record carries its specifications, mechanism, maintenance, and build guidance in its body, plus its reproducible calculation (the demo output). Sources are descriptive references to Signature design notes for the Signature edition; no external live service is claimed.

Tool connections

Client-side tools only, operating on the records loaded on this page. No external service connection is claimed.
