# Code Documentation Generator Database — files (code-documentation-generator-signature)

- `demo-code-documentation-generator-signature.py` — runnable demo program (run with `python3 demo-code-documentation-generator-signature.py`).
- `code-documentation-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/code-documentation-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-code-documentation-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
