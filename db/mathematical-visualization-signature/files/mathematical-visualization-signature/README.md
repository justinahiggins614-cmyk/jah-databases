# Mathematical Visualization Database — files (mathematical-visualization-signature)

- `demo-mathematical-visualization-signature.py` — runnable demo program (run with `python3 demo-mathematical-visualization-signature.py`).
- `mathematical-visualization-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/mathematical-visualization-signature/index.jsonl.gz` (24 records).
- The generator is `gen-mathematical-visualization-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
