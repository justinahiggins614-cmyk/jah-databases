# Chart Creator Database — files (chart-creator)

- `demo-chart-creator.py` — runnable demo program (run with `python3 demo-chart-creator.py`).
- `chart-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/chart-creator/index.jsonl.gz` (24 records).
- The generator is `gen-chart-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
