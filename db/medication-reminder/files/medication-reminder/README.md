# Medication Reminder Database — files (medication-reminder)

- `demo-medication-reminder.py` — runnable demo program (run with `python3 demo-medication-reminder.py`).
- `medication-reminder-sample.txt` — a plain-text sample of the database.
- The full database is `data/medication-reminder/index.jsonl.gz` (24 records).
- The generator is `gen-medication-reminder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
