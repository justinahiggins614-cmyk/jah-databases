Godel's First Incompleteness Theorem

JAH-MLOG-000001 · Godel's first incompleteness theorem

Description: Godel's first incompleteness theorem, proved by Kurt Godel in 1931, says that any consistent formal system strong enough to express elementary arithmetic is incomplete: it contains a true statement about numbers that it cannot prove. A formal system is a precise set of symbols and rules for writing proofs, and consistent means it never proves both a statement and its opposite. The theorem ended the hope that all of mathematics could be captured in one complete, mechanical set of rules.
