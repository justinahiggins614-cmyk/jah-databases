# Population Map Database — files (population-map)

- `demo-population-map.py` — runnable demo program (run with `python3 demo-population-map.py`).
- `population-map-sample.txt` — a plain-text sample of the database.
- The full database is `data/population-map/index.jsonl.gz` (24 records).
- The generator is `gen-population-map.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
