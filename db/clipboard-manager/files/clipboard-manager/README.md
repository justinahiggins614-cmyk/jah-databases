# Clipboard Manager Database — files (clipboard-manager)

- `demo-clipboard-manager.py` — runnable demo program (run with `python3 demo-clipboard-manager.py`).
- `clipboard-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/clipboard-manager/index.jsonl.gz` (24 records).
- The generator is `gen-clipboard-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
