# Dictionary entries — The International Travel Assistance Database

Key terms of this database, defined in plain words.

## travel assistance

Help given to a traveller abroad, recorded as a case with the traveller, the country, and the need, so that the help given can be followed from asking to answer.

## assistance case

One written record of a traveller's request for help abroad, with the need, the place, and the answer, kept as the single true record of the case.

## consulate

The office of one country in another country that helps its own travellers there, named in the case, so that where the help came from is part of the record.

## traveller

A person travelling in another country, named in the assistance case, so that the case can be traced to the person it concerns.

## destination country

The country a traveller is visiting when help is asked for, written in the case, so that where the help was needed can be read plainly.

## emergency contact

A named person to be told when a traveller abroad needs help, written in the case, so that the person to be reached can be found at once.

## travel document

A paper such as a passport that proves a traveller's identity and nationality, named in the case when it is part of the need, so that what was lost or needed can be read.

## assistance request

The written asking for help by a traveller abroad, naming the need and the place, kept with the case, so that the asking and the answer can be read together.

## assistance answer

The written answer given to an assistance request, naming what was done and when, kept with the case, so that the answer can be checked against the asking.

## language help

Help with the language of the country visited, recorded as part of a case, so that what language help was given can be read from the record.

## medical referral

The written naming of a place of care for a traveller abroad, recorded as a fact about the case, so that where the traveller was sent can be read; the record never gives medical advice.

## case number

The one identifier given to an assistance case when it is opened, written on every message that follows, so that the case can be found at any moment.
