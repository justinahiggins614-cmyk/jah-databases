# Random Number Generator Database — files (random-number-generator)

- `demo-random-number-generator.py` — runnable demo program (run with `python3 demo-random-number-generator.py`).
- `random-number-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/random-number-generator/index.jsonl.gz` (24 records).
- The generator is `gen-random-number-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
