A Town Bus Route With Stops in Order Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A transportation tracker website: a visitor picks a generic kind of transit route, such as a town bus route or a cross-town tram route, and the site shows an illustrative sample timetable for that kind, with the stops in order, the times, and the fare. The site names no real town, copies no real timetable, and makes no claim that any sample entry is a real route. This record covers A Town Bus Route With Stops in Order.

A town bus route gives a rider a plain way across town, with the stops in order, the times, and the fare written out before the rider sets out. The tracker must show the stops in the order the bus reaches them, so a rider knows where to get on and where to get off, and the times must be honest, so a rider who leaves at eight arrives when the timetable says. Without the stops in order, a rider cannot tell which stop comes first, and a timetable without an order is a list of names with no journey in it.

Worked example, Signature design: the same transit route is rebuilt from the Signature pattern, so a town bus route with stops in order runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
