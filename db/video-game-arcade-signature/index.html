Neon Paddle Duel Rank 1 · simple · pong · beginner

Neon Paddle Duel is an original arcade game about two glowing paddles dueling under neon light. You guard the left wall while the ball ricochets around a dark court, and every clean return adds to your score. The court is small and fast, so rallies feel tense even when the paddle barely moves.

The rules are simple: move the paddle up, down, or hold it still each tick, and meet the ball when it reaches your wall. A return scores a point for you; a ball that slips past scores for the other side and resets the rally. The first player to build a commanding lead wins the duel, and the demo plays one scripted rally to show the rhythm.

The best tactic is the quiet paddle. Start low, drift toward the middle, and make your final move only when the ball is two steps from the wall. Players who chase every bounce overshoot; players who wait for the last moment meet the ball exactly where it arrives.

    pscore, cscore = 0, 0
    serves = PARAMS["serves"]
    for tick, cmd in enumerate(cmds):
        if cmd == "up":
            paddle = max(0, paddle - 1)
        elif cmd == "down":
            paddle = min(7, paddle + 1)
        ball[0] += bdx
        ball[1] += bdy
        if ball[1] <= 0 or ball[1] >= 9:
            bdy = -bdy
            ball[1] = max(0, min(9, ball[1]))
        if ball[0] >= 11:
            bdx = -1
        if ball[0] <= 0:

                pscore += 1
            else:
                cscore += 1

                ball, bdx, bdy = [6, s], 1, 1 if s % 2 == 0 else -1
        if verbose:
            print("Tick %d: %s paddle %d ball %s you %d cpu %d" % (tick + 1, cmd, paddle, tuple(ball), pscore, cscore))

Lantern Maze Run is an original maze game set in a festival of paper lanterns. You guide a runner through lantern-lit lanes, gathering every lantern glow while a night watchman patrols the far side of the maze. The lanes twist around garden walls, and the watchman always walks toward your light, so every route is a choice between a shortcut and safety.

The rules are straightforward: move up, down, left, or right, and each lantern glow you step on adds ten points. You have three lives, and meeting the watchman costs one and sends you back to the start of the maze. Clearing every glow wins the run; losing all three lives ends it.

Smart runners clear the near lanes first and save the far corner for last, when the watchman's patrol is predictable. Never enter a dead-end lane while the watchman is close, and always leave yourself a second way out. The maze rewards patience more than speed, and the best runs look almost lazy.

AUTO = ['right', 'right', 'down', 'down', 'right', 'right', 'down', 'down', 'right', 'right', 'right']

def parse_map():
    walls, dots, player, ghost = set(), set(), None, None
    for y, row in enumerate(PARAMS["map"]):
        for x, ch in enumerate(row):
            if ch == "#":
                walls.add((x, y))
            elif ch == ".":
                dots.add((x, y))
            elif ch == "P":
                player = (x, y)
            elif ch == "G":
                ghost = (x, y)
    return walls, dots, player, ghost

DIRS = {"up": (0, -1), "down": (0, 1), "left": (-1, 0), "right": (1, 0)}

def step(state, cmd):
    walls, dots, player, ghost, score, lives = state
    dx, dy = DIRS.get(cmd, (0, 0))
    nx, ny = player[0] + dx, player[1] + dy
    if (nx, ny) not in walls:
        player = (nx, ny)
    if player in dots:
        dots = dots - {player}
        score += 10
    if ghost is not None:
        gx, gy = ghost
        best, bestd = ghost, abs(gx - player[0]) + abs(gy - player[1])
        for mx, my in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
            cand = (gx + mx, gy + my)
            if cand in walls:
                continue
            d = abs(cand[0] - player[0]) + abs(cand[1] - player[1])
            if d < bestd:
                best, bestd = cand, d
        ghost = best
    if ghost is not None and player == ghost:
        lives -= 1
        walls, dots, player, ghost = reset_positions()
    return (walls, dots, player, ghost, score, lives)

def reset_positions():
    walls, dots, player, ghost = parse_map()
    return walls, dots, player, ghost

Rows of fragments drift down from the night sky, and your single ground cannon slides along the ridge to blast them before they land. Column discipline wins this game. Finish a column before switching to the next, because a forgotten fragment in an old column is the one that lands while you are busy elsewhere. Move between shots, never during them, and the observatory will still be standing when the sky clears.
