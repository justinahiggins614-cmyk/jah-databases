# Metadata Extractor Database — files (metadata-extractor-signature)

- `demo-metadata-extractor-signature.py` — runnable demo program (run with `python3 demo-metadata-extractor-signature.py`).
- `metadata-extractor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/metadata-extractor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-metadata-extractor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
