# Phishing Awareness Tester Database — files (phishing-awareness-tester)

- `demo-phishing-awareness-tester.py` — runnable demo program (run with `python3 demo-phishing-awareness-tester.py`).
- `phishing-awareness-tester-sample.txt` — a plain-text sample of the database.
- The full database is `data/phishing-awareness-tester/index.jsonl.gz` (24 records).
- The generator is `gen-phishing-awareness-tester.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
