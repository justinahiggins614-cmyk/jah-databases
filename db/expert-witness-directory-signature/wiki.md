# The Expert Witness Directory Database

The Expert Witness Directory Database is the expert witness directory record database in the Signature network. It holds 24 full expert witness directory record records in the public edition and 24 in the Signature edition, in a teaching ladder of 8 simple, 8 compounded and 8 most complex records.

It expands the live database e2-religion-jehovahs-witnesses, which it links to and never rebuilds. The database carries the specification, models, test suites and verification records; it is not a running service.
