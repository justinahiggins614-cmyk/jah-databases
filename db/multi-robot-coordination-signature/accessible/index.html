Terms in plain words

Database
A named collection of records about one subject.
Record
One entry in a database: a single file with all of its data.
Slug
The short web-address name of a database, in lower-case letters with hyphens.
Manifest
The master list of every database in the network, kept in data/manifest.json.
Record kind
The type name of a record: the database slug with spaces instead of hyphens.
Identifier prefix
The short code at the start of every record identifier in a database.
Generator
A program that creates new records on demand from a seed number; the same seed always gives the same record.
Seed
The starting number given to a generator.
Generator gate
A check a generator must pass before its output counts.
JCC code (JAH Condensed Code)
A short key that points to one full record: JAHDB/<slug>#<id>. A pointer, never a replacement for the full data.
API (Application Programming Interface)
Rules that let one program ask another program for data or work, over the web.
MCP (Model Context Protocol)
An open standard that lets an AI program connect to outside tools and data through one shared set of rules.
AI
Artificial intelligence: a program that answers questions, explains things, and does work from data.
JSON (JavaScript Object Notation)
A plain-text way of writing structured data as named fields and lists.
HTML (HyperText Markup Language)
The language that marks up a web page.
Demo
A small working program that runs the checkable part of a record twice and prints both SHA-256 digests.
