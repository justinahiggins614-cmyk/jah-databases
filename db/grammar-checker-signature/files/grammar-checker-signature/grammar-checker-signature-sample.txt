Grammar Checker Database (grammar-checker-signature)

A grammar checker runs a small, named set of rules over entered text: type a sentence, press Check, and read the issues. The sentence "The cat sat." has 0 issues. The sentence "the cat sat." has 1 issue: it starts with a lowercase letter. The sentence "the  cat sat" has 3 issues: capital, double space, missing period. The rule set is bounded and named honestly: it never pretends to understand all grammar. Everything runs in this browser; no data leaves the page.
