# SSL Certificate Generator Database — files (ssl-certificate-generator)

- `demo-ssl-certificate-generator.py` — runnable demo program (run with `python3 demo-ssl-certificate-generator.py`).
- `ssl-certificate-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/ssl-certificate-generator/index.jsonl.gz` (24 records).
- The generator is `gen-ssl-certificate-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
