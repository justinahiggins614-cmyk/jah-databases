# Exterior Design Generator Database — files (exterior-design-generator-signature)

- `demo-exterior-design-generator-signature.py` — runnable demo program (run with `python3 demo-exterior-design-generator-signature.py`).
- `exterior-design-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/exterior-design-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-exterior-design-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
