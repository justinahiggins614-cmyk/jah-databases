# Compiler Generator Database — files (compiler-generator-signature)

- `demo-compiler-generator-signature.py` — runnable demo program (run with `python3 demo-compiler-generator-signature.py`).
- `compiler-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/compiler-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-compiler-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
