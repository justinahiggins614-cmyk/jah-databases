Compiler Generator Database (compiler-generator-signature)

A compiler generator is a rule-based local demo: it builds a toy compiler from set rules, and compiles set toy expressions. The generator builds a compiler from 3 rules. The rule is add: it adds two numbers. The expressions compile to 25 in total. Everything runs in this browser; no data leaves the page.
