## Spec
- **Mechanism:** Once a wire settles, it is effectively irreversible, unlike ACH, which can be returned within set windows. That finality makes wires a favorite target for fraud, so verification callbacks are standard practice. This overview edition presents Wire Transfer Finality as a core payments concept in modern banking.
