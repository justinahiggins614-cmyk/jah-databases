Data Catalog Manager Database (data-catalog-manager)

A data catalog manager is a rule-based local demo: it reads set toy catalogs, and counts the marks. The manager reads 3 catalogs. The catalog alpha holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
