# Data Catalog Manager Database — files (data-catalog-manager)

- `demo-data-catalog-manager.py` — runnable demo program (run with `python3 demo-data-catalog-manager.py`).
- `data-catalog-manager-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-catalog-manager/index.jsonl.gz` (24 records).
- The generator is `gen-data-catalog-manager.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
