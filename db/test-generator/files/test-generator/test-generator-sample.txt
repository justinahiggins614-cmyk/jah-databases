Test Generator Database (test-generator)

A test generator is a rule-based local demo: it makes test cases from set rules, and counts the cases it makes. The generator makes 5 cases from 5 inputs. Input 3 expects 6. 3 rules at 4 cases each make 12 cases. Everything runs in this browser; no data leaves the page.
