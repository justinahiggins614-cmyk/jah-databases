# Test Generator Database — files (test-generator)

- `demo-test-generator.py` — runnable demo program (run with `python3 demo-test-generator.py`).
- `test-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/test-generator/index.jsonl.gz` (24 records).
- The generator is `gen-test-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
