# Database Optimizer Database — files (database-optimizer-signature)

- `demo-database-optimizer-signature.py` — runnable demo program (run with `python3 demo-database-optimizer-signature.py`).
- `database-optimizer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-optimizer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-database-optimizer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
