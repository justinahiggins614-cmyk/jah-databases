# Car Payment Calculator Database — files (car-payment-calculator-signature)

- `demo-car-payment-calculator-signature.py` — runnable demo program (run with `python3 demo-car-payment-calculator-signature.py`).
- `car-payment-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/car-payment-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-car-payment-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
