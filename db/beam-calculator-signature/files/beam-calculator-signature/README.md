# Beam Calculator Database — files (beam-calculator-signature)

- `demo-beam-calculator-signature.py` — runnable demo program (run with `python3 demo-beam-calculator-signature.py`).
- `beam-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/beam-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-beam-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
