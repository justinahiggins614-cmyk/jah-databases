# Derivative Calculator Database — files (derivative-calculator)

- `demo-derivative-calculator.py` — runnable demo program (run with `python3 demo-derivative-calculator.py`).
- `derivative-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/derivative-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-derivative-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
