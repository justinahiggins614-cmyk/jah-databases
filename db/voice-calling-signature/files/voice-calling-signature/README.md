# Voice Calling Database — files (voice-calling-signature)

- `demo-voice-calling-signature.py` — runnable demo program (run with `python3 demo-voice-calling-signature.py`).
- `voice-calling-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/voice-calling-signature/index.jsonl.gz` (24 records).
- The generator is `gen-voice-calling-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
