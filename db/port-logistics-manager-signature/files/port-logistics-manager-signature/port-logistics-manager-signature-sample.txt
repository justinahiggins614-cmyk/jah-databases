Port Logistics Manager Database (port-logistics-manager-signature)

A port logistics manager is a rule-based local demo: it manages set toy shipments, and counts the marks. The manager reads 3 shipments. The shipment alpha holds 72 marks. The largest holds 72 marks. Everything runs in this browser; no data leaves the page.
