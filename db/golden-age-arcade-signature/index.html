Star Voyager Rank 1 · simple · vector · beginner

Star Voyager is an original vector-flight game about a lone survey ship mapping a quiet corner of space. The ship drifts among slow, bright rocks, and its beam can break them apart for points. The field is calm, the stars are still, and the whole game feels like a careful walk through a dark gallery.

The rules are simple: turn left or right, thrust to glide two steps in the direction you face, and shoot to break rocks up to three steps ahead. You have three lives, and touching a rock costs one. The demo plays a short flight with two clean hits and a few honest misses.

Voyager pilots fly in straight lines and shoot from range. Line up on a rock row, fire until it breaks, and thrust clear before the next rock drifts near. The survey rewards a steady hand far more than a fast one.

Paddle Clash Rank 2 · simple · pong · beginner

Paddle Clash is an original paddle game about two rivals meeting under festival lights for a single rally. You guard the left wall with a short paddle while the ball bounces around the court, and every return you make scores a point. The rally is fast, the court is small, and the crowd counts every return out loud.

The rules are direct: move the paddle up, down, or hold it still each tick, and meet the ball when it reaches your wall. A return scores for you; a ball that slips past scores for the other side and resets the rally. The demo plays one scripted rally that ends with the player one point ahead.

Clash players hold the middle and move late. The paddle starts in the center of its travel, and the winning move is a small step made at the last moment, not a long chase across the court. Players who waited won rallies; players who flailed lost them.

def pong_session(cmds, verbose):
    paddle, ball, bdx, bdy = 4, [6, 5], 1, 1
    pscore, cscore = 0, 0
    serves = PARAMS["serves"]
    for tick, cmd in enumerate(cmds):
        if cmd == "up":
            paddle = max(0, paddle - 1)
        elif cmd == "down":
            paddle = min(7, paddle + 1)
        ball[0] += bdx
        ball[1] += bdy
        if ball[1] <= 0 or ball[1] >= 9:
            bdy = -bdy
            ball[1] = max(0, min(9, ball[1]))
        if ball[0] >= 11:
            bdx = -1
        if ball[0] <= 0:
            if paddle <= ball[1] <= paddle + 2:
                bdx = 1
                pscore += 1
            else:
                cscore += 1
                s = serves[(pscore + cscore) % len(serves)]
                ball, bdx, bdy = [6, s], 1, 1 if s % 2 == 0 else -1
        if verbose:
            print("Tick %d: %s paddle %d ball %s you %d cpu %d" % (tick + 1, cmd, paddle, tuple(ball), pscore, cscore))
    return pscore, cscore

def auto_play():
    print("Pong tribute: auto session")
    pscore, cscore = pong_session(AUTO, True)
    print("FINAL SCORE: %d" % pscore)
    print("RESULT: YOU %d CPU %d" % (pscore, cscore))

def play():
    print("Pong tribute: type up/down/stay each tick, or quit. Guard the left wall.")
    cmds = []
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        if cmd not in ("up", "down", "stay"):
            print("Unknown command: %s" % cmd)
            continue
        cmds.append(cmd)
        pscore, cscore = pong_session(cmds, False)
        print("you %d cpu %d" % (pscore, cscore))
    pscore, cscore = pong_session(cmds, False)
    print("FINAL SCORE: %d" % pscore)
    print("RESULT: YOU %d CPU %d" % (pscore, cscore))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()

Moon Invaders Rank 4 · simple · fixed-shooter · beginner

Moon Invaders is an original fixed shooter about defending a moon base from descending sky fragments. Five columns of fragments in two rows drift down toward the base, and your ground cannon slides along the ridge to blast them. The sky clears column by column, and the base holds as long as the cannon keeps firing.

The rules are clean: move left or right, fire upward, and clear every fragment before it reaches the ground line. Column discipline is everything. A half-cleared column is a distraction, while a fully cleared column never threatens you again. Work from the edges inward, move between shots, and the moon base will still be standing when the sky empties.
