# SQL Editor Database — files (sql-editor)

- `demo-sql-editor.py` — runnable demo program (run with `python3 demo-sql-editor.py`).
- `sql-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/sql-editor/index.jsonl.gz` (24 records).
- The generator is `gen-sql-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
