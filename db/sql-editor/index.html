1. Description

A SQL editor writes queries and shows the table they return: type a query, press Run, and read the rows. The demo on this page runs queries in the browser over a seeded table of books, with no server and no connection. A broken query is shown, not hidden.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Counting the rows gives 3 rows. A query for books after 2019 finds 2 rows of 3. Sorting by year gives 2018, 2020 and 2022. Adding the years 2018, 2020 and 2022 gives 6060. The average year of 2018, 2020 and 2022 is 2020.

3. Science proof

A SQL editor works because a table is rows of facts under named columns, and a query picks the rows that match: a query for books after 2019 finds 2 rows of 3, and sorting by year gives 2018, 2020 and 2022. A broken query has a wrong word, and the editor shows it. That is why the local demo shows the query and the table together, and runs 0 queries on a server.
