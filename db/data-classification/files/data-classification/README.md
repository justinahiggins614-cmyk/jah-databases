# Data Classification Database — files (data-classification)

- `demo-data-classification.py` — runnable demo program (run with `python3 demo-data-classification.py`).
- `data-classification-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-classification/index.jsonl.gz` (24 records).
- The generator is `gen-data-classification.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
