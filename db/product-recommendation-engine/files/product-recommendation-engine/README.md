# Product Recommendation Engine Database — files (product-recommendation-engine)

- `demo-product-recommendation-engine.py` — runnable demo program (run with `python3 demo-product-recommendation-engine.py`).
- `product-recommendation-engine-sample.txt` — a plain-text sample of the database.
- The full database is `data/product-recommendation-engine/index.jsonl.gz` (24 records).
- The generator is `gen-product-recommendation-engine.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
