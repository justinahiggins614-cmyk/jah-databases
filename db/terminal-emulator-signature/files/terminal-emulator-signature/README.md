# Terminal Emulator Database — files (terminal-emulator-signature)

- `demo-terminal-emulator-signature.py` — runnable demo program (run with `python3 demo-terminal-emulator-signature.py`).
- `terminal-emulator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/terminal-emulator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-terminal-emulator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
