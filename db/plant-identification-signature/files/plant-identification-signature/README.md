# Plant Identification Database — files (plant-identification-signature)

- `demo-plant-identification-signature.py` — runnable demo program (run with `python3 demo-plant-identification-signature.py`).
- `plant-identification-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/plant-identification-signature/index.jsonl.gz` (24 records).
- The generator is `gen-plant-identification-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
