# Vehicle History Lookup Database — files (vehicle-history-lookup)

- `demo-vehicle-history-lookup.py` — runnable demo program (run with `python3 demo-vehicle-history-lookup.py`).
- `vehicle-history-lookup-sample.txt` — a plain-text sample of the database.
- The full database is `data/vehicle-history-lookup/index.jsonl.gz` (24 records).
- The generator is `gen-vehicle-history-lookup.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
