# Budget Planner Database — files (budget-planner)

- `demo-budget-planner.py` — runnable demo program (run with `python3 demo-budget-planner.py`).
- `budget-planner-sample.txt` — a plain-text sample of the database.
- The full database is `data/budget-planner/index.jsonl.gz` (24 records).
- The generator is `gen-budget-planner.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
