Fracture Classification

Fractures are described by location, pattern, and displacement — transverse, oblique, comminuted, open versus closed. Classification drives treatment: stable fractures get casts, unstable ones get surgery. Precise language prevents wrong care.

def fracture_clinic_slot(injury, days_since, weight_bearing):
    """Simple orthopedic triage: urgent OR vs clinic vs routine."""
    urgent = {"open fracture", "dislocation", "compartment syndrome", "cauda equina"}
    if injury.lower() in urgent: return "URGENT: to OR now"
    if not weight_bearing or days_since < 2: return "Same-day fracture clinic"
    return "Routine orthopedic clinic within 1 week"

Casting and Splinting
