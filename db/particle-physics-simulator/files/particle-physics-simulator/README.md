# Particle Physics Simulator Database — files (particle-physics-simulator)

- `demo-particle-physics-simulator.py` — runnable demo program (run with `python3 demo-particle-physics-simulator.py`).
- `particle-physics-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/particle-physics-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-particle-physics-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
