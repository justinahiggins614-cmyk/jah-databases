The Signature The Global Sock Exchange Database

Accessible version: plain text, no scripts, no sign-in, free forever. The global sock exchange swaps spare pairs of socks around the world: a pair of striped socks for a cold morning, a pair of spotty socks for a rainy day, each swap written out so a reader can see how one pair finds a new home. Every swap is a clearly labeled design study, never a claim about a live exchange.

Twenty-four full records, ordered simple to compounded to complex.
