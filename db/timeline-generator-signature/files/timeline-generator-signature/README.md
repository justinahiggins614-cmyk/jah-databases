# Timeline Generator Database — files (timeline-generator-signature)

- `demo-timeline-generator-signature.py` — runnable demo program (run with `python3 demo-timeline-generator-signature.py`).
- `timeline-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/timeline-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-timeline-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
