# Polynomial Solver Database — files (polynomial-solver)

- `demo-polynomial-solver.py` — runnable demo program (run with `python3 demo-polynomial-solver.py`).
- `polynomial-solver-sample.txt` — a plain-text sample of the database.
- The full database is `data/polynomial-solver/index.jsonl.gz` (24 records).
- The generator is `gen-polynomial-solver.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
