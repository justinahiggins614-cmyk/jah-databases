# Thermodynamics Calculator Database — files (thermodynamics-calculator)

- `demo-thermodynamics-calculator.py` — runnable demo program (run with `python3 demo-thermodynamics-calculator.py`).
- `thermodynamics-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/thermodynamics-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-thermodynamics-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
