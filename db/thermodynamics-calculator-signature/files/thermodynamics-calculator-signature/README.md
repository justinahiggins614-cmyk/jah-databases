# Thermodynamics Calculator Database — files (thermodynamics-calculator-signature)

- `demo-thermodynamics-calculator-signature.py` — runnable demo program (run with `python3 demo-thermodynamics-calculator-signature.py`).
- `thermodynamics-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/thermodynamics-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-thermodynamics-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
