# Video Converter Database — files (video-converter)

- `demo-video-converter.py` — runnable demo program (run with `python3 demo-video-converter.py`).
- `video-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-converter/index.jsonl.gz` (24 records).
- The generator is `gen-video-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
