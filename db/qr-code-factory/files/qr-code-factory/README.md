# The QR Code Factory Database — files (qr-code-factory)

- `demo-qr-code-factory.py` — runnable demo program (run with `python3 demo-qr-code-factory.py`).
- `qr-code-factory-sample.txt` — a plain-text sample of the database.
- The full database is `data/qr-code-factory/index.jsonl.gz` (24 records).
- The generator is `gen-qr-code-factory.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
