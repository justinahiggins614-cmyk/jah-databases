The QR Code Factory Database (qr-code-factory)

A QR code factory turns any text into a square pattern of dark and light modules that a camera can read: it picks the encoding mode, the version, and the error correction level, lays out the finder patterns, masks the data, and prints a code that scans.

Worked example: A QR Code is a square pattern of dark and light modules that stores text a camera can read in a fraction of a second. A version 1 code is 21 modules across, and the largest version, version 40, is 177 modules across.
