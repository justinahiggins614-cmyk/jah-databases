# Video Converter Database — files (video-converter-signature)

- `demo-video-converter-signature.py` — runnable demo program (run with `python3 demo-video-converter-signature.py`).
- `video-converter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-converter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-video-converter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
