# Automated Insight Generator Database — files (automated-insight-generator-signature)

- `automated-insight-generator-signature-sample.txt` — a plain-text sample of the database.

- The generator is `gen-automated-insight-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
