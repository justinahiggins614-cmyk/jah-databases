# Molecular Viewer Database — files (molecular-viewer-signature)

- `demo-molecular-viewer-signature.py` — runnable demo program (run with `python3 demo-molecular-viewer-signature.py`).
- `molecular-viewer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/molecular-viewer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-molecular-viewer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
