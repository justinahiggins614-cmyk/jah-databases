# Tokenizer Tester Database — files (tokenizer-tester)

- `demo-tokenizer-tester.py` — runnable demo program (run with `python3 demo-tokenizer-tester.py`).
- `tokenizer-tester-sample.txt` — a plain-text sample of the database.
- The full database is `data/tokenizer-tester/index.jsonl.gz` (24 records).
- The generator is `gen-tokenizer-tester.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
