1. Description

A to-do list is the simplest tool there is: one line per thing to do, checked off when it is done. No dates are required, no priorities are required, only the list itself.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

A list is a set of items, and done items are a subset. With 6 of 8 items checked, the done fraction is 6 over 8, which is 0.75, or 75 percent. Clearing done items is set subtraction: the open list is all items minus done items.

3. Science proof

A to-do list works because the brain treats an unfinished item as open work, and open work keeps nagging. Writing the item down closes the loop in the mind while keeping the work visible on the page. Checking it off gives a small sense of completion, which is why short lists get finished and long lists get split.
