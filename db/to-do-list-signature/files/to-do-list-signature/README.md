# To-do List Database — files (to-do-list-signature)

- `demo-to-do-list-signature.py` — runnable demo program (run with `python3 demo-to-do-list-signature.py`).
- `to-do-list-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/to-do-list-signature/index.jsonl.gz` (24 records).
- The generator is `gen-to-do-list-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
