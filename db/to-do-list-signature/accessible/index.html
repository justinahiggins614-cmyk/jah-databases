The To-do List Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. A to-do list is the simplest tool there is: one line per thing to do, checked off when it is done. No dates are required, no priorities are required, only the list itself.

Twenty-four full records, ordered simple to working to advanced.

    Record 1 of 24. simple. Feasibility: buildable-now. A to-do item is a single short line: one thing to do, nothing more. The list holds 'Buy milk' as its first item.

    Math proof: A list is a set of items, and done items are a subset. With 6 of 8 items checked, the done fraction is 6 over 8, which is 0.75, or 75 percent. Clearing done items is set subtraction: the open list is all items minus done items.

    Science proof: A to-do list works because the brain treats an unfinished item as open work, and open work keeps nagging. Writing the item down closes the loop in the mind while keeping the work visible on the page. Checking it off gives a small sense of completion, which is why short lists get finished and long lists get split.
