# Trend Analysis Database — files (trend-analysis-signature)

- `demo-trend-analysis-signature.py` — runnable demo program (run with `python3 demo-trend-analysis-signature.py`).
- `trend-analysis-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/trend-analysis-signature/index.jsonl.gz` (24 records).
- The generator is `gen-trend-analysis-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
