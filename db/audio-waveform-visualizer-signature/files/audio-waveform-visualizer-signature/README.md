# Audio Waveform Visualizer Database — files (audio-waveform-visualizer-signature)

- `demo-audio-waveform-visualizer-signature.py` — runnable demo program (run with `python3 demo-audio-waveform-visualizer-signature.py`).
- `audio-waveform-visualizer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-waveform-visualizer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-audio-waveform-visualizer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
