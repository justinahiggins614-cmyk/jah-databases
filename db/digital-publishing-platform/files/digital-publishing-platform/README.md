# Digital Publishing Platform Database — files (digital-publishing-platform)

- `demo-digital-publishing-platform.py` — runnable demo program (run with `python3 demo-digital-publishing-platform.py`).
- `digital-publishing-platform-sample.txt` — a plain-text sample of the database.
- The full database is `data/digital-publishing-platform/index.jsonl.gz` (24 records).
- The generator is `gen-digital-publishing-platform.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
