# Numerical Simulation Database — files (numerical-simulation)

- `demo-numerical-simulation.py` — runnable demo program (run with `python3 demo-numerical-simulation.py`).
- `numerical-simulation-sample.txt` — a plain-text sample of the database.
- The full database is `data/numerical-simulation/index.jsonl.gz` (24 records).
- The generator is `gen-numerical-simulation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
