# Data Synchronization Database — files (data-synchronization)

- `demo-data-synchronization.py` — runnable demo program (run with `python3 demo-data-synchronization.py`).
- `data-synchronization-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-synchronization/index.jsonl.gz` (24 records).
- The generator is `gen-data-synchronization.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
