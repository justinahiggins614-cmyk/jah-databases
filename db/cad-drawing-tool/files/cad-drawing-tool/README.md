# CAD Drawing Tool Database — files (cad-drawing-tool)

- `demo-cad-drawing-tool.py` — runnable demo program (run with `python3 demo-cad-drawing-tool.py`).
- `cad-drawing-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/cad-drawing-tool/index.jsonl.gz` (24 records).
- The generator is `gen-cad-drawing-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
