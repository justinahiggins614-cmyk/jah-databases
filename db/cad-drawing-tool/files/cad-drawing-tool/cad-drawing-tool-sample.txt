CAD Drawing Tool Database (cad-drawing-tool)

A CAD drawing tool is a rule-based local demo: it draws set toy shapes on a grid, and counts the lines and the corners. The tool draws 3 shapes. The line is 12 units long. The drawings hold 192 square units in total. Everything runs in this browser; no data leaves the page.
