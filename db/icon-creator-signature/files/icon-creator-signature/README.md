# Icon Creator Database — files (icon-creator-signature)

- `demo-icon-creator-signature.py` — runnable demo program (run with `python3 demo-icon-creator-signature.py`).
- `icon-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/icon-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-icon-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
