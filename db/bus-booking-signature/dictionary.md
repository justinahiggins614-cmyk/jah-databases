# Dictionary entries — The Bus Booking Database

Key terms of this database, defined in plain words.

## bus booking

The written record of a seat or seats reserved on a named bus service for a named journey, with the date, the stops, and the fare, so that the booking can be found and checked.

## bus route

The named path a bus service follows, with its stops in order, kept with the booking, so that the journey the booking covers can be read plainly.

## bus stop

A named place where a bus service picks up and sets down passengers, written in the booking with its name, so that the start and the end of the journey are known.

## timetable

The published list of the times a bus service leaves each stop, kept beside the booking, so that the booked departure can be checked against the service as published.

## fare

The price charged for a bus journey, written in the booking with its amount and what it covers, so that what was charged for the journey can be counted and checked.

## seat reservation

The holding of one or more named seats on a bus for a named journey, recorded with the seat numbers, so that the seats held and the seats free can be counted.

## ticket

The written or printed proof of a bus booking, naming the journey, the date, and the fare, kept with the booking, so that the booking can be shown when asked.

## coach

A bus built for longer journeys between towns, with seats for every passenger, named in the booking when the service uses one, so that the kind of vehicle is part of the record.

## bus station

The building or yard where bus services start and end, named in the booking, so that the place of departure and arrival is part of the record.

## departure time

The stated time a bus service leaves its starting stop, written in the booking, so that the booked journey can be checked against the timetable.

## arrival time

The stated time a bus service reaches its ending stop, written in the booking, so that the length of the booked journey can be read from the record.

## booking reference

The one identifier given to a bus booking when it is made, written on the ticket and in the record, so that the booking can be found at any moment.
