# Prescriptive Analytics Database — files (prescriptive-analytics)

- `demo-prescriptive-analytics.py` — runnable demo program (run with `python3 demo-prescriptive-analytics.py`).
- `prescriptive-analytics-sample.txt` — a plain-text sample of the database.
- The full database is `data/prescriptive-analytics/index.jsonl.gz` (24 records).
- The generator is `gen-prescriptive-analytics.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
