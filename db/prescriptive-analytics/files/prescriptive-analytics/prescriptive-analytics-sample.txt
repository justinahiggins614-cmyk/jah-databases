Prescriptive Analytics Database (prescriptive-analytics)

A prescriptive analytics is a rule-based local demo: it reads set toy plans, and counts the marks. The analytics reads 3 plans. The plan alpha holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
