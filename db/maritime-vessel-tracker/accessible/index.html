Accessible version: plain text, no scripts, no sign-in, free forever. A maritime vessel tracker is a rule-based local demo: it tracks set toy vessels, and counts the marks. The tracker reads 3 vessels. The vessel alpha holds 66 marks. The largest holds 66 marks. Everything runs in this browser; no data leaves the page.
