# Animation Creator Database — files (animation-creator)

- `demo-animation-creator.py` — runnable demo program (run with `python3 demo-animation-creator.py`).
- `animation-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/animation-creator/index.jsonl.gz` (24 records).
- The generator is `gen-animation-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
