A Recommendation With a Written Reason Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A recommendation website: members write short recommendations in plain words, each naming the thing, the reason it is worth trying, and the member who recommends it. The community votes the good ones up, the lists are public, and no recommendation is ever paid for or hidden. There are no private messages anywhere on the site. This record covers A Recommendation With a Written Reason.

A recommendation with a written reason is a recommendation a reader can judge, because a bare name tells the reader nothing, and a reason tells them whether the thing is for them. The recommendation should name the thing, the reason it is worth trying, and the member who recommends it, all in plain words. Without a written reason, the list is only a set of names, and a set of names helps nobody choose. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Worked example: in a website built this way, a recommendation with a written reason runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
