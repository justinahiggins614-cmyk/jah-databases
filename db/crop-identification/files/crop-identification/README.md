# Crop Identification Database — files (crop-identification)

- `demo-crop-identification.py` — runnable demo program (run with `python3 demo-crop-identification.py`).
- `crop-identification-sample.txt` — a plain-text sample of the database.
- The full database is `data/crop-identification/index.jsonl.gz` (24 records).
- The generator is `gen-crop-identification.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
