# Domain Valuation Calculator Database — files (domain-valuation-calculator)

- `demo-domain-valuation-calculator.py` — runnable demo program (run with `python3 demo-domain-valuation-calculator.py`).
- `domain-valuation-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/domain-valuation-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-domain-valuation-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
