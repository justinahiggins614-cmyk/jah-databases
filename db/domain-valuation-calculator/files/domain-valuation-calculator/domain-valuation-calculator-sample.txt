Domain Valuation Calculator Database (domain-valuation-calculator)

A domain valuation calculator is a rule-based local demo: it reads set toy values, and counts the coins. The calculator reads 3 values. The value plain holds 60 coins. The largest holds 60 coins. Everything runs in this browser; no data leaves the page.
