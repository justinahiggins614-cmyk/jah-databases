# Typography Designer Database — files (typography-designer)

- `demo-typography-designer.py` — runnable demo program (run with `python3 demo-typography-designer.py`).
- `typography-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/typography-designer/index.jsonl.gz` (24 records).
- The generator is `gen-typography-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
