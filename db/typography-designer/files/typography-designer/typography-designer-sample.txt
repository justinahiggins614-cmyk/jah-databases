Typography Designer Database (typography-designer)

A typography designer is a rule-based local demo: it builds a type scale from one base size and one ratio, and counts the steps. The scale starts at 16 points with a ratio of 1.25. The base size is 16 points. One step down from 16 is 12.8 points. Everything runs in this browser; no data leaves the page.
