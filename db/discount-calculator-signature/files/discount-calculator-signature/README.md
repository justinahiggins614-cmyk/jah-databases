# Discount Calculator Database — files (discount-calculator-signature)

- `demo-discount-calculator-signature.py` — runnable demo program (run with `python3 demo-discount-calculator-signature.py`).
- `discount-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/discount-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-discount-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
