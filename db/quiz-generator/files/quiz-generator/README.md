# Quiz Generator Database — files (quiz-generator)

- `demo-quiz-generator.py` — runnable demo program (run with `python3 demo-quiz-generator.py`).
- `quiz-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/quiz-generator/index.jsonl.gz` (24 records).
- The generator is `gen-quiz-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
