# Web Crawler Configuration Database — files (web-crawler-configuration)

- `demo-web-crawler-configuration.py` — runnable demo program (run with `python3 demo-web-crawler-configuration.py`).
- `web-crawler-configuration-sample.txt` — a plain-text sample of the database.
- The full database is `data/web-crawler-configuration/index.jsonl.gz` (24 records).
- The generator is `gen-web-crawler-configuration.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
