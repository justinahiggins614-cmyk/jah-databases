Web Crawler Configuration Database (web-crawler-configuration)

A web crawler configuration is a rule-based local demo: it configures set toy rules, and counts the marks. The configurator reads 3 rules. The rule alpha holds 21 marks. The largest holds 21 marks. Everything runs in this browser; no data leaves the page.
