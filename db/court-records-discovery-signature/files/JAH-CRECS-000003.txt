History
Courts have kept written records since the first clerk sat with a quill and a docket book, because a judgment that cannot be found again cannot be trusted. Discovery grew beside the courts: the formal search of filings, orders, and transcripts so that each side could read the same papers. From the hand-copied order in a courthouse file to the record kept in a database, the honest practice has been the same — write the case down whole. This database is built on that public practice of recording every court records discovery true. It is a record of published court papers only, and it gives no advice about any case.
