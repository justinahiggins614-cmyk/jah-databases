# Employee Onboarding Database — files (employee-onboarding)

- `demo-employee-onboarding.py` — runnable demo program (run with `python3 demo-employee-onboarding.py`).
- `employee-onboarding-sample.txt` — a plain-text sample of the database.
- The full database is `data/employee-onboarding/index.jsonl.gz` (24 records).
- The generator is `gen-employee-onboarding.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
