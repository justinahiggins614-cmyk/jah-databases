A website matched to a creator by plain-word questions asks a few simple questions about what the creator makes, then points to the blocks that fit, with the matching done by plain rules a maker can check. The compounded builder joins two ideas at once: two pages on one screen, a daily website everyone in a class builds together, and a streak that rewards a maker for coming back.
