# Accounting System Database — files (accounting-system)

- `demo-accounting-system.py` — runnable demo program (run with `python3 demo-accounting-system.py`).
- `accounting-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/accounting-system/index.jsonl.gz` (24 records).
- The generator is `gen-accounting-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
