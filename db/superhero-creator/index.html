The Garden Guardian Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A superhero creator website: a visitor picks the parts of a hero, such as a power, a home town, and a code to live by, and the site joins them into one invented hero, with a plain description of the powers, the home town, and the code. Every hero is an invented creation written for this database, and no part of it names a real person or a real character. This record covers The Garden Guardian.

The Garden Guardian has the power to make plants grow where she walks, living in a small town with one shared garden and never harming a living thing. The creator must show the powers, the home town, and the code in plain words, so a storyteller can see the whole hero at once and change any part.
