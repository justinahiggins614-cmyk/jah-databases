# Body Measurement Tracker Database — files (body-measurement-tracker)

- `demo-body-measurement-tracker.py` — runnable demo program (run with `python3 demo-body-measurement-tracker.py`).
- `body-measurement-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/body-measurement-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-body-measurement-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
