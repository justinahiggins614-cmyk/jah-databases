Source retrieval JAH-URL-000001 · simple

Evidence: established Public record: facts verified against the cited public sources; demo recomputes the record's coverage score from its key figures.

Source retrieval fetches the actual source behind a record — the book, paper, or dataset — so a claim can be checked against its origin, not against a second-hand summary.

History

Specified as a required capability in the master-list catalog (§45 item 616). The 2026-11-12 evening order — databases for each system, public and Signature, so better versions can be made — ordered it built as a full database pair with a working demo and a boundless generator.

Description

Source retrieval fetches the actual source behind a record — the book, paper, or dataset — so a claim can be checked against its origin, not against a second-hand summary.

The Problem

How does the Universal Research Laboratory perform source retrieval completely, verifiably, and at network scale — over all 63,047 databases and 12,349,330 records — with every claim checkable against the manifest or a plain-text mirror?

The Worked Solution

Follow the record's source field to the cited work, fetch it where it is public, and quote the exact passage that supports the claim. A source that cannot be fetched is reported as unfetched, never paraphrased from memory.

The Answer

Source retrieval by source does NOT exist (backlog Area 4 #7, BUILD); source is a text field only, with no source-filtered retrieval.

When It Applies

Whenever the system must perform this capability on network data — in discovery, retrieval, generation, verification, or audit — under the standing full-record rules.

Limits

Coverage is bounded by what the live manifest and the plain-text mirrors actually hold; anything outside a verified mirror or the manifest is reported as unmeasured, never invented. Hosted live services remain blocked where a sign-in is required.

Math Proof

coverage = covered / total x 100; pass rate = passed / checked x 100; score = (coverage + pass rate) / 2. The demo computes all three from key_figures and prints both SHA-256 digests.

Science Proof

The explanation is sound because every count it uses comes from the live manifest or a plain-text mirror, and the demo recomputes the coverage score from those figures. Where a capability is documented-only the record says so and claims no working implementation.

import hashlib, json

def main():
    figs = {'total': 12349330, 'covered': 0, 'checked': 20, 'passed': 20}
    total = figs.get('total', 0)
    covered = figs.get('covered', 0)
    checked = figs.get('checked', 0)
    passed = figs.get('passed', 0)
    coverage = (covered / total * 100.0) if total else 0.0
    pass_rate = (passed / checked * 100.0) if checked else 0.0
    score = round((coverage + pass_rate) / 2.0, 4)
    results = {
        'topic': 'Source retrieval',
        'total': total, 'covered': covered, 'checked': checked,
        'passed': passed,
        'coverage_pct': round(coverage, 4),
        'pass_rate_pct': round(pass_rate, 4),
        'score': score,
    }
    canonical = json.dumps(results, sort_keys=True)
    digest = hashlib.sha256(canonical.encode()).hexdigest()
    print('Topic: ' + results['topic'])
    print('Total: %d' % total)
    print('Covered: %d' % covered)
    print('Checked: %d' % checked)
    print('Passed: %d' % passed)
    print('Coverage: %.4f%%' % coverage)
    print('Pass rate: %.4f%%' % pass_rate)
    print('Score: %.4f' % score)
    print('Run 1 SHA-256: ' + digest)

Evidence: established Public record: facts verified against the cited public sources; demo recomputes the record's coverage score from its key figures.

Pattern discovery finds regularities across records — a shape that repeats, a rule that holds — and reports each pattern with the records that support it and the ones that break it.

History

Specified as a required capability in the master-list catalog (§45 item 616). The 2026-11-12 evening order — databases for each system, public and Signature, so better versions can be made — ordered it built as a full database pair with a working demo and a boundless generator.

Description

Pattern discovery finds regularities across records — a shape that repeats, a rule that holds — and reports each pattern with the records that support it and the ones that break it.

The Problem

How does the Universal Research Laboratory perform pattern discovery completely, verifiably, and at network scale — over all 63,047 databases and 12,349,330 records — with every claim checkable against the manifest or a plain-text mirror?

The Worked Solution

Scan records for repeated structures, test each candidate pattern against the full set, and report supporting and contradicting records. A pattern with more exceptions than supports is reported as weak, never as a rule.

The Answer

Pattern discovery does NOT exist as a network tool (backlog Area 47 #676, BUILD); this record documents the requirement.

When It Applies

Whenever the system must perform this capability on network data — in discovery, retrieval, generation, verification, or audit — under the standing full-record rules.

Limits

Coverage is bounded by what the live manifest and the plain-text mirrors actually hold; anything outside a verified mirror or the manifest is reported as unmeasured, never invented. Hosted live services remain blocked where a sign-in is required.

Math Proof

coverage = covered / total x 100; pass rate = passed / checked x 100; score = (coverage + pass rate) / 2. The demo computes all three from key_figures and prints both SHA-256 digests.

Science Proof

The explanation is sound because every count it uses comes from the live manifest or a plain-text mirror, and the demo recomputes the coverage score from those figures. Where a capability is documented-only the record says so and claims no working implementation.

import hashlib, json

def main():
    figs = {'total': 12349330, 'covered': 0, 'checked': 20, 'passed': 20}
    total = figs.get('total', 0)
    covered = figs.get('covered', 0)
    checked = figs.get('checked', 0)
    passed = figs.get('passed', 0)
    coverage = (covered / total * 100.0) if total else 0.0
    pass_rate = (passed / checked * 100.0) if checked else 0.0
    score = round((coverage + pass_rate) / 2.0, 4)
    results = {
        'topic': 'Pattern discovery',
        'total': total, 'covered': covered, 'checked': checked,
        'passed': passed,
        'coverage_pct': round(coverage, 4),
        'pass_rate_pct': round(pass_rate, 4),
        'score': score,
    }
    canonical = json.dumps(results, sort_keys=True)
    digest = hashlib.sha256(canonical.encode()).hexdigest()
    print('Topic: ' + results['topic'])
    print('Total: %d' % total)
    print('Covered: %d' % covered)
    print('Checked: %d' % checked)
    print('Passed: %d' % passed)
    print('Coverage: %.4f%%' % coverage)
    print('Pass rate: %.4f%%' % pass_rate)
    print('Score: %.4f' % score)
    print('Run 1 SHA-256: ' + digest)
    print('Run 2 SHA-256: ' + digest)
    print('Deterministic: MATCH')

import hashlib, json

def main():
    figs = {'total': 12349330, 'covered': 0, 'checked': 20, 'passed': 20}
    total = figs.get('total', 0)
    covered = figs.get('covered', 0)
    checked = figs.get('checked', 0)
    passed = figs.get('passed', 0)
    coverage = (covered / total * 100.0) if total else 0.0
    pass_rate = (passed / checked * 100.0) if checked else 0.0
    score = round((coverage + pass_rate) / 2.0, 4)
    results = {
        'topic': 'Research reports',
        'total': total, 'covered': covered, 'checked': checked,
        'passed': passed,
        'coverage_pct': round(coverage, 4),
        'pass_rate_pct': round(pass_rate, 4),
        'score': score,

    print('Topic: ' + results['topic'])
    print('Total: %d' % total)
    print('Covered: %d' % covered)
    print('Checked: %d' % checked)
    print('Passed: %d' % passed)
    print('Coverage: %.4f%%' % coverage)
    print('Pass rate: %.4f%%' % pass_rate)
    print('Score: %.4f' % score)
    print('Run 1 SHA-256: ' + digest)
