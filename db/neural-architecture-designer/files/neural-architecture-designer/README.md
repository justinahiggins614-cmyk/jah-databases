# Neural Architecture Designer Database — files (neural-architecture-designer)

- `demo-neural-architecture-designer.py` — runnable demo program (run with `python3 demo-neural-architecture-designer.py`).
- `neural-architecture-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/neural-architecture-designer/index.jsonl.gz` (24 records).
- The generator is `gen-neural-architecture-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
