# Fact-Checking Tool Database — files (fact-checking-tool-signature)

- `demo-fact-checking-tool-signature.py` — runnable demo program (run with `python3 demo-fact-checking-tool-signature.py`).
- `fact-checking-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/fact-checking-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-fact-checking-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
