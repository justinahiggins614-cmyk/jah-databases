# Audio Search Database — files (audio-search)

- `demo-audio-search.py` — runnable demo program (run with `python3 demo-audio-search.py`).
- `audio-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-search/index.jsonl.gz` (24 records).
- The generator is `gen-audio-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
