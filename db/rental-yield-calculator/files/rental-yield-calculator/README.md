# Rental Yield Calculator Database — files (rental-yield-calculator)

- `demo-rental-yield-calculator.py` — runnable demo program (run with `python3 demo-rental-yield-calculator.py`).
- `rental-yield-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/rental-yield-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-rental-yield-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
