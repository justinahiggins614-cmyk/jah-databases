Specialist AI

JAH Fault Diagnosis Guide is the archive-aware specialist AI for this database. Duties: answer questions from this database's records, explain each record's method and limits, and help build an assistant like the user's personal assistant. It answers what its records cover; questions outside this database are routed to the relevant database or to the network hub, and it states plainly when a record does not cover a question.

Validation engine

Build-time validation performed on every record: schema completeness (all required fields present), body length, ladder tier coverage (simple, compounded, most-complex all present), demo re-execution with byte-for-byte output match, ID prefix and uniqueness checks, and evidence object completeness. Per-record validation results are stored in each record's validation object.

Evidence links

Each record carries an evidence object with sources, supporting records in this database, and reproducible calculations (the demo program). Evidence is rendered per record in the archive index; sources are public methodology and design references, never private data.

Tool connections

Client-side tools are exposed as window.RoboticsFaultDiagnosisTools once the archive loads: searchRecords(query), generateRecord(seed), validateRecord(record), and runTests(). These operate on the loaded records in the browser only; this is a static page and makes no claim about outside services.

Testing suite

Build-time tests, all passed 2026-10-25: retrieval (search finds a known title and ID), generation (generator emits deterministic seeded records), verification (every demo re-executed with matching output), and failure recovery (empty query returns all records, bad seed falls back to the default seed, malformed record is rejected by validation). Results are recorded in the lane report.

Boundless generator

Generator script: gen-robotics-fault-diagnosis.js — run node gen-robotics-fault-diagnosis.js --n 5. Seeded and deterministic; throttled; duplicate-checked; hard-stops at 1015 or when the topic space is genuinely exhausted. Generated records carry src: "generated" and are never mixed with assistant-built records.
