# Speech-to-Text Database — files (speech-to-text-signature)

- `demo-speech-to-text-signature.py` — runnable demo program (run with `python3 demo-speech-to-text-signature.py`).
- `speech-to-text-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/speech-to-text-signature/index.jsonl.gz` (24 records).
- The generator is `gen-speech-to-text-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
