# Evolutionary Computation Tool Database — files (evolutionary-computation-tool)

- `demo-evolutionary-computation-tool.py` — runnable demo program (run with `python3 demo-evolutionary-computation-tool.py`).
- `evolutionary-computation-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/evolutionary-computation-tool/index.jsonl.gz` (24 records).
- The generator is `gen-evolutionary-computation-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
