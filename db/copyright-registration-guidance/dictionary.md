# Dictionary entries — The Copyright Registration Guidance Database

Key terms of this database, defined in plain words.

## copyright registration guidance

The recorded help given to a maker of a work about the published requirements for registering copyright, so that the forms, the fees, and the filing can be read in plain view.

## copyright

The set of exclusive rights the law gives the maker of an original work, written in the record so that what the law grants can be read plainly.

## registration

The entry of a work in the public copyright register, kept in the record with its date and its number, so that the entry can be proved from the paper.

## work

An original creation such as a book, a song, or a picture, named in the record with its maker, so that what was registered can be read plainly.

## author

The maker of a work, named in the record with the work, so that who made the work can be traced to the paper.

## copyright office

The public office that keeps the copyright register, named in the record with the registration, so that where the entry was made can be read plainly.

## deposit copy

The copy of a work sent with a registration, kept in the record with its date, so that what was deposited can be counted.

## certificate

The written paper that proves a work was registered, kept in the record with its number and its date, so that the registration can be proved from the paper.

## term

The stated span of years for which copyright lasts, written in the record so that how long the rights run can be read plainly.

## public domain

The state of a work whose copyright has ended, written in the record so that which works belong to all can be read plainly.

## infringement

The use of a work without the permission the law requires, noted in the record only as a published term, so that the meaning can be read without any claim about any case.

## form

The printed or on-screen sheet on which a registration is requested, kept as a copy beside the request so that what was sent can be read again.
