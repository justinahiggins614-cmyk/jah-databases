The Virtual Gravity Playground Database

Accessible version: plain text, no scripts, no sign-in, free forever. The virtual gravity playground is a simulation only: a screen where balls drop, roll, bounce, and orbit, and a visitor can change the pull and watch the paths bend. Every record is a clearly labeled simulation, never a claim about real gravity or a real laboratory.
