Signature Global Database Graph is the Signature edition's original treatment of Global Database Graph, created for this database and not copied from any outside product or standard. The Global Database Graph is the graph of every database in the network: each database is a node, and each relationship between two databases — a shared subject, a shared record kind, a shared source — is an edge between them. A reader who opens the graph can see which databases sit next to each other and follow an edge from one database to a related one. The graph is a specification and a test suite in this database, not a running live graph service: this pair carries the graph design, per-graph checks, and client code, never the operating service itself.

This Signature edition record is an original creation for this database, written to describe Global Database Graph in the Signature edition's own words. It is not a copy of any outside standard or product, it carries no endorsement from any outside party, and this record does not state a release date for it.

A database graph works by treating each database as a node with its slug, name, and record kind, and by drawing an edge whenever two databases share a stated relationship, such as a subject or a source. A query starts at one node and follows edges to neighbours, so related databases are found by walking the graph instead of by searching a list. An edge that names a relationship no database states is refused, keeping the graph honest. The live manifest, recounted at 63,047 databases on 2026-11-02, is the node list the graph is drawn from.
