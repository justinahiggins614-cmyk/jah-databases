# Running Pace Calculator Database — files (running-pace-calculator)

- `demo-running-pace-calculator.py` — runnable demo program (run with `python3 demo-running-pace-calculator.py`).
- `running-pace-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/running-pace-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-running-pace-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
