# Video Transcription Database — files (video-transcription)

- `demo-video-transcription.py` — runnable demo program (run with `python3 demo-video-transcription.py`).
- `video-transcription-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-transcription/index.jsonl.gz` (24 records).
- The generator is `gen-video-transcription.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
