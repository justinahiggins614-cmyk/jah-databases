# Court Records Search Database — files (court-records-search)

- `demo-court-records-search.py` — runnable demo program (run with `python3 demo-court-records-search.py`).
- `court-records-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/court-records-search/index.jsonl.gz` (24 records).
- The generator is `gen-court-records-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
