Overview

The Signature Document Collaboration Database holds 24 full document collaboration record records, in a teaching ladder: 8 simple, 8 compounded, 8 most complex. This edition is the Signature edition. It expands the live database db-creator-collaboration, which holds 34 records; this pair links to it and never rebuilds it. This database carries the specification, models, test suites and verification records; it is not a running service.

Generator ceiling: up to 1,000,000,000 scales per file, generated on demand by the file AI — not stored files.

The Design/System

The design is one database per subject, with a public edition and a Signature edition side by side. Every record gives its history, its full content, its methods, its results as reported, and its skeptical analysis. Every technical term is defined in plain words where it first appears, and the glossary defines them all again. Each Signature record is a design study, labeled as a design, never presented as established fact.

The Generator

The boundless generator for this database is the file gen-document-collaboration-signature.js. It is seeded and deterministic: the same seed always gives the same record, and different seeds differ. It is throttled to 100 records per call, it stops at 1,000,000,000 records per file, and every generated record is labeled generated, never presented as an archive record.

The AI

The archive-aware AI for this database is JAH Signature Document Collaboration Designer. It explains this database in plain sentences, answers questions about every record, and can generate new records in this database's family. Its full specification is downloadable: document-collaboration-signature-ai.json.

The counting argument is exact: 24 records, 8 simple, 8 compounded, 8 most complex, and 8 + 8 + 8 = 24.
