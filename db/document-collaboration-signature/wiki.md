# The Document Collaboration Database

The Document Collaboration Database is the document collaboration record database in the Signature network. It holds 24 full document collaboration record records in the public edition and 24 in the Signature edition, in a teaching ladder of 8 simple, 8 compounded and 8 most complex records.

It expands the live database db-creator-collaboration, which it links to and never rebuilds. The database carries the specification, models, test suites and verification records; it is not a running service.
