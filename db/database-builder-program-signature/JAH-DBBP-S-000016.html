Database Builder: Signature Test Suite

JAH-DBBP-S-000016 — database builder program record

The Signature test suite tests the Signature edition by execution: every Signature capability has a test, every Signature interface call has a test, and the verdict is pass only when failures are zero. A Signature test that fails names its input, its expected output, and its actual output. This record lists the Signature tests and the evidence each one produces. In this Signature edition the program offers 8 capabilities (generating a database from a short specification (1); creating records that pass validation on first build (2); writing the manifest entry with a free slug and ID prefix (3); checking the new database against CHECK 2 (4); producing public and Signature editions together (5); reusing the live construction-pattern database (6); an API other programs use to build databases (7); a plain-text build report readable without JavaScript (8)), 6 interfaces (Specification form — subject, record kind, and fields, in plain words; Field editor — add, name, and describe each field; Build button — one action that builds the whole database; Build report — what was built, record counts, validation result; Builder API — machine-readable database building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (subject — what the database is about; record_kind — what sort of record it holds; fields — the named fields each record carries; slug — the database's short web-address name; id_prefix — the short code at the start of every record identifier; records — the records built, public and Signature; manifest_entry — the entry written for the manifest; validation — the CHECK 2 result for the new database). This record is number 16 of 24 in the Signature edition of the Database Builder database pair, and it specifies the signature test suite topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
