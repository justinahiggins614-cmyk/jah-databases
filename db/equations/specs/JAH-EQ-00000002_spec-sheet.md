# Solve 3x^2 − 75 = 0 — Spec sheet

Record JAH-EQ-00000002 — quadratic.
JCC v1 code: JAHDB/equations#JAH-EQ-00000002

## Equation

3x^2 − 75 = 0

## Solution

x = 5 or x = −5

## Steps
1. 3x^2 − 75 = 0
2. Discriminant D = b² − 4ac = 0² − 4(3)(-75) = 900
3. √D = 30
4. x = (−b ± √D) / 2a = (0 ± 30) / 6
5. x = 5 or x = −5
