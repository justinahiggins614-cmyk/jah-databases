## Equation

∫(5x^2 − 9x + 9) dx = ?

## Solution

5/3x^3 − 9/2x^2 + 9x + C

## Steps
1. ∫(5x^2 − 9x + 9) dx
2. Power rule ∫x^n dx = x^(n+1)/(n+1):
3. ∫5x^2 dx = 5/3x^3
4. ∫−9x dx = −9/2x^2
5. ∫9 dx = 9x^1
6. = 5/3x^3 − 9/2x^2 + 9x + C
