# Solve the system: 1x + 1y = -4; 4x + 6y = -16 — Spec sheet

Record JAH-EQ-00000003 — system2.
JCC v1 code: JAHDB/equations#JAH-EQ-00000003

## Equation

1x + 1y = -4 and 4x + 6y = -16

## Solution

x = −4, y = 0

## Steps
1. (1) 1x + 1y = -4
2. (2) 4x + 6y = -16
3. Determinant = 1(6) − 1(4) = 2
4. x = (6(-4) − 1(-16)) / 2 = −4
5. y = (1(-16) − 4(-4)) / 2 = 0

## Check

1(−4) + 1(0) = -4 ✓
