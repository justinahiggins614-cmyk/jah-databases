## Steps
1. f(x) = 4x^3 + 2x^2 + 9x − 3
2. Apply the power rule d/dx[x^n] = n·x^(n−1):
3. d/dx[4x^3] = 12x^2
4. d/dx[2x^2] = 4x
5. d/dx[9x] = 9
6. d/dx[-3] = 0 (constant)
7. f'(x) = 12x^2 + 4x + 9
