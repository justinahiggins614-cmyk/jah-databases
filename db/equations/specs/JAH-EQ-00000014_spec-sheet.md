# Solve x^2 + 6x − 27 = 0 — Spec sheet

Record JAH-EQ-00000014 — quadratic.

## Equation

x^2 + 6x − 27 = 0

## Solution

x = 3 or x = −9

## Steps
1. x^2 + 6x − 27 = 0
2. Discriminant D = b² − 4ac = 6² − 4(1)(-27) = 144
3. √D = 12
4. x = (−b ± √D) / 2a = (-6 ± 12) / 2
5. x = 3 or x = −9
