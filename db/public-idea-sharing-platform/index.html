An idea-sharing website: each idea is a public card with two parts, the problem in plain words and the proposal in plain words. An idea board where every idea is public lets anyone read every idea, so a good idea is never hidden in a private drawer. The board needs each idea written plainly, so a reader who was not there when it was written can still understand it. Without a public board, ideas are shared in private and the best idea in the room is the one nobody else ever hears.
