# Customer Support Ticketing Database — files (customer-support-ticketing)

- `demo-customer-support-ticketing.py` — runnable demo program (run with `python3 demo-customer-support-ticketing.py`).
- `customer-support-ticketing-sample.txt` — a plain-text sample of the database.
- The full database is `data/customer-support-ticketing/index.jsonl.gz` (24 records).
- The generator is `gen-customer-support-ticketing.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
