# Medical Calculator Database — files (medical-calculator-signature)

- `demo-medical-calculator-signature.py` — runnable demo program (run with `python3 demo-medical-calculator-signature.py`).
- `medical-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/medical-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-medical-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
