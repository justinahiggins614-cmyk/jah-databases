# Task Manager Database — files (task-manager-signature)

- `demo-task-manager-signature.py` — runnable demo program (run with `python3 demo-task-manager-signature.py`).
- `task-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/task-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-task-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
