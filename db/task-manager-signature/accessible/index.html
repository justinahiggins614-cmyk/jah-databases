The Task Manager Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. A task manager keeps every task in one list, with a due date, a priority and a state, so nothing is forgotten and the most important work is done first.

Twenty-four full records, ordered simple to working to advanced.

Full record index: https://justinahiggins614-cmyk.github.io/jah-databases-data-2/data/task-manager-signature/index.jsonl.gz

  1. One Task, Written Down

    Record 1 of 24. simple. Feasibility: buildable-now. A task is a promise kept in words: what must be done, by when, and whether it is done. Task 'Buy milk' is due Friday and is not done yet.

    Math proof: Progress is a fraction: done tasks divided by all tasks. With 9 of 12 tasks done, progress is 9 over 12, which is 0.75, or 75 percent. Sorting is an ordering: tasks sort by due date first and by priority second, so the earliest and most important task is always at the top.

    Science proof: A task manager works because human memory is limited: writing a task down moves it from memory to a list, where it cannot be forgotten. Checking a task off gives a visible reward, and a visible reward makes the next task easier to start. That is why a list with states, dates and priorities helps people finish more work than memory alone.
