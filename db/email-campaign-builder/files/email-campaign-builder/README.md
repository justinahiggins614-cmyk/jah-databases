# Email Campaign Builder Database — files (email-campaign-builder)

- `demo-email-campaign-builder.py` — runnable demo program (run with `python3 demo-email-campaign-builder.py`).
- `email-campaign-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/email-campaign-builder/index.jsonl.gz` (24 records).
- The generator is `gen-email-campaign-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
