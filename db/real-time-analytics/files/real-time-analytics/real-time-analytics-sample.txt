Real-Time Analytics Database (real-time-analytics)

A real-time analytics is a rule-based local demo: it reads set toy streams, and counts the marks. The analytics reads 3 streams. The stream alpha holds 24 marks. The largest holds 24 marks. Everything runs in this browser; no data leaves the page.
