# Real-Time Analytics Database — files (real-time-analytics)

- `demo-real-time-analytics.py` — runnable demo program (run with `python3 demo-real-time-analytics.py`).
- `real-time-analytics-sample.txt` — a plain-text sample of the database.
- The full database is `data/real-time-analytics/index.jsonl.gz` (24 records).
- The generator is `gen-real-time-analytics.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
