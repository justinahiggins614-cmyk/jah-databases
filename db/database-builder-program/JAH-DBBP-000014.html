Database Builder: Integration with the JAH Network

JAH-DBBP-000014 — database builder program record

The Database Builder belongs to the JAH Network: it links to the network's databases, websites, and AIs, and it can be reached from the network's front door and the 'Merica-L Command Center. Its records cite the network's own data first, and its links name the database or website they point to. This record specifies the network links the program carries, what each one leads to, and the rule that governs them: link, never rebuild — what the network already does, the program uses instead of copying. In this public edition the program offers 8 capabilities (generating a database from a short specification (1); creating records that pass validation on first build (2); writing the manifest entry with a free slug and ID prefix (3); checking the new database against CHECK 2 (4); producing public and Signature editions together (5); reusing the live construction-pattern database (6); an API other programs use to build databases (7); a plain-text build report readable without JavaScript (8)), 6 interfaces (Specification form — subject, record kind, and fields, in plain words; Field editor — add, name, and describe each field; Build button — one action that builds the whole database; Build report — what was built, record counts, validation result; Builder API — machine-readable database building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (subject — what the database is about; record_kind — what sort of record it holds; fields — the named fields each record carries; slug — the database's short web-address name; id_prefix — the short code at the start of every record identifier; records — the records built, public and Signature; manifest_entry — the entry written for the manifest; validation — the CHECK 2 result for the new database). This record is number 14 of 24 in the public edition of the Database Builder database pair, and it specifies the integration with the jah network topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
