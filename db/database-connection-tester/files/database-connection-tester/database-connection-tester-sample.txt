Database Connection Tester Database (database-connection-tester)

A database connection tester is a rule-based local demo: it tests set toy links, and counts the marks. The tester reads 3 links. The link alpha holds 21 marks. The largest holds 21 marks. Everything runs in this browser; no data leaves the page.
