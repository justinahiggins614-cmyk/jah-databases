Clipboard Manager Database (clipboard-manager-signature)

A clipboard manager keeps a local history of copied text. Type or paste text, press Copy, and read the history. A history of 3 entries: alpha, beta and gamma. Copying 'hello world' stores 11 characters. 5 entries hold 3 different texts. Everything runs in this browser; no data leaves the page.
