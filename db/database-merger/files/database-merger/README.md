# Database Merger Database — files (database-merger)

- `demo-database-merger.py` — runnable demo program (run with `python3 demo-database-merger.py`).
- `database-merger-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-merger/index.jsonl.gz` (24 records).
- The generator is `gen-database-merger.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
