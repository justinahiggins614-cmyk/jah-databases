# Graphing Calculator Database — files (graphing-calculator)

- `demo-graphing-calculator.py` — runnable demo program (run with `python3 demo-graphing-calculator.py`).
- `graphing-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/graphing-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-graphing-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
