Related databases

These neighbors are narrow slices, not duplicates of this umbrella catalog: sewing-repair-guides (repairs), sewing-public (public sewing records), quilting (quilt craft), tailors-seamstresses (the trade), e2-hobby-sewing (hobby sewing), embroidery (decorative stitching), fundamentals-knitting (knitting), fundamentals-crochet (crochet), the pair edition sew-patterns-signature (The Signature Sew Patterns Database), and the stitch-patterns pair stitch-patterns and stitch-patterns-signature (stitch patterns, built alongside this pair). Each covers its own slice; this catalog covers finished sew patterns across garments, home goods, and accessories.

Specialist AI

JAH Sew Pattern Guide answers questions about these patterns: measurements, fabric choice, cutting layouts, seam allowances, construction order, finishing, and fitting adjustments. Ask it which pattern fits a measurement set, how much fabric a size needs, or how to fix a fitting problem, and it answers from the records on this page.

Boundless generator

The boundless generator varies the 16 seed patterns deterministically: size grades, fabric widths, and piece dimensions. It is seeded, throttled, and duplicate-checked, with a hard stop at 10^15 records or when the variation space is genuinely exhausted. Generated records carry src "generated" and are never mixed with assistant-built records. The generator script is gen-sew-patterns.js; run it with node gen-sew-patterns.js --n 5.

Validation engine

Every record is checked for a complete body, a runnable demo whose stored output byte-matches a fresh run, a stated ladder tier, a stated edition source, and a valid record kind. The full validation report is in SEW-REPORT.md in the package, and the browser checks run through window.SewPatternsTools.validateRecord(record).

Tool connections

Client-side tools only, operating on the records loaded on this page. The tools object is window.SewPatternsTools with searchRecords(query), generateRecord(seed), validateRecord(record), and runTests(). See the page script for their definitions; they run entirely in the browser on loaded records.

Testing suite

Tests: archive retrieval returns 16 records; the generator emits deterministic records; every demo re-executes byte-identically; the page renders all ladder tiers; the merger preserves provenance. Results are reported by window.SewPatternsTools.runTests().
