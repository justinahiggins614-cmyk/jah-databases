# Invoice Generator Database — files (invoice-generator-signature)

- `demo-invoice-generator-signature.py` — runnable demo program (run with `python3 demo-invoice-generator-signature.py`).
- `invoice-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/invoice-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-invoice-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
