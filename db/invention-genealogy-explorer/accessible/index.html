The Invention Genealogy Explorer Database

Accessible version: plain text, no scripts, no sign-in, free forever. The invention genealogy explorer traces how one invention descends from older ones: a new tool naming the older tools it builds on, a new method naming the older methods it improves, all drawn as a family tree in plain words. Every tree is a design study of generic inventions, never a claim about any real patent or inventor.

Twenty-four full records, ordered simple to compounded to complex.
