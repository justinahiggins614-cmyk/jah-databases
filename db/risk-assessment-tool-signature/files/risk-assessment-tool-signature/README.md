# Risk Assessment Tool Database — files (risk-assessment-tool-signature)

- `demo-risk-assessment-tool-signature.py` — runnable demo program (run with `python3 demo-risk-assessment-tool-signature.py`).
- `risk-assessment-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/risk-assessment-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-risk-assessment-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
