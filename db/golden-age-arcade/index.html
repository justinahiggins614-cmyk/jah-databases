Computer Space Rank 1 · simple · vector · beginner

Computer Space arrived in 1971 as the first commercial coin-operated video game, a two-player space duel played on a small television screen inside a futuristic fiberglass cabinet. One player steered a rocket ship and the other steered a pair of flying saucers, and the game awarded points for hits while a timer counted down. It sold modestly, but it proved that a video game could be a product in a public place.

This tribute recreates the space duel as a single-ship vector flight: turn, thrust, and shoot at drifting rocks on a dark field. The demo changes the original by replacing the second player with a set of stationary targets, so the duel's flying and shooting can be practiced alone. It is an original tribute inspired by the mechanics, not the cabinet itself.

The duel rewards leading your shots. Aim where the target will be, not where it is, and use short thrusts to adjust position rather than long burns that carry you past the action. Early players learned that the ship's drift was the real opponent, and the ones who mastered it could hold the screen for a full timed game.

Pong Rank 2 · simple · pong · beginner

Pong arrived in 1972 and became the first video game most people ever played. Two paddles faced each other across a simple court, a square ball bounced between them, and the first player to reach eleven points won. The game was so intuitive that a short instruction line on the cabinet was all anyone needed, and it launched the arcade industry almost overnight.

This tribute recreates the paddle rally: you guard the left wall with a short paddle while the ball bounces around the court. The demo changes the original by scripting a rally against the wall instead of a two-player match, so the timing of the return is easy to study. Every return you make scores a point, and the rally in the demo ends with the player one point ahead.

Pong strategy is almost entirely about patience. Hold the paddle near the center, move only when the ball commits to a direction, and let the bounce do the work. The players who won most often were the ones who moved least, because a still paddle is never caught out of position.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Pong (1972). It is not Pong (1972), and it uses no art, music, or code from that game.

Type up/down/stay each tick to guard your wall, quit to stop.

import sys
PARAMS = {'serves': [5, 3, 7]}
AUTO = ['stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'up', 'up', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay', 'stay']

def pong_session(cmds, verbose):
    paddle, ball, bdx, bdy = 4, [6, 5], 1, 1
    pscore, cscore = 0, 0
    serves = PARAMS["serves"]
    for tick, cmd in enumerate(cmds):
        if cmd == "up":
            paddle = max(0, paddle - 1)
        elif cmd == "down":
            paddle = min(7, paddle + 1)
        ball[0] += bdx
        ball[1] += bdy
        if ball[1] <= 0 or ball[1] >= 9:
            bdy = -bdy
            ball[1] = max(0, min(9, ball[1]))
        if ball[0] >= 11:
            bdx = -1
        if ball[0] <= 0:
            if paddle <= ball[1] <= paddle + 2:
                bdx = 1
                pscore += 1
            else:
                cscore += 1
                s = serves[(pscore + cscore) % len(serves)]
                ball, bdx, bdy = [6, s], 1, 1 if s % 2 == 0 else -1
        if verbose:
            print("Tick %d: %s paddle %d ball %s you %d cpu %d" % (tick + 1, cmd, paddle, tuple(ball), pscore, cscore))
    return pscore, cscore

def auto_play():
    print("Pong tribute: auto session")
    pscore, cscore = pong_session(AUTO, True)
    print("FINAL SCORE: %d" % pscore)
    print("RESULT: YOU %d CPU %d" % (pscore, cscore))

def play():
    print("Pong tribute: type up/down/stay each tick, or quit. Guard the left wall.")
    cmds = []
    for line in sys.stdin:
        cmd = line.strip().lower()
        if cmd == "quit":
            break
        if cmd not in ("up", "down", "stay"):
            print("Unknown command: %s" % cmd)
            continue
        cmds.append(cmd)
        pscore, cscore = pong_session(cmds, False)
        print("you %d cpu %d" % (pscore, cscore))
    pscore, cscore = pong_session(cmds, False)
    print("FINAL SCORE: %d" % pscore)
    print("RESULT: YOU %d CPU %d" % (pscore, cscore))

if __name__ == "__main__":
    if "--play" in sys.argv:
        play()
    else:
        auto_play()

Breakout Rank 3 · simple · pong · beginner

Breakout arrived in 1976 as a single-player twist on the paddle game: instead of an opponent, the player faced a wall of colored bricks at the top of the screen. The ball bounced off the paddle, smashed bricks, and scored more for the higher, harder-to-reach rows. It turned a two-player rally into a solitary test of control, and it became one of the defining games of the decade.

This tribute adapts the brick-breaking idea to the paddle-rally engine: you guard the left wall and return the ball, with the rhythm of the rally standing in for the rhythm of breaking bricks. The demo changes the original by scripting a rally that ends in a miss, because Breakout's real lesson was what happened when the ball got past you: the game ended, and you started over wiser.

The Breakout habit is watching the ball's angle, not the paddle. Players who tracked the ball's path could position the paddle before the ball arrived, while players who watched only their paddle were always a step behind. That lesson, look ahead rather than at your hands, carried into every paddle game that followed.

Space Invaders Rank 4 · simple · fixed-shooter · beginner

Space Invaders arrived in 1978 and became a cultural phenomenon: rows of pixel aliens marched down the screen while the player fired from a lone cannon at the bottom, ducking behind shields that crumbled under fire. Its descending rhythm, which sped up as the aliens thinned, created a tension no earlier game had managed, and its high-score table turned every cabinet into a local contest.

This tribute recreates the fixed shooter with five columns of invaders in three rows and a cannon that slides along the bottom. The demo changes the original by slowing the descent to one row every third turn, giving a new player time to learn the column-clearing rhythm. The scripted session clears all fifteen invaders for a clean win.

Clear columns one at a time, from the edges inward. A half-cleared column leaves a lone invader that is easy to forget and hard to hit late, while a fully cleared column never threatens you again. Keep the cannon moving between shots, and the invasion will stall before it ever reaches your shields.

Playable tribute note: The demo below is an original tribute inspired by the mechanics of Space Invaders (1978). It is not Space Invaders (1978), and it uses no art, music, or code from that game.

def auto_play():
    cols = PARAMS["cols"]
    invaders = set()
    for r in range(PARAMS["rows"]):
        for c in range(cols):
            invaders.add((r, c))
    player = PARAMS["start_col"]
    score = 0
    turn = 0
    print("Fixed shooter tribute: auto session")

        turn += 1
        if cmd == "left":
            player = max(0, player - 1)
        elif cmd == "right":
            player = min(cols - 1, player + 1)
        elif cmd == "shoot":
            col_hits = [(r, c) for (r, c) in invaders if c == player]
            if col_hits:
                invaders.discard(max(col_hits))

        if turn % 3 == 0 and invaders:
            invaders = set((r + 1, c) for (r, c) in invaders)

Asteroids Rank 5 · simple · vector · beginner

Asteroids arrived in 1979 and gave vector graphics their signature game: a small ship drifting through a field of tumbling rocks, each one splitting into smaller, faster fragments when shot. The ship's thrust carried real momentum, so flying felt like gliding in space, and the game's stark white lines on black became an icon of the era.

This tribute recreates the asteroid field with a ship, a line of rocks to the east, and one large rock that splits when hit. The demo changes the original by parking the rocks in place, so a new pilot can practice aiming without chasing drifting debris. The scripted session breaks the large rock and one smaller rock nearby, while the large rock's fragments drift onward into the dark.

Asteroids pilots shoot from a distance and drift clear. Fire at a rock, then thrust away before its fragments spread, and never sit still in the middle of the field. The players who survived longest treated the screen as open water: always moving, always with an escape route, never cornered against an edge.

def parse_map():
    walls, dots, player, ghost = set(), set(), None, None
    for y, row in enumerate(PARAMS["map"]):
        for x, ch in enumerate(row):
            if ch == "#":
                walls.add((x, y))
            elif ch == ".":
                dots.add((x, y))
            elif ch == "P":
                player = (x, y)
            elif ch == "G":
                ghost = (x, y)
    return walls, dots, player, ghost

DIRS = {"up": (0, -1), "down": (0, 1), "left": (-1, 0), "right": (1, 0)}

def step(state, cmd):
    walls, dots, player, ghost, score, lives = state
    dx, dy = DIRS.get(cmd, (0, 0))

        dots = dots - {player}
