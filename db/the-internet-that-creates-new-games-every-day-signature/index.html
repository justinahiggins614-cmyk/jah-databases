Inventing a new game for the day is an old habit: a riddle at breakfast, a counting game on a walk, a new rule added to an old pastime. The website form grows out of that habit, adding one fresh game each morning and a plain record of every game that came before. Field guides and indexes are as old as books themselves: a table of contents that tells a reader where everything lives. This index follows that habit, listing the twenty-three content records of this database in the order a reader should meet them.

Dependencies

What must exist first: a fresh invented game each morning, plain rules for each game, a fair start for every player, and a review step before publishing. A tournament system, a creator studio, a review step, translations, and an offline pack are also needed before the complex daily games open.
