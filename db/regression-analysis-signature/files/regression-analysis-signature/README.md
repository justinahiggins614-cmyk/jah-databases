# Regression Analysis Database — files (regression-analysis-signature)

- `demo-regression-analysis-signature.py` — runnable demo program (run with `python3 demo-regression-analysis-signature.py`).
- `regression-analysis-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/regression-analysis-signature/index.jsonl.gz` (24 records).
- The generator is `gen-regression-analysis-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
