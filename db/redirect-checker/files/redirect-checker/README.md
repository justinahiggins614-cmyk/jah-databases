# Redirect Checker Database — files (redirect-checker)

- `demo-redirect-checker.py` — runnable demo program (run with `python3 demo-redirect-checker.py`).
- `redirect-checker-sample.txt` — a plain-text sample of the database.
- The full database is `data/redirect-checker/index.jsonl.gz` (24 records).
- The generator is `gen-redirect-checker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
