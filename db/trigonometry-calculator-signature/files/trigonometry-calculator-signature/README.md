# Trigonometry Calculator Database — files (trigonometry-calculator-signature)

- `demo-trigonometry-calculator-signature.py` — runnable demo program (run with `python3 demo-trigonometry-calculator-signature.py`).
- `trigonometry-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/trigonometry-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-trigonometry-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
