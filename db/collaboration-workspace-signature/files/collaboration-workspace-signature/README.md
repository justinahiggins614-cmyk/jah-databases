# Collaboration Workspace Database — files (collaboration-workspace-signature)

- `demo-collaboration-workspace-signature.py` — runnable demo program (run with `python3 demo-collaboration-workspace-signature.py`).
- `collaboration-workspace-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/collaboration-workspace-signature/index.jsonl.gz` (24 records).
- The generator is `gen-collaboration-workspace-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
