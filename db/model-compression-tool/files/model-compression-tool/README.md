# Model Compression Tool Database — files (model-compression-tool)

- `demo-model-compression-tool.py` — runnable demo program (run with `python3 demo-model-compression-tool.py`).
- `model-compression-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/model-compression-tool/index.jsonl.gz` (24 records).
- The generator is `gen-model-compression-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
