# Nanotechnology Modeling Database — files (nanotechnology-modeling)

- `demo-nanotechnology-modeling.py` — runnable demo program (run with `python3 demo-nanotechnology-modeling.py`).
- `nanotechnology-modeling-sample.txt` — a plain-text sample of the database.
- The full database is `data/nanotechnology-modeling/index.jsonl.gz` (24 records).
- The generator is `gen-nanotechnology-modeling.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
