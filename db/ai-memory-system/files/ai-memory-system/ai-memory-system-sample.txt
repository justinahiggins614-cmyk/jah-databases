AI Memory System Database (ai-memory-system)

An AI memory system is a rule-based local demo: it stores facts under keys, recalls them by key, and forgets them on request. The memory holds 2 facts. Storing one more fact gives 2 facts. A capacity of 100 with 40 used leaves 60 free. Everything runs in this browser; no data leaves the page.
