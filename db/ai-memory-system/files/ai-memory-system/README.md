# AI Memory System Database — files (ai-memory-system)

- `demo-ai-memory-system.py` — runnable demo program (run with `python3 demo-ai-memory-system.py`).
- `ai-memory-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-memory-system/index.jsonl.gz` (24 records).
- The generator is `gen-ai-memory-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
