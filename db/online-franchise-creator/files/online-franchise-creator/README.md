# The Online Franchise Creator Database — files (online-franchise-creator)

- `demo-online-franchise-creator.py` — runnable demo program (run with `python3 demo-online-franchise-creator.py`).
- `online-franchise-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/online-franchise-creator/index.jsonl.gz` (24 records).
- The generator is `gen-online-franchise-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
