# Population Map Database — files (population-map-signature)

- `demo-population-map-signature.py` — runnable demo program (run with `python3 demo-population-map-signature.py`).
- `population-map-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/population-map-signature/index.jsonl.gz` (24 records).
- The generator is `gen-population-map-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
