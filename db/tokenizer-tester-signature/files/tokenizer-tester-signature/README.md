# Tokenizer Tester Database — files (tokenizer-tester-signature)

- `demo-tokenizer-tester-signature.py` — runnable demo program (run with `python3 demo-tokenizer-tester-signature.py`).
- `tokenizer-tester-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/tokenizer-tester-signature/index.jsonl.gz` (24 records).
- The generator is `gen-tokenizer-tester-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
