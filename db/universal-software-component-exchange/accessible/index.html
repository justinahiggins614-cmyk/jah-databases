The Universal Software Component Exchange Database

Accessible version: plain text, no scripts, no sign-in, free forever. The universal software component exchange lists small reusable parts of websites, such as a button, a form, or a search box, each described once in plain words so many small sites can use the same part. Every listing is a clearly labeled design study of a generic part, never a real product.

Twenty-four full records, ordered simple to compounded to complex.
