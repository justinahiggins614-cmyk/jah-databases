Neural Network Visualizer Database (neural-network-visualizer)

A neural network visualizer is a rule-based local demo: it reads set toy layers, and counts the marks. The visualizer reads 3 layers. The layer input holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
