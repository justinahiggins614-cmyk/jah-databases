# Citation Finder Database — files (citation-finder-signature)

- `demo-citation-finder-signature.py` — runnable demo program (run with `python3 demo-citation-finder-signature.py`).
- `citation-finder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/citation-finder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-citation-finder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
