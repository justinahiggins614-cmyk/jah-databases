SSL Expiration Checker Database (ssl-expiration-checker-signature)

An SSL expiration checker is a rule-based local demo: it reads set toy certs, and counts the days. The checker reads 3 certs. The cert shop holds 45 days. The largest holds 45 days. Everything runs in this browser; no data leaves the page.
