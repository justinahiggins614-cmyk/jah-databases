# Video Subtitle Generator Database — files (video-subtitle-generator-signature)

- `demo-video-subtitle-generator-signature.py` — runnable demo program (run with `python3 demo-video-subtitle-generator-signature.py`).
- `video-subtitle-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-subtitle-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-video-subtitle-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
