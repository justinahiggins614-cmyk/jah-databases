# Math Tutor Database — files (math-tutor-signature)

- `demo-math-tutor-signature.py` — runnable demo program (run with `python3 demo-math-tutor-signature.py`).
- `math-tutor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/math-tutor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-math-tutor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
