About this data base

Archive
This database's 3D-print tangible archive (JAH-SPEC/JAH-PAT tangible references), preserved as structured, searchable data.
Record schema
id · name · model_type · material · dims_mm{w,h,d} · volume_cm3 · infill_pct · layer_height_mm · filament_g · layers · est_print_hours
Generator
jahdb-print3d-1.0 — deterministic (mulberry32). Builds each model from raw dimensions with internally consistent parameters; an independent verifier recomputes volume, filament mass (from genuine material densities), layer count, and the print-time estimate from the raw dims before acceptance.
Drift control
Every generated record is checked against an archive sample for duplicate model names and re-validated by the independent checker.
Cross-database
The generator can borrow a numeric theme from any of the other 36 data bases when you tick the box.
AI
JAH Print Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
