# Contract Template Creator Database — files (contract-template-creator)

- `demo-contract-template-creator.py` — runnable demo program (run with `python3 demo-contract-template-creator.py`).
- `contract-template-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/contract-template-creator/index.jsonl.gz` (24 records).
- The generator is `gen-contract-template-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
