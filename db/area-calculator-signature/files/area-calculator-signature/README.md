# Area Calculator Database — files (area-calculator-signature)

- `demo-area-calculator-signature.py` — runnable demo program (run with `python3 demo-area-calculator-signature.py`).
- `area-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/area-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-area-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
