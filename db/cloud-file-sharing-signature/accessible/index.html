  12. A Streak of Files Shared Each Week

    Record 12 of 24. compounded. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    Cloud file sharing helps a person send a file to another person without carrying it by hand, in plain words, with the file named, the size written out, and the sharing rules plain to see. Every example is a clearly labeled illustrative sample of a generic kind of file, never a real file belonging to a real person. A streak gives a person a reason to come back next week: one file shared each week in a row builds a chain, and breaking the chain costs something the person has earned. The streak must be forgiving, because a person who misses one week through no fault of their own should not lose a month of sharing.
