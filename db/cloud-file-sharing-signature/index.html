A Written Guide Shared With a Friend Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A file sharing website: a visitor picks a generic kind of file, such as a written guide, a set of pictures, or a short recording, and the site shows how that kind is shared: a plain name, a size, and a sharing link that can be opened or closed. The site stores no real files, names no real person, and every example is labeled as an illustration of the method. This record covers A Written Guide Shared With a Friend.

A written guide shared with a friend gives a person a plain way to pass on what they know, with the guide named, the size written out, and the sharing rules plain to see. The sharing site must show the plain name, the size, and a link that can be opened or closed, so the friend can open the guide and the sender can close it again. Without those plain facts, a friend cannot tell whether the guide is open or closed, and a link that may or may not work is no help at all.

A file sharing website: a visitor picks a generic kind of file, such as a written guide, a set of pictures, or a short recording, and the site shows how that kind is shared: a plain name, a size, and a sharing link that can be opened or closed. The site stores no real files, names no real person, and every example is labeled as an illustration of the method. This record covers A File Matched to a Plain-Word Name.

A file matched to a plain-word name would let a person who cannot name a kind of file still find it, by saying something plain like the guide about the garden or the pictures from the seaside. Matching by plain words needs a system that understands what garden or seaside means for a file, and turns those plain words into the right shared copy. That understanding is still research-stage: small tests match simple names well, but longer wishes and unusual names still confuse the matcher.

Worked example, Signature design: the same shared file is rebuilt from the Signature pattern, so a file matched to a plain-word name runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

Matching a name to a file began with a person who knew the shelf by heart and could find any file from memory.
