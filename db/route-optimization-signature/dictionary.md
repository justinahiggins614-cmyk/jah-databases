# Dictionary entries — The Route Optimization Database

Key terms of this database, defined in plain words.

## route optimization

The work of choosing the best order for the stops on a route, by a stated method, so that the route chosen can be checked against the method that chose it.

## route

An ordered list of stops to be visited, written in the record, so that the journey the route covers can be read plainly.

## stop

One place a route visits, named in the record with its place, so that every place on the route can be read in order.

## cost

The measured price of a route, such as its length or its time, written in the record as a figure, so that one route can be compared with another by the same measure.

## distance

How far a route travels, written in the record with its unit, so that the length of the route can be read and compared.

## travel time

How long a route takes, written in the record, so that the time of the route can be read and compared with other routes.

## order

The sequence in which the stops on a route are visited, written in the record, so that the order chosen can be read and checked.

## candidate route

One possible order for the stops of a route, written down so that it can be measured and compared with other orders before the best is chosen.

## shortest path

The path between two places with the least length by the stated measure, written in the record, so that the shortest way can be read beside the way chosen.

## vehicle routing problem

The named problem of choosing routes for vehicles that must visit many stops, stated in the record, so that the problem the route answers can be read plainly.

## travelling salesman problem

The named problem of visiting a set of places once each and returning to the start by the shortest way, stated in the record, so that the problem the route answers can be read plainly.

## optimization method

The stated steps by which the best route is chosen, written in the record, so that the choosing can be repeated and checked.
