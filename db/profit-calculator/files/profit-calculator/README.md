# Profit Calculator Database — files (profit-calculator)

- `demo-profit-calculator.py` — runnable demo program (run with `python3 demo-profit-calculator.py`).
- `profit-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/profit-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-profit-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
