# Railroad Scheduling Database — files (railroad-scheduling)

- `demo-railroad-scheduling.py` — runnable demo program (run with `python3 demo-railroad-scheduling.py`).
- `railroad-scheduling-sample.txt` — a plain-text sample of the database.
- The full database is `data/railroad-scheduling/index.jsonl.gz` (24 records).
- The generator is `gen-railroad-scheduling.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
