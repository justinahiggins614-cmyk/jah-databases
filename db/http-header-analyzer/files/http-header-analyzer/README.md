# HTTP Header Analyzer Database — files (http-header-analyzer)

- `demo-http-header-analyzer.py` — runnable demo program (run with `python3 demo-http-header-analyzer.py`).
- `http-header-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/http-header-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-http-header-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
