# Electrical Load Estimator Database — files (electrical-load-estimator-signature)

- `demo-electrical-load-estimator-signature.py` — runnable demo program (run with `python3 demo-electrical-load-estimator-signature.py`).
- `electrical-load-estimator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/electrical-load-estimator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-electrical-load-estimator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
