# World Clock Database — files (world-clock)

- `demo-world-clock.py` — runnable demo program (run with `python3 demo-world-clock.py`).
- `world-clock-sample.txt` — a plain-text sample of the database.
- The full database is `data/world-clock/index.jsonl.gz` (24 records).
- The generator is `gen-world-clock.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
