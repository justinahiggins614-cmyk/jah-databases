Genomic Sequence Viewer Database (genomic-sequence-viewer)

A genomic sequence viewer is a rule-based local demo: it views set toy sequences, and counts the marks. Reference display only: no gene-drive content, no sequence synthesis; design-study only with biosafety screening. Sample sequences only, no real patient data. The viewer reads 3 sequences. The sequence alpha holds 135 marks. The largest holds 135 marks. Everything runs in this browser; no data leaves the page.
