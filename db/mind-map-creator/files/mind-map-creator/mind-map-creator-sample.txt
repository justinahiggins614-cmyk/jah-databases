Mind Map Creator Database (mind-map-creator)

A mind map creator is a rule-based local demo: it joins set toy ideas into a map, and counts the nodes, the links and the leaves. The map holds 5 nodes. The node is idea. The leaf is sketch. Everything runs in this browser; no data leaves the page.
