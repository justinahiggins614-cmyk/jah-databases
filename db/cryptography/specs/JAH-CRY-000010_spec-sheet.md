## Spec
- **Mechanism:** Poly1305 is a one-time message authenticator designed by Daniel J. Bernstein, evaluated modulo the prime 2^130-5. It is fast in software and avoids the timing side channels that plague some table-driven MACs. Paired with ChaCha20, it forms the ChaCha20-Poly1305 authenticated encryption suite in RFC 8439. Filed as JAH-CRY-000010 in the JAH Cryptography Database archive.
