## Spec
- **Mechanism:** PBKDF2 is a password-based key derivation function that applies a pseudorandom function thousands of times to slow down guessing attacks. Published in PKCS#5 v2.0 (2000) and RFC 2898, it takes a password, salt, iteration count, and output length.
