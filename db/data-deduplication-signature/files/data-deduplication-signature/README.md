# Data Deduplication Database — files (data-deduplication-signature)

- `demo-data-deduplication-signature.py` — runnable demo program (run with `python3 demo-data-deduplication-signature.py`).
- `data-deduplication-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-deduplication-signature/index.jsonl.gz` (24 records).
- The generator is `gen-data-deduplication-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
