Data Deduplication Database (data-deduplication-signature)

A data deduplication is a rule-based local demo: it reads set toy pairs, and counts the marks. The deduplication reads 3 pairs. The pair alpha holds 21 marks. The largest holds 21 marks. Everything runs in this browser; no data leaves the page.
