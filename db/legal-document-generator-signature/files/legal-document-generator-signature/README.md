# Legal Document Generator Database — files (legal-document-generator-signature)

- `demo-legal-document-generator-signature.py` — runnable demo program (run with `python3 demo-legal-document-generator-signature.py`).
- `legal-document-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/legal-document-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-legal-document-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
