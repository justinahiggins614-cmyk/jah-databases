# Fuel Consumption Calculator Database — files (fuel-consumption-calculator)

- `demo-fuel-consumption-calculator.py` — runnable demo program (run with `python3 demo-fuel-consumption-calculator.py`).
- `fuel-consumption-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/fuel-consumption-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-fuel-consumption-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
