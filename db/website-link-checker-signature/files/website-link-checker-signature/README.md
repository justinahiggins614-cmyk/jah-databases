# Website Link Checker Database — files (website-link-checker-signature)

- `demo-website-link-checker-signature.py` — runnable demo program (run with `python3 demo-website-link-checker-signature.py`).
- `website-link-checker-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/website-link-checker-signature/index.jsonl.gz` (24 records).
- The generator is `gen-website-link-checker-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
