# Notification Automation Database — files (notification-automation)

- `demo-notification-automation.py` — runnable demo program (run with `python3 demo-notification-automation.py`).
- `notification-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/notification-automation/index.jsonl.gz` (24 records).
- The generator is `gen-notification-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
