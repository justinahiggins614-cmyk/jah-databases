# Stock Analysis Tool Database — files (stock-analysis-tool-signature)

- `demo-stock-analysis-tool-signature.py` — runnable demo program (run with `python3 demo-stock-analysis-tool-signature.py`).
- `stock-analysis-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/stock-analysis-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-stock-analysis-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
