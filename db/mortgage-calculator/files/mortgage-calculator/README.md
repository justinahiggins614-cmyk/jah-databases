# Mortgage Calculator Database — files (mortgage-calculator)

- `demo-mortgage-calculator.py` — runnable demo program (run with `python3 demo-mortgage-calculator.py`).
- `mortgage-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/mortgage-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-mortgage-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
