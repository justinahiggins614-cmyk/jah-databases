Data Segmentation Database (data-segmentation-signature)

A data segmentation is a rule-based local demo: it reads set toy segments, and counts the marks. The segmentation reads 3 segments. The segment low holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
