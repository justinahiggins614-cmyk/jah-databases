# Distance Calculator Database — files (distance-calculator)

- `demo-distance-calculator.py` — runnable demo program (run with `python3 demo-distance-calculator.py`).
- `distance-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/distance-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-distance-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
