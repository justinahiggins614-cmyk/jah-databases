# Limit Calculator Database — files (limit-calculator-signature)

- `demo-limit-calculator-signature.py` — runnable demo program (run with `python3 demo-limit-calculator-signature.py`).
- `limit-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/limit-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-limit-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
