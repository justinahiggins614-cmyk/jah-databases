Molecular Docking Simulator Database (molecular-docking-simulator)

A molecular docking simulator is a rule-based local demo: it simulates set toy molecules, and counts the marks. Reference display only: no pathogen content, no toxin content, no gene-drive content, no sequence synthesis; design-study only with biosafety screening. Sample molecules only, no real patient data. The simulator reads 3 molecules. The molecule alpha holds 243 marks. The largest holds 243 marks. Everything runs in this browser; no data leaves the page.
