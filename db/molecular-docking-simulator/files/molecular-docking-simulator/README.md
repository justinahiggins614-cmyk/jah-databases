# Molecular Docking Simulator Database — files (molecular-docking-simulator)

- `demo-molecular-docking-simulator.py` — runnable demo program (run with `python3 demo-molecular-docking-simulator.py`).
- `molecular-docking-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/molecular-docking-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-molecular-docking-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
