# Land Area Calculator Database — files (land-area-calculator)

- `demo-land-area-calculator.py` — runnable demo program (run with `python3 demo-land-area-calculator.py`).
- `land-area-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/land-area-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-land-area-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
