# Furniture Placement Simulator Database — files (furniture-placement-simulator)

- `demo-furniture-placement-simulator.py` — runnable demo program (run with `python3 demo-furniture-placement-simulator.py`).
- `furniture-placement-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/furniture-placement-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-furniture-placement-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
