# AI Engineer Database — files (ai-engineer)

- `demo-ai-engineer.py` — runnable demo program (run with `python3 demo-ai-engineer.py`).
- `ai-engineer-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-engineer/index.jsonl.gz` (24 records).
- The generator is `gen-ai-engineer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
