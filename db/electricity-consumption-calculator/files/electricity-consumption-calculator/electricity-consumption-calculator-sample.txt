Electricity Consumption Calculator Database (electricity-consumption-calculator)

An electricity consumption calculator is a rule-based local demo: it calculates set toy devices, and counts the marks. The calculator reads 3 devices. The device alpha holds 57 marks. The largest holds 57 marks. Everything runs in this browser; no data leaves the page.
