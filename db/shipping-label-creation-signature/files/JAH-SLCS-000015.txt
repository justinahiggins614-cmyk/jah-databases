History
A parcel has always needed a name on it: in the days of hand-carried letters, the address was written on the wrapper, and the carrier read it to know where the parcel must go. As parcels grew to millions, the written address grew into the shipping label — a printed sheet that carries the sender, the destination, the service, and the marks that let each handler read it the same way. Creating a shipping label means making that sheet true, so that a parcel can travel from one hand to another without being lost. This database is built on that public practice of labelling every parcel true before it travels.
