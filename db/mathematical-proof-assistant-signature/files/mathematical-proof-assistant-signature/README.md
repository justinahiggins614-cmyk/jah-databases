# Mathematical Proof Assistant Database — files (mathematical-proof-assistant-signature)

- `demo-mathematical-proof-assistant-signature.py` — runnable demo program (run with `python3 demo-mathematical-proof-assistant-signature.py`).
- `mathematical-proof-assistant-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/mathematical-proof-assistant-signature/index.jsonl.gz` (24 records).
- The generator is `gen-mathematical-proof-assistant-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
