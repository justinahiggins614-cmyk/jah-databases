Specialist AI

JAH Vinyl Record Guide Signature is the archive-aware specialist AI for this database. Duties: answer questions from this database's own records first, explain each record in plain sentences, generate new records in this database's schema on request, and route questions outside this database to the relevant related database or to the wider network. It gives general reference information only, drawn from this database's own records, and it never reproduces song words, audio, artwork, or verbatim articles.

Boundless generator

Generator script: gen-vinyl-records-signature.js — run node gen-vinyl-records-signature.js --n 5. Seeded and deterministic; throttled; duplicate-checked; hard-stops at 1015 or when the topic space is genuinely exhausted. Generated records carry src: "generated" and are never mixed with assistant-built records.

Validation engine

Checks performed on every record at build time: schema completeness (all required fields present), field consistency (ID prefix, edition, and source label agree), teaching ladder placement, demo re-execution (each demo program run and its stdout compared byte-for-byte with the stored demo output), safety gates (public facts verified before writing; Signature records labeled Signature-original and never presented as real; no song words, audio, artwork, or verbatim articles anywhere), and a forbidden-string gate over all shipped content files. Build-time result for this database: 16 of 16 records passed all checks; 0 failed.

Evidence links

Every record carries an evidence object rendered with the record below: its sources, its supporting records in this database, and its reproducible calculation (the demo output). Sources are descriptive references to general release and chart-history reference material for the public edition and to Signature design notes for the Signature edition; no external live service is claimed.
