# Python Playground Database — files (python-playground)

- `demo-python-playground.py` — runnable demo program (run with `python3 demo-python-playground.py`).
- `python-playground-sample.txt` — a plain-text sample of the database.
- The full database is `data/python-playground/index.jsonl.gz` (24 records).
- The generator is `gen-python-playground.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
