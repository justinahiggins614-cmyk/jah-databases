# Audio Converter Database — files (audio-converter-signature)

- `demo-audio-converter-signature.py` — runnable demo program (run with `python3 demo-audio-converter-signature.py`).
- `audio-converter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-converter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-audio-converter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
