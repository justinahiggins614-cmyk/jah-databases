# Logic Gate Simulator Database — files (logic-gate-simulator)

- `demo-logic-gate-simulator.py` — runnable demo program (run with `python3 demo-logic-gate-simulator.py`).
- `logic-gate-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/logic-gate-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-logic-gate-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
