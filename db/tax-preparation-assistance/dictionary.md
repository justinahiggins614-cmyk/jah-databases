# Dictionary entries — The Tax Preparation Assistance Database

Key terms of this database, defined in plain words.

## tax return

The written account of what was earned and what is owed for a stated year, filed with the tax authority, with every figure traced to the record it came from.

## tax year

The year a tax return covers, named with its first and last day, so that income and costs can only be counted in the year they belong to.

## income

Money received for work, for goods, or for the use of property, recorded by source, so that the return can show where every part of it came from.

## deduction

An amount the law allows to be taken off income before the tax is counted, named with its reason and its proof, so the return shows why the income was reduced.

## tax credit

An amount the law allows to be taken off the tax itself, named with its reason and its proof, so the return shows why the tax was reduced.

## filing status

The named position of the person filing, such as filing alone or filing jointly, which decides how the return is counted, written on the return itself.

## withholding

Tax taken from pay before the worker receives it, recorded by the payer, so the return can show how much tax was already paid during the year.

## refund

Money returned by the tax authority when more tax was paid during the year than the return shows is owed, counted from the figures on the return.

## amount owed

The tax the return shows is still unpaid after counting what was already paid, written on the return with the date by which it is owed.

## supporting record

A paper that proves a figure on the return, such as a statement of pay or a receipt for a cost, kept with the return so the figure can be checked.

## filing deadline

The date by which the return must be filed, named in advance, so the preparer can work to it and the return is not late.

## preparation checklist

The ordered list of papers and steps for preparing a return, each ticked when done, so the preparer can see at a glance what remains before the return is complete.
