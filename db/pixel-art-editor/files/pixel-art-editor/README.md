# Pixel Art Editor Database — files (pixel-art-editor)

- `demo-pixel-art-editor.py` — runnable demo program (run with `python3 demo-pixel-art-editor.py`).
- `pixel-art-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/pixel-art-editor/index.jsonl.gz` (24 records).
- The generator is `gen-pixel-art-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
