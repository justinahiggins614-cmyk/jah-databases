Pixel Art Editor Database (pixel-art-editor)

A pixel art editor is a local demo: it draws set toy grids of coloured pixels, and counts the colours in the grid. The editor draws a grid 3 wide and 3 high. The first pixel is R. The first row reads RGB. Everything runs in this browser; no data leaves the page.
