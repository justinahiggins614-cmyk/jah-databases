# Robotics Simulator Database — files (robotics-simulator-signature)

- `demo-robotics-simulator-signature.py` — runnable demo program (run with `python3 demo-robotics-simulator-signature.py`).
- `robotics-simulator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/robotics-simulator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-robotics-simulator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
