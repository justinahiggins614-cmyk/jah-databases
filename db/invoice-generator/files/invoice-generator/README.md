# Invoice Generator Database — files (invoice-generator)

- `demo-invoice-generator.py` — runnable demo program (run with `python3 demo-invoice-generator.py`).
- `invoice-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/invoice-generator/index.jsonl.gz` (24 records).
- The generator is `gen-invoice-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
