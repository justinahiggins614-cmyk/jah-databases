# Online Classroom Database — files (online-classroom)

- `demo-online-classroom.py` — runnable demo program (run with `python3 demo-online-classroom.py`).
- `online-classroom-sample.txt` — a plain-text sample of the database.
- The full database is `data/online-classroom/index.jsonl.gz` (24 records).
- The generator is `gen-online-classroom.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
