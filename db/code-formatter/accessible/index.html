The Code Formatter Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. A code formatter takes messy code and returns the same code, neatly spaced: indentation fixed, spaces around operators, semicolons in place, blank lines where they belong. Paste code, press Format, and copy the neat result. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced.

  1. What a Code Formatter Is

    Record 1 of 24. simple. Feasibility: buildable-now. A formatter takes messy code and returns the same code, neatly spaced. Formatting 3 lines of messy code gives 3 lines of neat code

    Math proof: Formatting is counting and spacing: 3 lines of messy code give 3 lines of neat code. Indenting 3 lines inside a block adds 2 spaces to each line. A line of 90 characters wraps into 2 lines of 45 characters. Sorting 3 imports gives c, a, b in the order a, b, c. Checking 5 files finds 2 that need formatting, and formatting 10 files changes 6 of them.

    Science proof: A formatter works because code has a shape that spacing can carry: brackets open and close blocks, semicolons end statements, and blank lines separate sections. The formatter reads that shape and rewrites only the spacing, so the code means exactly the same after formatting as before: 1 + 2 is 3 before and after. That is why the formatter shows the neat code beside the messy code, so the sameness can be checked.
