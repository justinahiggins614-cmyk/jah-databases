# Data Pipeline Builder Database — files (data-pipeline-builder-signature)

- `data-pipeline-builder-signature-sample.txt` — a plain-text sample of the database.

- The generator is `gen-data-pipeline-builder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
