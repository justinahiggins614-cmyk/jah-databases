Linear Algebra: Systems of Linear Equations

Record identifier: JAH-LINALG-000001. Ladder rank: 1 of 24. Subject: systems of linear equations.

A system of linear equations is a set of equations in which each equation is linear: each term is a constant times a single variable, with no products or powers of variables. The solution set is the set of assignments to the variables that satisfy every equation at once. A system has no solution, exactly one solution, or infinitely many. Gaussian elimination solves a system by adding multiples of equations to each other until the system is triangular. A system is inconsistent when elimination produces an equation such as 0 = 1. A free variable is one that can take any value, giving infinitely many solutions. Linear Algebra: Vectors, Span, and Linear Independence

Record identifier: JAH-LINALG-000002. Ladder rank: 2 of 24. Subject: vectors, span, and linear independence.

A vector is a list of numbers, added entry by entry and scaled by multiplying every entry by the same number. The span of a set of vectors is the set of all their linear combinations (sums of scaled copies). A set of vectors is linearly independent when the only combination that gives the zero vector is the one with all coefficients zero. A vector is in the span of others when it can be written as a combination of them. A set containing the zero vector is always linearly dependent. In n-dimensional space, any set of more than n vectors is linearly dependent. Linear Algebra: Bases and Dimension

Record identifier: JAH-LINALG-000003. Ladder rank: 3 of 24. Subject: bases and dimension.

A basis of a vector space is a linearly independent set that spans the whole space. The dimension of the space is the number of vectors in any basis: every basis of the same space has the same number of vectors. Coordinates are the coefficients of a vector in a given basis. Every vector in the space has exactly one expression as a combination of basis vectors. The standard basis of n-dimensional space is the vectors with a 1 in one place and 0 elsewhere. A basis can be extended: any independent set can be enlarged to a basis. Linear Algebra: Matrix Arithmetic

Record identifier: JAH-LINALG-000004. Ladder rank: 4 of 24. Subject: matrix arithmetic.

A matrix is a rectangular array of numbers, with rows and columns. Matrices are added entry by entry and multiplied by a number entry by entry. Matrix multiplication is defined when the number of columns of the first equals the number of rows of the second: the (i, j) entry of the product is the dot product (sum of pairwise products) of row i of the first with column j of the second. Matrix multiplication is associative but not commutative: AB is usually different from BA. The identity matrix has 1s on its diagonal and 0s elsewhere, and leaves any matrix unchanged on multiplying. The transpose of a matrix flips it across its diagonal, swapping rows and columns. Linear Algebra: Matrix Inverses

Record identifier: JAH-LINALG-000005. Ladder rank: 5 of 24. Subject: matrix inverses.

The inverse of a square matrix A is a matrix A^-1 such that A times A^-1 and A^-1 times A both equal the identity matrix. A matrix has an inverse exactly when its determinant (a single number computed from its entries) is non-zero. The inverse solves the system A x = b as x = A^-1 b. A 2 by 2 matrix [[a, b], [c, d]] has inverse (1/(ad - bc)) times [[d, -b], [-c, a]], when ad - bc is not zero. The inverse of a product is the product of the inverses in reverse order. A singular matrix (determinant zero) has no inverse, and the system A x = b may have no solution or infinitely many. Linear Algebra: Determinants

Record identifier: JAH-LINALG-000006. Ladder rank: 6 of 24. Subject: determinants.

The determinant is a single number assigned to a square matrix. For a 2 by 2 matrix [[a, b], [c, d]] it is ad - bc. Geometrically it is the factor by which the matrix scales areas (in two dimensions) or volumes (in three): a determinant of 2 doubles areas, a determinant of 0 collapses the plane onto a line or a point, and a negative determinant also flips orientation. A matrix is invertible exactly when its determinant is non-zero. The determinant of a product is the product of the determinants. The determinant of a triangular matrix is the product of its diagonal entries. Linear Algebra: Eigenvalues and Eigenvectors

Record identifier: JAH-LINALG-000007. Ladder rank: 7 of 24. Subject: eigenvalues and eigenvectors.

An eigenvector of a square matrix A is a non-zero vector v that A only scales: A v = lambda v, where the number lambda is the eigenvalue. Eigenvectors are the directions a transformation leaves unchanged in direction, and eigenvalues are the factors by which it stretches them. The eigenvalues are the roots of the characteristic polynomial, det(A - lambda I) = 0. A 2 by 2 matrix has at most 2 eigenvalues, counting multiplicity. Eigenvectors for distinct eigenvalues are linearly independent. Linear Algebra: Diagonalisation

Record identifier: JAH-LINALG-000008. Ladder rank: 8 of 24. Subject: diagonalisation of matrices.

A square matrix A is diagonalisable when it can be written as P D P^-1, where D is a diagonal matrix (non-zero entries only on the diagonal) and P is the matrix whose columns are the eigenvectors. Then powers of A are easy: A to the power k equals P D^k P^-1, and D^k just raises the diagonal entries to the power k. A matrix is diagonalisable exactly when it has a full set of linearly independent eigenvectors. A matrix with n distinct eigenvalues is always diagonalisable. Symmetric matrices are always diagonalisable, with orthogonal eigenvectors. Linear Algebra: Inner Products and Orthogonality

Record identifier: JAH-LINALG-000009. Ladder rank: 9 of 24. Subject: inner products and orthogonality.

An inner product is a way of multiplying two vectors to get a number, generalising the dot product: the dot product of (x1, x2) and (y1, y2) is x1 y1 + x2 y2. Two vectors are orthogonal (perpendicular) when their inner product is zero. The length of a vector is the square root of its inner product with itself. The Cauchy-Schwarz inequality says the absolute value of the inner product is at most the product of the lengths. An orthonormal set is a set of mutually orthogonal vectors, each of length 1. The projection of one vector onto another is the closest point on the other's line. Linear Algebra: Orthogonal Projections and Least Squares

Record identifier: JAH-LINALG-000010. Ladder rank: 10 of 24. Subject: orthogonal projections and least squares.

The orthogonal projection of a vector onto a subspace is the closest point in the subspace to the vector. Least squares fits a line (or another model) to data by minimising the sum of the squares of the errors (the differences between the observed and predicted values); the solution is the projection of the data vector onto the column space of the design matrix. The projection is the unique point in the subspace whose difference from the vector is orthogonal to the subspace. The normal equations A^T A x = A^T b give the least-squares solution. The residual (the difference between the data and the fit) is orthogonal to every column of A. Linear Algebra: The Rank of a Matrix

Record identifier: JAH-LINALG-000011. Ladder rank: 11 of 24. Subject: rank of a matrix.

The rank of a matrix is the dimension of its column space (the span of its columns), which equals the dimension of its row space. It counts the number of independent directions the matrix preserves. A square matrix is invertible exactly when its rank equals its size. The rank is the number of pivots (leading entries) in the row-echelon form. The rank-nullity theorem says rank plus nullity (the dimension of the solution space of A x = 0) equals the number of columns. The rank of a product is at most the smaller of the ranks of the factors. Linear Algebra: Linear Transformations

Record identifier: JAH-LINALG-000012. Ladder rank: 12 of 24. Subject: linear transformations.

A linear transformation is a function between vector spaces that preserves addition and scaling: T(u + v) = T(u) + T(v) and T(c u) = c T(u). Every linear transformation between finite-dimensional spaces is given by a matrix, and the matrix's columns are the images of the basis vectors. Rotation, reflection, scaling, and projection are all linear transformations. The kernel of a transformation is the set of vectors it sends to zero; the image is the set of outputs. A transformation is one-to-one exactly when its kernel contains only the zero vector. Linear Algebra: Change of Basis

Record identifier: JAH-LINALG-000013. Ladder rank: 13 of 24. Subject: change of basis.

A change of basis rewrites the coordinates of a vector, or the matrix of a transformation, in a new basis. If P is the matrix whose columns are the new basis vectors written in the old basis, then the new coordinates are P^-1 times the old coordinates, and the new matrix of a transformation is P^-1 A P. The change-of-basis matrix P has the new basis vectors as its columns. Similar matrices (related by P^-1 A P) have the same eigenvalues, trace, and determinant. Choosing a good basis can diagonalise a matrix, making it easy to work with. Linear Algebra: The Singular Value Decomposition

Record identifier: JAH-LINALG-000014. Ladder rank: 14 of 24. Subject: the singular value decomposition.

The singular value decomposition (SVD) writes any matrix A as U times Sigma times V^T, where U and V are orthogonal matrices (their columns are orthonormal) and Sigma is diagonal with non-negative entries, the singular values, in decreasing order. It is the generalisation of diagonalisation to non-square matrices. The singular values are the square roots of the eigenvalues of A^T A. The best rank-k approximation to A is obtained by keeping the k largest singular values. The SVD gives the least-squares solution, the pseudoinverse, and the principal components of data. Linear Algebra: Quadratic Forms

Record identifier: JAH-LINALG-000016. Ladder rank: 16 of 24. Subject: quadratic forms.

A quadratic form is a homogeneous polynomial of degree 2 in several variables, such as 3x squared + 2xy + 3y squared. It is written as x^T A x for a symmetric matrix A, and its shape is read from the eigenvalues of A: all positive means a bowl, mixed signs means a saddle. A symmetric matrix is diagonalisable by an orthogonal change of basis. A quadratic form is positive definite when it is positive for every non-zero vector. The principal axes of the form are the eigenvectors of its matrix. Linear Algebra: Markov Chains

Record identifier: JAH-LINALG-000018. Ladder rank: 18 of 24. Subject: Markov chains.

A Markov chain is a system that moves between states with fixed probabilities, where the next state depends only on the current state. Its transition matrix has columns (or rows) that sum to 1, and the long-run behaviour is given by the steady-state vector, an eigenvector with eigenvalue 1. The transition matrix is stochastic: its entries are probabilities that sum to 1 in each column. The steady-state vector satisfies P v = v and its entries sum to 1. A regular chain converges to its steady state regardless of the starting distribution. Linear Algebra: The Geometry of Linear Maps

Record identifier: JAH-LINALG-000019. Ladder rank: 19 of 24. Subject: the geometry of linear maps.

A map with determinant 2 doubles areas; with determinant 0 it flattens the square onto a line; with a negative determinant it flips the square over. The image of the unit square under a matrix is the parallelogram spanned by the matrix's columns. The determinant is the signed area of that parallelogram. An orthogonal matrix preserves lengths and angles: it is a rotation or a reflection. Linear Algebra: Solving Least Squares by QR

Record identifier: JAH-LINALG-000020. Ladder rank: 20 of 24. Subject: solving least squares by QR factorisation.

The QR factorisation writes a matrix A as Q times R, where Q has orthonormal columns and R is upper triangular (non-zero entries only on and above the diagonal). Least squares is then solved by a triangular system, which is fast and numerically stable. It is the preferred method in practice over the normal equations. The columns of Q are obtained by Gram-Schmidt orthogonalisation of the columns of A. R is upper triangular, so R x = Q^T b is solved by back-substitution. QR avoids forming A^T A, whose condition number (a measure of sensitivity to error) is the square of A's. Linear Algebra: Dual Spaces and Linear Functionals

Record identifier: JAH-LINALG-000021. Ladder rank: 21 of 24. Subject: dual spaces and linear functionals.

In finite dimensions, the dual space has the same dimension as the original, and every functional is given by a dot product with a fixed vector. A linear functional satisfies f(u + v) = f(u) + f(v) and f(c u) = c f(u). The dual basis is the set of functionals that pick out the coordinates in a given basis. The double dual (the dual of the dual) is naturally the original space. Linear Algebra: The Gram-Schmidt Process

Record identifier: JAH-LINALG-000022. Ladder rank: 22 of 24. Subject: the Gram-Schmidt process.

The Gram-Schmidt process turns a list of independent vectors into an orthonormal list (vectors of length 1, pairwise perpendicular) spanning the same space, by subtracting the projections onto the vectors already built. It is the algorithm behind QR factorisation and the construction of orthonormal bases. Each new vector has its projections onto the earlier ones subtracted. The result is normalised to length 1. The process keeps the span: the new list spans the same space as the old. // own demo, ported from Python), then a determinism check: the lines

'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
