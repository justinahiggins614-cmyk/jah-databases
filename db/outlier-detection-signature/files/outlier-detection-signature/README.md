# Outlier Detection Database — files (outlier-detection-signature)

- `demo-outlier-detection-signature.py` — runnable demo program (run with `python3 demo-outlier-detection-signature.py`).
- `outlier-detection-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/outlier-detection-signature/index.jsonl.gz` (24 records).
- The generator is `gen-outlier-detection-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
