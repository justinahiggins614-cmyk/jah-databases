# Image Format Converter Database — files (image-format-converter)

- `demo-image-format-converter.py` — runnable demo program (run with `python3 demo-image-format-converter.py`).
- `image-format-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/image-format-converter/index.jsonl.gz` (24 records).
- The generator is `gen-image-format-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
