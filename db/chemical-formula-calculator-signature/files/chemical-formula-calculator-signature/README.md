# Chemical Formula Calculator Database — files (chemical-formula-calculator-signature)

- `demo-chemical-formula-calculator-signature.py` — runnable demo program (run with `python3 demo-chemical-formula-calculator-signature.py`).
- `chemical-formula-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/chemical-formula-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-chemical-formula-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
