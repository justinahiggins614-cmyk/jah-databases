# Aviation Flight Tracker Database — files (aviation-flight-tracker)

- `demo-aviation-flight-tracker.py` — runnable demo program (run with `python3 demo-aviation-flight-tracker.py`).
- `aviation-flight-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/aviation-flight-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-aviation-flight-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
