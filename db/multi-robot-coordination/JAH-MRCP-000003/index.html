Descriptions

Formation Control for Mobile Robot Teams is a public record about Rules that hold a team of robots in a chosen shape while it moves. Formation control keeps robots in a chosen shape, such as a line, a wedge or a grid, while the whole shape moves toward a goal, so the team can sweep an area or carry a load together. In leader-follower formation, one robot leads and the others hold fixed offsets from it; in virtual-structure formation, the robots hold offsets from a moving imaginary shape instead. Behaviour-based formation gives each robot simple rules, such as stay near your neighbour and avoid collisions, and the shape emerges from those rules without any robot knowing the whole plan. Formations are used by drone light shows, where hundreds of drones hold positions in the sky, and by warehouse robots moving in lanes. Workflow

The worked solution has 5 steps, each of which can be checked on its own. Step 1: Choose the shape and the spacing between robots. Step 2: Assign each robot a slot in the shape. Step 3: Move the shape toward the goal one step at a time. Step 4: Let each robot correct its own position from its neighbours' positions. Step 5: Check the shape error and tighten the spacing if it drifts. class MultiRobotCoordinationProgram:
    """Working program for this record; run() recomputes the demo result."""
    def run(self):
        import hashlib
        FIGURES = {'robots': 16, 'shape_error_cm': 12, 'spacing_m': 3, 'speed_ms': 2, 'success_pct': 97, 'waypoints': 24}
        LABEL = 'multi-robot-coordination-000003'
        def compute():
            vals = list(FIGURES.values())
            total = sum(vals)
            n = len(vals)
            mean = round(total / n, 4) if n else 0
            out = {"count": n, "label": LABEL, "max": max(vals), "mean": mean, "min": min(vals), "total": total}
            return out
        outputs = compute()
        result = "|".join(f"{k}={v}" for k, v in sorted(outputs.items()))
        h1 = hashlib.sha256(result.encode()).hexdigest()
        outputs2 = compute()
        result2 = "|".join(f"{k}={v}" for k, v in sorted(outputs2.items()))
        h2 = hashlib.sha256(result2.encode()).hexdigest()
        for k, v in sorted(outputs.items()):
            print(f"{k}: {v}")
        print(f"Result: {result}")
        print(f"Run 1 SHA-256: {h1}")
        print(f"Run 2 SHA-256: {h2}")
        print(f"Deterministic: {'MATCH' if h1 == h2 else 'MISMATCH'}")
