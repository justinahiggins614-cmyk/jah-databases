# Database Synchronization Database — files (database-synchronization)

- `demo-database-synchronization.py` — runnable demo program (run with `python3 demo-database-synchronization.py`).
- `database-synchronization-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-synchronization/index.jsonl.gz` (24 records).
- The generator is `gen-database-synchronization.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
