# Font Pairing Tool Database — files (font-pairing-tool)

- `demo-font-pairing-tool.py` — runnable demo program (run with `python3 demo-font-pairing-tool.py`).
- `font-pairing-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/font-pairing-tool/index.jsonl.gz` (24 records).
- The generator is `gen-font-pairing-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
