# Inference Speed Tester Database — files (inference-speed-tester)

- `demo-inference-speed-tester.py` — runnable demo program (run with `python3 demo-inference-speed-tester.py`).
- `inference-speed-tester-sample.txt` — a plain-text sample of the database.
- The full database is `data/inference-speed-tester/index.jsonl.gz` (24 records).
- The generator is `gen-inference-speed-tester.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
