# HVAC Sizing Calculator Database — files (hvac-sizing-calculator)

- `demo-hvac-sizing-calculator.py` — runnable demo program (run with `python3 demo-hvac-sizing-calculator.py`).
- `hvac-sizing-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/hvac-sizing-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-hvac-sizing-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
