About this data base

What it is
The network proving itself: each record is a complete, reproducible demonstration run — a real request, the live databases consulted, the artifact the archive-aware AIs generated, the verification checks, and the replay steps.
The pipeline
1. Intake — the request is taken as typed, or from a preset. 2. Database access — the live manifest is searched and the matching databases' real indexes are fetched; the page shows exactly which databases were consulted, with links. 3. Generation — the specialized generator composes a full, useful artifact from the cited records. 4. Verification — every cited record ID is confirmed in its live index, quoted text is matched against source records, and any math is recomputed independently. 5. Saved — the artifact downloads as a file, a made-with entry is prepared, and the run is logged for replay.
Reproducibility
Preset requests are deterministic: same request, same databases, same checks. python3 code/demo_replay.py re-runs all five canonical presets headlessly against the local data and asserts every pipeline stage — see REPLAY.md.
