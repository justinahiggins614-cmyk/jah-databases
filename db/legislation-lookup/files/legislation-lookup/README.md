# Legislation Search Database — files (legislation-lookup)

- `demo-legislation-lookup.py` — runnable demo program (run with `python3 demo-legislation-lookup.py`).
- `legislation-lookup-sample.txt` — a plain-text sample of the database.
- The full database is `data/legislation-lookup/index.jsonl.gz` (24 records).
- The generator is `gen-legislation-lookup.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
