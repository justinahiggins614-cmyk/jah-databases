# Database Converter Database — files (database-converter)

- `demo-database-converter.py` — runnable demo program (run with `python3 demo-database-converter.py`).
- `database-converter-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-converter/index.jsonl.gz` (24 records).
- The generator is `gen-database-converter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
