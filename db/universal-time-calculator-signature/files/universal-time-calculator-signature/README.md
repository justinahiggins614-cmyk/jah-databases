# Universal Time Calculator Database — files (universal-time-calculator-signature)

- `demo-universal-time-calculator-signature.py` — runnable demo program (run with `python3 demo-universal-time-calculator-signature.py`).
- `universal-time-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/universal-time-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-universal-time-calculator-signature.js`; the generator website is `generator-signature/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
