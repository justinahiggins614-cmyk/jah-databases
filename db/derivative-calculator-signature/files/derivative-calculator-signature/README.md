# Derivative Calculator Database — files (derivative-calculator-signature)

- `demo-derivative-calculator-signature.py` — runnable demo program (run with `python3 demo-derivative-calculator-signature.py`).
- `derivative-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/derivative-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-derivative-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
