Overview

The Audio Editor Service Database holds 24 full audio editor service record records, in a teaching ladder: 8 simple, 8 compounded, 8 most complex. This edition is the public edition. It expands the live database software-audio-editors, which holds 20 records; this pair links to it and never rebuilds it. This database carries the specification, models, test suites and verification records; it is not a running service.

Generator ceiling: up to 1,000,000,000 scales per file, generated on demand by the file AI — not stored files.

The Design/System

The design is one database per subject, with a public edition and a Signature edition side by side. Every record gives its history, its full content, its methods, its results as reported, and its skeptical analysis. Every technical term is defined in plain words where it first appears, and the glossary defines them all again. Each public record is a verified public fact with its source cited, retrieved 2026-11-21.

The Generator

The boundless generator for this database is the file gen-audio-editor-service.js. It is seeded and deterministic: the same seed always gives the same record, and different seeds differ. It is throttled to 100 records per call, it stops at 1,000,000,000 records per file, and every generated record is labeled generated, never presented as an archive record.

The AI

The archive-aware AI for this database is JAH Audio Editor Service Archivist. It explains this database in plain sentences, answers questions about every record, and can generate new records in this database's family. Its full specification is downloadable: audio-editor-service-ai.json.

Math Proof

The counting argument is exact: 24 records, 8 simple, 8 compounded, 8 most complex, and 8 + 8 + 8 = 24. The formal statement is: duration(sound) = samples(sound) / samples per second; loudness change in decibels = 20 * log10(new level / old level) (stated, not machine-checked) The scientific statement is: accuracy = correctly changed samples / all samples the change should touch (stated, not machine-checked) Both are stated, not machine-checked, and the record-level proofs are in each record's math proof.
