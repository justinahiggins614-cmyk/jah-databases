# Unit Testing Platform Database — files (unit-testing-platform)

- `demo-unit-testing-platform.py` — runnable demo program (run with `python3 demo-unit-testing-platform.py`).
- `unit-testing-platform-sample.txt` — a plain-text sample of the database.
- The full database is `data/unit-testing-platform/index.jsonl.gz` (24 records).
- The generator is `gen-unit-testing-platform.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
