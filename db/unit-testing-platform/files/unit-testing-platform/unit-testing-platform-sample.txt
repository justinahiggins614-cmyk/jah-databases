Unit Testing Platform Database (unit-testing-platform)

A unit testing platform is a rule-based local demo: it runs set toy tests, counts the passes, and reports the share. The platform runs 4 unit tests. The test add passes. 1 of 4 tests fails. Everything runs in this browser; no data leaves the page.
