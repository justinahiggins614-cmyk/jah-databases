# AI App Builder Database — files (ai-app-builder-signature)

- `demo-ai-app-builder-signature.py` — runnable demo program (run with `python3 demo-ai-app-builder-signature.py`).
- `ai-app-builder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-app-builder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-app-builder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
