# Financial Forecasting Tool Database — files (financial-forecasting-tool)

- `demo-financial-forecasting-tool.py` — runnable demo program (run with `python3 demo-financial-forecasting-tool.py`).
- `financial-forecasting-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/financial-forecasting-tool/index.jsonl.gz` (24 records).
- The generator is `gen-financial-forecasting-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
