# AI Code Reviewer Database — files (ai-code-reviewer-signature)

- `demo-ai-code-reviewer-signature.py` — runnable demo program (run with `python3 demo-ai-code-reviewer-signature.py`).
- `ai-code-reviewer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-code-reviewer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-code-reviewer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
