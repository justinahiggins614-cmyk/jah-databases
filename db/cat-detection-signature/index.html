JAH-DET-000012 — JAH ear-triangle pair kernel (5x5 original)

The cat silhouette's best match clearly exceeds the dog's, because the template's twin triangles line up with real ear triangles and find only background where floppy ears hang. This is JAH's 'draw the anatomy, then match the drawing' approach — the opposite of learning templates from data, and honest about its limits: it detects the drawing's idea of a cat, which covers alert sitting cats well and curled sleeping cats not at all.

The experiment's value is as a *part* in a larger Signature pipeline: ear-pair evidence is one vote among several (eyes, whisker lines, contour closure), and the votes combine in record 19's scoring formula. No single vote decides; the design assumes every part detector is fallible.

JAH-DET-000013 — JAH whisker-line detector experiment

The horizontal lines produce a large positive total, the vertical lines nearly nothing, and the blank exactly nothing. The kernel is doing precisely what line-detector theory says it should — and JAH's experimental contribution is not the kernel shape (line kernels are old) but the *role* he assigns it: a deliberately weak vote in a multi-part score.

This is a design philosophy worth naming: the Signature pipeline ranks evidence by reliability. Ears are strong evidence (rigid, high-contrast, cat-specific geometry). Whiskers are weak evidence (fine, easily confused, resolution-dependent). A detector that lets weak evidence outvote strong evidence makes confident mistakes; JAH's scoring formula prevents that by construction.

JAH-DET-000014 — JAH eye-pair detector experiment

JAH-DET-000015 — JAH multi-scale search experiment

Single-scale matching scores the small-eared cat well and the large-eared cat poorly; the two-level search recovers the large-eared cat at the half-resolution level. The experiment is small and honest: two levels, one template, synthetic silhouettes — but it proves the mechanism JAH's pipeline relies on, that one fixed template can cover a range of sizes by searching scales instead of growing templates.

His lab note adds the cost accounting real systems need: each pyramid level multiplies the work, so his pipeline searches coarse-to-fine — find candidate regions cheaply at low resolution, then spend the expensive fine matching only where candidates exist. The demo shows the principle; the discipline is in the budgeting.

JAH-DET-000016 — JAH negative-space discipline: what must NOT fire the kernels

The table is the experiment. Ear-pair evidence is clean: high on the cat, low everywhere else. Eye evidence is useful but confusable: the headlight pair scores like eyes, because at the level of 'two dark-or-bright blobs', headlights and eyes genuinely rhyme. JAH's pipeline design absorbs this instead of denying it — eyes vote, but ears outvote them, and night scenes require ear confirmation.

This is the Signature method stated as procedure: propose a part, build the distractor set, run everything, publish the full table including the misses. A detector whose failures are documented is engineering; a detector whose failures are hidden is marketing.

JAH-DET-000018 — JAH kernel-combination algebra experiment

The cascade is the only treatment that strongly separates the crisp ear tip from the soft distractor: Sobel alone sees both as edges, the junction kernel alone sees both as brightness junctions, but the cascade demands *junctions of real edges* — a stricter, more anatomical property. That strictness-by-composition is JAH's algebra in one line.

His lab note generalizes: every stage of his pipeline is a composition, and he tests compositions the way chemists test compounds — not by theory but by margin over the parts. # JAH experimental ear-junction kernel (Signature-original)
K = [[-1,-1,2],[-1,2,-1],[2,-1,-1]]
def response(img):
    return sum(img[y][x]*K[y][x] for y in range(3) for x in range(3))
def place(base, pts, v=10):
    im=[row[:] for row in base]
    for (y,x) in pts: im[y][x]=v
    return im
flat=[[0]*7 for _ in range(7)]
def window(im,cy,cx): return [row[cx-1:cx+2] for row in im[cy-1:cy+2]]
vjunc = place(flat, [(1,5),(2,4),(3,3),(2,2),(1,1)])       # V junction (ear-tip-like)
vedge = place(flat, [(1,3),(2,3),(3,3),(4,3),(5,3)])       # straight vertical edge
for name, im, at in (("V-junction",vjunc,(2,3)),("vertical edge",vedge,(3,3)),("flat field",flat,(3,3))):
    print("%-14s kernel response = %d" % (name, response(window(im,*at))))
print("Signature experiment: the kernel prefers the junction it was designed for.")
