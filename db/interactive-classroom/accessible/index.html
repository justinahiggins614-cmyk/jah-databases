    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    The interactive classroom is a public room for learning together: live polls, a hand raised without speaking aloud, a shared board for class notes, small group tables, and a library everyone can open. The classroom must offer a poll with four plain choices, show the result as soon as the votes are in, and keep the lesson moving after the poll. Without a live poll, the teacher asks a question aloud and hears only the loudest learner, while the rest of the room stays silent.
