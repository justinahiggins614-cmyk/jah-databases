Mixed Reality Collaboration Database

Slug: mixed-reality-collaboration · Record kind: mixed reality collaboration record · Records: 24 · Version: 1.0.0, 2026-11-18 · Status: Live.

AI: JAH Mixed Reality Collaboration Librarian

Descriptions

Working together in mixed reality, where real and virtual things share one room: shared rooms, anchors, avatars, shared objects, voice and gesture, permissions, recording, and cross-device joining — a full specification for each part, documented from public knowledge and established practice.

Math Proof

Every record in this database carries a math proof in plain words: its figures are added twice, in two different orders, and the two SHA-256 fingerprints must match. The arithmetic is machine-checked by each record's demo; the scientific claim is stated, not machine-checked.

Science Proof

Every record rests on established practice, not on a new discovery: organized work, written procedures, checked steps, and filed records. The public edition documents the specification from public knowledge; the Signature edition holds design-studies, labeled as designs throughout.

History

This database is Wave 1 of the Cutting-Edge Website Types Catalog 1 (another AI's words as pasted by Manon 2026-11-18 ~02:11 EST, source unconfirmed). It covers Catalog 1 type #27. Built 2026-11-18; published live 2026-11-23.

Workflow

Each record follows the same workflow: a problem, a worked solution in ordered steps, an answer with named checks, key figures, a demo that recomputes the figures, and a program that recomputes the same result. Open any record below for its full workflow.

Generator

The generator for this database is a seeded boundless generator (gen-mixed-reality-collaboration.js in the wave1 package): the same seed always emits the same record, up to 1,000,000,000 scales per file, generated on demand by the file AI — not stored files. Gates: emitted record_kind equals the manifest record kind; slug form; identifier prefix; hard stop 1,000,000,000; generator prefix; JCC code round-trip.

AI

The specialist AI for this database is JAH Mixed Reality Collaboration Librarian. Download both AIs with their specifications: Database AI specification (JSON), Generator AI specification (JSON).

Demo

Each record has a working demo: a small program that recomputes the record's figures twice and prints both SHA-256 digests. Open any record below and run its demo.js with Node; the output was verified byte-identical at build time.

Sources and Citations

Every record cites at least two sources, each fetched and read on 2026-11-18, with web address, resource identifier, and retrieval date. The full source list is in each record. The database's own data file is downloadable below.
