# Model Compression Tool Database — files (model-compression-tool-signature)

- `demo-model-compression-tool-signature.py` — runnable demo program (run with `python3 demo-model-compression-tool-signature.py`).
- `model-compression-tool-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/model-compression-tool-signature/index.jsonl.gz` (24 records).
- The generator is `gen-model-compression-tool-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
