# Product Configurator Database — files (product-configurator-signature)

- `demo-product-configurator-signature.py` — runnable demo program (run with `python3 demo-product-configurator-signature.py`).
- `product-configurator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/product-configurator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-product-configurator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
