# Reading Comprehension Tester Database — files (reading-comprehension-tester)

- `demo-reading-comprehension-tester.py` — runnable demo program (run with `python3 demo-reading-comprehension-tester.py`).
- `reading-comprehension-tester-sample.txt` — a plain-text sample of the database.
- The full database is `data/reading-comprehension-tester/index.jsonl.gz` (24 records).
- The generator is `gen-reading-comprehension-tester.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
