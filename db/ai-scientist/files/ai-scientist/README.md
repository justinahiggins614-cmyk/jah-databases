# AI Scientist Database — files (ai-scientist)

- `demo-ai-scientist.py` — runnable demo program (run with `python3 demo-ai-scientist.py`).
- `ai-scientist-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-scientist/index.jsonl.gz` (24 records).
- The generator is `gen-ai-scientist.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
