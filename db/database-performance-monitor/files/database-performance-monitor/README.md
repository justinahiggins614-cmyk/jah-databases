# Database Performance Monitor Database — files (database-performance-monitor)

- `demo-database-performance-monitor.py` — runnable demo program (run with `python3 demo-database-performance-monitor.py`).
- `database-performance-monitor-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-performance-monitor/index.jsonl.gz` (24 records).
- The generator is `gen-database-performance-monitor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
