Website Builder: Overview and Purpose

JAH-WBLD-000001 — website builder record

The Website Builder exists to do one job well, and this record states that job in full: what the program does, who it does it for, and what counts as done. Everything else in the program — every screen, every interface call, every test — is judged against this statement. If a feature does not serve the stated purpose, it does not belong in the program. This record is the anchor the other twenty-three records in this edition refer back to. In this public edition the program offers 8 capabilities (building a complete website from a title and sections (1); a front door with hero, title, status line, and tab bar (2); one tab page per major section, catalog tab last (3); network navigation at the bottom of every page (4); an accessible plain version of every page (5); reusable templates for new sites (6); an API other programs use to build websites (7); a plain-text build report (8)), 6 interfaces (Site form — title, description, and sections, in plain words; Template picker — choose a reusable site design; Live preview — see the site as it will look, before saving; Build report — pages built, links checked, validation result; Builder API — machine-readable website building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (title — the site's title; sections — the tab pages, in order, catalog last; pages — the pages built; template — the reusable design used; navigation — the network navigation at the bottom of every page; accessible — the plain version of every page; links_checked — the link check result; validation — the page check result). This record is number 1 of 24 in the public edition of the Website Builder database pair, and it specifies the overview and purpose topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
