Website Builder: Who Uses It and Why

JAH-WBLD-000002 — website builder record

The Website Builder serves people who need its job done without learning the machinery underneath: a user with a question, a builder with a specification, and a program that needs the same job done by machine. Each of these users arrives differently — by screen, by command, or by interface call — and each must get the same correct answer. This record names those users, what each one brings, and what each one must receive before the program counts as working for them. In this public edition the program offers 8 capabilities (building a complete website from a title and sections (1); a front door with hero, title, status line, and tab bar (2); one tab page per major section, catalog tab last (3); network navigation at the bottom of every page (4); an accessible plain version of every page (5); reusable templates for new sites (6); an API other programs use to build websites (7); a plain-text build report (8)), 6 interfaces (Site form — title, description, and sections, in plain words; Template picker — choose a reusable site design; Live preview — see the site as it will look, before saving; Build report — pages built, links checked, validation result; Builder API — machine-readable website building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (title — the site's title; sections — the tab pages, in order, catalog last; pages — the pages built; template — the reusable design used; navigation — the network navigation at the bottom of every page; accessible — the plain version of every page; links_checked — the link check result; validation — the page check result). This record is number 2 of 24 in the public edition of the Website Builder database pair, and it specifies the who uses it and why topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
