Website Builder: Access Control and Permissions

JAH-WBLD-000010 — website builder record

The Website Builder controls who may do what: reading is open where the data is public, and every action that changes, builds, or publishes anything requires the right permission — and the permission is checked before the action, not after. Denied actions are refused with a clear message and written to the log. This record names the permission levels, what each one may do, and the defensive rule that governs them all: the program never grants access it was not asked to grant. In this public edition the program offers 8 capabilities (building a complete website from a title and sections (1); a front door with hero, title, status line, and tab bar (2); one tab page per major section, catalog tab last (3); network navigation at the bottom of every page (4); an accessible plain version of every page (5); reusable templates for new sites (6); an API other programs use to build websites (7); a plain-text build report (8)), 6 interfaces (Site form — title, description, and sections, in plain words; Template picker — choose a reusable site design; Live preview — see the site as it will look, before saving; Build report — pages built, links checked, validation result; Builder API — machine-readable website building for other programs; Plain-text mode — the build report as readable plain text), and 8 data fields (title — the site's title; sections — the tab pages, in order, catalog last; pages — the pages built; template — the reusable design used; navigation — the network navigation at the bottom of every page; accessible — the plain version of every page; links_checked — the link check result; validation — the page check result). This record is number 10 of 24 in the public edition of the Website Builder database pair, and it specifies the access control and permissions topic in full — what it is, how it works, what it accepts, what it returns, and how it is tested — so that a builder can build it and a tester can verify it without guessing.
