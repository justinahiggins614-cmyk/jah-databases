# Charging Station Finder Database — files (charging-station-finder-signature)

- `demo-charging-station-finder-signature.py` — runnable demo program (run with `python3 demo-charging-station-finder-signature.py`).
- `charging-station-finder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/charging-station-finder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-charging-station-finder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
