Room Measurement Tool Database (room-measurement-tool-signature)

A room measurement tool is a rule-based local demo: it measures set toy rooms, and counts the marks. The tool reads 3 rooms. The room north holds 18 marks. The largest holds 18 marks. Everything runs in this browser; no data leaves the page.
