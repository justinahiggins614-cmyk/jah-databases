# Heart Rate Tracker Database — files (heart-rate-tracker)

- `demo-heart-rate-tracker.py` — runnable demo program (run with `python3 demo-heart-rate-tracker.py`).
- `heart-rate-tracker-sample.txt` — a plain-text sample of the database.
- The full database is `data/heart-rate-tracker/index.jsonl.gz` (24 records).
- The generator is `gen-heart-rate-tracker.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
