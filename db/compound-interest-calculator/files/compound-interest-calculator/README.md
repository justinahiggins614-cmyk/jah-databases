# Compound Interest Calculator Database — files (compound-interest-calculator)

- `demo-compound-interest-calculator.py` — runnable demo program (run with `python3 demo-compound-interest-calculator.py`).
- `compound-interest-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/compound-interest-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-compound-interest-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
