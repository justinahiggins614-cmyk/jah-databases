# Audio Compressor Database — files (audio-compressor)

- `demo-audio-compressor.py` — runnable demo program (run with `python3 demo-audio-compressor.py`).
- `audio-compressor-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-compressor/index.jsonl.gz` (24 records).
- The generator is `gen-audio-compressor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
