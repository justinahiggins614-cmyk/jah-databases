Database

Record

Slug
The short web-address name of a database, in lower-case letters with hyphens.
Manifest
The master list of every database in the network, kept in data/manifest.json.
Record kind
The type name of a record: the database slug with spaces instead of hyphens.
Identifier prefix
The short code at the start of every record identifier in a database.
Generator
A program that creates new records on demand from a seed number; the same seed always gives the same record.
Seed
The starting number given to a generator.
Generator gate
A check a generator must pass before its output counts.
JCC code (JAH Condensed Code)
A short key that points to one full record: JAHDB/<slug>#<id>. A pointer, never a replacement for the full data.
