# Flight Planning Tool Database — files (flight-planning-tool)

- `demo-flight-planning-tool.py` — runnable demo program (run with `python3 demo-flight-planning-tool.py`).
- `flight-planning-tool-sample.txt` — a plain-text sample of the database.
- The full database is `data/flight-planning-tool/index.jsonl.gz` (24 records).
- The generator is `gen-flight-planning-tool.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
