1. Description

A midi editor lists note events with tick, note, loudness and length, and lets each be changed. Type the events, press Edit, and read the list. A track holds 3 events. A note on at tick 0: note 60, loudness 100, length 120. Moving up an octave gives 72, 76 and 79. Everything runs in this browser; no data leaves the page.
