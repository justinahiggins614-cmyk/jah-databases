A memory game begins with a grid of face-down cards, and the player must remember where each picture is: turn two cards, find a pair, and keep it, or turn two that do not match and watch them turn back. A game that lays the grid out fairly, with the same number of pairs for every player, a shuffle that is fair every time, and a grid that fits the player's level, turns remembering into playing: the player studies the grid, turns the cards, and the pairs are found by memory, not by luck. Worked example: a grid of eight cards holds four pairs, shuffled fairly, and the player turns two cards, finds a pair, and keeps it.

History

A memory game with endless grids is a lonely grind: each player plays alone, the grids never end, and there is nothing to talk about afterward, because no two players played the same grid. A daily challenge that asks one grid a day, the same grid for everyone, turns playing into a shared habit: every morning there is one grid, everyone plays it, and afterward everyone can talk about it, because they all played the same one. Worked example: on Monday the grid holds four pairs, everyone plays it, and in the evening the solution with the fewest moves is shown.

History

Field guide indexes descend from the tables of contents of books and the catalogues of libraries, where a list of what a collection holds came first and the collection itself came second; this index is the same old habit, written for a database of designs.

Proposed solution

List every record by number, in ladder order; Give each record a one-line account of what it covers; Mark each record simple, compounded, or complex; Point simple readers to records 1 to 8, and advanced readers to records 17 to 23; Keep the index beside the records, never apart from them.

Dependencies

The twenty-three records themselves, listed in order; the ladder ranks simple, compounded, and complex; agreement that an index lists, and never replaces, the records it points to.

Feasibility

buildable-now — An index is a list with one-line accounts, written with tools that exist today; only care in listing stands in the way.
