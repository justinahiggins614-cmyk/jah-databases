Database Splitter Database (database-splitter)

A database splitter is a rule-based local demo: it splits set toy parts, and counts the marks. The splitter reads 3 parts. The part alpha holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
