# Database Splitter Database — files (database-splitter)

- `demo-database-splitter.py` — runnable demo program (run with `python3 demo-database-splitter.py`).
- `database-splitter-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-splitter/index.jsonl.gz` (24 records).
- The generator is `gen-database-splitter.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
