Workflow Manager Database (workflow-manager-signature)

A workflow manager moves tasks through steps, from start to done. Add tasks, move them forward a step at a time, count them by step, and watch the report. Everything runs in this browser and saves locally; no data leaves the page.

Worked example: A workflow of 4 steps moves a task from start to done.
