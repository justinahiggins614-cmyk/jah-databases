# Flooring Calculator Database — files (flooring-calculator)

- `demo-flooring-calculator.py` — runnable demo program (run with `python3 demo-flooring-calculator.py`).
- `flooring-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/flooring-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-flooring-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
