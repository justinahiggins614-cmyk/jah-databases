The Limit Calculator Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. A limit calculator finds what a function nears: pick a function, press Calculate, and watch the values close in from both sides. As x nears 2, (x squared - 4) / (x - 2) nears 3.9 from below and 4.1 from above: the limit is 4. Everything runs in this browser; no data leaves the page.
