Record identifier: JAH-CCLMECH-000001. Ladder rank: 1 of 24. Subject: kinematics and the description of motion.

Kinematics is the description of motion without asking what causes it: position, velocity, and acceleration as functions of time, in one, two, and three dimensions. Velocity is the rate of change of position; acceleration is the rate of change of velocity. Velocity is the derivative of position with respect to time. Acceleration is the derivative of velocity with respect to time. In two dimensions, motion can be split into independent horizontal and vertical parts. Record identifier: JAH-CCLMECH-000002. Ladder rank: 2 of 24. Subject: Newton's laws of motion.

Classical Mechanics: Work, Energy, and Power

Record identifier: JAH-CCLMECH-000003. Ladder rank: 3 of 24. Subject: work, energy, and power.

Kinetic energy is (1/2) m v squared; gravitational potential energy is m g h. In a closed system with conservative forces, total mechanical energy is conserved. Classical Mechanics: Oscillations and the Harmonic Oscillator

Record identifier: JAH-CCLMECH-000007. Ladder rank: 7 of 24. Subject: oscillations and the harmonic oscillator.

Damping and driving produce resonance. The equation is x double-dot = -(k/m) x, with omega = sqrt(k/m). The period is 2 pi sqrt(m/k), independent of amplitude. Driving at the natural frequency produces resonance, with large amplitude. Classical Mechanics: Lagrangian Mechanics

Record identifier: JAH-CCLMECH-000009. Ladder rank: 9 of 24. Subject: Lagrangian mechanics.

Lagrangian mechanics reformulates dynamics in terms of energy: the Lagrangian L is kinetic minus potential energy, and the motion follows the Euler-Lagrange equations, one per generalised coordinate. It handles constraints naturally and reveals conservation laws through symmetry (Noether's theorem). L = T - V, kinetic minus potential energy. The Euler-Lagrange equation is d/dt (dL/d q-dot) - dL/dq = 0. A symmetry of L gives a conserved quantity (Noether's theorem). Classical Mechanics: Hamiltonian Mechanics and Phase Space

Record identifier: JAH-CCLMECH-000010. Ladder rank: 10 of 24. Subject: Hamiltonian mechanics and phase space.

Hamiltonian mechanics describes motion in phase space, the space of positions and momenta: the Hamiltonian H is the total energy, and the motion follows Hamilton's equations, q-dot = dH/dp and p-dot = -dH/dq. The three-body problem asks for the motion of three masses under mutual gravitation. Unlike the two-body problem, it has no general closed-form solution: the motion is chaotic, and only special solutions (such as Lagrange's triangular points) are known exactly. The five Lagrange points are positions where a small body can orbit with two larger ones. The two-body problem is solvable; the three-body problem is not, in general. The motion is chaotic: small changes grow exponentially. The five Lagrange points (L1 to L5) are equilibrium positions in the rotating frame. Classical Mechanics: Damped and Driven Oscillations

Record identifier: JAH-CCLMECH-000019. Ladder rank: 19 of 24. Subject: damped and driven oscillations.

Real oscillators lose energy to friction (damping) and are often driven by a periodic force. Light damping gives a slowly decaying oscillation; critical damping returns to equilibrium fastest without oscillating; heavy damping creeps back. Driving at the natural frequency gives resonance, with amplitude limited only by damping. Damping adds a force -b v; the amplitude decays as e^(-(b/2m) t). Critical damping is b squared = 4 m k, the fastest non-oscillating return. Resonance: driving at the natural frequency maximises the amplitude. // Edition demo for the Classical Mechanics Database (college-classical-mechanics).
// One summary line per record (the same computation as each record's
// own demo, ported from Python), then a determinism check: the lines
// are hashed twice and the two digests must match.
'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
