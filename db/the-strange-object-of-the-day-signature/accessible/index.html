The Signature The Strange Object of the Day Database

Accessible version: plain text, no scripts, no sign-in, free forever. The strange object of the day shows one odd object each day, with a picture, plain clues, and a written story of what it might be: a tool with no name, a shape with no clear use, a thing that looks like nothing else. Every object is a clearly labeled design study of a generic kind of thing, and the site never claims a pictured object is a real product or a real antique.

Twenty-four full records, ordered simple to compounded to complex.
