Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A friendship website: a visitor lists a few interests in plain words, the site suggests public groups and public gatherings built around those interests, and friendship grows from shared activity in the open, never from private contact. There are no private messages anywhere on the site: every conversation is public, every group has written rules, and every moderation action is written in a public log. Profiles show interests and the groups a person has joined, never personal data, never a home address, never a phone number. This record covers Finding Friends by Shared Interest.

Finding friends as an adult is hard, because the places where friendships used to form, like school and the neighborhood, are behind most people, and the open web offers strangers without any shared ground. Friendship by shared interest fixes this by starting from what two people both love, so the first conversation has a subject before it has a greeting. Without a shared interest to start from, strangers must invent small talk from nothing, and most of them give up before the friendship begins.

Worked example, Signature design: the same friendship circle is rebuilt from the Signature pattern, so finding friends by shared interest runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
