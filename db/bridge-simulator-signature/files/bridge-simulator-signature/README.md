# Bridge Simulator Database — files (bridge-simulator-signature)

- `demo-bridge-simulator-signature.py` — runnable demo program (run with `python3 demo-bridge-simulator-signature.py`).
- `bridge-simulator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/bridge-simulator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-bridge-simulator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
