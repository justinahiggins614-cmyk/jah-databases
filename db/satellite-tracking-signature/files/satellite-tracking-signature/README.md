# Satellite Tracking Database — files (satellite-tracking-signature)

- `demo-satellite-tracking-signature.py` — runnable demo program (run with `python3 demo-satellite-tracking-signature.py`).
- `satellite-tracking-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/satellite-tracking-signature/index.jsonl.gz` (24 records).
- The generator is `gen-satellite-tracking-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
