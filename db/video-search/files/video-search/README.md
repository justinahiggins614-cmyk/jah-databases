# Video Search Database — files (video-search)

- `demo-video-search.py` — runnable demo program (run with `python3 demo-video-search.py`).
- `video-search-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-search/index.jsonl.gz` (24 records).
- The generator is `gen-video-search.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
