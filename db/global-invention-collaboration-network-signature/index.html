Section 1: Description and history

The global invention collaboration network gathers makers from many towns around one shared project, a water pump, a windmill, a footbridge, with each maker's part written down in plain words. Every project is a design study of a generic shared build, never a real build and never a claim about real makers. Two workshops in two towns building one thing together is an old habit: a letter with a sketch, a part sent by cart, a note of who did which piece. The website form grows out of that habit, adding a plain project for each shared build and a list anyone can join.
