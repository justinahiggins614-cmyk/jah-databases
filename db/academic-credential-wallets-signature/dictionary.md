# Dictionary entries — The Academic Credential Wallets Database

Key terms of this database, defined in plain words.

## academic credential wallet

The recorded store in which a holder gathers academic credentials, so that each award, its issuer, and its proof can be shown from one place.

## credential

A written statement that a person has completed a course or holds an award, kept in the record with its issuer and its date, so that the award can be proved from the paper.

## holder

The person whose credentials a wallet holds, recorded under a name and a number so that every paper for that holder can be matched to the same person.

## issuer

The university, college, or body that awarded a credential, named in the record with the credential, so that where the award came from can be read plainly.

## proof

The written evidence that a credential was truly awarded, kept in the record with the credential, so that the award can be proved from the paper.

## wallet

The kept store of a holder credentials, held in the record with the holder, so that the whole learning of a person can be shown from one place.

## entry

A single credential placed in a wallet, kept in the record with the credential and the date it was added, so that the adding can be proved from the paper.

## share

The written record of a credential shown from a wallet to a named reader, kept with the credential and the date, so that the showing can be followed.

## expiry

The stated last day on which a credential remains in force, written in the record with the credential, so that the life of the award can be read plainly.

## revocation

The written ending of a credential by its issuer, kept in the record with its date and its grounds, so that the ending can be proved from the paper.

## digital identity

The recorded set of facts by which a holder is known in a digital store, kept in the record so that the holder can be matched to the wallet.

## ledger

The ordered list of entries in a credential wallet, kept in date order, so that every credential in the wallet can be found by its place in the list.
