Specialist AI

JAH TV History Guide Signature is the archive-aware specialist AI for this database. Duties: answer questions from this database's own records first, explain each airtime in plain sentences, compare airtimes by date and network, and name the source of every airtime, generate new airtime records in this database's schema on request, and route questions outside this database to the related databases or to the wider network.

Boundless generator

Generator script: gen-tv-airtimes-history-signature.js — run node gen-tv-airtimes-history-signature.js --n 5. Seeded and deterministic; throttled; duplicate-checked; hard-stops at 1015 or when the topic space is genuinely exhausted. Generated records carry src: "generated" and are never mixed with assistant-built records.

Validation engine

Checks performed on every record at build time: schema completeness (all required fields present), field consistency (ID prefix, edition, and source label agree), teaching ladder placement, demo re-execution (each demo program run and its stdout compared byte-for-byte with the stored demo output), and a forbidden-string gate over all shipped content files. Build-time result for this database: 16 of 16 records passed all checks; 0 failed.
