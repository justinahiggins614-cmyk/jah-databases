# Dictionary entries — The Homework Assistance Database

Key terms of this database, defined in plain words.

## homework assistance

The recorded help given to a learner working on homework, so that the task, the subject, and the answer given can be read and used with their terms in plain view.

## homework

Work set by a teacher to be done by a learner outside the lesson, kept in the record with its subject and its due date, so that what was set can be read plainly.

## tutor

A person who helps a learner with homework one to one, named in the record with the learner, so that who gave the help can be read plainly.

## learner

A person who asks for help with homework, recorded under a name and a number so that every paper for that learner can be matched to the same person.

## subject

A named branch of study, such as arithmetic or reading, written in the record so that the homework can be matched to the lesson it practises.

## task

A single piece of homework set for a learner, kept in the record with its subject and its due date, so that what was set can be read plainly.

## answer

The written account of how a homework task was worked through, kept in the record with the task, so that the help given can be followed step by step.

## study skill

A named way of working, such as planning time or taking notes, written in the record so that the help given can be matched to the way of working it teaches.

## session

One meeting at which homework help is given, kept in the record with its date and its learner, so that the meeting can be followed step by step.

## exercise book

The ruled book in which a learner writes homework, kept in the record with the learner, so that the written work can be matched to the learner who wrote it.

## mark

The recorded result given for a piece of homework, kept with the learner, the task, and the date, so that the result can be proved from the paper.

## assistance letter

The written note sent after homework assistance is given, naming the learner, the tasks discussed, and the answers given, so that the help can be proved from the paper.
