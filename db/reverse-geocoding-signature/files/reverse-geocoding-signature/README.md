# Reverse Geocoding Database — files (reverse-geocoding-signature)

- `demo-reverse-geocoding-signature.py` — runnable demo program (run with `python3 demo-reverse-geocoding-signature.py`).
- `reverse-geocoding-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/reverse-geocoding-signature/index.jsonl.gz` (24 records).
- The generator is `gen-reverse-geocoding-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
