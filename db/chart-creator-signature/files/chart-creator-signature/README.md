# Chart Creator Database — files (chart-creator-signature)

- `demo-chart-creator-signature.py` — runnable demo program (run with `python3 demo-chart-creator-signature.py`).
- `chart-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/chart-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-chart-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
