# Dictionary entries — The Infinite Vending Machine Database

Key terms of this database, defined in plain words.

## vending machine

A box that sells things without a shopkeeper: you choose, you pay, and the machine hands you the thing.

## shelf

The row inside a machine where one kind of thing waits to be chosen; the infinite machine's shelf has no end.

## coil

The spiral that holds a row of snacks and turns once to drop one item down to the collection tray.

## collection tray

The opening at the bottom of a machine where the thing you bought lands, ready to be picked up.

## stock

The things a machine holds right now, counted by kind, so the machine knows what it can still sell.

## surprise selection

A choice the machine makes for you when you ask for a surprise, drawn from its whole shelf.

## free

Costing nothing: in this machine every request is free, and no payment of any kind is taken or handled.

## request

What a visitor asks the machine for, in words, which the machine answers with the thing or the nearest thing.

## menu

The list of what a machine offers, shown so a visitor can choose without guessing.

## restocking

Filling a machine's shelves again, counted and recorded, so the machine never promises what it does not hold.

## design study

A careful design of something imagined, labeled as a design, never presented as a real machine that exists.

## ledger

The machine's own written record of every request and every answer, kept in order.
