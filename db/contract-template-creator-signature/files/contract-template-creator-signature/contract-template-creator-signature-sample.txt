Contract Template Creator Database (contract-template-creator-signature)

A contract template creator is a rule-based local demo: it writes set toy contracts from set toy clauses, and counts the clauses and the words. The creator writes 3 clauses. The clause is called pay. The clauses average 20 words. Everything runs in this browser; no data leaves the page.
