# Contract Template Creator Database — files (contract-template-creator-signature)

- `demo-contract-template-creator-signature.py` — runnable demo program (run with `python3 demo-contract-template-creator-signature.py`).
- `contract-template-creator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/contract-template-creator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-contract-template-creator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
