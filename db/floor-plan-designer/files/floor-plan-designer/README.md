# Floor Plan Designer Database — files (floor-plan-designer)

- `demo-floor-plan-designer.py` — runnable demo program (run with `python3 demo-floor-plan-designer.py`).
- `floor-plan-designer-sample.txt` — a plain-text sample of the database.
- The full database is `data/floor-plan-designer/index.jsonl.gz` (24 records).
- The generator is `gen-floor-plan-designer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
