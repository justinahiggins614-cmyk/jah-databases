# Construction Progress Tracker Database — files (construction-progress-tracker-signature)

- `demo-construction-progress-tracker-signature.py` — runnable demo program (run with `python3 demo-construction-progress-tracker-signature.py`).
- `construction-progress-tracker-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/construction-progress-tracker-signature/index.jsonl.gz` (24 records).
- The generator is `gen-construction-progress-tracker-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
