# Secure File Sharing Database — files (secure-file-sharing)

- `demo-secure-file-sharing.py` — runnable demo program (run with `python3 demo-secure-file-sharing.py`).
- `secure-file-sharing-sample.txt` — a plain-text sample of the database.
- The full database is `data/secure-file-sharing/index.jsonl.gz` (24 records).
- The generator is `gen-secure-file-sharing.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
