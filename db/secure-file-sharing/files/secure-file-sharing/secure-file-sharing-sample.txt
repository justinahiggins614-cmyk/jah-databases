Secure File Sharing Database (secure-file-sharing)

Secure file sharing is a defensive local demo: it lists set toy files, adds the bytes, and counts the share link. No file leaves this page: sharing is BLOCKED. The share holds 2 files. The file notes.txt holds 120 bytes. The files average 460 bytes. Everything runs in this browser; no data leaves the page.
