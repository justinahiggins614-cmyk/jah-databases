A Riddle Duel Across the Table Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A puzzle arena website: two visitors join the same puzzle, such as a riddle duel or a number grid race, and the site gives both the same clues, the same time, and the same scoring, with a plain winner at the end. Every puzzle is an original generic puzzle written for this database, never copied from any game, and the arena names no real game. This record covers A Riddle Duel Across the Table.

A riddle duel across the table gives two players the same riddle, the same time, and the same scoring, with a plain winner at the end. The arena must give both players the same riddle at the same moment, so neither player gains by seeing it first. Without the same start, one player gains an unfair head start, and a head start is a poor way to win a duel. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Worked example: in a website built this way, a riddle duel across the table runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
