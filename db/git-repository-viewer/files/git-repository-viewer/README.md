# Git Repository Viewer Database — files (git-repository-viewer)

- `demo-git-repository-viewer.py` — runnable demo program (run with `python3 demo-git-repository-viewer.py`).
- `git-repository-viewer-sample.txt` — a plain-text sample of the database.
- The full database is `data/git-repository-viewer/index.jsonl.gz` (24 records).
- The generator is `gen-git-repository-viewer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
