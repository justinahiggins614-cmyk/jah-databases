About this data base

Archive
This database's space-mapping archive (JAH-MAP records), preserved as structured, searchable data.
Record schema
id · name · kind · blurb · rooms[{x,y,w,h,label}] · doors[{x,y}]
Generator
jahdb-space-1.0 — deterministic (mulberry32). Builds each map as a left-to-right room tiling from a real archive layout; an independent verifier re-checks that rooms tile contiguously, doors sit on room boundaries, and the blurb names every room.
Drift control
Every generated record is checked against an archive sample for duplicate map names and re-validated by the independent checker.
Cross-database
The generator can borrow a numeric theme from any of the other 36 databases when you tick the box.
AI
JAH Space Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
