# Building Layout Designer Database — files (building-layout-designer-signature)

- `demo-building-layout-designer-signature.py` — runnable demo program (run with `python3 demo-building-layout-designer-signature.py`).
- `building-layout-designer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/building-layout-designer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-building-layout-designer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
