# Scientific Graph Generator Database — files (scientific-graph-generator-signature)

- `demo-scientific-graph-generator-signature.py` — runnable demo program (run with `python3 demo-scientific-graph-generator-signature.py`).
- `scientific-graph-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/scientific-graph-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-scientific-graph-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
