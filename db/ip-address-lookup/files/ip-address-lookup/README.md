# IP Address Lookup Database — files (ip-address-lookup)

- `demo-ip-address-lookup.py` — runnable demo program (run with `python3 demo-ip-address-lookup.py`).
- `ip-address-lookup-sample.txt` — a plain-text sample of the database.
- The full database is `data/ip-address-lookup/index.jsonl.gz` (24 records).
- The generator is `gen-ip-address-lookup.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
