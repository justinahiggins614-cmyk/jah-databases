# Database Record Scoring Database — files (database-record-scoring-signature)

- `demo-database-record-scoring-signature.py` — runnable demo program (run with `python3 demo-database-record-scoring-signature.py`).
- `database-record-scoring-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-record-scoring-signature/index.jsonl.gz` (24 records).
- The generator is `gen-database-record-scoring-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
