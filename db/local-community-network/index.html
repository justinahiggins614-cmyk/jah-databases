The board needs to be public, so any neighbor can read it without signing in, and it needs a date on every notice, so an old notice does not pretend to be new. Finding Neighbors Who Share One Interest Record 5 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A neighborhood website: a public board where neighbors post notices, list local events, and run a lost-and-found. Every post is public; there are no private messages anywhere on the network. Every board has written rules, and every moderation action is written in a public log that any neighbor can read. This record covers Finding Neighbors Who Share One Interest.

Finding neighbors who share one interest is the heart of the network: a visitor names an interest and the network shows the public groups and public posts about it, with no personal data shown to anyone.
