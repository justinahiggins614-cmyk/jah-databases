Code Validator Database (code-validator-signature)

A code validator reads code and finds its errors: unbalanced brackets, wrong indents, bad names and unknown keywords. The demo on this page checks code in the browser, with no server and no connection. Everything runs in this browser; no data leaves the page.

Worked example: A validator checks 1 file: 2 brackets open, 2 close, 0 errors
