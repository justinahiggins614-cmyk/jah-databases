# AI Engineer Database — files (ai-engineer-signature)

- `demo-ai-engineer-signature.py` — runnable demo program (run with `python3 demo-ai-engineer-signature.py`).
- `ai-engineer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-engineer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ai-engineer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
