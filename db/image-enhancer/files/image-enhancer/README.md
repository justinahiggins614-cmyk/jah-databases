# Image Enhancer Database — files (image-enhancer)

- `demo-image-enhancer.py` — runnable demo program (run with `python3 demo-image-enhancer.py`).
- `image-enhancer-sample.txt` — a plain-text sample of the database.
- The full database is `data/image-enhancer/index.jsonl.gz` (24 records).
- The generator is `gen-image-enhancer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
