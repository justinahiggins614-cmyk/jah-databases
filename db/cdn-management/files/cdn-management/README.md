# CDN Management Database — files (cdn-management)

- `demo-cdn-management.py` — runnable demo program (run with `python3 demo-cdn-management.py`).
- `cdn-management-sample.txt` — a plain-text sample of the database.
- The full database is `data/cdn-management/index.jsonl.gz` (24 records).
- The generator is `gen-cdn-management.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
