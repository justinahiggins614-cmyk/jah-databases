  1. A GPA From Letter Grades

    Record 1 of 24. simple. Feasibility: buildable-now. The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

    The GPA calculator turns letter grades and credit hours into a plain estimate of a grade point average, with every figure shown and every figure labeled an estimate, never an official record. A GPA from letter grades starts with a table everyone can see: A is worth 4, B is worth 3, C is worth 2, D is worth 1, and the table must be printed beside the result. Without the table, the number means nothing, because a different table would give a different average from the same grades. The calculator turns each letter into its number, adds them with their credit hours, and shows the table, so any learner can check the average by hand. Worked example: in a website built this way, a gpa from letter grades runs as a small, complete feature a visitor can try in one sitting, with the rules of this database applied throughout.

Grade point tables grew out of letter grades, which schools have turned into numbers for generations to average them fairly.
