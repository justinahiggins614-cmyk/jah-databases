# XML Editor Database — files (xml-editor-signature)

- `demo-xml-editor-signature.py` — runnable demo program (run with `python3 demo-xml-editor-signature.py`).
- `xml-editor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/xml-editor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-xml-editor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
