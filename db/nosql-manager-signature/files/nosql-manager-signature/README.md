# NoSQL Manager Database — files (nosql-manager-signature)

- `demo-nosql-manager-signature.py` — runnable demo program (run with `python3 demo-nosql-manager-signature.py`).
- `nosql-manager-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/nosql-manager-signature/index.jsonl.gz` (24 records).
- The generator is `gen-nosql-manager-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
