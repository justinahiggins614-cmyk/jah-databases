# Noise Remover Database — files (noise-remover-signature)

- `demo-noise-remover-signature.py` — runnable demo program (run with `python3 demo-noise-remover-signature.py`).
- `noise-remover-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/noise-remover-signature/index.jsonl.gz` (24 records).
- The generator is `gen-noise-remover-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
