# Geometry Calculator Database — files (geometry-calculator)

- `demo-geometry-calculator.py` — runnable demo program (run with `python3 demo-geometry-calculator.py`).
- `geometry-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/geometry-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-geometry-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
