# Loan Calculator Database — files (loan-calculator)

- `demo-loan-calculator.py` — runnable demo program (run with `python3 demo-loan-calculator.py`).
- `loan-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/loan-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-loan-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
