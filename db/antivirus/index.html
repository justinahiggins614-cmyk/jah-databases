About this data base

Archive
This database's antivirus add-on archive (JAH-AV records): documented historic malware families plus generated defense drills across ten threat types, marching to 1,000,000.
Record schema
id · name · year · type · level · vector · solution · status · origin · note
Generator
jahdb-antivirus-1.0 — deterministic (mulberry32). Builds new drills in the archive's own family-variant scheme with the archive's per-type defense profiles; an independent verifier rebuilds the name, vector and solution from the private params. status/origin are always 'generated' with the drill disclaimer.
Drift control
Every generated drill name is checked against an archive sample — it must not duplicate a stored record name.
Cross-database
The generator can borrow a numeric theme from any of the other 36 databases when you tick the box.
AI
JAH Antivirus Librarian — archive-aware. On-device Standard 1.0, no key needed; uses the shared Signature backend automatically when configured.
