# Book Writer Database — files (book-writer-signature)

- `demo-book-writer-signature.py` — runnable demo program (run with `python3 demo-book-writer-signature.py`).
- `book-writer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/book-writer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-book-writer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
