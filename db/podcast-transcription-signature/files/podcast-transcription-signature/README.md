# Podcast Transcription Database — files (podcast-transcription-signature)

- `demo-podcast-transcription-signature.py` — runnable demo program (run with `python3 demo-podcast-transcription-signature.py`).
- `podcast-transcription-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/podcast-transcription-signature/index.jsonl.gz` (24 records).
- The generator is `gen-podcast-transcription-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
