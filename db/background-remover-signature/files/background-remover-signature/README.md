# Background Remover Database — files (background-remover-signature)

- `demo-background-remover-signature.py` — runnable demo program (run with `python3 demo-background-remover-signature.py`).
- `background-remover-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/background-remover-signature/index.jsonl.gz` (24 records).
- The generator is `gen-background-remover-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
