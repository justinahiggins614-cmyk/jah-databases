# News Search Database — files (news-search-signature)

- `demo-news-search-signature.py` — runnable demo program (run with `python3 demo-news-search-signature.py`).
- `news-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/news-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-news-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
