# Webcam Recorder Database — files (webcam-recorder-signature)

- `demo-webcam-recorder-signature.py` — runnable demo program (run with `python3 demo-webcam-recorder-signature.py`).
- `webcam-recorder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/webcam-recorder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-webcam-recorder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
