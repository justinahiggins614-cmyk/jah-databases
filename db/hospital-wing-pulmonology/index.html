Pulmonary Function Tests

PFTs measure how much air lungs hold and how fast they exhale — diagnosing asthma, COPD, and fibrosis. The FEV1/FVC ratio is the key number. Blowing hard into a tube reveals lung truth.

def pft_interpret(fev1_pct, fvc_pct, ratio):
    """Basic spirometry pattern interpreter."""
    if ratio < 0.70 and fev1_pct < 80: return "Obstructive pattern (asthma/COPD) - consider bronchodilator reversibility"
    if fvc_pct < 80 and ratio >= 0.70: return "Restrictive pattern - consider lung volumes & imaging"
    if fev1_pct >= 80 and fvc_pct >= 80: return "Normal spirometry"
    return "Mixed/indeterminate - full PFTs with DLCO recommended"
print(pft_interpret(55, 85, 0.62))
