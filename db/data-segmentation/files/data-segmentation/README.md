# Data Segmentation Database — files (data-segmentation)

- `demo-data-segmentation.py` — runnable demo program (run with `python3 demo-data-segmentation.py`).
- `data-segmentation-sample.txt` — a plain-text sample of the database.
- The full database is `data/data-segmentation/index.jsonl.gz` (24 records).
- The generator is `gen-data-segmentation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
