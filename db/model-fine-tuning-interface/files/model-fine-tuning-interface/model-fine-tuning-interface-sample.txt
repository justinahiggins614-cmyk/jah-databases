Model Fine-Tuning Interface Database (model-fine-tuning-interface)

A model fine-tuning interface is a rule-based local demo: it tunes set toy models, and counts the marks. The interface reads 3 models. The model alpha holds 27 marks. The largest holds 27 marks. Everything runs in this browser; no data leaves the page.
