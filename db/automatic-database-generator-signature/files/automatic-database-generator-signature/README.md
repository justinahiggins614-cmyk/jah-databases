# Automatic Database Generator Database — files (automatic-database-generator-signature)

- `demo-automatic-database-generator-signature.py` — runnable demo program (run with `python3 demo-automatic-database-generator-signature.py`).
- `automatic-database-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/automatic-database-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-automatic-database-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
