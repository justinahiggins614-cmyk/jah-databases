A Goal Written in Plain Words Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A goal tracking website: a visitor writes a goal in plain words, breaks it into small steps, marks each step done as it is finished, and watches a progress bar move. Goals stay private to the visitor unless the visitor chooses to share one, and every goal has a start date, a target date, and a list of steps in plain sentences. The tracker never sells a goal, never shares it without permission, and never pretends a goal is finished before its steps are done. This record covers A Goal Written in Plain Words.

A goal that is never written down is easy to forget and hard to measure, because nobody can tell whether it is done or not. Writing the goal in plain words fixes the finish line: the words say what done looks like, when it should happen, and what counts as finished. Without plain words, a goal drifts into a wish, and a wish has no steps, no date, and no moment when a person can honestly say it is done. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.
