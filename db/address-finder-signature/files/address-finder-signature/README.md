# Address Finder Database — files (address-finder-signature)

- `demo-address-finder-signature.py` — runnable demo program (run with `python3 demo-address-finder-signature.py`).
- `address-finder-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/address-finder-signature/index.jsonl.gz` (24 records).
- The generator is `gen-address-finder-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
