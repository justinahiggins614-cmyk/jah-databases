# Bulk Record Importer Database — files (bulk-record-importer)

- `demo-bulk-record-importer.py` — runnable demo program (run with `python3 demo-bulk-record-importer.py`).
- `bulk-record-importer-sample.txt` — a plain-text sample of the database.
- The full database is `data/bulk-record-importer/index.jsonl.gz` (24 records).
- The generator is `gen-bulk-record-importer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
