# Polling System Database — files (polling-system-signature)

- `demo-polling-system-signature.py` — runnable demo program (run with `python3 demo-polling-system-signature.py`).
- `polling-system-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/polling-system-signature/index.jsonl.gz` (24 records).
- The generator is `gen-polling-system-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
