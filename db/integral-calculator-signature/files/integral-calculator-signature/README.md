# Integral Calculator Database — files (integral-calculator-signature)

- `demo-integral-calculator-signature.py` — runnable demo program (run with `python3 demo-integral-calculator-signature.py`).
- `integral-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/integral-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-integral-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
