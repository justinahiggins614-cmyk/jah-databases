Database Record Ranking Database (database-record-ranking-signature)

A database record ranking is a rule-based local demo: it ranks set toy ranks, and counts the marks. The ranker reads 3 ranks. The rank alpha holds 33 marks. The largest holds 33 marks. Everything runs in this browser; no data leaves the page.
