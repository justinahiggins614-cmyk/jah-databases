A learning twin website: a visitor answers plain questions about how they learn best, and the twin offers a profile, a subject, a pace, a kind of practice, with a plain reason for each setting. Every profile is a design study, and the twin never claims to know a real learner or to judge a person's needs. This record covers A Learning Profile Asked for in Plain Words.

This record is about a learning profile asked for in plain words, one profile in a shared list of learning profiles that any reader can follow in plain words, with the subject, the pace, and the limits of the profile written out. The design for this record must state the idea in plain sentences, name what a visitor does first, and say what good looks like when it works, so a reader can judge the design without building anything. Without that plain statement, the idea stays vague, a visitor cannot tell what the design promises, and a promising idea is lost because nobody could explain it in words a newcomer can follow. A reader who can follow the design in words can also check it, and a design that can be checked is a design worth building.

Worked example, Signature design: the same learning profile is rebuilt from the Signature pattern, so a learning profile asked for in plain words runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.

History
