# Ratio Calculator Database — files (ratio-calculator-signature)

- `demo-ratio-calculator-signature.py` — runnable demo program (run with `python3 demo-ratio-calculator-signature.py`).
- `ratio-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/ratio-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-ratio-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
