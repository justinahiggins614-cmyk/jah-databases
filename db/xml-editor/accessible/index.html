The XML Editor Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. An XML editor writes elements and shows the tree they make, side by side: type the elements, press Check, and see the tree. The editor counts the elements, finds broken elements, and fixes them. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced.
