# Geographic Data Analysis Database — files (geographic-data-analysis-signature)

- `demo-geographic-data-analysis-signature.py` — runnable demo program (run with `python3 demo-geographic-data-analysis-signature.py`).
- `geographic-data-analysis-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/geographic-data-analysis-signature/index.jsonl.gz` (24 records).
- The generator is `gen-geographic-data-analysis-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
