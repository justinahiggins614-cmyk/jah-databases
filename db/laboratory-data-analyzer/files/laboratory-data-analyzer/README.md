# Laboratory Data Analyzer Database — files (laboratory-data-analyzer)

- `demo-laboratory-data-analyzer.py` — runnable demo program (run with `python3 demo-laboratory-data-analyzer.py`).
- `laboratory-data-analyzer-sample.txt` — a plain-text sample of the database.
- The full database is `data/laboratory-data-analyzer/index.jsonl.gz` (24 records).
- The generator is `gen-laboratory-data-analyzer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
