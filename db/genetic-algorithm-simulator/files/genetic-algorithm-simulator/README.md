# Genetic Algorithm Simulator Database — files (genetic-algorithm-simulator)

- `demo-genetic-algorithm-simulator.py` — runnable demo program (run with `python3 demo-genetic-algorithm-simulator.py`).
- `genetic-algorithm-simulator-sample.txt` — a plain-text sample of the database.
- The full database is `data/genetic-algorithm-simulator/index.jsonl.gz` (24 records).
- The generator is `gen-genetic-algorithm-simulator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
