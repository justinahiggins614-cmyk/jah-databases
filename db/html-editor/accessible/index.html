The HTML Editor Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. An HTML editor writes tags and shows the page they make, side by side: type the tags, press Preview, and see the page. The editor counts the tags, finds broken tags, and fixes them. Everything runs in this browser; no data leaves the page.
