# Diagram Creator Database — files (diagram-creator)

- `demo-diagram-creator.py` — runnable demo program (run with `python3 demo-diagram-creator.py`).
- `diagram-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/diagram-creator/index.jsonl.gz` (24 records).
- The generator is `gen-diagram-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
