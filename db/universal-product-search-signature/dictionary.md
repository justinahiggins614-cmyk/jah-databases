# Dictionary entries — The Universal Product Search Database

Key terms of this database, defined in plain words.

## product

A thing or service offered for sale, named and described, so that a search can match it against what a person asks for and list it with its source.

## query

The words a person types to ask for a product, kept whole in the record, so that the search can be repeated and its answers checked against the same words.

## index

The ordered list of products a search can draw from, kept current, so that a product added to the index can be found and one removed from it cannot.

## match

A product whose description fits the query by the stated rule, listed with the words that matched, so that the reason for its listing can be seen.

## ranking

The order in which matching products are listed, set by a stated rule, so that the first result is first for a reason any reader can check.

## relevance

How closely a product fits the query, measured by the stated rule, so that a closer fit ranks above a weaker one and the order can be explained.

## filter

A stated limit on a search, such as a price range or a kind, applied to every result alike, so that the listed products are only those inside the limit.

## facet

One named way of sorting results, such as by kind or by maker, kept beside the results, so that a reader can narrow the list without asking again.

## source

The place a product listing came from, named beside the listing, so that every result can be traced to the seller or catalogue that offered it.

## duplicate

The same product listed twice from different places, caught by the stated rule and listed once, so that the count of results is the count of products, not of listings.

## search log

The kept record of queries asked and answers given, with dates, so that the search can be checked, repeated, and improved from what people actually asked.

## result page

One page of listed results, numbered and kept in order, so that a reader can move through the matches without losing their place or seeing a product twice.
