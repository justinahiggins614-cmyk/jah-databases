Financial Reporting System Database (financial-reporting-system-signature)

A financial reporting system is a rule-based local demo: it reads set toy report amounts, and counts the total. The system reads 3 reports. The report q1 holds 120000. The largest holds 135000 amounts. Everything runs in this browser; no data leaves the page.
