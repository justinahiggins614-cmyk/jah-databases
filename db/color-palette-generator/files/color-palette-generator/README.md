# Color Palette Generator Database — files (color-palette-generator)

- `demo-color-palette-generator.py` — runnable demo program (run with `python3 demo-color-palette-generator.py`).
- `color-palette-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/color-palette-generator/index.jsonl.gz` (24 records).
- The generator is `gen-color-palette-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
