# Sequence Generator Database — files (sequence-generator-signature)

- `demo-sequence-generator-signature.py` — runnable demo program (run with `python3 demo-sequence-generator-signature.py`).
- `sequence-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/sequence-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-sequence-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
