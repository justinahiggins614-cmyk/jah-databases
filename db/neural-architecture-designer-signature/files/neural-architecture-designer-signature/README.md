# Neural Architecture Designer Database — files (neural-architecture-designer-signature)

- `demo-neural-architecture-designer-signature.py` — runnable demo program (run with `python3 demo-neural-architecture-designer-signature.py`).
- `neural-architecture-designer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/neural-architecture-designer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-neural-architecture-designer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
