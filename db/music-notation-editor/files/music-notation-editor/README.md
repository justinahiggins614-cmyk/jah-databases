# Music Notation Editor Database — files (music-notation-editor)

- `demo-music-notation-editor.py` — runnable demo program (run with `python3 demo-music-notation-editor.py`).
- `music-notation-editor-sample.txt` — a plain-text sample of the database.
- The full database is `data/music-notation-editor/index.jsonl.gz` (24 records).
- The generator is `gen-music-notation-editor.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
