# Homework Assistant Database — files (homework-assistant-signature)

- `demo-homework-assistant-signature.py` — runnable demo program (run with `python3 demo-homework-assistant-signature.py`).
- `homework-assistant-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/homework-assistant-signature/index.jsonl.gz` (24 records).
- The generator is `gen-homework-assistant-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
