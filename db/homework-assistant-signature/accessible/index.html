The Homework Assistant Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. A homework assistant works problems step by step with a small set of rules that run locally: type a problem, press Solve, and read the steps. It never pretends to be a live tutor. 2 + 3 = 5. 47 + 58 = 105. 1/2 + 1/4 = 3/4. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced.
