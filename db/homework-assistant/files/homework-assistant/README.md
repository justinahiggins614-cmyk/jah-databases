# Homework Assistant Database — files (homework-assistant)

- `demo-homework-assistant.py` — runnable demo program (run with `python3 demo-homework-assistant.py`).
- `homework-assistant-sample.txt` — a plain-text sample of the database.
- The full database is `data/homework-assistant/index.jsonl.gz` (24 records).
- The generator is `gen-homework-assistant.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
