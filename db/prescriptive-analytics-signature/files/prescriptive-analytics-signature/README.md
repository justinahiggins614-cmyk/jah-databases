# Prescriptive Analytics Database — files (prescriptive-analytics-signature)

- `demo-prescriptive-analytics-signature.py` — runnable demo program (run with `python3 demo-prescriptive-analytics-signature.py`).
- `prescriptive-analytics-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/prescriptive-analytics-signature/index.jsonl.gz` (24 records).
- The generator is `gen-prescriptive-analytics-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
