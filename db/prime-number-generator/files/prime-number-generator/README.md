# Prime Number Generator Database — files (prime-number-generator)

- `demo-prime-number-generator.py` — runnable demo program (run with `python3 demo-prime-number-generator.py`).
- `prime-number-generator-sample.txt` — a plain-text sample of the database.
- The full database is `data/prime-number-generator/index.jsonl.gz` (24 records).
- The generator is `gen-prime-number-generator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
