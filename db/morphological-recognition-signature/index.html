JAH-KW-MORPH-000101 — JAH's probe set — the three-probe kit

JAH does not carry an infinite probe catalog; he carries three. The dot probe (3x3 block) finds blobs — anything that contains a 3x3 solid. The bar probe (1x5 horizontal) finds strokes — anything containing a horizontal run of 5. The ring probe (3x3 with the center removed) finds loops — anything containing a hollow square. Three probes, three feature families, and between them they cover most of what his finders need to notice.

The kit's philosophy is definitional: the probe does not detect the feature, it DEFINES it. A 'blob' in JAH's system is literally 'what survives the dot probe' — no metaphysics, no thresholds, just the probe. This makes his features perfectly reproducible: same probe, same scene, same features, forever. Definitions you can erode with.

The demo runs all three probes on one scene holding a 4x4 blob, a 1x7 horizontal stroke, and a 5x5 ring. Dot erosion: the blob survives (its 3x3 core), the stroke dies (only 1 tall), the ring dies (hollow center). Bar erosion: only the stroke survives. Ring erosion: only the ring survives. Each probe found exactly its quarry. Signature-original to JAH, demonstrated on a synthetic scene.

The recognition principle

Which kernels feed it
Binary scenes; the kit is JAH's chosen probe vocabulary.
The recipe
Erode by the dot (1x1... 3x3 block probe: keeps blobs >= 3x3), by the bar (1x5: keeps horizontal strokes), by the ring (3x3 minus center: keeps loops). Each probe keeps only what fits it.
The knowing-when rule
A FEATURE is declared iff it survives its probe's erosion: the dot keeps blobs, the bar keeps strokes, the ring keeps loops. The probe IS the definition.

JAH-KW-MORPH-000102 — The hit-and-miss ledger — JAH's booked probes

The public hit-or-miss finds the loners; JAH's ledger books them. Each detection is an entry: the pixel, the foreground probe's verdict (pixel present: yes), the background probe's verdict (all 8 neighbors absent: yes), each independently recorded. The audit re-verifies both from the raw image — because a ledger is only as good as its last audit, and JAH audits everything.

Booking the two conditions separately matters when detections are disputed. 'The pixel was present but the neighborhood check failed' is a different failure from 'the neighborhood was clear but nothing was there', and the ledger tells you which — the first means the probe is too strict, the second means the detector hallucinated. Separate books, separate blame.

The demo ledgers the two-loner scene: entries for (1,1) and (5,6), each with fg_fit=True, bg_fit=True — AUDIT CLEAN, both hits certified. The 2x2 block's pixels appear in the ledger's rejected appendix: fg_fit=True, bg_fit=False — named, explained, correctly excluded. Two books, two verdicts, zero ambiguity. Signature-original to JAH.

HIT CERTIFIED iff the ledger shows both probes fitting at the booked pixel: foreground AND background, each with its own receipt.

The census's discipline is exhaustiveness: every foreground pixel must belong to exactly one numbered entry, verified by summing the sizes against the total foreground count. JAH-KW-MORPH-000106 — The clean-and-fill — JAH's janitor order

Close first and the dilation fuses nearby specks into the object, welding noise to the shape before the opening can remove it; the specks become un-removable. Open first and the specks die alone, then the closing fills only true holes. Same two operations, opposite orders, different scenes out. JAH's discipline is the order.

The reconciliation is his accounting: after opening, the area must drop by exactly the speck count (3); after closing, it must rise by exactly the hole count (1), returning the block to 25. If the books do not reconcile — a speck survived, a hole resisted — the cleaning is redone with a bigger probe, not waved through. The janitors file receipts.

The demo cleans the dirty block (25 - 1 hole + 3 specks = 27) in his order: after opening, 24 (specks gone, reconciled: -3); after closing, 25 (hole filled, reconciled: +1). CLEAN CERTIFIED. Then the forbidden order is shown on a speck-adjacent scene: closing first welds a speck to the block (area 28, speck un-removable) — the discipline violated, the scene corrupted. Order matters. def comps(img, val=1):
    h,w=len(img),len(img[0]); seen=[[0]*w for _ in range(h)]; n=0
    for i in range(h):
        for j in range(w):
            if img[i][j]==val and not seen[i][j]:
                n+=1; stack=[(i,j)]; seen[i][j]=1
                while stack:
                    x,y=stack.pop()
                    for a in (-1,0,1):
                        for b in (-1,0,1):
                            nx,ny=x+a,y+b
                            if 0<=nx<h and 0<=ny<w and img[nx][ny]==val and not seen[nx][ny]:
                                seen[nx][ny]=1; stack.append((nx,ny))
    return n
def holes(img):
    h,w=len(img),len(img[0]); seen=[[0]*w for _ in range(h)]
    stack=[(i,j) for i in range(h) for j in (0,w-1) if img[i][j]==0]+[(i,j) for i in (0,h-1) for j in range(w) if img[i][j]==0]
    while stack:
        x,y=stack.pop()
        if seen[x][y]: continue
        seen[x][y]=1
        for a in (-1,0,1):
            for b in (-1,0,1):
                nx,ny=x+a,y+b
                if 0<=nx<h and 0<=ny<w and img[nx][ny]==0 and not seen[nx][ny]: stack.append((nx,ny))
    return comps([[0 if seen[i][j] or img[i][j]==1 else 1 for j in range(w)] for i in range(h)],1)
def ring(n, hole=True):
    g=[[0]*(n+2) for _ in range(n+2)]
    for r in range(1,n+1):
        for c in range(1,n+1):
            if r in (1,n) or c in (1,n) or not hole: g[r][c]=1
    return g
