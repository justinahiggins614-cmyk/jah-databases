# Batch Processing Database — files (batch-processing-signature)

- `demo-batch-processing-signature.py` — runnable demo program (run with `python3 demo-batch-processing-signature.py`).
- `batch-processing-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/batch-processing-signature/index.jsonl.gz` (24 records).
- The generator is `gen-batch-processing-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
