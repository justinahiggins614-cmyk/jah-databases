# Dictionary entries — The Universal URL Resolver Database

Key terms of this database, defined in plain words.

## address

A written location of a page or file on the web, made of a scheme, a host, and a path, read from left to right.

## resolver

A service that takes an address as given and returns the one address that truly answers, or a named failure.

## redirect

An answer that says the thing asked for now lives at a different address, naming the new address in full.

## canonical address

The one chosen address for a page that can be reached by several addresses, so the page is counted once, not many times.

## scheme

The first word of an address, such as http or https, that says which rules the rest of the address follows.

## host

The named machine in an address, the part that tells the network which computer to ask for the page.

## path

The part of an address after the host, naming the page or file wanted, step by step through the site.

## query

The part of an address after a question mark, carrying extra instructions for the page, such as a search term.

## fragment

The part of an address after a hash mark, naming a place inside a page, read by the browser and never sent to the server.

## short link

A short address that stands in for a long one, kept in a table that the resolver reads to find the long address.

## resolution failure

A named answer that an address cannot be resolved, with the reason given, such as no such host or no such page.

## ledger

The resolver's own written record of every address asked, every redirect followed, and every answer given, kept in order.
