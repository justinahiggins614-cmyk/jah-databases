Keyword Difficulty Analyzer Database (keyword-difficulty-analyzer)

A keyword difficulty analyzer is a rule-based local demo: it analyzes set toy keywords, and counts the marks. The analyzer reads 3 keywords. The keyword alpha holds 21 marks. The largest holds 21 marks. Everything runs in this browser; no data leaves the page.
