# Audio Search Database — files (audio-search-signature)

- `demo-audio-search-signature.py` — runnable demo program (run with `python3 demo-audio-search-signature.py`).
- `audio-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/audio-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-audio-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
