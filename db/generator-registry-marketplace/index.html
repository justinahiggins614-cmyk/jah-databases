Glossary: terms in plain words

Every technical term on this page is defined in plain words on first use. No acronym (a shortened form made from the first letters of a phrase) appears without its full expansion first.

database
a database is an organized collection of records that can be searched, read, and added to
record
a record is one complete entry in a database, with all of its fields filled in
slug
a slug is the short web-address name of a database, written with lower-case words joined by hyphens
manifest
the manifest is the master list of all databases in the network, with each database's slug, record kind, identifier prefix, and record count
record kind
a record kind is the label that says what sort of entry a record is, for example a universal security center record
identifier prefix
an identifier prefix is the fixed letters at the start of every record identifier in one database, for example JAH-UISC-
generator
a generator is a program that creates new records or files on demand from a starting number called a seed, instead of storing every output in advance
seed
a seed is a starting number fed to a generator so that the same seed always produces the same output
generator gate
a generator gate is a check a generator must pass before its output is accepted, for example the emitted record kind must match the manifest record kind
JCC code
a JCC code, which stands for JAH Condensed Code, is a short code that points to one exact record, written as JAHDB followed by the database slug, a hash sign, and the record identifier
API
an API, which stands for Application Programming Interface, is a defined way for one program to ask another program for data or work
MCP
an MCP, which stands for Model Context Protocol, is a plug that lets an AI (artificial intelligence) program read a database directly
AI
AI stands for artificial intelligence, which is a program that performs tasks that usually need human thought, such as answering, classifying, or generating
SQLite
SQLite is a small database engine that stores a whole database in one file on disk
SQL
SQL, which stands for Structured Query Language, is the language used to ask questions of a relational database
JSON
JSON, which stands for JavaScript Object Notation, is a plain-text format for storing structured data with named fields
HTML
HTML, which stands for HyperText Markup Language, is the language that marks up the structure of a web page
CSS
CSS, which stands for Cascading Style Sheets, is the language that describes how a web page looks
URL
a URL, which stands for Uniform Resource Locator, is the full web address of a page or file
HTTP
HTTP, which stands for HyperText Transfer Protocol, is the set of rules a browser uses to fetch a page from a web server
HTTPS
HTTPS, which stands for HyperText Transfer Protocol Secure, is HTTP sent over a protected connection
test suite
a test suite is a collection of automated tests that check whether a program behaves as specified
demo
a demo, short for demonstration, is a small working program that runs and shows its result
website interface
a website interface is the set of web pages through which a person or a program uses a system
JAH
JAH is the initials of Justin Addam Higgins, the maker name used across the network
design-study
a design-study is a Signature-made design, an invented proposal that is labeled as a design and never presented as an established fact
UNREACHABLE
UNREACHABLE is the label recorded for a resource whose fetch failed, together with the exact reason the fetch returned
sandbox
a sandbox is an isolated space where a program runs apart from the rest of the system, so what it does cannot reach outside files or programs
permission
a permission is a named right to do one thing, such as read a file or run a program, granted to one identity and checked before the action
identity
an identity is a unique name and record for one person, program, database, file, or website in the network, so it can be told apart from every other
provenance
provenance is the recorded origin of a piece of information: where it came from, who made it, and when it was fetched
lineage
lineage is the chain of earlier records and sources that a record descends from, kept so its history can be traced
registry
a registry is a catalog that lists every item of one kind, with each item's name, location, and description, so it can be found and inspected
marketplace
a marketplace is a place where listed items can be found, compared, and reused under stated rules
coordinator
a coordinator is a program that plans work, hands tasks to specialist programs, and gathers their results into one answer
specialist
a specialist is an AI (artificial intelligence) program that does one kind of work well, such as one subject or one task
build
a build is the act of turning source code and parts into a working application, package, or executable file
deployment
deployment is the act of placing a built application where it can run and be used, with its settings in place
dashboard
a dashboard is one page that shows the current state of a system: its health, its errors, and its resource use
recovery
recovery is the act of bringing a system back to working order after a failure, using saved copies and written procedures
workload
a workload is the set of jobs a system is asked to run, measured by how much processor time, memory, storage, and network they need
audit log
an audit log is a written record of who did what and when, kept so actions can be checked later
encryption
encryption is the act of scrambling data with a key so only holders of the key can read it
vulnerability
a vulnerability is a weakness in a program or system that could let something go wrong or let an unwanted action happen
schema
a schema is the declared shape of a database: its fields, their types, and how they relate
duplicate
a duplicate is a second copy of the same record or file, carrying the same content under a different name or identifier
index
an index is a list that maps each word or value to the records that contain it, so searches find them quickly
snapshot
a snapshot is a saved copy of a database or file at one moment in time, kept so an earlier state can be restored
rollback
a rollback is the act of returning a database or system to an earlier saved state after a change goes wrong
contract
a contract is a written promise between two programs about what one will send and what the other will return
dependency
a dependency is a part or library that a program needs in order to run
compatibility
compatibility is the property of two programs or parts working together on the same system without conflict
regression
a regression is a fault that appears in work that used to pass, usually after a change somewhere else
observability
observability is the property of a system that lets its inner state be seen and measured from outside, through logs, measures, and traces
consensus
consensus is agreement reached between several programs after comparing their answers and the evidence behind them
evidence
evidence is the record, test result, or source that backs up a claim, kept so the claim can be checked
