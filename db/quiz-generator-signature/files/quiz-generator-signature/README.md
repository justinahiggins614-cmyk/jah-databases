# Quiz Generator Database — files (quiz-generator-signature)

- `demo-quiz-generator-signature.py` — runnable demo program (run with `python3 demo-quiz-generator-signature.py`).
- `quiz-generator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/quiz-generator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-quiz-generator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
