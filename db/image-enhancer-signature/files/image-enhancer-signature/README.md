# Image Enhancer Database — files (image-enhancer-signature)

- `demo-image-enhancer-signature.py` — runnable demo program (run with `python3 demo-image-enhancer-signature.py`).
- `image-enhancer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/image-enhancer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-image-enhancer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
