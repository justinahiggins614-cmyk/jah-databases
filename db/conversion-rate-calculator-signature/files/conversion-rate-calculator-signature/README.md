# Conversion Rate Calculator Database — files (conversion-rate-calculator-signature)

- `demo-conversion-rate-calculator-signature.py` — runnable demo program (run with `python3 demo-conversion-rate-calculator-signature.py`).
- `conversion-rate-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/conversion-rate-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-conversion-rate-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
