# Internal Website Search Database — files (internal-website-search-signature)

- `demo-internal-website-search-signature.py` — runnable demo program (run with `python3 demo-internal-website-search-signature.py`).
- `internal-website-search-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/internal-website-search-signature/index.jsonl.gz` (24 records).
- The generator is `gen-internal-website-search-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
