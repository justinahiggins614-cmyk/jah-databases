# Dictionary entries — The Digital Address Book Database

Key terms of this database, defined in plain words.

## entry

One person's record in the book, holding their name and every address the owner keeps for them, in one place.

## contact

A person the owner can reach, named in the book with at least one working address, kept so the person can be found again.

## address

One way to reach a person, such as a street address, a phone number, or an email address, kept beside the person's name.

## group

A named set of entries, such as family or colleagues, kept so that the whole set can be found or written to at once.

## search

Finding an entry by typing part of a name, an address, or a note, and receiving every entry that matches, in order.

## duplicate

A second entry for the same person, made by mistake, which the book must find and merge so that one name means one entry.

## note

A short written reminder kept on an entry, such as where the owner met the person, read only by the owner.

## birthday

A date kept on an entry, so that the owner can remember the day, with the year kept only when the person has shared it.

## export

Copying the book's entries into a standard file, so they can be carried to another book without being typed again.

## import

Reading entries from a standard file into the book, checking each one against the entries already there, so nothing is doubled.

## card format

The standard way entries are written when they are shared between books, with each field named the same way everywhere.

## owner

The one person whose book it is, the only person who may read, change, or share its entries.
