Vector Graphics Editor Database (vector-graphics-editor-signature)

A vector graphics editor is a local demo: it draws set toy points and paths, and measures the path length and the box. The editor draws 2 points. The segment from (0, 0) to (3, 4) is 5.0 long. The drawing is 3 wide. Everything runs in this browser; no data leaves the page.
