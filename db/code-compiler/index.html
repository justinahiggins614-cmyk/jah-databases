1. Description

A code compiler reads code and turns it into a program a machine can run: type a sum, press Compile, and read the answer. Compiling '2 + 3' gives 5, and reading '2 + 3 * 4' gives 14. The compiler counts the tokens, finds broken programs, and fixes them. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Compiling '2 + 3' gives 5. Reading '2 + 3 * 4' gives 14: multiply first, then add. Doubling 21 gives 42. Adding 1, 2, 3, 4 and 5 gives 15. Two files: 5 lines and 3 lines, 8 lines in all.

3. Science proof

A code compiler works because code is tokens in order, and each step turns them into an answer: reading 'x = 2 + 3' gives 5 tokens, and compiling '2 + 3' gives 5. A broken program gives 1 error and 0 compiled lines, and fixing it gives 5 and 0 errors. That is why the local demo shows the code and the answer together, and runs 0 compilations on a server.
