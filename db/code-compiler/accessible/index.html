The Code Compiler Database (Public)

Accessible version: plain text, no scripts, no sign-in, free forever. A code compiler reads code and turns it into a program a machine can run: type a sum, press Compile, and read the answer. Compiling '2 + 3' gives 5, and reading '2 + 3 * 4' gives 14. The compiler counts the tokens, finds broken programs, and fixes them. Everything runs in this browser; no data leaves the page.

Twenty-four full records, ordered simple to working to advanced.
