1. Description

A task manager keeps every task in one list, with a due date, a priority and a state, so nothing is forgotten and the most important work is done first.

Twenty-four full records, ordered simple to working to advanced, each written in human-readable sentences and paragraphs, each carrying a history, a design, a problem, a proposed solution, dependencies, a feasibility label with its reason, a verification path, a science proof, a math proof, a formal statement, an equation, a proof sketch, a runnable demo program whose output is reproduced on the page, and two named specialist AIs.

2. Math proof

Progress is a fraction: done tasks divided by all tasks. With 9 of 12 tasks done, progress is 9 over 12, which is 0.75, or 75 percent. Sorting is an ordering: tasks sort by due date first and by priority second, so the earliest and most important task is always at the top.

3. Science proof

A task manager works because human memory is limited: writing a task down moves it from memory to a list, where it cannot be forgotten. Checking a task off gives a visible reward, and a visible reward makes the next task easier to start. That is why a list with states, dates and priorities helps people finish more work than memory alone.
