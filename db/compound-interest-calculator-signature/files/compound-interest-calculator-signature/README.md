# Compound Interest Calculator Database — files (compound-interest-calculator-signature)

- `demo-compound-interest-calculator-signature.py` — runnable demo program (run with `python3 demo-compound-interest-calculator-signature.py`).
- `compound-interest-calculator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/compound-interest-calculator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-compound-interest-calculator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
