# Survey Builder Database — files (survey-builder)

- `demo-survey-builder.py` — runnable demo program (run with `python3 demo-survey-builder.py`).
- `survey-builder-sample.txt` — a plain-text sample of the database.
- The full database is `data/survey-builder/index.jsonl.gz` (24 records).
- The generator is `gen-survey-builder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
