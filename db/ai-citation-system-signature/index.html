Signature Universal Citation Standard is the Signature edition's original treatment of Universal Citation Standard, created for this database and not copied from any outside product or standard. The Universal Citation Standard is the one citation form used across the whole network, so a citation to a database, a file, a record, a page, or a section all follow the same shape. Every citation names what it points to, where it lives, and which version it refers to, in the same order every time. A reader who learns the form once can read any citation in the network.

This Signature edition record is an original creation for this database, written to describe Universal Citation Standard in the Signature edition's own words. It is not a copy of any outside standard or product, it carries no endorsement from any outside party, and this record does not state a release date for it.

A universal standard works by fixing the fields every citation must carry — the kind of thing cited, its identifier, its location, and its version — and by fixing their order, so a citation can be parsed by a person and by a machine in the same way. A citation missing a required field is incomplete and is not published. Because the form is the same everywhere, a citation written in one database can be followed from any other.
