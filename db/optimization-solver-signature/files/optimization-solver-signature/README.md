# Optimization Solver Database — files (optimization-solver-signature)

- `demo-optimization-solver-signature.py` — runnable demo program (run with `python3 demo-optimization-solver-signature.py`).
- `optimization-solver-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/optimization-solver-signature/index.jsonl.gz` (24 records).
- The generator is `gen-optimization-solver-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
