# Comment System Database — files (comment-system-signature)

- `demo-comment-system-signature.py` — runnable demo program (run with `python3 demo-comment-system-signature.py`).
- `comment-system-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/comment-system-signature/index.jsonl.gz` (24 records).
- The generator is `gen-comment-system-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
