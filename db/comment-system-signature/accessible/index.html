The Comment System Database (Signature)

Accessible version: plain text, no scripts, no sign-in, free forever. A comment system lets readers leave notes under a page: comments, replies, likes and flags, with a moderator keeping the thread kind. The demo on this page is a LOCAL DEMO ONLY: the comments live only in this page, 0 comments are sent to a server, and real posting is BLOCKED. A real comment system needs a server, and this page honestly says so.
