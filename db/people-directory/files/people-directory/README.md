# People Directory Database — files (people-directory)

- `demo-people-directory.py` — runnable demo program (run with `python3 demo-people-directory.py`).
- `people-directory-sample.txt` — a plain-text sample of the database.
- The full database is `data/people-directory/index.jsonl.gz` (24 records).
- The generator is `gen-people-directory.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
