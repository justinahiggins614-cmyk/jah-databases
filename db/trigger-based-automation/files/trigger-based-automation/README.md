# Trigger-Based Automation Database — files (trigger-based-automation)

- `demo-trigger-based-automation.py` — runnable demo program (run with `python3 demo-trigger-based-automation.py`).
- `trigger-based-automation-sample.txt` — a plain-text sample of the database.
- The full database is `data/trigger-based-automation/index.jsonl.gz` (24 records).
- The generator is `gen-trigger-based-automation.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
