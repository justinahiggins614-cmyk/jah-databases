A Storefront for Games Made by Players Record 1 · simple

Feasibility: buildable-now The design uses only web pages, forms, and counters that exist today; only the design work stands in the way.

A marketplace website for games made by players: each listing shows honest screenshots, the rules in plain words, the number of players, and the length of a game. A free-play shelf lets a visitor try a game before committing. Payments inside the marketplace are for the game itself only; no game on the marketplace uses real-money play inside the game. Reviews are checked against fake reviews, and creators see plain sales numbers. This record covers A Storefront for Games Made by Players.

A storefront for games made by players needs to show each game honestly: what it is, how it plays, how long it takes, and how many players it needs. The storefront is the front door of the marketplace, and a visitor who cannot understand a listing in one minute will not buy it. Without an honest storefront, good games are buried under confusing listings, and the players who made them are never found. This record states the design in plain sentences so a reader can judge it on its own merits, and its demo checks the arithmetic behind the design.

Worked example: in a website built this way, a storefront for games made by players runs as a small, complete feature a visitor can try in one sitting, with the fair-play and moderation rules of this database applied throughout.
