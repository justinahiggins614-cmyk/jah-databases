# CSS Editor Database — files (css-editor-signature)

- `demo-css-editor-signature.py` — runnable demo program (run with `python3 demo-css-editor-signature.py`).
- `css-editor-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/css-editor-signature/index.jsonl.gz` (24 records).
- The generator is `gen-css-editor-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
