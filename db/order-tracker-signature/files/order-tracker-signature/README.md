# Order Tracker Database — files (order-tracker-signature)

- `demo-order-tracker-signature.py` — runnable demo program (run with `python3 demo-order-tracker-signature.py`).
- `order-tracker-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/order-tracker-signature/index.jsonl.gz` (24 records).
- The generator is `gen-order-tracker-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
