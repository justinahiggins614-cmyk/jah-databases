# Dictionary entries — The Security Operations Center Database

Key terms of this database, defined in plain words.

## security operations center

A team and its tools that watch a network day and night, read the logs, answer alerts, and follow written plans when something goes wrong.

## log

A line written by a program for every important thing it does, with the time, so that later readers can see what happened and in what order.

## alert

A message that something may be wrong, raised by a rule that watches the logs and fires when a pattern matches.

## incident

An event that harms, or may harm, a system or its people, such as a break-in, a failure, or a leak.

## triage

Sorting new alerts quickly into real trouble, false alarm, or something to watch, so the worst is handled first.

## playbook

A written plan for one kind of incident, listing the steps in order, who does each step, and how the end is judged.

## containment

Stopping an incident from spreading, by cutting off the affected part while the rest keeps working.

## forensics

The careful study of what happened after an incident, using logs and copies, without changing the evidence.

## threat intelligence

Knowledge about attackers and their methods, shared openly, so that defenders can recognize an attack they have never seen.

## false alarm

An alert raised by a rule when nothing is actually wrong, which still must be read and marked, so the rule can be improved.

## detection time

The time between an event happening and the alert that names it, which the center works to keep short.

## escalation

Passing an incident up to a person with more authority or more skill, when it is too big or too strange for the first responder.
