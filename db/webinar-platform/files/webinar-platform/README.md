# Webinar Platform Database — files (webinar-platform)

- `demo-webinar-platform.py` — runnable demo program (run with `python3 demo-webinar-platform.py`).
- `webinar-platform-sample.txt` — a plain-text sample of the database.
- The full database is `data/webinar-platform/index.jsonl.gz` (24 records).
- The generator is `gen-webinar-platform.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
