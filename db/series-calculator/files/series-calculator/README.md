# Series Calculator Database — files (series-calculator)

- `demo-series-calculator.py` — runnable demo program (run with `python3 demo-series-calculator.py`).
- `series-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/series-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-series-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
