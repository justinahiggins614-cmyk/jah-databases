Address Finder Database (address-finder)

An address finder is a rule-based local demo: it reads set toy places and their distances, and finds the nearest place. The finder reads 3 places. The place hall is 2 miles away. The largest holds 8 miles. Everything runs in this browser; no data leaves the page.
