# Address Finder Database — files (address-finder)

- `demo-address-finder.py` — runnable demo program (run with `python3 demo-address-finder.py`).
- `address-finder-sample.txt` — a plain-text sample of the database.
- The full database is `data/address-finder/index.jsonl.gz` (24 records).
- The generator is `gen-address-finder.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
