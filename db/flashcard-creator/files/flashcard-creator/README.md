# Flashcard Creator Database — files (flashcard-creator)

- `demo-flashcard-creator.py` — runnable demo program (run with `python3 demo-flashcard-creator.py`).
- `flashcard-creator-sample.txt` — a plain-text sample of the database.
- The full database is `data/flashcard-creator/index.jsonl.gz` (24 records).
- The generator is `gen-flashcard-creator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
