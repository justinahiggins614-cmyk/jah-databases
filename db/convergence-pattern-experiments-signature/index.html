The Signature water-drop baseline trial is an original experiment design: drops fall at fixed positions into a still tray, a camera records the ripple field, and the analysis asks whether the combined pattern shows a single convergence point or simply the expected interference of overlapping circles. The baseline matters because any claim about convergence must first survive comparison with ordinary wave addition, which already produces striking patterns from plain geometry.
