# Database Converter Database — files (database-converter-signature)

- `demo-database-converter-signature.py` — runnable demo program (run with `python3 demo-database-converter-signature.py`).
- `database-converter-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/database-converter-signature/index.jsonl.gz` (24 records).
- The generator is `gen-database-converter-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
