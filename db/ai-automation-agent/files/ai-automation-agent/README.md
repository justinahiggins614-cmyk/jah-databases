# AI Automation Agent Database — files (ai-automation-agent)

- `demo-ai-automation-agent.py` — runnable demo program (run with `python3 demo-ai-automation-agent.py`).
- `ai-automation-agent-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-automation-agent/index.jsonl.gz` (24 records).
- The generator is `gen-ai-automation-agent.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
