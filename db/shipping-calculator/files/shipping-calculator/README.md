# Shipping Calculator Database — files (shipping-calculator)

- `demo-shipping-calculator.py` — runnable demo program (run with `python3 demo-shipping-calculator.py`).
- `shipping-calculator-sample.txt` — a plain-text sample of the database.
- The full database is `data/shipping-calculator/index.jsonl.gz` (24 records).
- The generator is `gen-shipping-calculator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
