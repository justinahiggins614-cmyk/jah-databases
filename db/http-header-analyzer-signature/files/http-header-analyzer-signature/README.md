# HTTP Header Analyzer Database — files (http-header-analyzer-signature)

- `http-header-analyzer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/http-header-analyzer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-http-header-analyzer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
