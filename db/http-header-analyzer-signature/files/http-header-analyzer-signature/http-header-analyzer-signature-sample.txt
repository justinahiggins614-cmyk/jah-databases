HTTP Header Analyzer Database (http-header-analyzer-signature)

An HTTP header analyzer is a rule-based local demo: it reads set toy headers, and counts the marks. The analyzer reads 3 headers. The header host holds 45 marks. The largest holds 45 marks. Everything runs in this browser; no data leaves the page.
