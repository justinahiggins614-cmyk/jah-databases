# Website Change Detector Database — files (website-change-detector)

- `demo-website-change-detector.py` — runnable demo program (run with `python3 demo-website-change-detector.py`).
- `website-change-detector-sample.txt` — a plain-text sample of the database.
- The full database is `data/website-change-detector/index.jsonl.gz` (24 records).
- The generator is `gen-website-change-detector.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
