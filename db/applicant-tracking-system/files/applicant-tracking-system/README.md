# Applicant Tracking System Database — files (applicant-tracking-system)

- `demo-applicant-tracking-system.py` — runnable demo program (run with `python3 demo-applicant-tracking-system.py`).
- `applicant-tracking-system-sample.txt` — a plain-text sample of the database.
- The full database is `data/applicant-tracking-system/index.jsonl.gz` (24 records).
- The generator is `gen-applicant-tracking-system.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
