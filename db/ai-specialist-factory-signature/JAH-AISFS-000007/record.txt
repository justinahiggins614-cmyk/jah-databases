DESCRIPTIONS
In this design versions are grown, not made: each specialist is a plant, and each version is a season of growth. Old versions are not thrown away; they are kept as cuttings, so any version can be grown again. The design suits factories whose specialists change slowly and whose users need to stay on an old version for a long time. This is a Signature design-study: an invented proposal for how the AI Specialist Factory Website could be arranged, labeled as a design throughout and never presented as established fact. The design works through 3 parts: Beds; Cutting store; Season calendar. Each part is named so the design can be read, judged, and changed. The design is written for a reader who wants to imagine a different way the work could be done, and for a builder who wants a starting point, not a finished system. Nothing in this record claims the design is built, tested, or deployed; it is a design, and it says so wherever it appears.

Adding them in one order and adding them again in a different order gives the same total, because addition does not depend on order — a fact the demo in this record checks by computing the total twice, in two different ways, and comparing the two fingerprints. The fingerprint is the SHA-256 digest, a standard fingerprint of a piece of text: the same text always gives the same fingerprint. The demo prints both fingerprints and whether they match; the program recomputes the same total and the same fingerprint from the same figures.
