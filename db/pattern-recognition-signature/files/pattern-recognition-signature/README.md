# Pattern Recognition Database — files (pattern-recognition-signature)

- `demo-pattern-recognition-signature.py` — runnable demo program (run with `python3 demo-pattern-recognition-signature.py`).
- `pattern-recognition-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/pattern-recognition-signature/index.jsonl.gz` (24 records).
- The generator is `gen-pattern-recognition-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
