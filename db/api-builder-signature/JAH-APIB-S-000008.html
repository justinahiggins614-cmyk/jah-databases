The Signature edition validates input the same way as the public edition — and then checks one thing more: that no generated content is ever passed off as a public record. A Signature record that claims to be public is refused, and the refusal is logged. This record lists the Signature validation rules, the errors each broken rule produces, and the recovery path for each one.
