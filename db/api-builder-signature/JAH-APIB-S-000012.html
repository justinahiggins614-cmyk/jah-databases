Signature import brings Signature designs in from other Signature tools, checking each incoming record against the same validation rules as typed input, and refusing any record that claims to be a public record. An import never overwrites existing data without saying so. This record specifies the Signature import formats, the checks each record passes through, and the report every import produces.
