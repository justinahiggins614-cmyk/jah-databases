# Soil Analysis Database — files (soil-analysis-signature)

- `demo-soil-analysis-signature.py` — runnable demo program (run with `python3 demo-soil-analysis-signature.py`).
- `soil-analysis-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/soil-analysis-signature/index.jsonl.gz` (24 records).
- The generator is `gen-soil-analysis-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
