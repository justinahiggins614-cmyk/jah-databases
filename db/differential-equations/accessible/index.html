Differential Equations: What a Differential Equation Is

Record identifier: JAH-DIFFEQ-000001. Ladder rank: 1 of 24. Subject: differential equations and their meaning.

A differential equation is an equation that involves a function and its derivatives (rates of change). The order is the highest derivative that appears. A solution is a function that satisfies the equation. An initial condition fixes the value of the solution (and possibly its derivatives) at a starting point, picking one solution from the family. The order of an equation is the highest derivative in it. A first-order equation has a one-parameter family of solutions; an initial condition picks one. An existence and uniqueness theorem states when a solution exists and is the only one. Differential Equations: Separable Equations

Record identifier: JAH-DIFFEQ-000002. Ladder rank: 2 of 24. Subject: separable differential equations.

A separable equation is one where the terms in x and the terms in y can be put on opposite sides of the equation: dy/dx = g(x) h(y). It is solved by dividing by h(y), integrating both sides, and solving for y. The method works when the variables separate cleanly. Separate: write dy / h(y) = g(x) dx, then integrate both sides. The constant of integration appears on one side and is fixed by the initial condition. Constant solutions, where h(y) = 0, can be lost by dividing, and must be checked separately. Differential Equations: First-Order Linear Equations

Record identifier: JAH-DIFFEQ-000003. Ladder rank: 3 of 24. Subject: first-order linear differential equations.

A first-order linear equation has the form dy/dx + P(x) y = Q(x). It is solved by an integrating factor: multiply by mu(x) = e to the power of the integral of P(x), which turns the left side into the derivative of mu times y, and then integrate. The method always works for this form. The integrating factor is mu(x) = e^(integral of P(x) dx). Multiplying by mu turns the left side into the derivative of (mu y). The general solution is y = (1/mu) times the integral of (mu Q) plus a constant. Differential Equations: Second-Order Linear Equations

Record identifier: JAH-DIFFEQ-000004. Ladder rank: 4 of 24. Subject: second-order linear differential equations.

A second-order linear equation with constant coefficients has the form a y'' + b y' + c y = 0 (the homogeneous case). It is solved by the characteristic equation a r squared + b r + c = 0: distinct real roots give exponentials, a repeated root gives an exponential times x, and complex roots give oscillations (sines and cosines times an exponential). The characteristic equation is a r^2 + b r + c = 0. Distinct real roots r1, r2 give y = C1 e^(r1 x) + C2 e^(r2 x). Complex roots alpha plus or minus beta i give y = e^(alpha x) (C1 cos(beta x) + C2 sin(beta x)). Differential Equations: The Harmonic Oscillator

Record identifier: JAH-DIFFEQ-000005. Ladder rank: 5 of 24. Subject: the harmonic oscillator.

Its solutions are sines and cosines: y = A cos(omega t) + B sin(omega t), oscillating with angular frequency omega (radians per second) and period 2 pi / omega. Adding damping (a first-derivative term) makes the oscillation decay. Differential Equations: The Laplace Transform

Record identifier: JAH-DIFFEQ-000006. Ladder rank: 6 of 24. Subject: the Laplace transform.

The Laplace transform turns a function of time into a function of a new variable s, by integrating f(t) times e^(-s t) from 0 to infinity. It turns differentiation into multiplication by s, so a differential equation becomes an algebraic equation, which is solved and then transformed back. The transform of f'(t) is s F(s) - f(0). The transform of e^(a t) is 1/(s - a). The transform of a constant 1 is 1/s, and of t is 1/s squared. Differential Equations: The Heat Equation

Record identifier: JAH-DIFFEQ-000008. Ladder rank: 8 of 24. Subject: the heat equation.

The heat equation is the partial differential equation u_t = k u_xx, where u is temperature, t is time, x is position, and k is the thermal diffusivity (a measure of how fast heat spreads). It says the rate of change of temperature at a point is proportional to the curvature of the temperature profile there: heat flows from hot to cold, smoothing the profile. The heat equation is solved by separation of variables, giving a Fourier series (a sum of sines and cosines). High-frequency components decay fastest, so the profile smooths over time. The steady state (the long-run temperature) is linear in x for fixed end temperatures. Differential Equations: The Wave Equation

Record identifier: JAH-DIFFEQ-000009. Ladder rank: 9 of 24. Subject: the wave equation.

The wave equation is the partial differential equation u_tt = c squared u_xx, where u is the displacement of a string or the pressure in a gas, and c is the wave speed. It says the acceleration at a point is proportional to the curvature there. Its solutions are waves travelling in both directions at speed c. The general solution is f(x - c t) + g(x + c t): a right-moving and a left-moving wave. A plucked string vibrates as a sum of standing waves (modes) with frequencies that are multiples of the fundamental. The wave speed c is the square root of tension over density for a string. Differential Equations: Laplace's Equation and Harmonic Functions

Record identifier: JAH-DIFFEQ-000010. Ladder rank: 10 of 24. Subject: Laplace's equation and harmonic functions.

Laplace's equation is u_xx + u_yy = 0, where the subscripts are second partial derivatives. A function satisfying it is called harmonic. It describes steady states: the temperature in a plate after a long time, or the electric potential in empty space. The mean value property says a harmonic function's value at a point is the average of its values on any circle around it. The maximum principle says the extremes occur on the boundary. Differential Equations: Fourier Series

Record identifier: JAH-DIFFEQ-000011. Ladder rank: 11 of 24. Subject: Fourier series.

A Fourier series represents a periodic function (one that repeats) as a sum of sines and cosines. The coefficients are found by integrating the function against each sine and cosine: the orthogonality of sines and cosines picks out one coefficient at a time. Fourier series solve the heat and wave equations by separating variables. The Fourier series of a function on (-pi, pi) is a0/2 plus the sum of a_n cos(nx) + b_n sin(nx). The coefficients are integrals: a_n is (1/pi) times the integral of f(x) cos(nx). A jump in the function causes the Gibbs overshoot: the partial sums overshoot by about 9 percent near the jump. Differential Equations: Numerical Methods for ODEs

Record identifier: JAH-DIFFEQ-000012. Ladder rank: 12 of 24. Subject: numerical methods for ordinary differential equations.

A numerical method for an ordinary differential equation approximates the solution step by step. Euler's method takes a step along the tangent line: y(n+1) = y(n) + h f(x(n), y(n)), where h is the step size. Runge-Kutta methods take several trial steps and combine them for higher accuracy. The error shrinks as the step size shrinks. Euler's method has error proportional to the step size h. The classic fourth-order Runge-Kutta method has error proportional to h to the fourth power. Stability matters: a method can blow up on a stiff equation (one with very different time scales) even with a small step. Differential Equations: Stability of Equilibria

Record identifier: JAH-DIFFEQ-000013. Ladder rank: 13 of 24. Subject: stability of equilibria.

An equilibrium of a differential equation is a state where nothing changes. It is stable when solutions starting nearby stay nearby, asymptotically stable when they also return to it, and unstable when they move away. For a linear system, stability is read from the eigenvalues: negative real parts mean stability. A linear system is asymptotically stable exactly when all eigenvalues have negative real parts. A saddle has eigenvalues of opposite signs and is unstable. Lyapunov's method proves stability for non-linear systems by finding an energy-like function that decreases. Differential Equations: Exact Equations

Record identifier: JAH-DIFFEQ-000014. Ladder rank: 14 of 24. Subject: exact differential equations.

A first-order equation M(x, y) dx + N(x, y) dy = 0 is exact when there is a function F with F_x = M and F_y = N, so the equation says dF = 0 and the solutions are the level curves F(x, y) = C. The test is that the partial derivative of M with respect to y equals the partial derivative of N with respect to x. The test for exactness is M_y = N_x. When the test fails, an integrating factor may make the equation exact. The solution is found by integrating M with respect to x and matching the y-dependence. Differential Equations: Undetermined Coefficients

Record identifier: JAH-DIFFEQ-000015. Ladder rank: 15 of 24. Subject: undetermined coefficients for non-homogeneous equations.

A non-homogeneous linear equation has a forcing term on the right: a y'' + b y' + c y = f(x). Its general solution is the homogeneous solution plus one particular solution. The method of undetermined coefficients guesses the form of the particular solution from the form of f(x) (a polynomial, an exponential, a sine or cosine, or a product) with unknown coefficients, and solves for them. The guess for a polynomial forcing term is a polynomial of the same degree. For an exponential e^(a x), guess A e^(a x), unless a is a root of the characteristic equation, in which case multiply by x. For a sine or cosine, guess a combination of sine and cosine. Differential Equations: Variation of Parameters

Record identifier: JAH-DIFFEQ-000016. Ladder rank: 16 of 24. Subject: variation of parameters.

Variation of parameters is the general method for a particular solution of a non-homogeneous linear equation: it builds the solution from the homogeneous solutions with variable coefficients, found by integrating. For y'' + P(x) y' + Q(x) y = R(x) with homogeneous solutions y1 and y2, the particular solution is -y1 times the integral of (y2 R / W) plus y2 times the integral of (y1 R / W), where W is the Wronskian (the determinant of the matrix of y1, y2 and their derivatives). The Wronskian W = y1 y2' - y1' y2 measures the independence of the two solutions. The formulas involve integrals that may have no elementary form. The method works for variable coefficients as well as constant ones. Differential Equations: Boundary Value Problems

Record identifier: JAH-DIFFEQ-000018. Ladder rank: 18 of 24. Subject: boundary value problems.

A boundary value problem fixes the solution's values at the ends of an interval, rather than at one starting point. For example, y'' = -y with y(0) = 0 and y(pi) = 0 has solutions sin(nx) for integer n, and the values of n for which a non-zero solution exists are the eigenvalues of the problem. Unlike initial value problems, a boundary value problem may have no solution, one, or infinitely many. A boundary value problem fixes values at two ends; an initial value problem fixes value and derivative at one point. The eigenvalues are the parameter values for which a non-zero solution exists. The eigenfunctions (the solutions) are orthogonal, and they build Fourier series. Differential Equations: The Logistic Equation

Record identifier: JAH-DIFFEQ-000019. Ladder rank: 19 of 24. Subject: the logistic equation.

The logistic equation is dy/dt = r y (1 - y/K), where r is the growth rate and K is the carrying capacity (the largest population the environment can support). It models growth that slows as the population approaches K: the solution is a sigmoid (S-shaped) curve rising from the starting value toward K. The equilibria are y = 0 (unstable) and y = K (stable). The solution is y(t) = K / (1 + A e^(-r t)), where A is set by the starting value. The growth is fastest at y = K/2, the inflection point of the S-curve. Differential Equations: The Pendulum Equation

Record identifier: JAH-DIFFEQ-000020. Ladder rank: 20 of 24. Subject: the pendulum equation.

The full equation has an energy integral: the sum of kinetic and potential energy is constant. Differential Equations: Green's Functions

Record identifier: JAH-DIFFEQ-000021. Ladder rank: 21 of 24. Subject: Green's functions.

A Green's function is the response of a linear system to a point impulse (a sudden kick at one place and time). Once the Green's function is known, the response to any forcing is the integral of the forcing times the Green's function: the system is a sum of its responses to many small kicks. It is the inverse of the differential operator, in the sense of an integral. The Green's function G(x, s) is the response at x to an impulse at s. The solution is the integral of G(x, s) times the forcing f(s). For the operator -d squared/dx squared on (0, 1), the Green's function is min(x, s) times (1 - max(x, s)). Differential Equations: Existence and Uniqueness Theorems

Record identifier: JAH-DIFFEQ-000023. Ladder rank: 23 of 24. Subject: existence and uniqueness theorems.

The existence and uniqueness theorem says that y' = f(x, y) with y(x0) = y0 has exactly one solution near x0, provided f is continuous and Lipschitz in y (its slope in y is bounded). When f is not Lipschitz, solutions can branch: several solutions can satisfy the same initial condition. Continuity plus a Lipschitz condition gives one solution. The proof builds the solution by Picard iteration. Without Lipschitz, solutions can branch. Differential Equations: Existence and Uniqueness Theorems

'use strict';
/* Node port of the Wave 1 Python demo template (College-Level Resources,
   Wave 1). The original Python demo is shipped alongside as demo.py; this
   file must print exactly the same bytes. Python-compatibility notes:
   - Python ints are exact: carried as BigInt and summed exactly.
   - CPython 3.12.3 builtin sum(): leading ints accumulate exactly, the
     FIRST float is plain-added to that exact sum (compensation starts at
     zero), later floats use the Neumaier compensation step, later ints are
     plain-added; the compensation is folded in at the end only when nonzero.
   - round(x, 4) is round-half-even on the exact binary value.
   - Floats print with Python repr rules (shortest digits, scientific
     notation when the exponent is below -4 or at/above 16, ".0" for whole
     floats, two-digit signed exponents). */
const crypto = require('crypto');

function pyRound(x, places) {
  if (!Number.isFinite(x)) return x;
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  dv.setFloat64(0, x);
  const bits = dv.getBigUint64(0);
  const sign = bits >> 63n;
  const exp = Number((bits >> 52n) & 0x7ffn);
  let mant = bits & ((1n << 52n) - 1n);
  let e2;
  if (exp === 0) { e2 = -1074; }
  else { mant |= (1n << 52n); e2 = exp - 1075; }
  const scale = 10n ** BigInt(places);
  let scaledNum, scaledDen;
  if (e2 >= 0) { scaledNum = mant * (2n ** BigInt(e2)) * scale; scaledDen = 1n; }
  else { scaledNum = mant * scale; scaledDen = 2n ** BigInt(-e2); }
  let q = scaledNum / scaledDen;
  const r = scaledNum % scaledDen;
  const twice = r * 2n;
  if (twice > scaledDen || (twice === scaledDen && q % 2n === 1n)) q += 1n;
  const ip = q / scale, fp = q % scale;
  const dec = (sign ? '-' : '') + ip.toString() + '.' + fp.toString().padStart(places, '0');
  return Number(dec);
}

function pyReprFloat(x) {
  if (x === 0) return Object.is(x, -0) ? '-0.0' : '0.0';
  if (!Number.isFinite(x)) return x > 0 ? 'inf' : '-inf';
  const neg = x < 0;
  const s = String(Math.abs(x));
  let digits, E;
  if (s.includes('e')) {
    const parts = s.split('e');
    digits = parts[0].replace('.', '');
    E = parseInt(parts[1], 10);
  } else if (s.includes('.')) {
    const parts = s.split('.');
    if (parts[0] !== '0') { digits = parts[0] + parts[1]; E = parts[0].length - 1; }
    else { const lz = parts[1].match(/^0*/)[0].length; digits = parts[1].slice(lz); E = -(lz + 1); }
  } else { digits = s; E = s.length - 1; }
  digits = digits.replace(/0+$/, '') || '0';
  let out;
  if (E < -4 || E >= 16) {
    const mant = digits.length === 1 ? digits : digits[0] + '.' + digits.slice(1);
    out = mant + 'e' + (E >= 0 ? '+' : '-') + String(Math.abs(E)).padStart(2, '0');
  } else if (E >= 0) {
    if (E + 1 >= digits.length) out = digits + '0'.repeat(E + 1 - digits.length) + '.0';
    else out = digits.slice(0, E + 1) + '.' + digits.slice(E + 1);
  } else {
    out = '0.' + '0'.repeat(-E - 1) + digits;
  }
  return neg ? '-' + out : out;
}

function pyStr(v) {
  if (!v.f) return typeof v.v === 'bigint' ? v.v.toString() : String(v.v);
  return pyReprFloat(v.v);
}

function compute(figures) {
  const vals = Object.values(figures);
  const allInt = vals.every((o) => o.f === 0);
  let total;
  if (allInt) {
    let t = 0n;
    for (const o of vals) t += o.v;
    total = { v: t, f: 0 };
  } else {
    let i = 0;
    let isum = 0n;
    while (i < vals.length && vals[i].f === 0) { isum += vals[i].v; i += 1; }
    let s = Number(isum) + Number(vals[i].v);
    let c = 0;
    i += 1;
    for (; i < vals.length; i += 1) {
      const o = vals[i];
      if (o.f === 1) {
        const x = o.v;
        const t = s + x;
        if (Math.abs(s) >= Math.abs(x)) c += (s - t) + x;
        else c += (x - t) + s;
        s = t;
      } else {
        s = s + Number(o.v);
      }
    }
    if (c) s = s + c;
    total = { v: s, f: 1 };
  }
  const n = vals.length;
  const totalR = total.f ? { v: pyRound(total.v, 4), f: 1 } : total;
  const mean = { v: pyRound(allInt ? Number(total.v) / n : total.v / n, 4), f: 1 };
  const max = vals.reduce((a, b) => (b.v > a.v ? b : a));
  const min = vals.reduce((a, b) => (b.v < a.v ? b : a));
  return { count: { v: n, f: 0 }, label: null, max, mean, min, total: totalR };
}

function entriesFor(label, figures) {
  const o = compute(figures);
  return { count: o.count, label: { v: label, f: -1 }, max: o.max, mean: o.mean, min: o.min, total: o.total };
}

function fmtEntry(o) { return o.f === -1 ? o.v : pyStr(o); }

function summarizeDemo(label, figures) {
  const entries = entriesFor(label, figures);
  return Object.keys(entries).sort().map((k) => k + '=' + fmtEntry(entries[k])).join('|');
}

function runDemo(label, figures) {
  const result = summarizeDemo(label, figures);
  const h1 = crypto.createHash('sha256').update(result).digest('hex');
  const result2 = summarizeDemo(label, figures);
  const h2 = crypto.createHash('sha256').update(result2).digest('hex');
  const entries = entriesFor(label, figures);
  const lines = [];
  for (const k of Object.keys(entries).sort()) lines.push(k + ': ' + fmtEntry(entries[k]));
  lines.push('Result: ' + result);
  lines.push('Run 1 SHA-256: ' + h1);
  lines.push('Run 2 SHA-256: ' + h2);
  lines.push('Deterministic: ' + (h1 === h2 ? 'MATCH' : 'MISMATCH'));
  return lines.join('\n') + '\n';
}
