# Research Aggregator Database — files (research-aggregator-signature)

- `demo-research-aggregator-signature.py` — runnable demo program (run with `python3 demo-research-aggregator-signature.py`).
- `research-aggregator-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/research-aggregator-signature/index.jsonl.gz` (24 records).
- The generator is `gen-research-aggregator-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
