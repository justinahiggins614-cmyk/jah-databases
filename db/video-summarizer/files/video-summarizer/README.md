# Video Summarizer Database — files (video-summarizer)

- `demo-video-summarizer.py` — runnable demo program (run with `python3 demo-video-summarizer.py`).
- `video-summarizer-sample.txt` — a plain-text sample of the database.
- The full database is `data/video-summarizer/index.jsonl.gz` (24 records).
- The generator is `gen-video-summarizer.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
