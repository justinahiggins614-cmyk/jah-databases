# AI Model Evaluator Database — files (ai-model-evaluator)

- `demo-ai-model-evaluator.py` — runnable demo program (run with `python3 demo-ai-model-evaluator.py`).
- `ai-model-evaluator-sample.txt` — a plain-text sample of the database.
- The full database is `data/ai-model-evaluator/index.jsonl.gz` (24 records).
- The generator is `gen-ai-model-evaluator.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
