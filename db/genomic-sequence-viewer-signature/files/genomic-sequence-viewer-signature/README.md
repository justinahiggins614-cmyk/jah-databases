# Genomic Sequence Viewer Database — files (genomic-sequence-viewer-signature)

- `demo-genomic-sequence-viewer-signature.py` — runnable demo program (run with `python3 demo-genomic-sequence-viewer-signature.py`).
- `genomic-sequence-viewer-signature-sample.txt` — a plain-text sample of the database.
- The full database is `data/genomic-sequence-viewer-signature/index.jsonl.gz` (24 records).
- The generator is `gen-genomic-sequence-viewer-signature.js`; the generator website is `generator/`.
- The two AI specs are `ai/website-ai.json` and `ai/thing-ai.json`.
