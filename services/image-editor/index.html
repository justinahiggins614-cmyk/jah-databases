How it works

Look at the sample Six rows of coloured squares stand in for a picture.
Press a filter Grey, invert, sepia, brighten, or darken — one change at a time, so you can see what it did.
Read the average colour The tool reads the average colour of the sample after each change.
Work out a size Type a picture's size, then crop, resize, or rotate it — the tool gives the new size in pixels.
Keep the original A filter can be taken away only if the original is kept.

This editor works on a sample picture on the page, to show how the tools work. It does not upload or keep your pictures. The database records explain cropping, resizing, layers, and saving as PNG or JPG.
