How it works

Type or change the code A short program is already there. Change it, or write your own.
Count the kinds of words See how many keywords, numbers, strings, and comments your code holds.
Run a demo sum Numbers with + - * / and brackets only. The snippet runs in the browser, never on a server.
Find and replace Change every place a word appears, and count how many changed.

Demo snippets run in the browser only. They do simple arithmetic and printing, and they never run on a server. The editor does not save files to a server; the database records explain saving, opening, and checking code.
