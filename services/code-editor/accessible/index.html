Code Editor

A free code editor. Count the kinds of words, run demo sums, and find and replace. No sign-in, no payment, free forever. Your words never leave the page.

Open the working tool (needs JavaScript)

How it works

  1. Type or change the code in the box.
  2. Count the kinds of words it holds.
  3. Run a demo sum with numbers and brackets.
  4. Find a word and replace it everywhere it appears.

Demo snippets run in the browser only. They do simple arithmetic and printing, and they never run on a server. The editor does not save files to a server; the database records explain saving, opening, and checking code.

The demo snippets

Demo sums that run in the browser only:

  • 2+3*4 — 14 (multiply first, then add).
  • (2+3)*4 — 20 (brackets first).
  • 10/4 — 2.5.
  • 7*6 — 42.

The editor never runs code on a server. It only does simple arithmetic and printing, in the browser, so it is safe to run.
