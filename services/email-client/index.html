How it works

Open the inbox Six sample messages wait there, newest first. Unread ones are bold.
Read a message Press a message to choose it and read its words.
Search the mailbox Search for a name or a word, across every folder.
Write a draft Fill in an address, a subject, and your words, then save it as a draft.
File it in Sent Filing a draft in Sent only files the sample. Nothing leaves this page.

Demo mailbox only. Live sending and delivery is a hosted service that this site does not provide, so no real mail is ever sent from here. The database records state the boundary in full.
