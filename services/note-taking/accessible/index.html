Note Taking

A free note-taker. Write notes, tag them, file them in folders, search them, and tick off checklists. No sign-in, no payment, free forever. Your words never leave the page.

Open the working tool (needs JavaScript)

How it works

  1. Write a note: one thing, in plain words, under a short title.
  2. File it in a folder and give it tags.
  3. Search your notes for one word.
  4. Tick off checklist items as you finish them.
  5. Export a note as text to keep it.

Notes stay in the browser unless you download them. The tool writes nothing to a server and keeps no record of who wrote what. When the page is closed, the notes are gone unless they were downloaded, so important notes should always be exported.

The note rules

How a good note is made:

  • One note, one thing — five lines or fewer, with its source named.
  • Short and often — a note in one minute beats a long note never written.
  • Few folders, clear rules — four folders hold most notebooks.
  • Tags gather — one tag gathers notes from every folder.
  • Download what matters — notes live on the page unless exported.
