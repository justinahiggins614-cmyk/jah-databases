How it works

  1. Make a PDF. Type a title and your lines, then press Make a PDF. The page writes a real PDF file, with the title at the top and your lines below it, and hands it to you to download. It makes a one-page PDF, up to 40 lines.
  2. Read a PDF. Drop a PDF in the box, or choose one. The page reads the file on this page only, counts its pages, and shows its title, its author if it has one, and its size.
  3. Open it anywhere. A PDF looks the same on every computer, because the words and fonts travel inside the file. Open it in a browser or any reader.

What it cannot do: it cannot join two PDFs into one, and it cannot split one PDF into separate pages, because those jobs need to rebuild the file's inner structure, which a plain page in a browser cannot safely do. It also cannot fill in forms or add a signature. Those limits are stated here so no one expects more.

What a PDF file is

A PDF file is a document that looks the same on every computer. It carries its words, its fonts, and its pictures inside the file itself, so the page does not change when it moves from one screen to another. The file starts with the letters %PDF, holds the words as text, and ends with a marker that closes the file. A small PDF can be built by hand: a header, a page, the words on the page, the font, and a table that says where each piece sits.

What it does

  • What a PDF file is — a document that looks the same on every computer.
  • Making a PDF from words you type — writing a small PDF by hand.
  • Reading a PDF: pages and words — turning pages one at a time, and searching the words stored as text.
  • The page count of a PDF — how many pages a file holds, counted from the page markers inside it.
  • Text inside a PDF — words stored as letters, so they can be searched and copied.
  • Fonts inside a PDF — letter shapes carried inside the file, or named so the reader can find them.
  • Pictures inside a PDF — photographs and drawings stored as picture data on a page.
  • The title and author of a PDF — facts written inside the file itself.
  • PDF versions: 1.4, 1.7 and 2.0 — the number that says which form of the format a file uses.
  • PDF/A: the archive form — a form of PDF made for keeping documents for a long time.
  • Filling in a form — blank boxes inside a PDF where a reader types an answer.
  • Signing a PDF in plain words — marking a file with the signer's name and date.
