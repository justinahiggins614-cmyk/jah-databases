File Converter

Turn one kind of file into another — right here, in your browser.

This is a file converter that runs entirely in your browser. Your files never leave this page. It turns CSV tables into JSON, Markdown into HTML, plain text into JSON, and pictures from one format to another — and it shows you the result before you download it. Free forever — no sign-in, no payment

How it works

Paste your content. Put text, a CSV table, JSON, Markdown, or HTML in the box above — or pick a picture file for picture conversion.
Pick the conversion. Choose what to turn it into from the list: CSV to JSON, Markdown to HTML, upper case, and the rest.
Press Convert. The result appears below, with its size. Download it or copy it — it never leaves this page.

What it cannot do: it converts text and pictures in your browser only — it cannot open files from other websites, it cannot read password-locked files, and a JPEG made from a PNG cannot be turned back into the original PNG, because the JPEG has already thrown away fine detail. A conversion that fails says so plainly, with the reason.

Good to know

Six things worth knowing before you convert anything.

CSV to JSON

The first row gives the field names, and every later row becomes one record. Commas inside quoted fields stay inside their field.

Read the full record →

Markdown to HTML

A line starting with # becomes a heading, a line starting with - becomes a list item, and **word** becomes bold.

Read the full record →

PNG to JPEG

JPEG stores photographs in far less space by throwing away fine detail the eye barely notices. The JPEG is smaller but not identical.

Read the full record →

Lossy and lossless

JPEG is lossy: it throws away detail. PNG and lossless WebP are lossless: they keep every pixel exactly.

Read the full record →

Checking a conversion

Compare before and after: the same words, the same rows, the same numbers, in the same order. The tool prints the counts.

Read the full record →

UTF-8 encoding

The tool reads and writes UTF-8, which covers nearly every written language, so letters with marks survive the trip.

Overview

The File Converter Service changes files from one shape to another — text to JSON, CSV to JSON, Markdown to HTML, upper and lower case, and picture formats — entirely in your browser. Nothing you paste leaves the page. The archive behind it, File Conversion and Format Interoperability Database, holds 16 records. A separate service database, The File Converter Service Database, holds 48 full records — 24 public records and 24 Signature records. The service is free forever: no sign-in, no payment, no tracking.
