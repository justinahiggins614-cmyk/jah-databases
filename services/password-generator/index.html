The Tool

How it works

Pick a length and the sets. Sixteen letters from all four sets is the standard. Longer is stronger — every extra letter multiplies the guessing work.
Press Make a password. The letters are drawn from the browser's own secure random source, so no pattern can be learned and no two runs give the same password.
Copy it into your keeper. Give every place its own password. The password never leaves this page and is never stored here.

What it cannot do: it cannot remember your passwords for you, it cannot check whether a password has leaked elsewhere, and a password it makes is only strong if you keep it secret and use it in one place only. The letters are drawn with crypto.getRandomValues, the browser's secure random source — never from a fixed list and never from a simple formula. A passphrase uses a word list of 128 ordinary words, loaded from the files below.

Good to know

Six things worth knowing before you pick a password.

Length first

Every extra letter multiplies the guessing work. A 16-letter password from all four sets is the standard; 12 is the minimum.

Read the full record →

Four words in a row

A passphrase of four words picked at random is long, strong, and plain enough to remember — but the words must be picked at random.

Read the full record →

One password per place

Reusing one password means one leak opens every place at once. A fresh password per place stops that chain.

Reading the strength meter

The meter counts length and character sets into bits of guessing work: weak, fair, strong, or very strong.

PINs and their limits

A 4-digit PIN has only 10,000 possibilities. It is safe only where the device locks after a few wrong tries.

Keyboard patterns to avoid

qwerty and 123456 are among the first guesses any attacker tries. The generator never draws from keyboard order.
