# Review Mode — Report Template

One report per database. Generated by `review_db.py <slug>`; this template
is the shape the tool fills. A report is evidence, not a certificate: a
database is only "done" when review mode says usable **and** the
full-file-check program's own verification agrees.

```markdown
# Review — `<slug>`

**Verdict: USABLE / PARTIAL / BROKEN** (usable / partial / broken)

**Date:** <date>. **Mode:** package-only review; nothing merged, pushed, or
deployed. **Manifest at review time:** <N> databases.

## Specification

- Name: <manifest name>
- Record kind: `<record_kind>` — AI: <ai_name>
- Tagline: <tagline>
- ID prefix: `<id_prefix>` — manifest record_count: <N> — source: <source>
- Full-file-check census class: **<CLASS>** (read: <read>, org: <org>,
  steps <n>/7, median body <n> chars)
- Index: `<local index path>`
- Primary sample source: <chunks (N files) | index> (<M> records sampled)

## Checks (evidence per check)

| Check | Result | Evidence |
|---|---|---|
| spec_present | PASS / PARTIAL / FAIL | manifest entry fields present/missing |
| index_loads | PASS / FAIL | path, records parsed |
| count_agrees | PASS / FAIL | manifest count vs index/chunk lines |
| records_parse | PASS / FAIL | sample size, titles, id-prefix matches |
| readable | PASS / PARTIAL / FAIL | readable n/M, median prose chars, garbled n |
| demos_run | PASS / FAIL | present/ran-OK/mismatch/failed/skipped + per-demo evidence |
| links_resolve | PASS / PARTIAL | page exists, markers (Exhaustive / Merger / stCount / old_loader) |
| citations_present | PASS / PARTIAL / FAIL | source present n/M + example JCC v1 code |

Demo totals (sampled): present <n>, ran OK <n>, output mismatch <n>,
failed <n>, skipped <n>.

## Notes

- <index title-only / chunk / image / duplicate notes, one per line>

## What this verdict means

- **usable:** spec present, index loads, counts agree, records parse and
  read, demos run, links resolve, citations present. No remediation needed
  from review mode.
- **partial:** data loads and reads, but at least one full-record step is
  missing. Remediation is a fill for the missing step(s) — queue it in the
  full-file-check priority queue, do not re-audit the whole database by hand.
- **broken:** index does not load, records do not parse, or sampled records
  carry no readable prose. Do not serve this database to an outside AI until
  fixed and re-reviewed.

## How this extends the full-file-check program

The census assigns this database a class from a network-wide scan; review
mode reads this one database end to end — spec, real files, executed demos,
resolved links, per-record citations — and gives a verdict with evidence.
It does not replace the census, the priority queue, or the fill waves.
```

## Verdict rules (as implemented in `review_db.py`)

- **broken** if `index_loads` FAIL, or `records_parse` FAIL, or `readable`
  FAIL (zero sampled records readable).
- **usable** only if every check is PASS.
- **partial** otherwise (data loads and reads, something is missing).
