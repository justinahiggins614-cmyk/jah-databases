Section 1 — Description and history

Signature Search is a mirror of the search-engine kind of website: a website whose job is to take a question in plain words and return the websites that hold the answer, ranked best first. The search-engine kind of website began as simple lists of sites, then as indexes of words on pages, and then as ranking systems that score pages against a question. This mirror follows that same shape — a box, a button, and a ranked list of results — rebuilt with Signature branding and the network's own data.

What this mirror searches is different from the kind it mirrors: it searches only The 'Merica-L Internet's own directory. Its index is built at build time from the network's own pages — the 39 websites and the per-artifact entry points — and it is stored in the page itself. It does not crawl the outside web, it does not keep a history of your searches, and it does not sell or share anything about you, because it never collects anything about you in the first place.

Section 2 — Math proof (standard math + metamath)

The mirror's ranking rule is a deterministic scoring function. For a query Q of words q1 … qn and an index entry E with a name and keywords, the score is: score(Q, E) = 3 × (number of query words appearing in E's name) + 1 × (number of query words appearing in E's keywords)

An entry appears in the results only if every query word appears in its name or its keywords. Results are ordered by score, highest first; ties are broken alphabetically by name, so the order is the same every time for the same query. That is the whole rule — there is no hidden ranking, no paid placement, and no personalisation.

Worked example: the query "songs" against the entry "Signature Music Studio" (keywords: music songs beats studio). The word "songs" appears in the keywords (1 point) and not in the name (0 points), so score = 3 × 0 + 1 × 1 = 1. The query "music studio" against "Signature Music Studio" scores 3 × 2 + 1 × 2 = 8: both words are in the name (6 points) and both are in the keywords (2 points).

In metamath form, the rule is a total function from (query, entry) pairs to the natural numbers, and the result order is the total order induced by (score descending, name ascending). Because the function depends only on the query and the fixed index, the same query always returns the same ordered results: the search is deterministic and reproducible.

Section 3 — Science proof

The science behind this mirror is information retrieval: the study of how to find documents that match a question. The mirror uses its simplest honest form. At build time it builds an index: for every website in the directory, it records the website's name and a set of keywords drawn from that name and its description. At search time it compares the query's words against that index, scores the matches, and returns the matches in ranked order.

Two measures from information retrieval describe how good a search is. Precision is the share of returned results that actually match what was asked. Recall is the share of matching websites in the index that the search actually returned. This mirror's rule — every query word must appear in the name or keywords — favours precision: it returns fewer results, but every result it returns contains every word you asked for.

The index is static: it is built once, from the network's own pages, and shipped inside the page. That is why the mirror needs no server, no account, and no tracking.
