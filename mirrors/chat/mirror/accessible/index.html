Section 1 — Description and history

Signature Chat is a mirror of the chat kind of website: a website whose job is to let people send written messages to each other, one to one and in groups, in rooms where messages appear in order. The chat kind of website grew from written notes passed back and forth, then from typed messages on a shared screen, and then from rooms where many people can talk at once. This mirror follows that same shape: a room, a message box, and replies that appear in order.

What this mirror shows is the network's own material. Its sample room holds five Signature scripted replies made for this mirror, plus a default reply and an empty-message prompt. They are labeled plainly as scripted sample replies, not as real messages from real people. The network itself holds 63,826 databases and 12,367,686 records across the 39 websites and the 2,700 per-artifact websites.

Section 2 — Math proof (standard math + metamath)

The mirror's reply rule is a deterministic function. For a message M, the mirror lowercases the message, splits it into words, and looks for a known word in a fixed order: hello, help, films, hours, bye. The rule is:

reply(M) is the reply of the first known word found in M, in the fixed order hello, help, films, hours, bye

An empty message gets the empty-message prompt. A message with no known word gets the default reply, which lists the words the room knows.

Worked example: the message "hello" carries the known word hello, so the room answers with the greeting: "Hello! Welcome to the sample room. Type help to see what this room can answer." The message "what are the hours" carries the known word hours, so the room answers with the hours reply. The message "zqxwv" carries no known word, so the room answers with the default reply. The message "hello bye" carries two known words, and hello wins because it comes first in the fixed order.

Section 3 — Science proof

The science behind this mirror is how chat works in plain words. A chat room is a shared list of messages in order: each person types a message, the message joins the list, and everyone in the room can read it. A one-to-one chat has two people; a group chat has more. The room keeps the order, so a reply sits after the message it answers.

This mirror models that idea with a fixed lookup table instead of a network: the reply set is a short list of word-to-reply pairs, and the rule in Section 2 picks the reply. A lookup table is the simplest honest form of a responder - it always gives the same answer to the same word, it needs no network, and it never pretends to be a real person. The sample members are made-up sample people; they are not real people.
