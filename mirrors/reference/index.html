Section 1

Description and history

Signature Reference is a mirror of the reference kind of website: a website whose job is to hold quotations, facts, and reference lists in one place, grouped by type, so a reader can look up a saying, check a fact, or browse a list. The reference kind of website began as books of sayings and lists, then as card files, and then as searchable lists on a screen. This mirror follows that same shape: entries with a title, a type, and a short text, with a search over the entries.

What this mirror holds is the network's own material. Its sample set is ten Signature sample entries made for this mirror: four sample sayings written for this mirror, three sample facts about the sample set itself, and three sample lists about mirrors and this mirror. They are labeled plainly as Signature sample entries, not as real-world facts, events, dates, or quotes, and no saying here is attributed to any real named person. The network itself holds 63,826 databases and 12,367,686 records across the 39 websites and the 2,700 per-artifact websites.

Section 2

Math proof (standard math + metamath)

The mirror's filter rule is a deterministic function. For a query Q of words q1 … qn and an entry E with a title, a type, and a text, the entry matches when:

match(Q, E) is true when every word of Q appears in E's title, type, or text

Every matching entry scores the same: the number of query words, which is the same for all matches of one query. Results are listed in the order the entries were written for this mirror, so the order is the same every time for the same query.

Worked example: the query "saying" against the sample set. Five entries carry the word "saying": the four sample sayings, whose type is Saying, and the sample list "Sample list: ways to use a reference", whose text says "Look up a saying". All five match, all score 1, and the first listed is "A slow morning makes a steady day". The query "list" matches four entries: "A tidy shelf finds its book", whose text mentions a list, and the three entries whose type is List.

Section 3

Science proof

The science behind this mirror is how reference material is organized and found: by type and by word. A reader who wants one type reads that type's entries; a reader who wants one word searches for that word. The mirror uses the simplest honest form of that idea: a fixed sample set of entries, each carrying a title, a type, and a short text, with a filter that keeps only the entries carrying every word asked for.

Two measures describe how good such a filter is. Precision is the share of returned entries that actually match what was asked. Recall is the share of matching entries in the set that the filter actually returned. This mirror's rule — every query word must appear — favours precision: it returns fewer entries, but every entry it returns contains every word you asked for. The sayings here are sample sayings written for this mirror, and the facts are facts about the sample set itself.
