Section 1

Description and history

Signature Radio is a mirror of the radio kind of website: a website whose job is to list live audio streams, grouped by station and by genre, so a listener can pick a station and listen to it. The radio kind of website began as lists of stations with frequencies, then as station guides with genres, and then as searchable stream lists on a screen. This mirror follows that same shape: stations with a name, a genre, and a short description, with a search over the stations.

What this mirror holds is the network's own material. Its sample set is ten Signature sample stations made for this mirror, with made-up names and descriptions, in the genres Calm, Talk, Stories, and Music. They are labeled plainly as Signature sample stations, not as real stations, real streams, or real-world broadcasts. The network itself holds 63,826 databases and 12,367,686 records across the 39 websites and the 2,700 per-artifact websites.

Section 2

Math proof (standard math + metamath)

The mirror's filter rule is a deterministic function. For a query Q of words q1 … qn and a station T with a name, a genre, and a description, the station matches when:

match(Q, T) is true when every word of Q appears in T's name, genre, or description

Every matching station scores the same: the number of query words, which is the same for all matches of one query. Results are listed in the order the stations were written for this mirror, so the order is the same every time for the same query.

Worked example: the query "calm" against the sample set. Four stations carry the word "calm": "Harbour Light Radio" (genre Calm), "Morning Desk Radio" (calm spoken programmes), "Quiet Night Radio" (genre Calm), and "Library Corner Radio" (genre Calm). All four match, all score 1, and the first listed is "Harbour Light Radio". The query "talk" matches three stations: "Meadow Talk Radio", "Morning Desk Radio", and "Plain Weather Radio".

Section 3

Science proof

The science behind this mirror is how a live audio stream works: a station sends sound in order, piece by piece, and a listener hears each piece as it arrives, instead of waiting for a whole recording to finish. A station list adds a second idea: each station carries a name and a genre, so a listener can pick by subject and by mood. The mirror uses the simplest honest form of that idea: a fixed sample set of stations, each carrying a name, a genre, and a short description, with a filter that keeps only the stations carrying every word asked for.

Two measures describe how good such a filter is. Precision is the share of returned stations that actually match what was asked. Recall is the share of matching stations in the set that the filter actually returned. This mirror's rule — every query word must appear — favours precision: it returns fewer stations, but every station it returns contains every word you asked for. The stations here are samples made for this mirror, with no real streams behind them.
