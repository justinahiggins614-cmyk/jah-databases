Section 1

Description and history

Signature Mail is a mirror of the mail kind of website: a website where a visitor writes a message, addresses it, and sends it. Mail websites began as plain lists of messages, then grew address books, subjects that say what a message is about, and folders that keep messages in order. This mirror follows the same shape — an address book, a subject, and a composed message — rebuilt with Signature branding and the network's own data.

What this mirror sends is different from the kind it mirrors: it sends nothing. Its address book is a sample set of eight names, made for this mirror, and its demo composes a message in the page and checks it, then stops. There is no sending on this page, no message store anywhere else, and no account. The mirror exists to show how a message is addressed and checked, using only the network's own data.

Section 2

Math proof (standard math + metamath)

The mirror's validation rule is a deterministic check. For a recipient R and a subject S, the message is ready only when both parts hold:

ready = (R is in the address book) AND (length of S is 1 or more)

Worked example: the recipient 'Rin' is in the address book, and the subject 'Harvest fair' has 12 characters. 12 is 1 or more, so both parts hold and the message is ready. A message to a name outside the address book fails the first part, and a message with an empty subject fails the second part. The same input always gives the same verdict, because the rule depends only on the fixed address book and the subject you type.

Section 3

Science proof

The science behind this mirror is addressing and validation: a message needs a recipient who can be found and a subject that says what it is about. A real mail system looks the recipient up in an address book, checks the message is complete, and then hands it to a delivery system. This mirror does the first two steps and stops: it looks the name up in its sample address book and checks the subject, then shows the composed message with its verdict.

The message never leaves the page. There is no delivery system here, no message store, and no account, so nothing can be sent by mistake. The mirror says so plainly in the hint, in this section, and in Section 6.
