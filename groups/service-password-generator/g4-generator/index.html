How it works

1. Pick a seed. The seed is a number. The same seed always builds the same set, so a teacher can hand out seed 21 and everyone gets the same work.

2. Everything comes from the real data. The passwords are built from the four letter, digit, and mark sets, and the passphrases from the 128-word list. The generator here uses a seed, so its sets repeat; the live tool on the service site uses the browser's own random source instead.

3. Every output is labeled generated. Nothing here is an archive record; the archive lives on the data page.

4. Nothing leaves the page. The set is built in your browser. Download it as JSON to keep or print.

What it does not do: it does not invent new facts — every question, plan, or password is built from the service's own checked data.
