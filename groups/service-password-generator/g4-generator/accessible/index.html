Seeded password generator

A password generator generator, alone. a set of seeded passwords and passphrases: the same seed always makes the same set, so a class can share one set The generator itself needs JavaScript; use the generator page to build a set.

How it works

  1. Pick a seed — the same seed always builds the same set.
  2. The passwords are built from the four letter, digit, and mark sets, and the passphrases from the 128-word list. The generator here uses a seed, so its sets repeat; the live tool on the service site uses the browser's own random source instead.
  3. Every output is labeled generated; nothing here is an archive record.
  4. Sets download as JSON.
