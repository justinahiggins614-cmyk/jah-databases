Phrase quiz generator

A translator generator, alone. a phrase quiz: seeded sets of English phrases to translate, with four choices each The generator itself needs JavaScript; use the generator page to build a set.

How it works

  1. Pick a seed — the same seed always builds the same set.
  2. The quiz draws from the checked phrasebook of 80 phrases in four languages; every translation is a phrasebook entry.
  3. Every output is labeled generated; nothing here is an archive record.
  4. Sets download as JSON.

Worked example — seed 7

  • Translate “hello” — choices: hola, perdon, lo siento, estoy bien. Answer: hola.
  • Translate “sorry” — choices: lo siento, todo recto, muchas gracias, no. Answer: lo siento.
  • Translate “good morning” — choices: queso, izquierda, buenos dias, amarillo. Answer: buenos dias.
  • Translate “how are you” — choices: como estas, blanco, bienvenido, domingo. Answer: como estas.
  • Translate “black” — choices: negro, ayuda, madre, grande. Answer: negro.
