The Signature PC System Depository — the generator (accessible)

The on-demand model generator is the depository’s own GEN/2.0 engine: give a seed or a model number from 1 to 1,000,000 and it builds that generated model, the same input always giving the same model.

Every output here is generated (simulated) — a possible model from the depository’s own GEN/2.0 lattice. A generated model is never an archive record.

How it works

  1. You give a seed word or a model number from 1 to 1,000,000.
  2. A seed word is hashed to a model number; the model number decodes through the mixed-radix lattice to one generated model.
  3. Same input, same output, every time.
