The Signature PC System Depository — the generator

The on-demand model generator is the depository’s own GEN/2.0 engine: give a seed or a model number from 1 to 1,000,000 and it builds that generated model, the same input always giving the same model.

Every output here is generated (simulated) — a possible model from the depository’s own GEN/2.0 lattice, built on this page by the depository’s own engine (js/gen.js + js/identity.js, copied unchanged). A generated model is never an archive record, and its ID never collides with an archive ID.

Press a Generate button.

How it works

  1. You give a seed word or a model number from 1 to 1,000,000.
  2. A seed word is hashed to a model number; the model number decodes through the mixed-radix lattice (architecture, material, ALU width, registers, cores, era, form factor) to one generated model.
  3. Same input, same output, every time. Nothing leaves your device.

What it cannot do: it cannot fetch the live archive, it cannot check the live web, and it cannot make a real archive record. A generated model is a possible model, not evidence the machine exists or was built.
