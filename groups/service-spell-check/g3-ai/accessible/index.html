The Spelling Helper

A page that is only the spelling helper. It answers spelling questions from the archive — rules, mix-ups, and words. The helper itself needs JavaScript; use the helper page to ask it.

Plainly stated: the helper on this site answers from the archive stored with the website. A hosted online helper that could fact-check against the live web is not live yet: that path is blocked until the network owner signs in to the Cloudflare account. This page never asks you for a key.
