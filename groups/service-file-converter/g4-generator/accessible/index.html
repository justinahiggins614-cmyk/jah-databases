Conversion plan generator

A file converter generator, alone. a conversion plan: seeded format pairs with the rule for each change and its fidelity check The generator itself needs JavaScript; use the generator page to build a set.

How it works

  1. Pick a seed — the same seed always builds the same set.
  2. The plans draw from the 10 documented format conversions; every rule is a documented conversion rule.
  3. Every output is labeled generated; nothing here is an archive record.
  4. Sets download as JSON.

Worked example — seed 7

  • text to text — Upper, lower, title, or sentence case.
  • JSON to JSON — Pretty-print spreads over lines; minify squeezes to one line.
  • PNG to WebP — Redrawn as WebP; lossless setting keeps every pixel.
  • JSON to CSV — Field names become the first row; each record becomes one row.
  • plain text to JSON — Words become the value of a field called text.
