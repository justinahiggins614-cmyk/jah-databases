Signature Arcade — Game-night planner

Plans a game night from the mirror's own catalog: three games, a number of rounds, and a secret-number challenge.

Seeded and deterministic: the same seed always gives the same output, and different seeds give different outputs. Every output is labeled generated — it is not an archive record.

The generator

How it works
  1. Type a seed — any words — or keep the one shown.
  2. Press Generate. The engine hashes the seed and picks from the mirror's own catalog.
  3. The same seed always gives the same output. Change the seed for a different output.
  4. Copy the output or download it as JSON. Every output is labeled generated.
