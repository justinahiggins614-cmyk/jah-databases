R Snippet Generator — plain version

A plain-text version of the R Snippet Generator. No JavaScript needed. Open the working generator (needs JavaScript).

What it does

You pick a seed number, and the generator writes real R snippets — summaries, plots, models and samples — from R's built-in datasets: mtcars, iris, faithful, AirPassengers, sleep and warpbreaks. The same seed always makes the same snippet.

Example snippet (seed 1, summarise)

# Summarise mpg in mtcars
# seed 1
x <- mtcars$mpg
mean(x, na.rm = TRUE)
median(x, na.rm = TRUE)
summary(x)

How it works

  1. Pick a seed number. The generator uses it to choose a dataset, a variable and a kind of snippet.
  2. Press Generate. Each snippet is a short, complete R script with a comment saying what it does.
  3. Copy the code or download it as a .R file and run it in R.

What it does not do: it only writes snippets from R's built-in datasets. It does not run R for you, and it does not invent new datasets.
