JAH R Archivist — plain version

A plain-text version of JAH R Archivist, the standalone R AI page. No JavaScript needed. Open the working page (needs JavaScript).

What it does

You ask a question about R. The page matches your words against the twenty stored public R records and answers with the matching record, quoted by title and record number. It never invents a record. If nothing matches, it says so and suggests a question it can answer.

Online fact-checking

The hosted online path is blocked for now, waiting on the owner's Cloudflare sign-in. Until then the page answers from the stored archive only. You never enter a key: there is no key field anywhere on the page.

  • What is the file extension? — .r
  • What paradigm is R? — Functional, procedural, with dynamic typing.
