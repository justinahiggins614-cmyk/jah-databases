R Data — the public records, plain

The public R records, all twenty of them, in plain readable form. No JavaScript, nothing to run — just the data.

R is a functional, procedural programming language with dynamic typing, created in 1993 by Ross Ihaka and Robert Gentleman. It is used for statistics and data analysis, and is known as the lingua franca of statisticians. Source: the R Programming Language Database (prog-lang-r), 20 public records, IDs JAH-PROG-015-000001 to JAH-PROG-015-000020.

R syntax and idioms, in words

The archive's own facts: R source files end in .r. The traditional first program is print("Hello, world!"). R is read and run line by line at an interactive prompt (a REPL), and its standard library ships with the language. The archive's vocabulary record explains the shared words: paradigm is a style of programming; typing is when types are checked — dynamic typing checks while the program runs; syntax is the grammar rules of the language.

In standard R, as documented in the R language reference, you give a name to a value with the arrow <-, as in x <- c(1, 2, 3), which makes a vector; you call a function by its name with brackets, as in mean(x); and you ask for help on anything with ?mean. A data frame is R's table: rows are observations, columns are variables. These are the idioms the generator on the generator page writes.
