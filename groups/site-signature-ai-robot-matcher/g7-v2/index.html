The Signature AI to Robot Matcher — The Pairing Workshop

Mascot: Bolt the friendly robot. Theme: The Pairing Workshop.

The themed world

The Pairing Workshop is a long hall of workbenches. On one side stand the minds, on the other the bodies. Bolt walks the hall with a clipboard, pairing each mind with the body that fits it best, and stamping the match score on the pair.

Tools

These tools run entirely on this page. They make names, scores, and picks — they never write a real record and never check the web.

Match meter

Type a mind name and a body name. The meter scores the fit from 55 to 100. It scores names only — it never writes a real pair.
