Element quiz generator

A periodic table generator, alone. an element quiz: seeded questions on symbols, names, and atomic numbers, drawn from all 118 elements The generator itself needs JavaScript; use the generator page to build a set.

How it works

  1. Pick a seed — the same seed always builds the same set.
  2. The quiz draws from all 118 elements in the table data; every symbol, name, and number is a table entry.
  3. Every output is labeled generated; nothing here is an archive record.
  4. Sets download as JSON.

Worked example — seed 7

  • What is the symbol of Roentgenium? — choices: Rg, Sr, Ar, Nh. Answer: Rg.
  • Which element has the symbol Hf? — choices: Americium, Antimony, Hafnium, Polonium. Answer: Hafnium.
  • What is the atomic number of Gadolinium? — choices: 4, 86, 80, 64. Answer: 64.
  • Which element has atomic number 6? — choices: Carbon, Holmium, Vanadium, Roentgenium. Answer: Carbon.
  • What is the symbol of Argon? — choices: Bh, Ar, U, Th. Answer: Ar.
