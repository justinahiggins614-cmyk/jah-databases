Signature Mail — Letter writer

Writes a letter from the mirror's own address book: a recipient, a subject, and a short letter, picked by seed.

Seeded and deterministic: the same seed always gives the same output. Every output is labeled generated — it is not an archive record.

How it works

Type a seed, press Generate, and the engine picks from the mirror's own catalog by that seed. The same seed always gives the same output.

Worked example

For the seed “sample-seed”, made by the engine itself (labeled generated):

{
 "seed": "sample-seed",
 "to": "Lena",
 "role": "librarian",
 "subject": "The new season",
 "greeting": "Dear Lena,",
 "body": "I hope this letter finds you well. The season is turning, and I thought of you.",
 "closing": "With best wishes,",
 "generated": true
}
