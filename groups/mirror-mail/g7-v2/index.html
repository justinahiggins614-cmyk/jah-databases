The world

Signature Mail is a mirror of the mail kind of website: a website where a visitor writes a message, addresses it, and sends it. Mail websites began as plain lists of messages, then grew address books, subjects that say what a message is about, and folders that keep messages in order. This mirror follows the same shape — an address book, a subject, and a composed message — rebuilt with Signature branding and the network's own data.

Letter composer

Composes a message by the mirror's own rule: the recipient must be in the address book and the subject must not be empty. The message is composed in the page and nothing is sent anywhere.

Looks a name up in the mirror's own address book and shows the role. It cannot add a name — it only looks up the eight sample names.

The Harbor Post stamp collection

Fun, labeled fun — not a fact. The Harbor Post stamp collection is a made-up set of stamps: a lantern stamp for night letters, a sailboat stamp for letters that cross the harbor, and a pigeon stamp for letters carried by Pip. None of these stamps were ever printed or posted; they are a story for letter writers.
