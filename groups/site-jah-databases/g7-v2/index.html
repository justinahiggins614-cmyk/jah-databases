Welcome to the Network Atlas — a grand library where every drawer holds a database and every shelf holds a world, with a wise owl to show you around.

Meet Atlas the Archive Owl, the mascot of this world.

The world

JAH Databases is the database hub of the whole network: 63,087 databases in the live manifest — 32,180 public databases and 30,907 Signature editions — joined by 40 main sites, 12 mirrors, and the file, database-website, and mix pages that bring the whole network to 66,219 websites.

Product lines

Designs, printables, and demos — free, downloadable, usable on the page. Every product is labeled Signature or Fun. Nothing here is for sale.

Directory card set (Signature)

A printable set of directory cards: one card per starting letter, listing how many public databases and how many Signature editions begin with that letter.

Making: print the printable file on card and cut out the cards. The counts come from the live manifest, read 2026-11-21.

Atlas poster (Fun)

A poster of the Network Atlas library: the tall shelves, the rolling ladder, the open atlas, and Atlas the owl on the top rung.

Making: print the printable file and pin it up. The shelves are a drawing — the real directory is Group 5 and Group 6.

Card-catalog drawer ornament (Signature)

A paper ornament: a small card-catalog drawer with index cards, to stand on a desk.

Making: print the printable file on card, cut out the drawer and the cards, fold along the marked lines, and glue the tabs. Write a database name on each card.
