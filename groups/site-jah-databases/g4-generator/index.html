JAH Databases — the database hub — the generator

The database-concept generator drafts a new database concept from real databases in the manifest: a subject, a kind, and a plain description, from a seed. Same seed, same concept.

Every output here is generated (simulated) — a database concept drafted from real databases in the manifest. A generated concept is never a database and never a record, and its ID never collides with a real database ID.

Press Generate.

How it works

  1. You give a seed — any word or number.
  2. The generator picks a real database from the 500-database pool on this page using that seed, the same way every time, and drafts a concept in its manner.
  3. Same seed, same output. A different seed gives a different output.
  4. Copy the output or download it as JSON. Nothing leaves your device.

What it cannot do: it cannot fetch the live archive, it cannot check the live web, and it cannot make a real database.
