Search-trail generator

Seeded search trails: a query, its ranked results, and their scores — made from the mirror's own 141-entry index.

Every output is generated — simulated, never presented as an archive record. The same seed always gives the same output; a different seed gives a different one. The generator makes up to 1,000,000,000 per file, or until genuinely complete, and it never overloads the host.

Press Run the generator.

How it works

  1. Type a seed — any word or number.
  2. Press Run. The generator picks from the mirror's own data using only that seed.
  3. The same seed always gives the same output. Change the seed to get a different one.
  4. Copy the output or download it as JSON. Every output carries its seed and its generated label.
