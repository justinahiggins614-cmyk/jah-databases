Ask about — sample questions

What does the query songs find?

The top result is Signature Music Studio (score 1). Only one entry in the index carries the word songs. A word in a name is worth 3 points; a word in keywords is worth 1 point.

How is a result scored?

Score equals 3 times the number of query words in the entry's name, plus 1 times the number in its keywords. An entry appears only if every query word is in its name or keywords. Results are ordered by score, highest first; ties break alphabetically.

Which website holds recipes?

The top result for recipes is The Signature Cookbook (score 1).

What is Signature Search?

A search mirror: it takes a question in plain words and returns the network's own websites, ranked best first. It searches only this network — never the outside web, never tracks, never asks for an account.
