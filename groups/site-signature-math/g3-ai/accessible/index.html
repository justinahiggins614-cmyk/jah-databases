Ask about

What is the Signature math grid?

The Signature math grid is the 12 by 12 source grid the site is built on. The site's own data file turns the grid's 144-bit string into text, sound, barcodes and more.

What does the Public Mathematics Database hold?

The Public Mathematics Database holds 81 public records, including Numerical Analysis (overview) and Mathematical Logic (history).

What is ASCII Text in the math data?

ASCII Text is one of the 32 conversion records in the site's own data file: ASCII is the 7-bit code with 128 code points, and the Signature bitstring is read in 7-bit groups, one character per group.

What records are in the math archive?

The math archive behind this page holds the Public Mathematics Database with 81 records, the Functions Database with 288 records, and the Signature Mathematics Database with 94 records.

How many worked problems does the math database hold?

The Signature Math Database holds 3,858 records, including 3,647 worked problems, 39 theorems with proofs, 26 constructions, 61 formulas and 53 definitions.
