How it works

  1. Type a seed word, or keep the one shown.
  2. Press Make a drill. The same seed always makes the same drill.
  3. Work the number into binary, octal and hexadecimal, then read the three conversion records it names.
  4. Copy the drill or download it as JSON.

It generates from the site's own 32 conversion records only. Every output is labeled generated and is never presented as an archive record.
