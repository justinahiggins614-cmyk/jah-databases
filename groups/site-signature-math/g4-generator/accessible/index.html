Signature Math — the generator (plain version)

Signature Math is the math everything Signature is built on: the deterministic math foundation, the 12 by 12 Signature source math grid, and the data-systems conversions. The site's own data file holds 32 conversion records, and it builds on the network's mathematics databases.

How it works

  1. Type a seed word, or keep the one shown.
  2. Press Make a drill. The same seed always makes the same drill.
  3. Work the number into binary, octal and hexadecimal, then read the three conversion records it names.
  4. Copy the drill or download it as JSON.

It generates from the site's own 32 conversion records only. Every output is labeled generated and is never presented as an archive record.

Worked example

Worked example (seed "grid-one"): the number is 74; binary 1001010, octal 112, hexadecimal 4A; records: Floating-Point (IEEE 754), ASCII Text, Barcode (Linear).
