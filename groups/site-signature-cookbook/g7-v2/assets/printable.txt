The Signature Cookbook — The Kitchen Garden — product lines (printable)

Recipe card set (Signature)
A set of printable recipe cards, one per recipe, with room for ingredients, steps, times, and servings.
Making: print the printable file on card, cut along the lines, and write in a recipe from the archive — Guacamole fits on one card.

Herb-garden markers (Signature)
Printable markers for the herb garden: basil, rosemary, thyme, and sage, with the planting row on the back.
Making: print the printable file on card, cut out the markers, and push them into the soil beside each herb.

Kitchen poster (Fun)
A poster of the Kitchen Garden world: Rosie the Rolling Pin waving from the kitchen table, tomatoes on the vine outside.
Making: print the printable file and pin it up. The rolling pin on it is a drawing, not a cook.

All designs are free printables. Nothing here is for sale.
