The world

Pip's Paper Library is a library where every page looks the same on every shelf. The shelves hold neat stacks of paper, the books are red-bound, and Pip checks each page with a magnifying glass. A page that leaves this library arrives looking exactly as it was made.

Pip the panda runs the world. The tools below are the same working tools as the full website, and the product lines are designs you can print and use — never goods for sale.
