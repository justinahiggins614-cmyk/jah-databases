History

Before the PDF, a document printed differently on every computer, because each computer had its own fonts and its own way of laying out a page. John Warnock of Adobe described the Camelot plan in 1991: a file that would look the same everywhere. The Portable Document Format, PDF, was released in 1993, and it carried the words, the fonts, and the pictures inside the file itself, so the page looked the same on any screen and any printer. PDF became an open standard, ISO 32000, in 2008, and PDF/A, a form made for long keeping, followed. The public references this database cites, the Wikipedia articles on the format and its tools, carry that history forward, and every record here names its source.
