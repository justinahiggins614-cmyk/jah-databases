PDF Tools generator

A pdf tools generator, alone. Pick a seed and it builds a one-page document built from real record titles and first lines. The generator itself needs JavaScript; use the generator page to build one.

How it works

  1. Pick a seed — the same seed always builds the same output.
  2. It draws from the 24 public records of the pdf tools pair — titles and first lines only.
  3. Every output is labeled generated, never presented as an archive record.
  4. Outputs download as JSON or in their own file form.
