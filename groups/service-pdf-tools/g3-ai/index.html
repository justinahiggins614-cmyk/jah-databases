Ask about — sample questions and their answers

Four questions the helper can answer, with the answers written out, so you can see what it knows before you type.

Q: What is a PDF file?

A: A PDF file is a document that looks the same on every computer. It carries its words, its fonts, and its pictures inside the file itself, so the page does not change when it moves from one screen to another. It is used for letters, reports, tickets, and forms, anywhere the page must arrive looking exactly as it was made.

Q: How do I make a PDF from words I type?

A: A PDF can be made from words you type by writing the words into a simple PDF file, with a title and the words laid out on a page. The file starts with the letters %PDF, holds the words as text, and ends with a marker that closes the file. Any reader can open it and show the page, with no special program needed.

Q: How many pages does a PDF have?

A: The page count is the number of pages in a PDF, counted from the page markers inside the file. A reader shows the count beside the page number, such as page 3 of 12. The count tells the reader how long the document is before they start, and it is the first thing this tool reads from any file it is given.
