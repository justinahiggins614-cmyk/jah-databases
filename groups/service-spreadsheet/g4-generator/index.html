How it works

1. Pick a seed. The seed is a number. The same seed always builds the same output, so a teacher can hand out seed 21 and everyone gets the same result.

2. It draws from the real records. The generator works from the 24 public records of the spreadsheet pair — titles and first lines only. Nothing is invented.

3. Every output is labeled generated. What it makes is a sample, clearly marked, never presented as an archive record.

4. Nothing leaves the page. The output is built in your browser. Download it as JSON or in its own file form to keep or print.

What it does not do: it does not write new archive records, and it does not check facts — the records it draws from are the facts.
