Spreadsheet generator

A spreadsheet generator, alone. Pick a seed and it builds a sample sheet with five items and a SUM totals row. The generator itself needs JavaScript; use the generator page to build one.

How it works

  1. Pick a seed — the same seed always builds the same output.
  2. It draws from the 24 public records of the spreadsheet pair — titles and first lines only.
  3. Every output is labeled generated, never presented as an archive record.
  4. Outputs download as JSON or in their own file form.
