Dossier folder (Signature)

A printable dossier folder, labelled with a subject, a category, and a classification line.

Making: print the printable file on card, fold along the marked lines, and file notes inside. The classification line is part of the design.

Lantern-night reading kit (Fun)

A kit for a night of reading: a lantern cut-out, a bookmark, and a reading log.

Making: print the printable file, cut out the lantern and the bookmark, and log each dossier read by lamplight.

Star-chart poster (Fun)

A poster of the night sky from the archive window, with the constellations named in the dossiers.

Making: print the printable file and pin it up. The chart is a drawing for fun, not a navigation chart.
