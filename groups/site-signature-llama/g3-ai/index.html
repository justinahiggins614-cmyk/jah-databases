Ask about

Sample questions, with their demo answers as written text:

Q: What is Signature Llama?

A: Signature Llama is the baseline model at the heart of this site — a tiny language model written and trained from scratch by Justin Addam Higgins. About 3 million parameters in version 1, a decoder-only transformer with a character-level tokenizer, trained on the Signature Dictionary and Signature spec text. It runs 100% in the browser in pure JavaScript, currently free for all internet tasks, no keys.

Q: How was it built?

A: From absolute scratch, in four stages: 1) the corpus builder gathered the Signature Dictionary definitions and spec text into one training file; 2) the tokenizer learned a character-level vocabulary; 3) the trainer ran a small transformer on it with PyTorch until the loss settled; 4) the exporter quantized the weights to int8 and packed them for the browser engine. Every line of model code was hand-written.

Q: Is it related to Meta’s Llama?

A: No. Signature Llama is an independent model created by Justin Addam Higgins, not affiliated with, endorsed by, or connected to Meta Platforms or the LLaMA model family. The name is branding for the Signature line.

Q: How many tools and terms are in the archive?

A: 125 tools and 312 dictionary terms, counted in the site’s own browse index (updated 2026-10-04). The manifest lists 125 records for the Signature Llama Database — the same 125 tools.

Q: How do I use it in my project?

A: Copy the 3-line embed code from the Use-it section of the site: include sigllama.js, call SigLlama.load() with the model folder URL, then SigLlama.generate() with your prompt. That is the whole integration — no keys, no server, no build step.
