The world

Signature Llama is a tiny model written and trained from scratch by Justin Addam Higgins, running in the browser, free for all internet tasks. The archive holds 125 tools and 312 dictionary terms, plus 28 explainer entries written on the site itself.

Tools

Two working tools, right here on the page. Each one says what it does and what it cannot do. Neither tool reaches the live web, and neither one needs a key.

Character counter

Type or paste text to count its characters and words. The site’s tokenizer is character-level, so the token estimate is one token per character — an estimate, not a model run.

Dictionary term finder

Search the 312 dictionary terms by word. Shows up to 10 matches.

Product lines

Designs, printables, and demos — free, downloadable, usable on the page. Every product is labeled Signature or Fun. Nothing here is for sale.

Field guide booklet (Signature)

A printable booklet of the Llama Library: the 28 explainer entries in short form, with room for notes.

Making: print the printable file, fold the pages along the marked lines, and staple the spine.

Llama figurehead print (Fun)

A print of Lolly the Llama with round glasses and an open book, in the Library style.

Making: print the printable file and pin it up. Lolly is a mascot, not a real llama.

Tool-pack cards (Signature)

A set of tool-pack cards in the style of the generator: three tools and one term on each card.

Making: print the printable file on card, cut out the cards, and run one pack per small job.
