Coffee Questions

Ask about coffee — drinks, methods, ratios, grinds, roasts — and get an answer drawn from the coffee archive. Free forever. No sign-in, no payment, no key needed.

Open the question page (needs JavaScript)

Plainly stated: the working page answers from the coffee archive loaded on the page (50 records, listed below). The hosted online fact-checking path is not connected yet — it waits on the Cloudflare sign-in — so the page does not reach the wider web, and it never asks you for a key. There is no key box on the page, by design.

How it answers

  1. You ask in plain words.
  2. The page hands the question to the network's archive library with the coffee database and the 50 archive records as context.
  3. You get an answer in plain sentences. If the library cannot be reached, the page falls back to a plain lookup over the same 50 records and says so.
  4. Nothing leaves the page. No key, no sign-in, no account.
