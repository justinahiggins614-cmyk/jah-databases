What this page is — honestly

A registry and discovery index. Nothing more.

Each of the 63,047 databases has its own boundless generator — a script that builds new records in that database's exact shape, deterministically, from a seed. This page lists all of them: one row per generator script, with its database, its record kind, and links to the database page and to the script itself.

There is no central server that executes generators. A generator runs in your browser, on its own database page, or as the script file linked in its row. This page never runs a generator for you, never stores your seeds, and never phones home — every search and filter below happens on your device, over data files published with this page.

Generated content is labeled simulated / Signature-generated wherever it appears. It is never presented as an authentic public record: public records and Signature-generated completions are kept apart, and a generated record never pretends to be harvested fact.

How to invoke a generator

  1. Find it below — search by name, subject, or record kind, or open its letter section.
  2. Open its database page (the “Database” link in its row) — the generator runs there, in your browser, with its demo and full records.
  3. Or take the script itself (the “Script” link) — db/<slug>/gen-<slug>.js — and run it anywhere JavaScript runs. Same seed gives the same record, every time.

One exception to “one generator per database”: the comics database carries two scripts — the database generator and a full 22-page issue renderer (gen-comics-full.js). That is why there are 63,048 scripts for 63,047 databases.
