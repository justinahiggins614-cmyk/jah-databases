What this registry is — honestly

A registry and discovery index, nothing more. Each of the 63,047 databases has its own boundless generator — a script that builds new records in that database's exact shape, deterministically, from a seed. There are 63,048 generator scripts in total: the comics database carries two (its database generator and a full 22-page issue renderer, gen-comics-full.js).

There is no central server that executes generators. A generator runs in your browser, on its own database page, or as the script file itself. To invoke one: open its database page at db/<slug>/ or take its script at db/<slug>/gen-<slug>.js. Same seed gives the same record, every time.

Generated content is labeled simulated / Signature-generated wherever it appears. It is never presented as an authentic public record.

Featured generators

  • The Universal Generator — JAH-UNI-, 300 records, universal creation. Describe anything and it builds a full record. Script: db/universal-generator/gen-universal-generator.js
  • The Signature Boundless Generator Archive — the archive-level deterministic engine, with 137,025 indexed outputs in data/generators/index.json.gz. An engine, not one more per-database row.
