The Seven Groups

Every subject gets seven websites — one of each kind, built together, equally. All free forever, no sign-in, no payment.

  • Group 1 — The full website, with everything — The subject's main website: the working tool or service, how it works, the records, the files — and a wiki section that gathers all of the subject's data from all seven groups, with every link.
  • Group 2 — The links list (static) — A website that is solely a links list: every site, database and file for the subject, on one plain page. No JavaScript.
  • Group 3 — The AI only — A website that is only the AI for the subject system — it answers from the subject's own records. The online fact-checking path is labeled honestly: it is blocked until the network's own key service is connected, and nobody is ever asked for a key.
  • Group 4 — The generator alone — A website that is only the generator for the subject: it makes new records, deterministically, on the page.
  • Group 5 — The data alone — The subject's public data alone, in plain readable words, no JavaScript — so public bodies, schools and libraries can use it.
  • Group 6 — The Signature data — All Signature-created data on the subject, labeled Signature throughout — never presented as public record.
  • Group 7 — Version 2: advanced, creative, themed — The second version of the subject's website: advanced and creative and themed, with images and tools and fun stuff — the whole world, with product lines. Free, as always.
