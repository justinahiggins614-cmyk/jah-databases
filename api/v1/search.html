Search — api/v1 (static)

This is the static form of GET /api/v1/search?q={text}&cursor=page:<n>. There is no server on GitHub Pages and no live server search API: this page matches your query in your browser over two files — search-db-index.json (one entry per database in the live manifest: 63,047 databases, by slug, name, and tagline) and search-index.json (160 pilot record titles, 10 databases). Text-only readers: fetch both files and match client-side (case-insensitive; every query word must appear in the searched text).

Databases

    Pilot records

      Database search covers all 63,047 databases in the live manifest (source: data/manifest.json, 2026-11-18; index generated 2026-11-18, 15,517,163 bytes). Record search covers the 10 pilot databases' titles only (160 records). To read records outside the pilot, use the plain-text mirrors or the compressed indexes — see the AI access guide. There is no live server search API; a hosted Worker API is blocked on Cloudflare sign-in.
